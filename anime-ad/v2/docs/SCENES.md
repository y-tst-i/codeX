# SCENES — 場面別の内容・固有技法・合図(cue)

全体 30.0秒 = 900フレーム。**リズム(名前)**: 静 → 対峙 → 一撃(間と爆発) → 余韻 → 高速カタログ(5連発) → 爆発(タイトル) → 脱力 → 荘厳な告知。
BPM150(1拍=0.4秒=12フレーム)。場面の境目は拍に乗っている。

| id | 全体時刻 | 尺 | フレーム | 世界(一言) |
|---|---|---|---|---|
| s1-million | 0.0–4.0 | 4.0s | 120 | 黒い虚空に赤い点の大群(数値・データの冷たさ) |
| s2-faceoff | 4.0–8.0 | 4.0s | 120 | 夕焼け空の視差世界、ドリーズームの対峙 |
| s3-punch | 8.0–13.2 | 5.2s | 156 | 一撃の瞬間(画面が割れる) → 破片が漂う余韻 |
| s5a | 13.2–14.0 | 0.8s | 24 | 8ビット・ピクセル世界 |
| s5b | 14.0–14.8 | 0.8s | 24 | 漫画のコマ割りページ |
| s5c | 14.8–15.6 | 0.8s | 24 | 水墨画(墨と余白) |
| s5d | 15.6–16.4 | 0.8s | 24 | 空気が歪む(波紋・風) |

場面間は**ハードカット**。各場面の「入り」と「出」は下に指定。時刻は**その場面の先頭からの秒**(local)。合図の時刻は ±1フレーム以内で守る(音がこの時刻に合わせて作られる)。

## s1-million (120f / 4.0s) — 「百万の赤」
**コンセプト**: 世界が終わる前の、冷たい静寂。画面は黒。上から赤い点の大群が、じわじわと押し寄せる。数字だけが淡々と増えていく。
**固有技法**: `canvas` で seed付き点群(2万点以上)を毎フレーム t の関数として描く。ゆっくりカメラが寄る(全体を scale 1.0→1.12)。
数値カウンターは tabular な等幅(Space Mono)で、桁が回る。**画面を叩く演出は使わない**。静かな恐怖。
**フォント**: Space Mono(数字・英字) + Noto Sans JP(漢字)。
**入り**: 最初の1フレームは純黒。**出**: 最後の2フレームは純黒(ハードカットで落ちる)。
**コピー(一字違わず)**: `魔王軍` / `1,000,000` / `勇者パーティ` / `全滅` / `Lv.1`
**合図(local秒)**:
- 0.00–0.40 純黒。0.40 赤い点の群れが画面上端から現れ始める。
- 0.40–2.00 カウンター 0 → 1,000,000 が加速して増える(左上に小さく「魔王軍」、数字は中央下寄りに大きめ)。点の密度も同期して増える。
- **2.00 CUE-A**: 数字が 1,000,000 に到達。数字が赤に変わり、一瞬だけ点群全体が脈動(拍動1回)。
- 2.40 / 2.60 / 2.80 / 3.00: 画面下部に並んだ味方4人の白い丸アイコン(「勇者パーティ」の見出し付き)が1人ずつ ✕ で消える(各 CUE-B1..B4)。
- **3.20 CUE-C**: 「全滅」の判子が押される(叩きつけでなく、**静かに赤い判が1回だけ沈み込む**)。
- **3.60 CUE-D**: 画面中央最下部に、ずっと小さな**白い点1つ**(これが主人公)がぽつんと光る。その横に小さく `Lv.1`。
- 3.90–4.00 純黒へ。

## s2-faceoff (120f / 4.0s) — 「対峙」
**コンセプト**: 夕焼けの荒野。画面右奥にそびえる巨大な魔王、左手前に小さな主人公(後ろ姿寄り)。一歩も引かない。
**固有技法**: **多層の視差 + ドリーズーム(vertigo)**。主人公のサイズは一定のまま、背景層だけ段階的に拡大して世界が迫る。
レジストリ `camera-dolly-zoom` / `focus-rack` を参照可。地平線の魔王軍のシルエット(槍の林)、山並み、巨大な魔王(demon.svg)、手前の主人公(hero.svg)。
空は橙→紫のグラデ+ゆっくり回る太陽光線(**sunburst はこの場面だけの専売**)。
**フォント**: Noto Sans JP 700。テープ(粘着テープ風の帯)で見出し。
**入り**: 最初のフレームは純白 → 0.3秒かけて世界が現れる(白フラッシュの減衰)。**出**: 3.80 から暗転、最後の2フレームは純黒。
**コピー**: `そこに立っていたのは——` / `Lv.1` / `Lv.999` / `魔王「たかがレベル1が、何の用だ？」`
**合図**:
- 0.00 白フラッシュ開始(0.3秒で減衰)。
- **0.60 CUE-A**: テープ「そこに立っていたのは——」が斜めに貼られる(音: whoosh)。
- **1.20 CUE-B**: 主人公の頭上に `Lv.1`(ポップ)。
- **1.60 CUE-C**: 魔王の頭上に `Lv.999`(重い着地、小さな衝撃)。魔王の目が赤く光る。
- 2.00–3.20 ドリーズーム(音: riser)。この間に魔王の台詞が**タイプライターで打たれる**(2.00 開始、3.20 に打ち終わり)。
- **3.20 CUE-D**: 主人公の瞳が白く光る(クローズアップへ寄る or 光のスパーク)。
- 3.60 CUE-E: 主人公の拳がぎゅっと握られる。
- 3.80–4.00 暗転(純黒で終わる)。

## s3-punch (156f / 5.2s) — 「一撃 → 余韻」(この映画の最大の山場)
**コンセプト**: 沈黙のあと、世界が割れる。画面そのものが割れて、破片がスローモーションで漂い、あの赤い点の大群が灰のように吹き飛ぶ。
**固有技法**: ①**フリーズフレームの連打(ストップモーション)**で溜め ②**画面が割れて破片になる(vfx-shatter か、clip-path の多角形ポリゴンを自作して破片を飛ばす)** ③スローモーションの粒子(s1の赤い点の「その後」)
④縦書きの筆文字。**集中線はこの場面だけ許可**(CUE-C の瞬間のみ。あとは使わない)。
**フォント**: 擬音「ドッ」= Dela Gothic One。「魔王、消滅。」= Yuji Boku または Shippori Mincho B1(縦書き `writing-mode: vertical-rl`、墨の太字)。判子の帯 = Noto Sans JP 700。
**入り**: 純黒。**出**: 破片と霧が漂う余韻の途中でハードカット(終わりに黒は入れない)。
**コピー**: `ドッ` / `魔王、消滅。` / `キラーン` / `※ただの準備運動です`
**合図**:
- 0.00–0.30 純黒。0.20 主人公の白い瞳だけが光る。
- **0.30 / 0.40 / 0.50 CUE-A1..A3**: 3枚の静止画がハードカットで切り替わる(拳の振りかぶり→溜め→直前。毎回少し寄る)。各3フレーム保持。
- **0.60 CUE-B**: 接触。純白2フレーム → 白黒反転2フレーム。
- **0.70 CUE-C**: 擬音「ドッ」+集中線の一撃フレーム(約0.2秒)。
- **0.90–1.20 CUE-D**: 画面にヒビが走り、割れて破片が四方に飛ぶ(この1.20で破片が見える)。
- 1.20–5.20 余韻: スローモーションで破片が漂う。赤い点の大群(s1の点)が灰のように外へ吹き飛んでいく。カメラは微かに揺れて収まる。
- **2.00 CUE-E**: 縦書き「魔王、消滅。」が右から筆で書かれるように現れる(墨が滲む、**叩きつけではなく筆の運び**)。
- **2.60 CUE-F**: 遠く(右上)に小さな星のきらめき「キラーン」(魔王が飛んでいった)。
- **4.00 CUE-G**: テープの判子「※ただの準備運動です」がぽんと貼られる。
- 4.40–5.20 静かに漂う。

## s5 カタログ (各 24f / 0.8s) — 「一撃で終わるものたち」
共通の型: 見出しテープ「◯◯は、」→ 大きな結果の単語 →「で終了。」。ただし**5つは世界も技法もフォントも別物**にする。
各ショットの合図(local): **0.00 カットイン / 0.15 CUE-A 見出し完了 / 0.25 CUE-B 接触(ヒット) / 0.45 CUE-C 結果の単語が読める / 0.60 CUE-D「で終了。」着地 / 0.80 終**。
各ショットとも最後のフレームまで画面は埋まっていること(空白で終わらない)。

### s5a — ドラゴン→デコピン  【8ビット・ピクセル世界】
**技法**: ドット絵(CSS box-shadow か canvas で粗いピクセルを自作)。画面は16:9の粗い解像度(例 120x68)を拡大表示、`image-rendering: pixelated`。
ピクセルのドラゴンが吠える→主人公の指のデコピン(ドットの手)→ドラゴンが星になって画面外へ。HUD風の枠。
**フォント**: DotGothic16。**色**: ピクセル特有の限定パレット(濃紺・緑・黄・赤)。
**コピー**: `ドラゴンは、` / `デコピン` / `で終了。`

### s5b — 大魔法→ビンタ  【漫画のコマ割りページ】
**技法**: 紙の質感の漫画ページに**3〜4コマ**が順に叩き込まれる(コマ枠が斜めに割れて現れる)。魔法陣(SVGの回転する輪と文字)が1コマ目、手のひらが2コマ目、吹っ飛ぶ魔術師が3コマ目。ハーフトーン網点・擬音の手書き。**集中線OK**。
**フォント**: RocknRoll One(または Dela Gothic One)。**色**: 紙色+黒+ピンク/赤。
**コピー**: `大魔法は、` / `ビンタ` / `で終了。`

### s5c — 伝説の剣→素手  【水墨画】
**技法**: 墨と余白。筆の線(SVG stroke-dashoffset で描かれる)。一振りの剣の刃が、素手に触れた瞬間に**真っ二つに折れて**切っ先が回転して飛ぶ。墨の飛沫(SVG filter か点)。朱の判子1つ。
**フォント**: Shippori Mincho B1 または Yuji Syuku。**色**: 紙(#fffdf5)+墨(#0a0a12)+朱(#ff2a4d)のみ。**他の場面と違い静かで鋭く**。
**コピー**: `伝説の剣は、` / `素手` / `で終了。`

### s5d — 最終兵器→くしゃみ  【空気が歪む】
**技法**: SVG `feTurbulence`+`feDisplacementMap`(baseFrequency と scale を GSAP で動かす)または波紋リングで**空気の歪み**を表現。
画面中央に巨大兵器(ミサイル/砲台のシルエット)。主人公の鼻がむずむず→「ハ…ハ…」と縮み→くしゃみの風圧で兵器が吹き飛ぶ(風を表す斜めの流線)。
**フォント**: Hachi Maru Pop(丸ゴ・かわいく)。**色**: 空色背景+白+黄。
**コピー**: `最終兵器は、` / `くしゃみ` / `で終了。`(補助の擬音 `ハ…ハ…` `ハクション！` を使ってよい)

### s5e — 神→一瞥  【金の超クローズアップ】
**技法**: 画面全体が**目**の超クローズアップ(SVGの虹彩・瞳孔・まつ毛、ゆっくり開く)。瞳に映る金色の神の姿が、目が合った瞬間にひび割れて光になって砕ける。
**フォント**: Zen Antique(厳か)。**色**: 黒+金+白。
**出**: 0.65–0.80 で**画面全体が純白へ**(次の s6 が白から始まる。最後の2フレームは純白)。
**コピー**: `神は、` / `一瞥` / `で終了。`

## s6-title (156f / 5.2s) — 「タイトル大爆発」(最も豪華に)
**コンセプト**: ここが映画の頂点。白から立ち上がり、金と黒の巨大タイトルが組み上がる。**この場面だけ「文字が弾け飛んで再集合し着地」を使ってよい**(`char-slam-explode`)。
**固有技法**: 背景に WebGL `halftone-field`(網点のライトフィールド)、`char-slam-explode`、`camera-shake`、`logo-sting`(リング+白フラッシュ)、`light-sweep-pass`、火花パーティクル(seed付きcanvas)。立体感のある厚み(金の押し出し・影)。
**フォント**: Dela Gothic One(または Noto Sans JP 700 + 太らせ)。
**入り**: 最初の2フレームは純白(s5eの終わりを受ける)→フラッシュ減衰。**出**: 余韻の途中でハードカット。
**コピー**: `レベル1なのに` / `世界最強` / `異世界無双、開幕。`
**合図**:
- 0.00 白。**0.20 CUE-A**: 衝撃(リング+白フラッシュ)。散らばった「世界最強」の4文字が組み上がり始める(0.20–0.90)。
- **0.90 CUE-B**: 4文字が着地(camera-shake 1回)。金の光が走る。
- **1.00 CUE-C**: 上に `レベル1なのに` が現れる(別の動きで。縮む叩きつけは「世界最強」側で使うので、こちらは**マスクで下から迫り上がる**)。
- 2.00 CUE-D: 光が左→右へ1回走る(light-sweep)。
- **2.60 CUE-E**: 赤いテープ「異世界無双、開幕。」が貼られる(小さな衝撃)。
- 2.60–5.20 金の粒がゆっくり降る。タイトルは静止せず微かに呼吸する。

## s7-huh (108f / 3.6s) — 「え？」(脱力の間)
**コンセプト**: 爆発の直後に、突然ふっと静かになる。パステルの晴れた日。主人公は自分の拳を不思議そうに見ている。映画の中で唯一**何も起きない**場面=笑いの間。
**固有技法**: 平坦な色面のミニマル構成(フラットなパステル空・雲がゆっくり流れる・地面の1本線)。**動きは少なく、間で笑わせる**。
吹き出しの文字が**1文字ずつ打たれる**(タイプライター)。カメラはごくゆっくり寄るだけ。集中線・シェイク・フラッシュ・太陽光線は禁止。
**フォント**: Hachi Maru Pop または Zen Maru Gothic(丸ゴ)。**色**: 水色・桃・クリーム・淡い黄(ここだけ優しい色)。
**入り**: 最初のフレームから穏やかな世界(s6から**ハードカット**で唐突に静かになるのが狙い)。**出**: ハードカット。
**コピー**: `え、今の…` / `技だったの？` / `強すぎて、敵がかわいそう。`
**合図**:
- 0.00 唐突な静けさ(動きがほぼ無い)。
- **0.50 CUE-A**: 主人公(hero.svg、リラックス姿勢、片手で頭をかく or 自分の拳を見る)が、ゆっくりこちらに首を向ける。
- **1.00 CUE-B**: 吹き出しがぽんと出る。`え、今の…` が1文字ずつ(1.00–1.60)。
- **1.80 CUE-C**: 2行目 `技だったの？` が1文字ずつ(1.80–2.60)。
- **2.70 CUE-D**: 主人公の頭上に小さな「？」がぽんと出る(ぽよん)。
- **3.00 CUE-E**: 画面下に小さく `強すぎて、敵がかわいそう。` がふわっと現れる。
- 3.60 終(ハードカット)。

## s8-announce (120f / 4.0s) — 「荘厳な告知」
**コンセプト**: 最後は一転して上品に。夜明け前の紺。細い金の線。**静かだが威厳がある**。叩きつけない。祝祭のあとの締め。
**固有技法**: `logo-assemble-lockup` 型 — タイトルが細い金線から**描き上がる**(SVG stroke描画 → 塗りが満ちる)。`halftone-dissolve` で背景が現れる。ごくゆっくりな光の掃引。
放送局名やロゴなどは出さない。**フォント**: Shippori Mincho B1(明朝)。
**入り**: 最初の2フレームは純白→0.4秒で紺へ減衰。**出**: 最後の2フレームは純黒(フェードアウト 3.5–4.0)。
**コピー**: `レベル1なのに` / `世界最強` / `TVアニメ` / `放送決定` / `※本作品は架空のアニメです。`
**合図**:
- 0.00 純白→紺へ。**0.40 CUE-A**: 衝撃の重い一音と同時に、金の細線でタイトルが描き始まる(0.40–1.60)。
- 1.60 CUE-B: 線が塗りになって満ちる。
- **1.80 CUE-C**: `TVアニメ` の小さなラベルが現れる。
- **2.20 CUE-D**: `放送決定` が静かに現れる(拡大・叩きつけなし。幅の広い字間から詰まっていく)。
- 2.80 CUE-E: `※本作品は架空のアニメです。` が薄く現れる。
- 3.50–4.00 フェードアウト(最後2フレーム純黒)。
