## e0-title (180f / 6.0s) — 「紙芝居の幕開け」
**コンセプト**: これは語り聞かせの紙芝居。小さな木の舞台の幕が開き、題名が筆で書かれる。あたたかく手作り感がある。
**固有技法**: 木枠の舞台(紙芝居の拍子木風)と左右の幕(赤い布、CSSの立体で左右へ開く)、和紙の背景、筆文字の描き上げ(SVG stroke-dashoffset)。**金の細い縁取りの作品ロゴは小さく**。
**フォント**: 「第1話」= Shippori Mincho B1 800。副題 = Yuji Boku。作品ロゴ = Dela Gothic One(金)。
**入り**: 純黒。**出**: 和紙の画面のまま(ハードカット)。
**コピー**: `第1話` / `レベル1の冒険者` / `レベル1なのに世界最強`(小さな作品ロゴ)
**合図**:
- 0.00–0.50 純黒。**0.50 CUE-A**: 舞台の照明がぱっとつく(木枠と幕が見える)。
- **1.00 CUE-B**: 幕が左右に開き始める(1.00–2.50、ゆっくり)。
- **2.50 CUE-C**: 幕が開き切る。和紙に「第1話」の判が押される(叩きつけでなくポンと)。
- **3.00 CUE-D**: 副題 `レベル1の冒険者` が筆で書かれ始める(3.00–4.50)。
- **4.50 CUE-E**: 筆が止まる。小さな作品ロゴが右下にふわっと現れる。
- 5.50–6.00 静止(ハードカットで終わる)。

## e1-guild (300f / 10.0s) — 「ギルドで登録」
**コンセプト**: 温かいランプ光の木造ギルド。新人を迎える受付嬢ミナは淡々としていて、アキラは元気いっぱい。
**固有技法**: **多層の視差の室内**(奥の冒険者たちの影、中景のカウンターと掲示板、手前の梁と植物)、ごくゆっくり左→右へカメラが動く。**冒険者カード**(UIとして画面に出る登録証)が書き換わる。測定水晶は「測定中…」の桁が回って最後に `Lv.1`(**一瞬だけ画面がバグったようにチラつく=伏線。ただしほとんど気づかない程度**)。
**色**: 琥珀・ランプの橙・濃い茶・水色(ミナのベスト)。
**入り/出**: ハードカット(入りは昼の薄暗い室内、出はアキラが扉を出た後の空の入口)。
**コピー(字幕)**: ミナ `では、まず薬草採取のご依頼を。` / アキラ `はい！がんばります！`。UI: `冒険者カード` `名前 アキラ` `Lv.1` `登録完了`。
**合図**:
- 0.00 室内をゆっくり横移動(奥の冒険者たちが談笑している)。
- **2.00 CUE-A**: 扉が開き、アキラ登場(逆光のシルエット)。
- **3.50 CUE-B**: カウンターに着く。ミナが無表情でこちらを見る(まばたき1回)。
- **4.50 CUE-C**: 水晶が置かれる。アキラが手をかざすと水晶が光る。「測定中…」の数字が回り始める。
- **5.50 CUE-D**: 数字が止まる。ほんの2フレームだけチラつき、`Lv.1` と表示。
- **6.00 CUE-E**: ミナが「登録完了」の判をカードに押す(ぽん)。
- **6.50–8.00**: ミナの字幕「では、まず薬草採取のご依頼を。」
- **8.20–9.50**: アキラの字幕「はい！がんばります！」、アキラがぴょこんと一礼。
- **9.00 CUE-F**: アキラが元気に扉へ向かう。
- 10.00 終。

## e2-meadow (300f / 10.0s) — 「草原のドタバタ(うっかり討伐)」
**コンセプト**: 明るい草原。アキラは薬草探しで頭がいっぱい。後ろでモンスターが次々と(彼のうっかりで)ひどい目に遭う。
**固有技法**: **横スクロールの多層視差**(雲、遠山、丘、草、手前の花)で歩くアキラを追う。右上に小さなゲーム風UI `討伐数 0` が出て、本人の知らないところで数字が増える(カウンターのロール)。
**色**: 明るい黄緑・空色・ミルク白。のどかさ。
**フォント**: UI = DotGothic16(または Noto Sans JP)。字幕は共通仕様。
**入り/出**: ハードカット。
**コピー**: アキラ `いい天気だなあ。` / `くしゅんっ！` / `わっ！` / UI `討伐数`
**合図**:
- 0.00 アキラが右へ歩く。背景が左へ流れる。
- **1.00–2.20**: 字幕「いい天気だなあ。」
- **2.50 CUE-A**: アキラの後ろの茂みからスライムがぴょこんと現れる(かわいい)。
- **3.00 CUE-B**: アキラのくしゃみ `くしゅんっ！`。風圧でスライムが「ぷしゅっ」と蒸発(白い蒸気と小さな星)。UIが `討伐数 1`。
- **4.50 CUE-C**: 狼がうなりながら現れる(アキラは気づかない)。
- **5.50 CUE-D**: アキラが石につまずいて「わっ！」。振り回した手が狼にかすり、狼が画面奥へ「キラーン」と飛ぶ。UI `討伐数 2`。
- **7.50 CUE-E**: 巨大な熊が出る。アキラは笑顔で手を振る(挨拶)。熊は回転しながら空へ。UI `討伐数 3`。
- **9.00 CUE-F**: アキラは満足げに薬草カゴを持ち上げる(中身はまだ空)。UIの数字が小さく点滅。
- 10.00 終。

## e3-castle (270f / 9.0s) — 「稲光の絶望」
**コンセプト**: 嵐の魔王城前。勇者パーティは自信満々だったが…。**ほとんどの時間が闇で、稲光の瞬間にだけ状況が見える**。光るたびに絵が少しずつ悪化していく。
**固有技法**: **稲光のストロボ**。暗闇+雨の中、雷が光る瞬間(3〜6フレーム)だけ場面が白黒の強いコントラストで見え、闇に戻ると次の稲光まで見えない。各稲光で別のタブロー(状況)を見せる。魔王軍=赤い光の点の大群(暗闇では赤い瞳として光る)。
**色**: 黒・青灰・稲光の白。赤い瞳だけが色。
**フォント**: 字幕は共通仕様。擬音なし。
**入り/出**: 入り=真っ暗(最初の稲光の前)。出=暗闇。
**コピー(字幕)**: レオン `魔王よ、覚悟！` / ゾルギア `…やれ。` / レオン `ここまで、か…`
**合図(稲光=FLASHES)**:
- 0.00–1.00 暗闇と雨音のみ(雨が画面に斜めの線)。
- **1.00 F1**: 稲光。レオンのパーティ4人が城門の前に並ぶ(後ろ姿)。字幕 `魔王よ、覚悟！`(1.00–2.20)。
- **2.50 F2**: 稲光。城のバルコニーに巨大なゾルギアのシルエット。赤い瞳が光る。字幕 `…やれ。`(2.50–3.60)。
- **4.00 F3**: 稲光。赤い瞳の大群が地平を埋め尽くして迫る。
- **5.00 F4**: 稲光。パーティの3人が倒れている(×印や転がった剣)。
- **6.00 F5**: 稲光。レオンだけが膝をつく。字幕 `ここまで、か…`(6.00–7.50)。
- **7.50 F6**: 稲光(長め、3フレーム→減衰)。レオンが空を見上げる。
- 8.00–9.00 雨の闇に戻る。ごく小さく遠くに「ぽつ…ぽつ…」と点(アキラの近づく気配=次場面への繋ぎ。赤でなく**白い小さな点が1つ**遠くで光る)。

## e4-corridor (270f / 9.0s) — 「迷子の廊下」
**コンセプト**: 魔王城の長い廊下。アキラは地図を逆さまに持ったまま、のんきに歩いている。居眠りする兵士たち、怪しい扉。緊張感のある場所なのに本人だけ気楽。
**固有技法**: **一点透視の擬似3D廊下**(CSS 3D: 床・壁・天井の板を translateZ で奥に並べ、カメラ=視点が奥へ進む)。左右の壁の松明が後ろへ流れる。扉の標識(`宝物庫` `牢獄` `魔王の間`)が横を通り過ぎる。視点は前進+わずかな上下の揺れ(歩行感)。
**色**: 暗い石の青紫+松明のオレンジ。
**入り/出**: 入り=暗い廊下の奥から。出=巨大な扉が開いて**光が溢れる**(最後の2フレームは白)。
**コピー**: アキラ `薬草は…こっちかな？` / 標識 `魔王の間` / アキラ `あ、ここかも。`
**合図**:
- 0.00 前進開始(松明が流れる)。
- **1.00–2.50**: 字幕「薬草は…こっちかな？」(アキラは地図を逆さまに持っている)。
- **3.00 CUE-A**: 左の扉(`宝物庫`)を通過。
- **4.00 CUE-B**: 居眠りする魔王軍の兵(ゴブリン)が壁際に並ぶ。アキラがぺこりとお辞儀して通る(兵は寝たまま)。
- **5.50 CUE-C**: 牢獄の扉を通過。中から「ガタガタ」と小さな音(扉が揺れる)。
- **6.50 CUE-D**: 巨大な扉と標識 `魔王の間` が正面に。アキラが指でなぞって読む。
- **7.50–8.20**: 字幕「あ、ここかも。」
- **8.20 CUE-E**: 扉がゆっくり開き、光が溢れる(8.50–9.00 純白へ)。

## e5-throne (360f / 12.0s) — 「謁見、そして」
**コンセプト**: 荘厳な魔王の間。巨大な魔王、小さなアキラ。空気は張りつめているが、アキラは道を聞きたいだけ。**うっかり手を振った瞬間、すべてが一瞬で終わる**。
**固有技法**: **ゆっくりしたドリー(カメラ前進)**、天窓から差し込む**光芒(薄い光の柱)**、魔王の赤い瞳の明滅。手を振る瞬間は**空気の揺らぎ(ripple)**が画面を一周し、魔王が**残像のように薄れて**消え、赤い光の粒だけが漂う(CMのs3の「破片」とは違い、**静か**)。
**色**: 黒曜石・深紅・天窓の淡い金。
**入り**: 純白から(前場面の光溢れ)→1秒かけて世界が現れる。**出**: ハードカット(静かな余韻の途中)。
**コピー(字幕)**: ゾルギア `たかがレベル1が、何の用だ？` / アキラ `あ、すみません。薬草ってこのへんに…` / ゾルギア `フハハハハ！ 愚か者め！` / アキラ `あっ、どうも〜。` / アキラ `…あれ？ いない。`
**合図**:
- 0.00 純白(0.5秒で世界へ)。魔王の間。玉座のゾルギアは巨大、遠くにアキラ(後ろ姿)。
- **1.00–3.00**: 字幕「たかがレベル1が、何の用だ？」。魔王の瞳が赤く光る(CUE-A 1.00)。
- **3.50–5.00**: 字幕「あ、すみません。薬草ってこのへんに…」。アキラは逆さの地図を見ている。
- **5.50 CUE-B**: ゾルギアが笑い出す。画面がごく小さく揺れる(1回)。字幕「フハハハハ！ 愚か者め！」(5.50–7.00)。
- **7.00 CUE-C**: ゾルギアが巨大な手を振り上げる(叩き潰そうとする)。光芒が強まる。
- **8.00 CUE-D**: アキラが気づいて、礼儀正しく手を振る。字幕「あっ、どうも〜。」(8.00–9.00)。
- **8.50 CUE-E**: **空気の揺らぎが一周**。ゾルギアが残像のように薄れて消える。窓がきしむ。赤い光の粒が舞い上がる。
- 9.00–10.50 無音に近い余韻。光の粒が漂う。玉座だけが残る。
- **10.00–11.00**: 字幕「…あれ？ いない。」(アキラが首をかしげる)。
- 12.00 終。

**色**: 橙・桃・紫・金。優しい。
**入り/出**: ハードカット。
**コピー(字幕)**: アキラ `あった！ 薬草！` / レオン `あいつは……何者だ……。`
**合図**:
- 0.00 廃墟と夕日。カメラは低い位置。
- **1.50 CUE-A**: 光の粒が金色になって漂い始める。
- **3.00 CUE-B**: アキラが薬草を見つける。字幕「あった！ 薬草！」(3.00–4.20)。アキラが嬉しそうにしゃがむ。
- **4.50 CUE-C**: 薬草を摘む(ぽん、と小さな光)。
- **5.00 CUE-D**: 背景の瓦礫の山からレオンの手がのぞく→起き上がる。字幕「あいつは……何者だ……。」(5.00–7.00)。

## e7-epilogue (300f / 10.0s) — 「表示のバグ」
**コンセプト**: 夜のギルド。薬草は10本ぴったり。しかしミナは水晶を再測定して、衝撃(?)の事実を淡々と告げる。**CMの「Lv.1」のオチ**。
**固有技法**: **水晶のHUD**(クローズアップで、桁が回るオドメーターが `65535`→`0`→`1` へ折り返す)、グリッチ(RGBずれ)、警告バナー `表示上限を超えています`、ミナの無表情。画面の下にギルドの夜の遠景。
**色**: 夜の紺・ランプの橙・水晶の水色・警告の赤。
**入り/出**: ハードカット。
**コピー**: ミナ `薬草、ぴったり10本ですね。` / HUD `測定中…` `Lv.65537` `表示上限(65535)を超えています` `Lv.1` / ミナ `…表示、直しておきますね。` / アキラ `？`
**合図**:
- 0.00 夜のギルド。アキラが薬草のカゴを差し出す。
- **1.00–2.50**: 字幕「薬草、ぴったり10本ですね。」
- **3.00 CUE-A**: ミナが水晶を取り出す。「念のため、もう一度」(字幕なし、動作のみ)。アキラが手をかざす。
- **4.00 CUE-B**: 水晶のクローズアップ。`測定中…` の桁が高速で回り始める。
- **5.00–6.50 CUE-C**: 数字が `65535` まで駆け上がる(カウント)。
- **6.50 CUE-D**: `65536`→画面がグリッチ→**`Lv.1`** へ折り返す(チャイム)。赤い警告バナー `表示上限(65535)を超えています` が出る。
- **7.00–8.20**: ミナの字幕「…表示、直しておきますね。」(ミナは無表情でカードを閉じる)。
- **8.50 CUE-E**: アキラの頭上に「？」。
- 10.00 終。

## e8-next (240f / 8.0s) — 「次回予告」
**コンセプト**: テレビアニメの次回予告のお約束。明るく、テンポよく、嘘っぽいくらい元気に。
**固有技法**: **平面カラーの高速カット**(各カット0.5秒=15フレーム。背景は単色ベタ+大きな文字+キャラのシルエット)。遷移は色ブロックのスライド(shutter/blinds系)。最後に「つづく」と作品ロゴ。
**色**: 黄・水色・ピンク・白・黒のベタ。
**フォント**: 太い丸ゴ/ゴシック(Dela Gothic One 等)。
**入り/出**: ハードカット(出は作品ロゴの余韻のまま黒へ)。
**コピー**: `次回` / `第2話` / `薬草が足りません` / `つづく` / `レベル1なのに世界最強`
**合図(0.5秒ごとのカット)**:
- 0.00 `次回` (黄ベタ)
- 0.50 アキラのシルエットと `第2話`(水色ベタ)
- 1.00–2.50 3カット: ミナ(無表情)、スライム、熊 を各0.5秒(ベタ色を変える)。文字なしの絵だけ。
- **2.50–5.00 CUE-A**: `薬草が足りません` が1文字ずつ(0.3秒おき)、色ブロックを背景に出る。
- 5.00 CUE-B: 全カットの短いフラッシュバック(5.00–6.00、3カット)。
