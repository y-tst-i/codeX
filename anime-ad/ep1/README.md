# 第1話「レベル1の冒険者」ショート版(約83秒・架空・オリジナル)

『レベル1なのに世界最強』(架空のTVアニメ)の第1話を、約83秒に縮めたもの。声なし・字幕つき。

- `level1-ep01-short-83s.mp4` : 完成動画(1920x1080 / 30fps / 2490フレーム / 83.000秒)
- `docs/BIBLE.md` `docs/SCENES.md` : 設計書(共通ルール・字幕仕様・場面ごとの世界/技法/台詞/合図)
- `source/<場面>/` : 場面別の HyperFrames プロジェクト。共通素材は `source/*.svg` と `source/gsap.min.js`
- `make_audio.py` + `instruments.py` : 全編の音楽・効果音を合成(numpy必須)→ `soundtrack.wav`
- `assemble.sh` : 場面mp4(各 `source/<場面>` を `npx hyperframes render` したもの)を `out/` に置き、ハードカット連結+音

あらすじ: ギルドで登録(測定は Lv.1)→草原でうっかり魔物を一掃→勇者パーティが魔王に全滅→迷子のアキラが魔王の間へ→手を振っただけで魔王が消える→夕焼けの薬草→ギルドで水晶が「Lv.65537(表示上限65535超過)→Lv.1」と判明(桁あふれで表示が1に戻っていただけ)→次回予告。
作品名・キャラ・台詞はすべてオリジナルの架空のもの。
