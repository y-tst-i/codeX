- ffprobe: 44100Hz / 2ch / 16bit / 661500 samples = **15.000000s**
- サンプルピーク **-1.00 dBFS**、True peak -0.9 dBTP、Integrated -23.0 LUFS(raw。ラウドネスの仕上げはしていない)
- 注意: SOUND_BIBLE は 48kHz と書いているが、依頼どおり 44.1kHz で出した

## (b) 合図表(前0.1s/後0.1s の RMS、10ms RMS の立ち上がり位置)
- 35 合図すべて OK(山を立てる合図は後が上がるか、±1f 以内に 6dB/10ms 以上の立ち上がりがある。無音にする合図は下がっている)
- 主な山の立ち上がり位置のずれ: G36 扉 -0.28f / G120 着地 -0.30f / G228 銃声 -0.28f / G330 命中 -0.26f / G384 タイトル -0.12f(約 -9ms のずれは 10ms 窓の測り方によるもの)
- 前→後 の比: 扉 +15.9dB、太鼓 G72 +3.4、着地 +21.0、足音 +5〜+18、心音 +12.1、銃声 **+26.3**、命中 +7.7、扉(呼応)+8.4、タイトル +13.5、ハープ +4.3
- 弱い所: G24 回転機構 +4.5dB(最初の立ち上がりはコントラバスのトレモロの粒で G21.4 に出る)、G108 クラッシュズーム +1.3dB(通過音は山が左右対称なので比が出にくい。G108 に太鼓の4打目を強めて置いた)、G282 ティンパニのロール +1.7dB(設計どおり「小さく」始める)
- 100ms RMS で一番大きい山は 銃声 G228(-11dBFS)> 着地 G120(-12)> 命中 G330(-15)

## (d) 純音
- ping / bell / sine_sweep / tinnitus / 単発ピンは **0回**
- 正弦波を使った所は低域の持続音だけ: s1 機内のうなり(55Hz の倍音5本をゆらす)、着地のサブ 40Hz(+80Hz、周波数固定)、s3 の 40Hz の低いうなり(+80Hz+低域ノイズ)、s5 のサブの膨らみ 36.7Hz。どれも周波数は動かさない。銃声の尾のピッチダウンは録音素材の再生速度を変えたもので、サイン波ではない
- 合成音の割合: エネルギーで 23.8%、合成音が主になっている 50ms 窓は 28.3%(どちらも 3割以下)
