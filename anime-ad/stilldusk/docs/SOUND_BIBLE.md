# SOUND_BIBLE — STILLDUSK 15秒PV 音の設計

映像の合図(cue)は SCENES.md と同じ時刻。G=全体フレーム、秒=G/30。出力は 48kHz ステレオ、長さ 15.000s ちょうど。

## 基本
- **BPM 150**(1拍=0.4s=12f)。小節頭(4拍=48f)は G0,48,96,144,192,240,288,336,384,432。場面の境目 G60/132/228/360 は拍頭。
- 打楽器の音楽は **s2 と s4 の加速部だけ**。s1・s3・s5 は拍のグリッドに環境音と単発を置くだけ(足音は拍に乗せる)。
- 見本(雨の夜の傘)と被せない: 雨・水滴・カリンバ・夜の街のざわめき・柔らかいピアノの主旋律を使わない。
- **禁止**: 純音(サイン波)の単発ピン、サイン波のスイープ(ピューン)、サイン波の耳鳴り。合成音は全体の3割以下(機内のうなり・風・低域ドローンに限る)。
- 効果音は `tools/sfx_lib.py find <語>` の録音素材を優先(探す語の候補を下に書く。無ければ sound-palette.md の代替表に従い GM の実音で置き換える)。楽器は `tools/midi_render.py`(GM)。

## 3層
| 層 | 内容 | 音量の目安 |
|---|---|---|
| 環境音 | s1 機内のうなり / s2 上空の風の轟音 / s3 砂嵐の風と砂粒 / s4 吸い込まれた低いうなり / s5 地平線の乾いた微風 | −24〜−30 LUFS 相当の下地 |
| 効果音 | 扉・着地・足音・きしみ・銃声・命中・破片。**目に見える動きすべてに付ける** | 主役。山は −1 dBTP 以内 |
| 音楽 | s2 太鼓+ブラス / s4 弦の塊→歪んだギター / s5 合唱+低いピアノ+ハープ | 効果音の下(−6dB) |

## 場面ごとの音の世界(隣り合う場面で楽器の系統を被らせない)
| 場面 | 楽器の系統 | 空間(残響の長さ・暗さ) | 帯域 |
|---|---|---|---|
| s1_hatch | 金属の機内のうなり(倍音 55/110/165Hz をゆらがせた合成+細かいノイズ)、コントラバスの低いトレモロ(GM 43)、息(録音)、油圧の抜け(録音) | 短く暗い(0.4s、金属の箱、高域を削る) | 低域 40–400Hz 中心、息だけ中域 |
| s2_drop | 風の轟音(ピンクノイズを帯域で動かす通過音)、和太鼓系(GM 116 Taiko)、ブラス・セクション(GM 61)、リバースシンバル(GM 119)、オケヒット(GM 55)+クラッシュ | 広い屋外。打撃にだけ長く明るい尾(2.0s) | 全域。着地で 30–60Hz のサブ |
| s3_stalk | 帯域を絞った暗い風(200–1.5kHz)、砂粒のさらさら、砂利/砂の足音(録音)、遠い金属のきしみ(録音)、尺八系の息の長音(GM 77、ごく小さく)、ほぼ無音区間に心音(GM 35) | 中程度で暗い(1.5s、金属の骨組みの反響、高域を 4kHz で落とす) | 中域。高域を抑える |
| s4_shot | 銃声(録音)+低いキック+ノイズの破裂、弦セクションの低いクラスター(GM 49)、ティンパニ(GM 47)、歪んだギター(GM 31)の刻み、ガラスの破砕(録音) | スロー区間は非常に長く暗い(4s、ローパス 300Hz まで閉じる)→ 加速〜命中は乾いて短い(0.3s) | スロー=低域だけ / 命中=全域で高域(ガラス)が明るい |
| s5_title | 地平線の微風、扉の油圧(s1 の呼応、ピッチを下げて柔らかく)、合唱 ウー(GM 53)、低いピアノのオクターブ(GM 0)、ハープの開いた5度(GM 46)、サブの低い膨らみ | 広く明るめ、長い(3.0s) | 低域+中域の合唱。最後は高域を抜いて消える |
- 使う音色の種類: 16以上(目標8以上)。同じ素材を2場面で使い回さない(s5 の扉は s1 と同じ素材を加工した「呼応」として1回だけ許可)。

## ほぼ無音(4か所。最低2の要件を満たす)
① G118–119 着地直前 / ② G210–227 照準(最重要。直後の銃声を倍にする)/ ③ G246–258 シグネチャの保持 / ④ G360–371 暗転と縦の隙間。

## Jカット・Lカット(4回)と、音も同時に切れる境目
- Jカット①: s2 の風 → G42(s1 の中)から先に鳴る。
- Lカット①: s2 の着地の轟音 → s3 の G170 まで残る。
- Jカット②: s5 の微風と合唱の息 → G354(s4 の中)から先に鳴る。
- Lカット②: s4 の命中の残響 → s5 の G380 まで残る。
- 絵と音が同時に切れるのは s3→s4(銃声)の1回だけ。

## 検証
- 各合図の音の立ち上がり(10ms窓RMSの増分)が表の秒 ±1f 以内か。特に G36・G120・G228・G330・G384。
- 場面ごとにスペクトル重心・高域比・RMS を出し、隣り合う場面で値が近すぎないか(s3 は暗く小さく、s4 の命中は明るく大きく)。
- ほぼ無音の4区間で RMS が −40dBFS 前後まで落ちているか。
