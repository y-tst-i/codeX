# BIBLE — STILLDUSK(スティルダスク)15秒PV 共通ルール
**世界の一言**: 自転が止まり、夕刻のまま固まった塩の惑星。墜ちた軌道リングの「影」だけが人の住める場所で、部隊はその影を奪い合う。(完全に架空。実在作品・企業・兵器・部隊章を連想させない)
**リズム**: 静(扉)→ 落下(速)→ 潜行(遅・息継ぎ)→ 一発(超スロー→加速→炸裂)→ 余韻(遅・タイトル)。150BPM=1拍12f。

## 規格
- 1920x1080 / 30fps / 合計450f=15.000s。場面: s1 60f / s2 72f / s3 96f / s4 132f / s5 90f。境目 f60,132,228,360(すべて拍頭)。
- 各場面は無音mp4、ハードカット連結。フレーム数は ffprobe で厳守(±0)。

## 配色(この6色以外は、これらの明度違い・不透明度違いだけ)
| 名 | HEX | 約束(何の光/物か) |
|---|---|---|
| CARBON 炭 | #0E0D0C | 影・機体・シルエット。真の黒(#000)は使わない |
| BONE 骨白 | #EDE4D3 | 塩の大地・文字・クロスヘア |
| AMBER 琥珀 | #D9822B | 止まった夕日に照らされた砂塵(世界の地の色) |
| FLARE 白熱 | #FFD9A0 | 太陽そのもの・扉の隙間の光・リムライト |
| RUST 錆 | #7A2E12 | 空の上部・機内の非常灯(s1は赤寄り #C2341B を許可) |
| CYAN 信号 | #3FE0D0 | 人工のエネルギーだけ(推進器・バイザー・弾丸の曳光)。自然光には絶対に使わない |
- 世界は琥珀/炭の暖色。CYAN は「人の武器」の印で、画面面積の5%以下(例外は s4 の銃口の閃光 L0–5 の6f と、命中の挿入 L102–104 の3f のみ)。
- 先行見本(雨の夜・青・傘)と被る色(夜の青、ネオンのピンク/紫、濡れ路面の反射)は使わない。

## フォント・文字
- Noto Sans JP(同梱)のみ。外部フォント読み込み禁止。
- 画面の文字は s5 の「STILLDUSK」と「COMING SOON」の2つだけ(一字固定)。他の場面に文字・数字・ロゴを一切出さない。

## 画面の約束(HUD・クロスヘア)
- HUD は出さない(弾数・体力・ミニマップ・キルログ・ボタン表示・スコアすべて禁止)。
- クロスヘアは **s3 のみ**、画面中心(960,540)固定の4本の短い線(各12x2px、BONE 70%)。開き幅 28px→8px。中心点なし。
- 一人称の武器は s3 だけ(右下の架空の銃身シルエット)。実在銃の形(マガジン形状・刻印・ブランド)に似せない。
- 流血・人体損壊なし。敵への命中は「バイザーの防護ガラスが砕ける」で表現(CYAN の破片)。

## 禁止事項
- 事実の捏造: 発売日・機種名・価格・受賞・評価・レーティング・「全米が」・推薦文・ストアバッジ。表記は COMING SOON のみ。
- 実在の連想: 実在ゲーム名に似た語(Horizon/Halo/Dust/Kiln 等)、実在企業ロゴ風マーク、実在の軍・国旗・部隊章。
- 雨・水たまり・濡れ反射・夜の青・傘(見本と被る)。
- 技法の使い回し: SCENES.md の「固有技法」は専売。他場面で主役にしない(ライトフラッシュは s1→s2 の1回、スローは s4 のみ、クロスヘアは s3 のみ、ビネットは s5 のみ)。
- 純白 #FFFFFF の全面は s1 終わりの #FFF1DC(暖白)以外に作らない。

## 決定性(全場面共通)
- 描画は時刻 t(=frame/30)の純関数。Math.random / Date.now / performance.now / requestAnimationFrame の累積禁止。
- 乱数は scene-lib.js の mulberry32 のみ。seed: s1=101, s2=202, s3=303, s4=404, s5=505(粒子の初期値は seed から一括生成し、位置は x0+v·t の閉形式)。
- 逐次シミュレーション(前フレームの状態に足す)禁止。速度の山谷は scene-lib.js の timeRemap で「経過した場面時刻 s(t)」を出してから描く。
- 揺れはローパスした連続関数(互いに素な周波数の sin の和+seed付きバリューノイズ)。毎フレーム独立の乱数は禁止。

## 検証(各担当)
- check → snapshot(入り/出/合図フレーム)→ render → ffprobe でフレーム数。合図フレームの絵が SCENES.md の記述どおりか自分の目で確認。
- つなぎ: 自場面の f0 と最終フレームを PNG で書き出し、SCENES.md の「つなぎ」の座標・色と照合。
