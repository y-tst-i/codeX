### s1_hatch (2.0s / 60f, G0–59) — 「隙間が、爆ぜる」
**物語上の役割**: 何も見えない暗闇の一点(光の隙間)に視線を集め、2秒で破裂させるフック。次の s2 の広さを最大にするための「狭さ」。
**世界**: 降下艇の機内、閉じた後部扉の前。外は夕刻のまま止まった世界。暗い炭色+赤い非常灯。
**カメラ**
  - サイズ: ミディアム(扉の左右パネル全体=幅960pxが画面中央に収まる)。根拠: 扉の「隙間」一本だけが情報になる距離。
  - アングル: 目の高さ、正対(座席から扉を見るPOV。手・体は映さない)。
  - 動き: ハンドヘルド(機体の振動)。x/y ±4px、回転 ±0.3°、0.7/1.3/2.9Hz の sin の和+seed101 のノイズ、縁隠しに scale 1.05。加えて L0–35 にゆっくり押し込み scale ×1.00→1.04(sine.inOut)。終了構図=画面全体が暖白(扉の向こうに「外」がある事実)。
  - レンズ感: 標準。
**光**: 光源=①扉の縦の隙間(外の太陽、FLARE #FFD9A0、硬い逆光)②左上の回転非常灯(#C2341B、(260,110))。コントラスト8:1以上のローキー。最も明るい読めるもの=縦の隙間。
**色**: CARBON #0E0D0C / 機内の肋材 #1A1714 / 非常灯 #C2341B / FLARE #FFD9A0 / 白飛び #FFF1DC。色の出来事= L36 で扉が割れた瞬間に赤→琥珀へ支配色が反転。
**構図**: 中央の一点(隙間)に視線を集める。ただし左右対称は s5 の専売なので、機内は非対称にする(非常灯は左だけ、肋材は x=180,420,1560 の3本、右側に吊られた装備の黒い塊)。隙間 x=960、y=200〜880、幅2px(グロー16px)。扉パネル 左 x480–960 / 右 x960–1440、y200–880。非常灯の回転光は2拍ごと(L0,24,48)に左から右へ壁を掃く。
**時間**: 通常。L36 から扉が開く(唯一の「動きの山」)。
  - L0–35: 隙間 2px→6px にわずかに開く(L30付近)、隙間から砂粒が逆光で数粒漏れる。
  - L36–41: 隙間 6→120px(power4.out)。同時に下方向へ +10px の衝撃ジョルト(4f で減衰)。
  - L42–53: パネルが左右に滑り去る(隙間 120→1200px、power2.in)。外の琥珀→FLARE のグラデーションが見え、明るさ(露出)が上がる。砂粒が画面手前へ吹き込む(中心から放射、拡大)。
  - L54–56: 全面 #FFF1DC の不透明度 0→1(linear)。L57–59: 1.0 保持(純粋な暖白3f)。
**効果**: ライトフラッシュ=扉が開いて外光が露出を超える(L54–59)。ローキー=機内に光源が2つしかない。
**つなぎ**: 入り=映像の開始(黒 #0E0D0C に隙間)。出=L57–59 全面 #FFF1DC → s2 L0–1 も全面 #FFF1DC(白で受け渡し)。
**合図(cue)**: 0.000s(G0)機内のうなり / 0.800s(G24)非常灯の掃き / 1.200s(G36)扉の破裂=フックの山 / 1.400s(G42)外の風が入る(s2 の風のJカット開始)/ 1.800s(G54)白飛び頂点。
**コピー(一字固定)**: なし(文字禁止)。
**辞書の技法(slug)**: camera-movement/handheld, lighting/low-key, effects/light-flash
**固有技法(この場面だけ)**: 回転非常灯のローキー、縦の光の隙間が開くリビール、ライトフラッシュ(全編で1回)。
**禁止**: 手・銃・HUD・文字を映す。#FFFFFF の純白。白に達しない「虹色の筋」だけのフラッシュ。

### s2_drop (2.4s / 72f, G60–131) — 「影へ落ちる」
**物語上の役割**: 狭さ(s1)から一気に「惑星の大きさ」へ。世界のルール(太陽が地平線にあり、リングの影だけが暗い)を1枚の地図で見せ、そこへ落ちる。最初の「速い」場面。
**世界**: 地上数百メートルから真下近く。塩の大地(骨白)、地平線の太陽による極端に長い影、斜めに横たわる墜ちた軌道リング。
**カメラ**
  - サイズ: 超ロング(バードアイ。人物は幅64pxの点)。根拠: 「影の帯」と「落ちる人」の位置関係=地図が事実。
  - アングル: バードアイ(約75°見下ろし。真俯瞰ではない)。
  - 動き: L0–47 地面が拡大 scale 1.0→1.5(power1.in=落下で近づく)。L48–57 クラッシュズームイン scale ×2.6(1.5→3.9、expo.out、10f、transform-origin=(960,500))。L58–59 静止。L60 着地衝撃の揺れ 8f(±14px→0、ローパスした減衰)。終了構図=砂塵の壁(着地で舞い上がった砂が画面を埋める)。
  - レンズ感: 望遠気味(地面の模様が平たく、高度感は影の長さで出す)。
**光**: 光源=左上の地平線の太陽(画面外)、硬い、真横の低角度。影は右下へ極端に長い(塩の隆起の影=長さ200〜400pxの細い筋)。最も明るい読めるもの=骨白の塩、その中の暗い帯(リングの影)に落ちる人物。
**色**: BONE #EDE4D3(塩)/ 影 #6E5A48 / リング本体 #2A211B / AMBER #D9822B(砂塵)/ 推進器 CYAN #3FE0D0(人物の背中の2点、各4px)。色の出来事= L60 着地で骨白が琥珀の砂塵に覆われる。
**構図**: 塩の亀裂は seed202 のボロノイ網(セル80〜140px)。リング本体は左上(0,160)から右下(1920,920)への緩い弧、幅140px。その影は弧の右下側に幅360pxの帯(#6E5A48、不透明度0.55)。**着地点 (960,500) は影の帯の中**。人物(真上から見たスカイダイビング姿勢: 頭=円 r9、肩=楕円 rx22 ry10、四肢を開く。puppet.js ではなく平面図用の別形状)を常に (960,500) に置く。人物の地面の影は (960+300,500+140) から着地の L60 で (960,500) に重なる(高度=影との距離)。
**時間**: 速い。速度の山= L48–57 のスナップ、L60 の着地。
**効果**: クラッシュズームイン=落下の最後の一瞬に焦点距離が詰まる(スナップ中だけ放射状ブラー、ghost 6枚)。着地の揺れ=地面に衝撃が入った物理(この場面だけ)。砂塵の輪= (960,500) から半径 0→1400px(L60–71、power2.out、AMBER)。
**つなぎ**: 入り= L0–1 全面 #FFF1DC(s1 の白を受ける)、L2–14 で白が抜けて俯瞰の大地が現れる(power2.out)。出= L66–71 で砂塵が全面を覆い、**最終フレーム L71 = 全面 #C9772E、中心 (960,500) 半径360pxに明るい #E8A65A の放射グラデ** → s3 L0 が同じ絵(砂塵越しの太陽)で受ける。
**合図(cue)**: 2.000s(G60)白から風の轟音 / 2.400s(G72)太鼓の1拍目(以後 G84,G96,G108)/ 3.200s(G96)ブラスの刻み / 3.600s(G108)クラッシュズームの風切り / 4.000s(G120)着地の衝撃=第2の山。
**コピー(一字固定)**: なし。
**辞書の技法(slug)**: camera-angles/birds-eye, camera-movement/crash-zoom-in
**固有技法(この場面だけ)**: バードアイの地図、影の距離で高度を見せる、クラッシュズーム、着地の揺れ。
**禁止**: 立ち姿の人物を寝かせて使う。ズームのスナップ後もズームを続ける。白から入る以外のフラッシュ。

### s3_stalk (3.2s / 96f, G132–227) — 「骨の回廊で、息を止める」
**物語上の役割**: 速さの後の息継ぎと緊張の蓄積。初めてプレイヤーの目(一人称)になり、敵を見つけ、照準が締まり、音が消える。s4 のスマッシュカットが壊す「静けさ」を築く。
**世界**: 墜ちたリングの内側。巨大な肋骨のようなアーチが奥へ並ぶ回廊、砂嵐、正面奥に鈍い円盤の太陽。
**カメラ**
  - サイズ: ロング(目線)。根拠: 消失点に立つ小さな敵=距離が事実。
  - アングル: 目の高さ(地平線 y=500)、正対。
  - 動き: 一人称の歩き=ドリーイン。L18–77 で回廊の奥行きを前進(CSS 3D の translateZ 0→900、power1.inOut)、歩行の上下動 ±5px を拍に合わせ(足音 L24,36,48,60,72)、銃身も同期して揺れる。L78 で停止、以後静止(呼吸の ±1.5px のみ)。終了構図=照準の中心に敵(見つけた、の事実)。
  - レンズ感: 広角寄り(回廊の遠近を強調)。
**光**: 光源=消失点の奥の太陽(砂越しの鈍い円盤 r=70、#F6D29A)、正面からの逆光、拡散。光芒がアーチの隙間から扇状に7本(不均等な幅、screen合成、blur 6px)。アーチと敵はシルエット(CARBON)、縁に細い FLARE のリム。最も明るい読めるもの=太陽の円盤→その直前に立つ敵。
**色**: AMBER #D9822B(霞)/ #C9772E(濃い砂塵)/ CARBON #0E0D0C(アーチ・敵・銃身)/ FLARE #FFD9A0(リム・光芒)/ CYAN #3FE0D0(敵のバイザーのみ)。色の出来事= L90 にバイザーがCYANに光る(この場面で唯一の寒色)。
**構図**: 一点透視。消失点 VP=(960,500)。アーチは VP を中心に相似に縮む門形(手前の幅1700px→奥へ)。敵(puppet.js の立ち姿シルエット)は VP の真下に立ち、L36 に高さ60px(足 y=560)、L77 に高さ100px(頭頂 y=490、バイザー (960,505)、胸 (960,540)、足 y=590)。一人称の銃身(架空の形)は右下: 上縁が (1210,800)→(1920,1010) の線、銃口は (1210,800–830)、上縁に FLARE 60% の 2px リム。クロスヘアは画面中心 (960,540) 固定。
**時間**: 通常(遅い場面)。
  - L0–17: 砂塵のベールが不透明度 1.0→0.35(power2.out)、回廊が現れる。
  - L18–77: 歩く。L36 敵が VP の霞から現れる(不透明度 0→1、12f)。L66 クロスヘア出現(4本、開き28px、BONE 70%)。
  - L78–95: 停止。ほぼ無音の区間。L78–89 クロスヘアが 28→8px に締まる(power3.out)。L90 敵のバイザーが CYAN に2f強く光り、以後50%(こちらに気づいた)。L95 で静止したまま終わる。
**効果**: 砂嵐=風に運ばれる粒(canvas 600粒、右→左へ 900〜1800px/s、近いほど大きく長い線)+横に流れるベール。光芒=砂の粒子が太陽の光の通り道を見せる(敵のシルエットが光芒を切る)。
**つなぎ**: 入り= L0 全面 #C9772E、(960,500) 中心 r360 に #E8A65A(s2 の砂塵の壁と同じ絵)。出= **L95: 琥珀の霞、VP (960,500) の太陽の直前に敵、バイザー (960,505) が CYAN 50%、クロスヘア 8px が (960,540)** → s4 L0 は全く別の絵(黒地、左 (180,540) の銃口の閃光)へスマッシュカット。
**合図(cue)**: 4.400s(G132)着地の轟音の尾(s2 からのLカット)/ 5.200s(G156)足音1(以後 G168,180,192,204)/ 5.600s(G168)敵の出現=遠い金属のきしみ / 6.600s(G198)クロスヘア出現 / 7.000s(G210)ほぼ無音に落ちる / 7.400s(G222)バイザーの光。
**コピー(一字固定)**: なし。
**辞書の技法(slug)**: camera-angles/pov, composition/one-point-perspective, lighting/volumetric-light, atmosphere/dust-storm, camera-movement/dolly-in

**禁止**: 弾数・体力などのHUD。クロスヘアを中心から動かす(世界の方を動かす)。消失点を2つにする。敵の顔・肌を見せる(シルエットのみ)。

### s4_shot (4.4s / 132f, G228–359) — 「一発が、砂を割る」(シグネチャ)
**物語上の役割**: 築いた静けさをスマッシュカットで壊し、時間を止めて「この世界の一発の重さ」を見せる見せ場。全編で唯一の加速で、炸裂へ叩き込む。
**世界**: リングの影の中、弾道の真横。暗い空気に砂粒が漂う。
**カメラ**
  - サイズ: クローズアップ(弾丸=長さ36px、曳光の尾300pxが画面の主役)。根拠: 普段は見えない弾と砂粒の相互作用が事実。
  - アングル: 弾道の真横(プロフィール)、水平。
  - 動き: 弾と並走するトラック(横移動)。背景・砂粒が左へ流れる量で速度を表す。終了構図=右側 (1480,520) で砕けた CYAN の破片が消えていく暗闇(命中した事実)。
  - レンズ感: 標準〜望遠(背景の霞を圧縮してボケさせる)。
**光**: 光源=①L0–5 銃口の閃光(CYAN 白熱 #E6FFFB 核/#3FE0D0 外縁、半径260)②弾丸自身の CYAN の曳光(実用光。半径200px以内の砂粒を CYAN に照らす、それより遠い粒は琥珀の残照)。背景は暗い(影の中)。最も明るい読めるもの=弾丸。
**色**: CARBON #0E0D0C(地)/ #120F0C(影の空気)/ 遠い霞の帯 AMBER 25%(y300–700)/ CYAN #3FE0D0 / 白熱 #E6FFFB。色の約束=寒色は弾の光源から出る分だけ。
**構図**: 弾道は y=540 の水平線、左→右。銃口(架空の形のシルエット)は L0 に (180,540)。弾の画面上の x: L0=210 → L5=620 → L17=700 → L77=1000(並走で遅く漂う)→ L78–101=1000→1180(加速、背景が流れ去る)。L96–101 に敵のバイザー(横顔シルエット、CYAN の縁)が右端から (1480,520) へ高速で入る。
**時間**(速度の山谷。scene-lib.js の timeRemap に渡す率 r):
  - L0–5: r=1.0(発射。閃光6f)
  - L6–17: r 1.0→0.04(power2.out)
  - L18–77: r=0.04(**シグネチャ。72f=2.4秒、弾が砂粒の中で止まって見える**)
  - L78–101: r 0.04→4.0(expo.in)=**全編唯一の加速**
  - L102–104: フラッシュカット挿入(3f。バイザーのひび。ここだけ CYAN が5%を超えてよい=BIBLE の例外)
