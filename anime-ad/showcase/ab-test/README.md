# A/Bテスト: 場面実装モデル(Opus vs Sonnet)
目的: 品質を落とさずにトークンを減らせるか。同じ場面カード(`../docs/SCENES.md` の s2-match / s4-dawn)・同じ道具(`tools/cin.py` `tools/new_scene.sh`)・同じ指示で、実装担当のモデルだけを変えた。
手順: 担当4人(場面2つ × モデル2つ)を並列に起動 → 動画を名前伏せ(A/B、左右はランダム)で比較 → 利用者が判定 → 開示。
結果: 利用者は s2・s4 とも B を良いと判断し、B はどちらも Opus(`BLIND_KEY.json`)。トークンは s2 で同程度(約8.4万 vs 約8.4万)。→ 実装は Opus を既定に。
注意: 2場面のみ。s4 の Opus はレート制限で中断・再開したためトークン数は比較に使えない。費用(単価)は比べていない。機械チェック(フレーム数・つなぎ色差)は両者通過で、見た目の差は拾えなかった。
再テスト: 別の場面種類(例: 走り/一致なしの単純な場面)で同じ手順を繰り返すと、場面の種類ごとに判断できる。
