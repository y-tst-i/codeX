# 見本「雨の夜、傘の赤」(15秒 / 1920x1080 / 30fps)

映画技法の辞書(claude-video-skill/references/cinematic)を設計書に落として作った見本。
場面ごとに別担当(サブエージェント)が作り、ffmpegで連結、音は別に合成。

| 場面 | 秒 | 使った技法 |
|---|---|---|
| s1-alley | 0–3.5 | 一点透視 / ドリーイン / ネオン実光源 / 雨 / ウェットダウン |
| s2-match | 3.5–7.0 | グラフィックマッチ(傘→信号→傘の群れ) / クレーンアップ / ラックフォーカス |
| s3-ramp | 7.0–11.0 | トラッキング / スピードランプ / モーションブラー / ウィップパン |
| s4-dawn | 11.0–15.0 | クレーンアップ / カラーシフト(夜→夕焼け) / 光芒 |

設計書: docs/BIBLE.md, docs/SCENES.md。音: make_audio.py(numpy合成)。
