# 音の設計書(見本「雨の夜、傘の赤」15秒 / BPM120 / 1拍=0.5秒)
音も映像と同じく「場面ごとに別の世界」にする。道具: 本物の楽器音源(FluidR3 GM, 無料) + 数式合成の効果音。

## 原則
1. **場面ごとに 楽器の系統・空間(残響)・帯域 を変える**(3つとも違う)。同じ残響・同じ音量処理を全体にかけない。
2. 音楽は MIDI(本物の楽器)、環境音・足音・風切り音は合成。役割で分ける。
3. 隣り合う場面で、楽器の系統が被らない。
4. 映像の山(合図)に音の山を合わせる(下の cue)。

## 場面ごとのパレット
| 場面 | 楽器(GM) | 空間 | 帯域 | 質感の狙い |
|---|---|---|---|---|
| s1 路地 0–3.5 | エレピ2(5) / フレットレスベース(35) / ビブラフォン(11) | 暗く長い(2.2s, damp 3500Hz) | lp 7k | 孤独・ノワール。雨と足音が主役、音楽はまばら |
| s2 一致 3.5–7.0 | チェレスタ(8) / ピチカート(45) / ハープ(46) / 弦アンサンブル(48) / ティンパニ(47) | 乾いて明るい(0.5s, damp 9000Hz) | hp 150 | つなぎごとに1音ずつ上がる(傘→信号→俯瞰)、7.0へ向けて膨らむ |
| s3 走り 7.0–11.0 | ドラムキット / 太鼓(116) / シンセベース(38) / ブラス(61) / オケヒット(55) / トレモロ弦(44) / リバースシンバル(119) | 短く締まる(0.7s, damp 6000Hz) | なし | 衝撃・推進。スロー(8.0–8.5)は音を抜いて低弦だけ |
| s4 夜明け 11.0–15.0 | ピアノ(0) / 合唱(52) / ハープ(46) / フルート(73) / 鳥(123) / チェレスタ(8) | 広く明るい(3.2s, damp 8000Hz) | hp 80 | 静けさ→12.5に和音で「晴れる」 |

## 合図(cue)と音
- 0.00 雨・ネオンのうなりが入る(黒から) / 0.5拍ごとに足音
- 3.50 チェレスタ E6(傘の円) / 4.00 A6(信号) / 4.50 C7(俯瞰) + 各回クリック
- 7.00 オケヒット+ブラス+キック+クラッシュ(ハードカットの衝撃)
- 8.00–8.50 スロー: ドラム抜き、トレモロ低弦+ティンパニ1発、低くこもった水音
- 9.50–10.50 ファスト: 16分ハット、スネア連打
- 10.50 ウィップ(風切り) / 10.0–11.0 リバースシンバルが11.0に着地
- 11.00 一気に静か(雨だけ、ピアノ低音の保持)
- 12.50 色が変わる: 合唱+ピアノのGadd9、ハープ上昇、鳥
- 14.00 チェレスタ G6 1音(「雨上がり」) / 14.6 から暗転に合わせて消える
