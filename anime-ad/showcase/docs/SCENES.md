# SCENES(技法ショーケース 15秒) — 場面カード

全体 15.0秒=450フレーム。リズム: 静(導入)→ 一致(つなぎ)→ 加速(時間)→ 解放(色)。

| id | 全体時刻 | 尺 | フレーム |
|---|---|---|---|
| s1-alley | 0.0–3.5 | 3.5s | 105 |
| s2-match | 3.5–7.0 | 3.5s | 105 |
| s3-ramp | 7.0–11.0 | 4.0s | 120 |
| s4-dawn | 11.0–15.0 | 4.0s | 120 |

---
### s1-alley (105f / 3.5s) — 「濡れた路地」
**物語上の役割**: 静かな導入。夜の路地の奥へ、赤い傘の人が歩いていく。世界の光源(ネオン)と雨を提示する。
**世界**: 夜・雨・狭い路地・ネオン看板(桃/橙)・街灯。
**カメラ**: サイズ=ロング〜ミディアム(人物は画面高の約30%)/ アングル=アイレベル、わずかに低め / 動き=**ドリーイン(前進)**、開始=路地入口、速度=3.5秒かけてゆっくり(power1.inOut)、終了構図=人物が少し大きくなり、奥のネオンが開く(最後のコマで見える新しい事実=路地の奥に明るい出口)/ レンズ感=35mm標準広角(P/(P+Z)の表)
**光**: ネオンの桃/橙が壁と濡れ路面を染める(キー=看板、側面から)。硬さ=硬。コントラスト=ローキー。最も明るい読めるもの=傘の赤。
**構図**: **一点透視**(消失点は画面中央やや右、x≈1100,y≈470)、導線=路面の水たまりと壁のライン。人物は消失点の手前を歩く(中心から少し左)。
**時間**: 通常速度。
**効果**: 雨(3層ストリーク)+**濡れ路面の反射**(ネオンが路面に伸びる)。ビネット弱め。
**つなぎ**: 入り=純黒から0.4秒でフェードイン(最初のフレームは純黒)。出=傘の赤い円が画面中央にあるフレームで終わる(次場面へのグラフィックマッチ。**傘の円の中心座標 (960,540)、直径 約360px で最後のフレーム**)。
**辞書で読むエントリ**: `composition/one-point-perspective`、`camera-movement/dolly-in`、`lighting/neon-practical`、`atmosphere/rain`、`atmosphere/wet-down`、`lighting/low-key`、`effects/vignette`
**固有技法(専売)**: 一点透視+ドリーイン+濡れ路面の反射。

### s2-match (105f / 3.5s) — 「赤い円」
**物語上の役割**: つなぎの見せ場。傘の円が別の赤い円に変わり、視点が真上へ移る。
**カメラ**: サイズ=クローズアップ → 極端なロング / アングル=アイレベル → **真俯瞰(オーバーヘッド)** / 動き=**グラフィックマッチのハードカット**後、**クレーンで上昇しながら引く**(速度=2.0秒、power2.out)。
**構図**: 前半=傘の赤い円が画面中央(直径約360px)。0.5秒で**交通信号の赤ランプ(同位置・同直径)にマッチカット**。さらに0.5秒で**真俯瞰の傘の群れ(多数の赤・黒・青の円=傘が並ぶ交差点)**に、中心の円(同じ赤)が残るようにマッチ。**反復とパターン**(円の繰り返し)。
**時間**: 通常。
**効果**: **ラックフォーカス**(信号のカットで背景のボケが解ける。blur 12px→0、0.3秒)。
**つなぎ**: 入り=s1の最後のフレーム(傘の赤い円、中心(960,540)、直径360px)と**同じ位置・同じ大きさ**から始める。出=真俯瞰の傘の群れの中で、主役の赤い傘が**画面右下(x≈1500,y≈820)**に小さく(直径約90px)残るフレーム。
**辞書で読むエントリ**: `editing/graphic-match`、`editing/match-cut`、`camera-angles/overhead`、`camera-movement/crane-up`、`composition/repetition-pattern`、`effects/rack-focus`
**固有技法(専売)**: グラフィックマッチ(円→円→円)と真俯瞰。

### s3-ramp (120f / 4.0s) — 「走る」
**物語上の役割**: 加速。雨が降り出す(強まる)中、傘の人が走り出す。時間を操作して、最後に場面を切り替える。
**カメラ**: サイズ=ミディアム〜ロング / アングル=ややロー / 動き=**トラッキング(横から追う)**、最後に**ウィップパン**(0.2秒、場面転換)。
**時間**: **スピードランプ**: 0.0–1.0s 通常→1.0–1.5sで**スローモーション(25%)に落とす**(傘を翻す瞬間、水しぶきが止まって見える)→1.5–2.5s で通常へ戻す→2.5–3.5s **ファストモーション(2倍)**で駆け抜け→3.6–4.0s ウィップパン。ランプの山=**1.0秒(傘が翻る拍)**。時間の再マップは proxy tween の t' = f(t)(辞書の時間再マップ参照)。
**光/色**: 夜のネオン(s1と同じ光源の約束)。雨が強まるので、背景が青緑に沈み、ネオンの桃が目立つ。
**効果**: **モーションブラー**(ファースト区間で水平方向)、水しぶきの粒子(seed付き)。
**つなぎ**: 入り=s2の最後(群れの上空)から**ハードカット**し、地上の横移動ショットへ(傘の赤は画面中央から少し左)。出=ウィップパンで**水平方向の流れる色**(桃/橙の線)になって終わる。最後の2フレームは橙〜白に近い明るい帯(s4の朝日へつながる)。
**辞書で読むエントリ**: `time-and-motion/speed-ramp`、`time-and-motion/slow-motion`、`time-and-motion/fast-motion`、`camera-movement/tracking`、`camera-movement/whip-pan`、`time-and-motion/motion-blur`
**固有技法(専売)**: スピードランプ(スロー→通常→ファスト)とウィップパン。

### s4-dawn (120f / 4.0s) — 「雨上がり」
**物語上の役割**: 解放。雨が上がり、夜から朝の光へ。傘を閉じる。**色の変化が「出来事」として1回だけ起きる**。
**カメラ**: サイズ=ミディアム→ロング / アングル=ローから始まりクレーンで上昇 / 動き=**クレーンアップ**(4.0秒、power2.inOut。最後のコマで見える新しい事実=街の向こうの朝焼けの空と、洗われた街並み)。
**光/色**: 開始=夜の青緑(s3と同じ)。**1.5秒の瞬間に雲が割れ、光が差す**。1.5〜2.5秒でカラーシフト(夜の青緑 → **ゴールデンアワーの金・桃**)。以降は金色のリム光(人物の傘の縁)。**変化はこの1回だけ。ずるずる流さない**。
**構図**: 人物は画面左下(三分割線の交点 x=640, y=720 付近)、**ネガティブスペース**(右上の空が広がる)。リードルームは右。
**時間**: 通常(最後の0.5秒だけ静止して余韻)。
**効果**: **ボリュメトリックライト**(雲間から光の筋)、**ライトリーク**(最後に一瞬)、雨粒が光る(最後の雫)。
**文字**: 最後の1秒だけ、画面下に小さく `雨上がり`(Noto Sans JP 700、色 #fffdf5、縁取り黒、48px)。叩きつけず、ふわっとフェード。
**つなぎ**: 入り=s3の最後(橙〜白の流れる光の帯)から、その光が朝の空の明るさに溶けるように始まる(最初の2フレームは橙〜白)。出=黒へ0.3秒フェードアウト(最後の2フレームは純黒)。
**辞書で読むエントリ**: `camera-movement/crane-up`、`color/color-shift`、`lighting/golden-hour`、`lighting/volumetric-light`、`composition/negative-space`、`effects/light-leak`、`composition/rule-of-thirds`
**固有技法(専売)**: 色の変化を出来事にする(カラーシフト)+クレーンアップ+ボリュメトリック。
