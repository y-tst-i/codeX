# NEON ALLEY — 設計書(BIBLE + SCENES + SOUND)

15.000s / 450f / 1920x1080 / 30fps。three.js 1本(proj/index.html)で全場面を描き、場面ごとにグループと照明・環境マップ・カメラを切り替える。
テンポ 120BPM(1拍 = 0.5s = 15f)。場面の境目はすべて拍の上。

## BIBLE(共通ルール)
- 主役: 架空の小型配達ロボ「ポッド」。丸角の箱型ボディ(クローム)、前面に黒いバイザー+ピル型の目2つ(発光)、背中に荷物箱(発光ストライプ)、4輪、短いアンテナ(先端が点滅)。実在キャラに似せない。
- 世界: 雨上がりの路地。濡れた路面 = 鏡(Reflector)+ 粗いアスファルト板(水たまりの所だけ穴)。床への映り込みが全場面の共通言語。
- 色: 場面ごとに一色に振り切る。S1 シアン/青、S2 赤/マゼンタ、S3 橙/琥珀、S4 青×ピンクの二色。白は閃光(場面転換)専用。
- 光: 発光体は emissiveIntensity 4〜10 で Bloom の閾値を超えさせる。奥はボケ(DoF)+霧で霞ませる。粒子(雨・飛沫・火花)で密度を出す。
- 文字: 看板は架空の一般名詞のみ(配達/夜市/営業中/酒場/電気/路地)。ブランド・ロゴ・実績・日付は出さない。タイトルは「NEON ALLEY」のみ。
- 使い回し禁止: 雷は S3 だけ、光の筋(ワープ)は S3→S4 の転換だけ、文字の点灯は S4 だけ、スローは S3 だけ。
- 技術: 時刻 t の純関数 update(t)。乱数は mulberry32。post=fast(DoF+Bloom+色補正)。仕上げに ffmpeg でグレイン。

## SCENES(場面カード)
| 場面 | 時間 | 世界 | サイズ/アングル/動き | 光・色 | 固有技法 | 入り/出 |
|---|---|---|---|---|---|---|
| S1 起動 | 0.0–3.0 (0–89f) | 水たまりの縁 | 超ローアングル、床すれすれのドリーイン。手前に水面の波紋 | シアン/青。奥にネオンのボケ | ラックフォーカス(手前の水滴→ロボ)、目の点灯 1.5s | 入: 黒から / 出: 目のフレア→白 2f |
| S2 疾走 | 3.0–7.0 (90–209f) | 看板の並ぶ路地 | ロー・横移動の追走 → 5.0s で正面へ回り込み、ダッチ | 赤/マゼンタ。看板が流れる | 視差(壁・看板・柱)、車輪の水しぶき | 入: 白から / 出: 箱を踏んで跳ぶ |
| S3 跳躍 | 7.0–10.5 (210–314f) | 雷の落ちる交差点 | 跳躍の頂点でスロー(タイムリマップ)、カメラが90°回り込む | 橙/琥珀。雷の白 | 雷+火花、バレットタイム | 出: 着地→光の筋→白 |
| S4 タイトル | 10.5–15.0 (315–449f) | 巨大ネオン看板の下 | ロボが滑って停止、カメラが引いて上がる。13.6s から完全静止 | 青×ピンク | 文字が1字ずつ点灯(11.2–12.6s) | 最後 1.4s 静止 |

## SOUND(合図表)
- 全体: 120BPM。GM音源(FluidR3)の MIDI + 合成(雨・風・衝撃)+ 同梱SFX。目標 -14 LUFS / -1 dBTP。
- S1: 雨音(ピンクノイズ+水滴)、低いパッド。1.5s 目の起動音(上昇グライド)。2.5s ライザー。3.0s 衝撃。
- S2: キック4つ打ち+スネア+シンセベース+アルペジオ(赤い世界=歪んだのこぎり)。5.0s 回り込みに whoosh。
- S3: 7.0s 跳躍 whoosh → スロー区間はローパスで水中のような音、雷 8.0s(轟音+クラック)。9.8s 着地のしぶき。10.0–10.5 ライザー。
- S4: 10.5s 大きな衝撃+和音。11.2–12.6 文字の点灯ごとにネオンの「ジッ」音。13.6s 最後の和音 → 余韻で静かに終わる。
