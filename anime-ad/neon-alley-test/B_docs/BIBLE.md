# BIBLE — 「NEON ALLEY」15秒(共通ルール)

架空の作品。実在のキャラ・ブランド・ロゴ・実績・受賞・日付は入れない。無料の道具のみ(three.js 0.181.2、HyperFrames、ffmpeg、FluidSynth+無料 SoundFont、Kenney CC0 効果音)。

## 1. 数値の約束(全場面共通)
- 1920×1080、30fps、合計 **450 フレーム = 15.000 秒**。場面長は整数フレームで、拍(BPM 120 → 1拍 = 15f)の倍数。
- 場面の境目(全体フレーム): s1 = 0–89(90f)/ s2 = 90–209(120f)/ s3 = 210–344(135f)/ s4 = 345–449(105f)。合計 90+120+135+105 = 450。
- 場面間は**ハードカットで連結**(フェードやクロスディゾルブで重ねない)。転換の効果(ウィップの流れ・白の閃光)は**各場面の中で描き切る**。
- 各場面の成果物は**無音 mp4**、フレーム数厳守(`ffprobe -count_frames` で確認)。
- 時間の基準は時刻 t だけ(seek 安全)。乱数は seed 付き(`mulberry32`)。rAF・Clock・Math.random を使わない。
- 黒の基準: 一番暗い所は #000000〜#0A0A0A まで沈める(参照画像は黒が深い)。白飛びは s3 末尾の閃光(下の例外)と s4 冒頭の残光だけ。
- 色のついた細線は**幅 4px 以上**(2px 以下は yuv420 で色がずれる)。ネオン管は芯 6〜10px + にじみ。

## 2. 主役(配達ロボット)— 全場面で同じ形(オリジナル)
- **形**: 角を丸めた低い箱型の車体(長さ 0.56m・幅 0.36m・高さ 0.30m、側面から見て縦横比 約 1:2.1)。後ろに大きな車輪2つ(Ø0.22m、黒いゴム+銀のハブ)、前に小さな補助輪1つ。
- **前面**: 横長の細いスリット状ライト1本(0.24×0.03m)= **#E8F4FF**(白に近い青白。全場面で同じ色)。
- **上面**: 荷物のふた(継ぎ目の線)と、ふたの留め具ランプ1個 = **#FFB23E**(琥珀)。後部から細いアンテナ(0.25m、しなる)、先端に同じ琥珀の玉。
- **材質**: 車体 #22252B のつや消し寄りの金属(three: metalness .8 / roughness .35)、縁の面取り #9AA3AE のヘアライン金属(縁に鋭い白いハイライトが走る)。
- **してはいけない形**: 球体の頭・ヘッドホン・顔・目・口・手足・緑の表情ライト(参照画像のキャラに寄る)。ロボットに名前・文字・ロゴを描かない。
- 2D 場面の側面図の基準寸法: 車体 300×142px(s2)。3D 場面は実寸メートルで作る。

## 3. 参照画像(ref/)から取る「水準」— 絵柄・登場物は真似ない
見たもの → この作品での使い方:
- 場面ごとに色を1色系へ**振り切る**(同じ路地が緑/橙/青に丸ごと染まる ref_07・ref_08、赤一色の ref_02、青と黄の ref_01) → 場面ごとに主色を1つ決め、色の変化はカットで起こす(§4)。
- **濡れた床の鏡像**: 光源が床に縦に伸びて映り、像は上の約60%の明るさで少しぼける(ref_07/08) → 全場面の床は濡れ路面(`atmosphere/wet-down`)。
- **にじみ**: ネオン管のまわりに管幅の約2〜3倍の光の輪、画面の明部がふわっと広がる → 2D は glow+`look_pass.sh cinematic`、3D は UnrealBloom。
- **金属の鋭い白いハイライト**(ref_01 の金属の縁、ref_02 の黒い光沢) → ロボットの縁の面取りに細い白の反射を必ず入れる。
- **短い光の筋の粒子**(ref_04/05 の火花は長さ10〜40pxの白〜桃の線)、**白い閃光と放射状の筋**(ref_06 は画面全体が灰白になり中心に白い円) → s3 の火花と s3→s4 の閃光に使う(この2場面だけ)。
- **奥のボケと光の筋**(ref_03 の舞台照明の光芒) → s1 のボケ、s3 の頭上のネオンからの光。
- 再現しないもの: スマホの画面枠・UI・カーソル・ロゴ・漢字の看板・落書き風ロゴ・人物像・球体のキャラ。

## 6. 禁止(例外は §5 の表と下の明記だけ)
- 画面の文字は s4 の「NEON ALLEY」だけ(一字固定・半角大文字・間に半角スペース1つ)。他にコピー・字幕・ロゴを出さない。
- 実在の看板・店名・漢字の看板・実在の街並みを描かない。
- 降っている雨を描かない(**雨上がり**)。水は「濡れた路面・水たまり・軒からの1滴・跳ねた飛沫・宙の水滴」だけ。
- 純白 #FFFFFF の全画面は s3 の 343–344f(全体)だけ。s4 は冒頭の残光(全体 345–356f、345f は平均輝度 85% 以上の白〜クリーム #F4EEE6)で白から琥珀へ戻る。
- 画面揺れは s3 の着地(全体 315–320f、振幅 6px 以下)だけ。
- 3D(three.js)は s3・s4 だけ。s1・s2 は Canvas 2D。
- フレームの外の UI(枠・ボタン・カーソル)、スマホの縦画面の枠を描かない。

## 7. 技術
- 2D 場面(s1・s2): `bash tools/new_scene.sh B/work/<id> <秒> <地の色> --depth` → `draw(t)` だけ書く。書き出し後に `bash tools/look_pass.sh B/out/<id>_raw.mp4 B/out/<id>.mp4 cinematic`(納品は look_pass 後のほう)。
- 3D 場面(s3・s4): `bash tools/new_scene_three.sh B/work/<id> <秒> <地の色> --post fast` → `build()` と `update(t)`。トーンマッピングは Neutral、Bloom は threshold 1.6 / strength .2〜.35 から(three-3d.md §4)。暗部が潰れたら雛形のトーンマッピングを確認する。look_pass はかけない(色の差を保つ)。グレインは ffmpeg `noise=c0s=2:allf=t` で 2D と揃える。
- 3D の床の映り込み: 物体を y 反転で複製して床の下に置き、床を半透明(opacity .55〜.7)+粗さで像をぼかす方法を既定にする(安く、決定的)。`Reflector` を使う場合は seek で一致を確認。
- フォント: 使わない(タイトルはネオン管の一筆書きの線で作る)。
- 素材: 外部モデル・HDRI は使わなくてよい(環境は `RoomEnvironment` を弱く)。使うなら CC0(Poly Haven / ambientCG / Kenney)のみで、出典を CREDITS に書く。

## 8. 使い回し禁止
- 他の場面のコード・部品の見た目(看板の形・粒子・光の帯)を持ち込まない。共通はロボットの寸法と色(§2)だけ。
- 同じショットサイズ・同じ動き・同じ主色を隣り合う場面で続けない(§SCENES の差分表)。

## 9. 検証(各場面)
1. `cd B/work/<id> && npx hyperframes check`(error 0)。
2. `npx hyperframes snapshot --at <カードの合図の時刻>` で合図の拍の絵を確認。
3. 書き出し → `ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames,width,height,r_frame_rate` でフレーム数・1920×1080・30fps。
4. 先頭と末尾のフレームを PNG で出し、カードの「つなぎ」の座標と色(±40px、主色の色相 ±15°)を確認。
