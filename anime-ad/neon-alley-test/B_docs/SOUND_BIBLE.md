# SOUND_BIBLE — 「NEON ALLEY」15秒の音

## 1. 形式と全体
- **44.1kHz**・ステレオ・24bit の wav、長さ **15.000 秒 = 661,500 サンプル**ちょうど(450f と一致)。
- BPM 120(1拍 = 15f = 0.5s)。調は A マイナー、最後(s4 の 390f)だけ A の sus4 → 長三和音に開く。
- 仕上げの音量は `assemble.sh` で **-14 LUFS**(参照は約 -13.7)、トゥルーピーク -1 dBTP 以下。
- 生成スクリプトは決定的(seed 固定)にして `B/audio/make_audio.py` に残す。出力 `B/audio/neon_alley.wav`、合図 `B/audio/cues.json`。
- 道具: 音楽 = `tools/midi_render.py`(FluidSynth+無料 SoundFont。`apt-get update` を先に)、効果音 = `tools/sfx_lib.py`(Kenney CC0。名前は `references/sfx-catalog.md` から実在のものだけ)。有料・ログインの要るサービスは使わない。

## 2. 3層
1. **環境音(空間の地)**: 場面ごとに別(§3)。雨上がりなので「降る雨」の音は使わない(軒の滴・水たまり・遠い街のうなり)。
2. **効果音**: 目に見える動きすべてに付ける(着水・踏む・走行・看板の通過・沈み込み・跳躍・宙の水滴・着地・アーク・点灯・明滅)。
3. **音楽**: 場面ごとに楽器の系統を変える(§3)+ **全編に切れ目のないベッド**。
   - ベッド: GM 89 Warm Pad(A1+E2 の持続)+ GM 33 Fingered Bass の A1 ペダル(拍の頭に軽く)。平均 -27〜-24 dBFS RMS。expression(CC11)で場面の山に合わせて強弱、ほぼ無音の窓で下げる(**ゼロにしない**)。

## 3. 場面ごとの音の世界(隣り合う場面で楽器の系統・空間・帯域を全部変える)
| 場面 | 楽器の系統(音楽) | 環境音 | 主な効果音(実在の名前) | 空間(残響) | 帯域 |
|---|---|---|---|---|---|
| s1 0–89f | 鍵盤打楽器: GM 12 Vibraphone(prog 11)を3音だけ(30・45・60f)、長く伸ばす | 軒の滴の粒(まばら)+遠い街の低いうなり(ピンクノイズを lp 400Hz)| 着水 `drop`、踏む `impactSoft_medium`+帯域ノイズ 300〜3kHz の短い減衰、近づくモーター= GM 126 Helicopter(prog 125)を lp 800Hz で低く | 暗く長い 3.5s | hp 120Hz / lp 5kHz(こもった静けさ) |
| s2 90–209f | バンド: GM ドラム(ch10、キック4つ打ち+スネア2・4+ハイハット8分)+ GM 39 Synth Bass 1(prog 38)の16分 | 路地を切る風(ピンクノイズを 200〜3kHz で絞り、速さでうねらせる)+走行音(濡れた路面のゴロゴロ= lp 600Hz のノイズ)| 看板の通過= ネオンの唸り(下の合成)を毎拍ドップラーで通過、沈み込み `creak`+`impactMetal_light`、跳躍 `impactSoft_heavy`+`cloth` | 乾いた部屋 0.3s | hp 40Hz / 全帯域(一番明るい) |
| s3 210–344f | 声と弦: GM 49 String Ensemble 1(prog 48)のトレモロ + GM 53 Choir Aahs(prog 52)の持続、閃光前に GM 120 Reverse Cymbal(prog 119) | 静止中は環境音を切り、高い合唱の1音だけ残す | 宙の水滴= `glass` を低く・ピッチ下げ、着地 `impactPlate_heavy`+サブ 45Hz(減衰 300ms)、アーク `glitch`+`impactGlass_light`、火花のはぜ `impactGlass_light` を細かく | 大きなホール 4.5s(静止中は lp 2kHz で遠く)| hp 60Hz / lp 12kHz |
| s4 345–449f | 金管と太鼓: GM 48 Timpani(prog 47)のロール(345〜390f)+ GM 63 Synth Brass 1(prog 62)の一撃(390f、A sus4→A) | ネオン管の唸り(合成、点灯した管の数に比例して少しずつ厚く)| 点灯 `switch`(5回、左右に振る)、アンテナの明滅 `pluck` | 暖かいプレート 2.2s | hp 50Hz / lp 9kHz(暖色) |
- 楽器・音色の種類: Warm Pad・Fingered Bass・Vibraphone・Helicopter(機械音の代用)・ドラム・Synth Bass・String Ensemble・Choir・Reverse Cymbal・Timpani・Synth Brass = **11種**(15秒の目標 8種以上)。
- 合成音は「街のうなり・風・走行音・ネオンの唸り・サブ」に限る。全体の**3割以下**。ネオンの唸り= 120Hz のノコギリ波を bp 200〜2kHz で絞り、ゆらぎ(seed 付き)を加えたもの。
- **使わない**: 純音のピン、サイン波のスイープ(ピューン)、白色ノイズの雨。(使用回数 0 を目標。どうしても使う場合も1本で最大2回、実音と重ねる)
- 定番の「ピアノと弦の汎用スコア」にしない。ピアノは使わない。

- 緩急: s2 で加速、s3 の 250f で減速(はっきり1回)、s3 の静止が息継ぎ。

## 5. 自己検証(数値で。Claude は音を聴けないので最終判断は人の耳)
1. 長さ 661,500 サンプル・44,100Hz を確認。
2. 合図ごとに前後 100ms の RMS 比(山の合図は +6dB 以上)。`B/audio/cues.json` を作り、結合後に `python3 tools/sync_check.py` で映像の閃光(82f・343f)と音の立ち上がりを突き合わせる。
3. 場面ごとのスペクトル重心と高域比が4場面で互いに違う(s2 が最も高く、s1 が最も低い想定)。
4. ほぼ無音の窓3か所の RMS が範囲内。純音ピン・サインスイープ・白色ノイズの使用回数 0。
5. `ffmpeg -lavfi showspectrumpic` のスペクトログラムを1枚出して、場面の境目で質感が変わっているか見る。
