# SCENES — 「NEON ALLEY」場面カード

全体: 450f / 30fps / BPM 120(1拍 = 15f)。フレーム番号は**全体フレーム**(場面内のフレームは「局所 f」と書く)。座標は 1920×1080 の px。
映画のリズム: **静(水滴)→ 疾走(赤)→ ★無重力と閃光(青)→ ★点灯と静止(琥珀)**。
見せ場: ★ **s3**(3D・effort high)と ★ **s4**(タイトル・3D・effort high)。s1・s2 は Canvas 2D+`--depth`+`look_pass.sh cinematic`(effort medium)。

## 隣り合う場面の差分(5軸のうち3つ以上)
| つなぎ | サイズ | 動き | 光 | 色 | つなぎ方 | 変わる軸 |
|---|---|---|---|---|---|---|
| s1→s2 | マクロ超接写 → 側面のミディアム | ゆっくりの寄り → 高速の横追い | 上からの柔らかい看板光 → 横を通り過ぎる硬い光 | ティール → 赤 | ウィップパン(流れの方向と光の筋を一致) | 5 |
| s2→s3 | ミディアム側面 → 下からのフルショット | 横追い → 半周の回り込み | 横の硬い光 → 頭上の管からの逆光・縁光 | 赤 → 青 | アクションつなぎ(跳躍の上昇) | 5 |
| s3→s4 | フル → 正面の引き | 回り込み → ほぼ固定(わずかな寄り→完全静止) | 逆光 → 正面のネオン(タイトルが光源) | 青 → 琥珀 | 白の閃光(ショートの火花が原因) | 5 |

### s1 (3.0s / 90f, 全体 0–89) — 「水たまりの中の夜」
**物語上の役割**: 静けさの中で、雨上がりの路地の「濡れた夜」を一滴で見せ、遠くから何かが来る予感を作る。次の s2 の疾走と対比(静↔動)。
**世界**: 雨上がりの路地の水たまり、深夜、無風、ティール一色。
**カメラ**
  - サイズ: マクロの超接写(水面から高さ約3cm)。根拠: 水たまりに映る街=この世界が濡れていることを、一滴の波紋で見せる。
  - アングル: 水面を 10° 見下ろす。
  - 動き: スロープッシュイン(`scale 1.00→1.06`、0–82f、sine.inOut)。終了構図で新しい事実=**ピントの奥に、近づいてくる白い横長の光(ロボットの前面ライト)**。84–89f は左向きのウィップパン(つなぎ)。
  - レンズ感: マクロ(極薄の被写界深度)。
**光**: 光源=画面外 左上のティールの看板(水面に逆さに映る)。キー側=左上、硬さ=軟、色温度=寒色(ティール)。コントラスト=高(地は #03161A)。最も明るい読めるもの= 0–60f は水滴と波紋のハイライト、60f 以降はロボットのライト #E8F4FF。
**色**: #03161A(地)/ #00D2C8(看板の映り込み)/ #FF3FA4(遠いボケ玉 2〜3個)/ #E8F4FF(ライト)/ #0B3A3F(水面の中間)。色の出来事は無し(ティールで通す)。
**構図**: 水面が y 380–1080 を占め、上 0–380 は遠い路地(ボケ)。看板の逆さの像(読めない横棒3本と円弧1つ)を (620,760) 付近に。視線: 落ちる水滴(上中央)→ 着水点 (960,640) → 右奥の光 (1500,410) → 右から入る車輪。
**時間**: 通常。水滴の落下(18–30f)は通常速度。
**効果**: ラックフォーカス=ピント面が水滴の層(0–45f)→ 奥の路地の層(45–66f、sine.inOut)へ送られる。ボケ玉=奥の看板の点光源が絞り開放でにじむ(半径 40〜120px、マゼンタとティール)。波紋の屈折=水面の輪が映り込みを押し広げる(`feDisplacementMap` 相当、強さ 12〜20)。ウィップのブラー=カメラが左へ振られる。
**動きの段取り**
  - 18–30f: 軒からの一滴が y −20 → (960,640) へ落下(重力。最後に伸びる)。
  - 30f: 着水。小さな王冠(高さ 40px)+波紋の輪 3本が半径 0→520px(30–75f、power2.out)、映り込みが揺れる。
  - 45–66f: ピント送り。奥 (1500,410) に白い横長の光(幅 40px)がくっきり現れ、近づいて幅 40→160px(60–80f)。
  - 76–82f: 右端から黒いタイヤ(半径 260px、銀のハブ)が手前に入り、82f に (1180,700) で水たまりを踏む → 飛沫が左上へ(粒 60〜90個、長さ 6〜24px、ティールを反射)。ライトは (1300,600)。
  - 84–89f: 画面全体を左へウィップ(x 方向ブラー bx 0→90、power4.in)。89f(最終フレーム)= 画面全体が横の筋。ライトの白い筋が **y=600、x 300–1700、太さ 10px、#E8F4FF**。地の筋はティール #00D2C8 と #03161A。
**つなぎ**: 入り=作品の冒頭。0f は地 #03161A に看板の映り込みがかすかに(全体の平均輝度 8% 以下)。出=89f の横の筋(上記)を s2 の 90f に渡す。
**合図(cue)**: 0.000 / 1.000(30f 着水)/ 1.500(45f ピント送り開始)/ 2.000(60f 光がくっきり)/ 2.733(82f 水たまりを踏む)/ 2.800(84f ウィップ開始)
**コピー(一字固定)**: なし
**固有技法(この場面だけの専売)**: マクロ+ラックフォーカス、大きなボケ玉、ウィップパン(出のみ)。
**禁止**: 降る雨、文字、ロボットの全身(タイヤとライトだけ)、赤・青・琥珀の主色、画面揺れ。

### s2 (4.0s / 120f, 全体 90–209) — 「赤い路地を走る」
**物語上の役割**: ロボットの正体と速さを見せる。s1 の静けさを破る勢いの場面。最後に跳んで s3 の山へ渡す。
**世界**: 狭い路地(両側の壁に読めないネオンの記号)、深夜、赤一色。
**カメラ**
  - サイズ: ミディアム(ロボットの全身+上下に路地)。根拠: 初めてロボットの全身の形と走りを見せる。
  - アングル: ロボットの高さ(地面から 0.3m)の水平。わずかなローアングル(5°見上げ)。
  - 動き: トラッキング(横移動の追い撮り)。ロボットを x=760(画面の40%)に固定し、背景を左へ流す。195f 以降はロボットがカメラを追い越して右上へ抜ける。終了構図で新しい事実=**ロボットが地面を離れ、宙に出る**。
  - レンズ感: 標準(視差で奥行きを出す)。
**光**: 光源=通り過ぎる壁の赤い看板(拍ごとに1枚、105・120・135・150・165・180f に画面中央を通過)。キー側=左上(看板)、硬さ=硬、色温度=赤。縁光=背後の橙 #FF6A1F。看板が通るたびに赤い光の帯がロボットの車体を左→右へ横切る(4f)。最も明るい読めるもの=前面ライト #E8F4FF と看板の芯。
**色**: #14030A(地)/ #FF2A3D(看板)/ #FF6A1F(縁光)/ #3A0A12(壁)/ #E8F4FF(ライト)。色の出来事: 90f のカットで赤へ(切り替わりそのものが出来事)。
**構図**: 路面の線 y=780(車輪の接地)。ロボット車体の中心 (760,640)、車体 300×142px、前面は右(進行方向)。前面ライトは (905,600)。前方(右)にリードルーム 1010px。層: 手前の柱(1.33倍・強いブラー)/ 壁と看板(1.0倍)/ 奥の街の光(0.375倍)/ 濡れた路面の映り込み(看板の縦の光の筋)。
**時間**: 通常。跳躍の予備動作(190–194f で車体が 12px 沈む)と跳躍(195f)。
**効果**: モーションブラー=シャッター角 270° で、層の速度に比例(壁 2400px/s → bx ≈ 0.045·速度 で上限 90)。路面の光の筋=濡れた路面に映る看板が縦に伸びて流れる。`--depth` の粒・接地影(車体の下、楕円 260×24px)・霞(奥の層を地の色へ 40% 寄せる)。
**動きの段取り**
  - 90–95f: s1 から続く左向きのウィップの流れが止まる(bx 90→0、power4.out)。95f でロボットの側面がくっきり。
  - 95–189f: 走行。車輪の回転、車体の上下 2px(周期 10f)、アンテナが後ろへしなる(角度 −25°±5°)。
  - 190–194f: 沈み込み(予備動作)。195f: 跳躍。195–209f でロボットの中心が (760,640) → (1320,420)、車体が −12°(前が上)に傾く。カメラは追いつけず、ロボットが右上へ抜けていく。
  - 209f(最終フレーム): ロボット中心 **(1320,420)**、傾き −12°、速度 右上(vx +600、vy −900 px/s)。車輪の下から飛沫が後ろへ(粒 20個)。赤の看板が左端 (180,300) に。
**つなぎ**: 入り=s1 89f の横の筋(ライトの白い筋 y=600)を、90f で同じ y=600 の筋として受け、95f までにロボットの前面ライト (905,600) に収束させる(流れの方向=左、両側で同じ)。出=209f の上昇するロボット (1320,420)、右上へ向かう動きを s3 の 210f に渡す(アクションつなぎ)。
**合図(cue)**: 3.000(90f カット・ドラム頭)/ 3.500・4.000・4.500・5.000・5.500・6.000(看板の通過 105〜180f、毎拍)/ 6.333(190f 沈み込み)/ 6.500(195f 跳躍)/ 6.667(200f 次の場面の合唱が先に入る=Jカット)
**コピー(一字固定)**: なし(看板は読めない記号)
**固有技法(この場面だけの専売)**: トラッキング+多層の視差(0.375/1/1.33)+モーションブラー。
**禁止**: 文字、ボケ玉(半径 12px 超)、白い閃光、画面揺れ、青・ティール・琥珀の主色(ロボットの留め具ランプ・アンテナの玉 #FFB23E は可)。

### ★見せ場 s3 (4.5s / 135f, 全体 210–344) — 「宙で止まる、そして閃光」 [three.js 3D・effort high]
**物語上の役割**: 作品の山。跳んだロボットのまわりで時間が止まり、カメラだけが回り込んでこの路地の全体(頭上のネオン)を見せる。着地の直後、頭上の管がショートして白に飛び、タイトルへ渡す。
**世界**: 路地の交差点、頭上に平行に張られたネオン管7本(青 #2D6BFF と紫 #8A4DFF が交互、地上 4.5m、長さ 6m)、床は大きな水たまり(幅 3.2m)。深夜、青一色。
**カメラ**
  - サイズ: フルショット(ロボットの全身+水たまり+頭上の管)。
  - アングル: 開始は低い(カメラ高 0.4m、見上げ 20°)→ 終わりは 1.2m(見上げ 8°)。
  - 動き: 半周の回り込み(オービット 180°)。半径 2.2m、方位 −40°(前左 3/4)→ +140°(後ろ右)、局所 0–105f、sine.inOut。カメラの時間は**スピードランプの影響を受けない**(止まった時間の中をカメラだけが動く)。終了構図で新しい事実=**ロボットの背中越しに、頭上の管の1本(画面 (1100,180) 付近)がちらついている**。
  - レンズ感: 広角(24mm 相当、FOV 縦 50°)。床の映り込みが大きく見える距離。
**光**: 光源=頭上のネオン管7本(emissive 4〜6、上からの逆光)。キー側=上・奥、硬さ=中(管が長いので柔らかめの影)、色温度=寒色。縁光=紫。フィル=ロボット手前に弱い冷たい点光源(車体が真っ黒に潰れないように、three-3d.md §6)。最も明るい読めるもの=ロボットの前面ライトと、宙に止まった水滴の反射。
**色**: #03061A(地)/ #2D6BFF(管・主)/ #8A4DFF(管・縁光)/ #7FE3FF(水滴の反射)/ #FFFFFF(火花と閃光のみ)。色の出来事: 210f のカットで青へ。339f からの白。
**構図**: 210f(局所0)= ロボット中心 **(1240,470)**、前が上へ 15° 傾き、車体の幅約 420px、右上へ上昇中。床の映り込みが下 1/3。視線: ロボット → 宙の水滴 → 頭上の管 → (着地後)ちらつく1本 → 火花。
**時間**(ロボット・水滴・火花の時間 = 率 r):
  - 局所 0–40f(全体 210–250): r=1.0。ロボットは放物線で上昇(頂点 床上 1.4m、水平距離 3.2m で水たまりを越える)。
  - 局所 40–52f(全体 250–262): r 1.0→0.06(滑らかに)。
  - 局所 52–75f(全体 262–285): **ほぼ静止**(r=0.06)。頂点付近で水滴約300粒が宙に浮き、カメラだけが回る。
  - 局所 75–85f(全体 285–295): r 0.06→1.0。
  - 局所 105f(全体 315): 着地(水たまりの縁)。飛沫の王冠、車体のサスペンションが 4cm 沈む。画面揺れ 315–320f、振幅 6px 以下。
**効果**: スピードランプ/静止=時間だけが止まる演出(カメラは等速)。宙の水滴=跳躍で跳ね上げた水が管の光を反射(小さな球、InstancedMesh)。ショート=頭上の管の1本の継ぎ目が火を噴く(物理的原因)。火花=長さ 10〜40px・幅 4px 以上の白〜桃の線(325–339f、上から床へ落ち、床で跳ねる)。アーク=327・331・335f に管が瞬間的に白く光る(各 1f)。閃光=アークが広がって画面が白へ(339f から opacity 0→1 を 3f、power1.in。**343–344f は全画面 #FFFFFF**)。閃光の中に放射状の白い筋(中心 (960,500)、20〜30本)。DoF は背景をなじませる程度(maxCoc 10、ボケ玉にしない)。Bloom は管と火花に。
**つなぎ**: 入り=s2 209f のロボット (1320,420)・右上へ上昇を、210f の (1240,470)・上昇で受ける(同じ跳躍の続き。色は赤→青が出来事)。出=344f の全画面 #FFFFFF(中心 (960,500) に放射の筋の名残)を s4 の 345f に渡す。
**合図(cue)**: 7.000(210f カット・青の一撃)/ 8.333(250f 減速開始)/ 8.733(262f 静止=ほぼ無音の始まり)/ 9.500(285f 時間が戻る)/ 10.500(315f 着地)/ 10.900・11.033・11.167(327・331・335f アーク)/ 11.300(339f 閃光の立ち上がり)/ 11.433(343f 全白)
**コピー(一字固定)**: なし
**固有技法(この場面だけの専売)**: 半周オービット+スピードランプ(バレットタイム)、火花の粒子、白の閃光。
**禁止**: 文字、赤・ティール・琥珀の主色、ボケ玉、ウィップ、横の追い撮り、球体の頭やヘッドホンの形(§BIBLE 2)、GlitchPass・AfterimagePass・TAA。

### ★見せ場 s4 (3.5s / 105f, 全体 345–449) — 「NEON ALLEY が灯る」 [three.js 3D・effort high]
**物語上の役割**: タイトル。白から戻ると、路地の突き当たりの壁にネオン管の文字が灯り、ロボットがそれを見上げて止まる。最後は静止して終わる。
**世界**: 路地の突き当たり、れんがとコンクリートの壁、濡れた床、深夜、琥珀一色。
**カメラ**
  - サイズ: 正面の引き(ロング)。文字が横幅の約73%。
  - アングル: 水平(カメラ高 1.0m)。
  - 動き: ゆっくりのドリーイン(距離 2% 寄る、局所 0–75f、sine.out)→ 局所 75–104f(全体 420–449)は**完全に静止**(カメラも物も粒も動かない。管のちらつきも止める)。終了構図で新しい事実=**灯った「NEON ALLEY」と、それを見上げるロボット**。
  - レンズ感: 標準(35mm 相当、FOV 縦 34°)。
**光**: 光源=タイトルの管そのもの(emissive 6、点灯後)。キー側=正面上(文字)、硬さ=中、色温度=暖(琥珀)。ロボットは文字側(左上)から琥珀の光を受け、縁に白い細いハイライト。最も明るい読めるもの=文字の芯 #FFE3B0。
**色**: #120803(地)/ #FF8A1F(管)/ #FFE3B0(管の芯)/ #2A1408(壁)/ #FF3F7F(下線の管1本だけ)。色の出来事: 345–356f の白からの戻り(残光)、390f の全点灯。
**構図**: 文字「NEON ALLEY」= x 260–1660、高さ 180px(y 380–560、中心 y 470)、NEON と ALLEY の間 90px。一筆書きの丸い管(太さ 10px の芯+にじみ)、管の支持金具と配線を壁に。下線(桃)= y 610、x 700–1220。床の水平線 y≈660、床に文字の映り込み(y 700–1000、明るさ約60%、縦にぼける)。ロボット= 中心 **(1480,840)**、車体幅約 200px、前左向きの 3/4(文字を見上げる。前面ライトは左を向く)。視線: 中心の白の名残 → 中央から外へ灯る文字 → 下線 → 右下のロボット。
**時間**: 通常。点灯は中央から外へ、2文字ずつ(各点灯は「点く 1f → 消える 1f → 点く」):
  - 360f: NEON の N(4文字目)+ ALLEY の A / 364f: O + L / 368f: E + L / 372f: NEON の N(1文字目)+ E / 376f: Y。
  - 390f: 全点灯の山(emissive 4→8→6、下線の桃が灯る)。
  - 405f: ロボットのアンテナの玉が1回明滅、前面ライトが一段明るく(反応)。
  - 420–449f: 完全な静止画(30f)。
**効果**: 白の残光=s3 の閃光で露出が飛んだ目が戻る(exposure 3.0→1.0、345–356f、power2.out。345f は平均輝度 85% 以上の白〜クリーム #F4EEE6、356f で地の色)。中央 (960,500) の白の名残が、最初に灯る2文字の光になる。ネオンの点灯=管に電気が入る(ちらつきは点灯の瞬間だけ)。床の映り込み=濡れた床。Bloom は管だけ。DoF は壁にピント(ボケ玉にしない)。
**つなぎ**: 入り=s3 344f の全画面 #FFFFFF と中心 (960,500) の放射の名残を、345f の白〜クリームの画面で受け、中心から琥珀の文字へ収束させる。出=作品の終わり(449f は 420f と同じ静止画)。
**合図(cue)**: 11.500(345f 白からの戻り・低い一撃)/ 12.000・12.133・12.267・12.400・12.533(360〜376f 点灯)/ 13.000(390f 全点灯の山)/ 13.500(405f アンテナの明滅)/ 14.000(420f 静止の始まり=ほぼ無音)/ 15.000(終わり)
**コピー(一字固定)**: `NEON ALLEY`(半角大文字、間に半角スペース1つ。他の文字は一切出さない)
**固有技法(この場面だけの専売)**: ネオン管の点灯+空間の中の文字(壁に取り付けた物体としての文字)、最後の完全静止。
**禁止**: 文字の追加(サブタイトル・日付・ロゴ・クレジット)、青・赤・ティールの主色、火花、オービット、画面揺れ、ボケ玉、最後の 30f に動くもの。
