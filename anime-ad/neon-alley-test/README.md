# スキルあり vs なし(NEON ALLEY 15秒、2026-10-07)— 結果: スキルなしが勝った
同じ依頼(`BRIEF.md`)・同じ手本の画像(ウェブ上の3D体験の画面録画8コマ。第三者の素材のためこのリポジトリには入れていない)で、2本を名前伏せ(X/Y)で作り、利用者が判定。
- **A(スキルなし)**: 担当1人(general-purpose, Opus, high)が設計・映像・音・結合まで通しで。
- **B(スキルあり)**: スキルの手順どおり。設計1人 → 場面4人(2D×2 medium、3D×2 high)+音1人(medium)。進行役が結合。
結果: 利用者の判定は **Y = A(スキルなし)**。「どう見ても Y」。X=B。鍵は `BLIND_KEY_skilltest.json`。
| | A(スキルなし) | B(スキルあり) |
|---|---|---|
| トークン | 約23万 | 約85万(設計14.6・場面1 9.7・場面2 10.1・場面3 22.6・場面4 17.8・音 10.0 万) |
| 映像の作り | 4場面すべて three.js 3D(映り込み・ボケ・ブルーム) | 場面1・2は Canvas 2D+後処理、場面3・4が3D |
| 書き出し後の容量(同じ設定で再書き出し) | 約23MB | 約13MB(細部・動きの情報量が A のほうが多い) |
考えられる原因(未検証の仮説): ①スキルの「3Dは見せ場だけ」「節約」のルールが質を下げた ②担当ごとの分業で全体のまとまりが弱い ③エフォートの違い(A=high、B の一部=medium)。
注意: 1回・1人の判定。動画ファイルは大きいため保存していない(再現は BRIEF と手本で)。
