# ISLAND 7｜TikTok用ティーザー動画

縦型（1080×1920・30fps・30秒）の、ナレーション・BGM・効果音付きモーショングラフィックス。
映像・音楽・効果音・ナレーションは、すべて `make_tiktok.py` のコードから合成しています。

- 完成動画：`out/island7_tiktok.mp4`
- カバー画像：`out/cover.jpg`

## 構成（バズを狙った設計）

| 秒 | シーン | セリフ | 狙い |
|---|---|---|---|
| 0.0〜3.8 | フック | 「7日後、この島に最大級の嵐が来る。」 | 1フレーム目から大きな文字と衝撃音で指を止める |
| 3.8〜7.5 | カウントダウン | 「残された時間は、たった6日間。」 | DAY 1→6の数字送りで緊張感を出す |
| 7.5〜12.2 | 3つの行動 | 「やれることは3つだけ。探索。整備。設置。」 | ビートに合わせてカードが飛び込むテンポ感 |
| 12.2〜16.9 | 4つの能力 | 「防護、排水、アクセス、ライフライン。島を育てろ！」 | レベルアップ音と一緒にLv.7 MAXまで上がる快感 |
| 16.9〜21.6 | 台風上陸（ドロップ） | 「そして7日目。超大型台風が上陸する。」 | 直前の無音からビートが落ちる。画面揺れと島HPの急減 |
| 21.6〜25.3 | 問いかけ | 「あなたなら何を守る？コメントで教えて！」 | コメントを促してエンゲージメントを稼ぐ |
| 25.3〜30.0 | ロゴ | 「アイランドセブン。チームで、生き延びろ。」 | タイトルを記憶に残す。冒頭のコピーで締めてループ視聴を誘う |

- BGM：128BPMのEDM系（キック・クラップ・808ベース・アルペジオ・パッド）。シーンの切れ目は2拍単位で揃えてあります
- 音圧：約-14.5 LUFS（TikTokの音量正規化の目安付近）
- 字幕：音を出さずに見る人向けに、画面下にセリフの字幕を表示（TikTokのUIに隠れない位置）
- ナレーション：オフラインの日本語音声合成（Open JTalk）を使用

## 再生成

```bash
pip install numpy pillow imageio-ffmpeg pyopenjtalk-plus
python3 promo/tiktok/make_tiktok.py            # 動画を書き出す（4コアで約1分）
python3 promo/tiktok/make_tiktok.py --preview  # 確認用の静止画シートと音声だけ
```

セリフは `SCENES`（画面に出す文字と読み上げ文の組）を変えるだけで差し替えられ、シーンの長さはセリフの長さから自動で決まります。
