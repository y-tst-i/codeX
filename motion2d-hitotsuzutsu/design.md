# 設計メモ: 「ひとつずつ」紹介(架空のアプリ)

- 15.000 秒 / 450 コマ / 1920x1080 / 30 fps / ループなし / 96 BPM(1 拍 = 0.625 秒 = 18.75 コマ)
- 本体: `hitotsuzutsu.html`(Canvas 2D 1 枚、`window.renderAt(t)`、`?t=` で止める、`__ready`)
- 書き出し: `node render.cjs frames` → `work/frames/*.png` → ffmpeg → `work/video_only.mp4`
- 伝えたいこと: やることを 1 つ片づけると、カード → 数 → 週のグラフ → 名前へと結果がつながっていく。静かで、紙のような手触り。

一度に主役の動きは 1 つ: カード登場 → 選択 → 拡大 → チェック ×3 → 大チェック → 戻り → 数 → 窓 → 棒 → タイトル → アイコン の順で、重なるのは脇役(カーソルの移動、チェック欄の遅れ、数の遅れ)だけ。各動きの後に 0.05〜0.6 秒の間。

| 役 | hex | 使う所 |

| 地 BG | `#F3EFE6` | 一覧・詳細の背景(+ 種つき乱数で焼いたごく弱い紙目) |
| 紙 PAPER | `#FCFAF5` | カード・詳細画面・週の画面とタイトルの地 |
| 文字 INK | `#2B2824` | 見出し・タスク名・カーソル・「できた」ボタン・区切り線 |

| 差し色 ACC | `#2E6A4E` | **チェックとグラフだけ**(チェック欄・ステップのチェックと線・窓の輪・棒・チェックのアイコン) |

禁止したもの: 紫や青のグラデーション、光の玉・ブルーム・ネオン・レンズフレア、飾りの粒、暗い背景、作った実績や数字(人数・受賞・日付・価格は無し。グラフは単位なしの架空の値)。

## 文字
- フォント: このマシンの `IPAPGothic`(IPA P ゴシック。太字は Chrome の合成)。外部 CDN なし。
- 大きさ: タイトル 250 px、見出し 60 px、タスク名 48 px(詳細 100 px)、ステップ名 36 px、補助 30 px 以上、「架空のアプリ」28 px(全コマ右下、地の色の札の上)。
- 読んでいる最中の文字は動かさない(動くのは登場・退場の間だけ)。

## 動きの約束
- イージングの系統: kit の多項式の曲線(cubic の ease-in-out / ease-out / ease-in、タイトルだけ #005 の quintic ease-out)に統一。行き過ぎは、ギャラリーが指定した所だけ(#002 の backOut 2.6、#002/#001 の spring)。
- 距離の換算: デモのカード(幅 146 px)→ この作品のカード(幅 520 px)で ×3.4(#081)、グラフとタイトルは ×2.8(#002 の棒の幅 44 → 123 px、#005 の上がり 120 → 336 px)。時間・遅れ・イージングは元のまま。
- 拍: 主な打点(全カード着地・選択クリック・チェック 3 回・大チェック・数の入れ替わり開始・窓の開始・今日の棒の着地・タイトル・アイコン)を拍に置いた。タイトルは quintic ease-out なので 12.55 秒(拍 20)で 97% まで上がり、完全に止まるのは 12.875 秒。
