# 動き → Motion Prompt ID 対応表

ギャラリー: https://showheyohtaki.github.io/motion-prompt/ (catalog version 1.495bd9fdec、168 個)。`search` / `list` で候補を探し、`get` / `kit` で取ったコード(`work/gallery/`)をもとに移植した。移植の仕方は porting.md §3「数値を移す」: デモの絵(写真・ブラウザの窓など)はこの作品の内容に置き換え、時間・遅れ・イージング・行き過ぎ・順番はコードの値のまま。距離はカードの倍率(×3.4 / ×2.8)で換算。`hitotsuzutsu.html` の中に kit motion と kit lp2 のライセンス行と、使った道具の抜粋(式は kit のまま。lp2 の path/click だけ周期での折り返しを外した)を残し、各ブロックに出典 ID を書いた。

## ギャラリー由来の割合
- 数え方: 依頼書の範囲で「意図して入れた動き」を、場面の拍ごとに 1 件と数える(同じ ID の再使用も 1 件ずつ。ただし同じ場面で同じ動きを繰り返すもの — ③ のステップ 3 回・② の 2 枚のホバー — は 1 件にまとめる)。0 コマ目の構図・静止・カーソルの移動そのものは数えない。
- 対象 15 件: カード登場(#002)/ 寄り(自作)/ ホバー(#081)/ 波紋(#085)/ 拡大(#161)/ ステップのチェック(#068)/ 大チェック(#160)/ 戻り(#161)/ 数の入れ替わり(#164)/ 円の窓(#017)/ 棒の伸び(#002)/ 棒の退場(#002)/ 見出し・曜日の退場(自作)/ タイトル(#005)/ アイコン(#001)。
- **ギャラリー由来 13 / 15 = 87%**(自作 2: 寄り、見出し・曜日の退場)。使った ID は 11 個: #001, #002, #005, #017, #068, #081, #085, #160, #161, #164(#002 と #161 は 2 回)。
- 目標の 7〜8 割より高いのは、UI の場面の多くにちょうど合う要素があったため。数を増やすための飾りは足していない。
