# PC の Claude Code への依頼(Audio Studio で「水晶の空」の曲を3案生成する)

あなた(PC の Claude Code)への依頼です。読み手は初心者です。日本語で、専門用語を避けて、短く報告してください。

## 先に読む
1. `docs/crystal-sky/BRIEF_MUSIC.md`(曲の仕様。形・音楽の条件)。
2. `docs/sound-upgrade/PC_AUDIO_STUDIO_TASK.md` と `docs/sound-upgrade/audio_studio_pc/REPORT.md`(前回の依頼と、わかったこと: メモリ・やり方・つまずき)。**正解表(`answer_key/`)は開かない。**
前回の経験: ①15秒ちょうどで生成すると、終盤が無音になりやすい → **26〜30秒で生成して、先頭の20.0秒を切る**(最後は、切るときに短く自然に減衰させる。突然の無音にしない)。②メモリが足りない時がある → 1案ずつ生成し、1案ごとにモデルを解放。空きメモリが足りなければ、他のアプリを閉じる/再起動を、先に利用者に伝える。③小型モデルは調が指定どおりにならないことがある。

## やること
1. 環境の確認(モデル名・CPU・生成時間・空きメモリ)。**再インストール・再ダウンロードはしない。複数のモデルを同時に起動しない。**
2. **曲を3案、生成する**(各 20.0 秒、96 BPM 狙い、インストゥルメンタル、壮大なファンタジー・オーケストラ。仕様は BRIEF_MUSIC.md)。方向性を変える:
   - E1: 荘厳(弦と合唱が中心、ゆっくり大きく盛り上がる)
   - E2: 冒険的(ホルンとブラスが主旋律、リズミカルな弦の刻み)
   - E3: 神秘的(ハープ、ベル、合唱のパッドが中心、静かに広がる)
   各案のプロンプト・シード・モデル・生成時間を記録する。同じプロンプトで2回作って、良さそうな方を残してもよい(負荷が大きければ1回)。
3. 数値の検査(PC の Python があれば。無ければ省略可): 長さ、テンポ、音量(LUFS)、ピーク、100ミリ秒ごとの音量が曲の中央値から -15 dB 以上落ちる窓の有無、最後の減衰の様子。**聴けないので、聴感の評価は書かない。**
4. 置き場所: リポジトリの `docs/crystal-sky/audio_studio_pc/`(新しいフォルダ)に、`E1.wav`〜`E3.wav`、`generation_log.json`、`REPORT.md`(確認事項・数値・つまずき)。大きな物(モデル・キャッシュ)は入れない。push できない場合は、置き場所のパスを利用者に伝える(利用者が GitHub の画面からアップロードする)。
