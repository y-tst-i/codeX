# 「水晶の空」20秒 — MIDI 版の曲 2 案(M1 荘厳 / M2 冒険的)報告

仕様: `docs/crystal-sky/BRIEF_MUSIC.md`。作り方: MIDI + FluidSynth 2.x + MuseScore General(`MuseScore_General_Full.sf2`)。道具は `claude-video-skill/sound-kit/tools/`(`midi_render.py` で鳴らす、`assemble.sh` の2回通し loudnorm)と `claude-video-skill/tools/audio_measure.py`。無料の道具だけ。旋律は今回新しく書いたもの(既存曲の引用なし)。

**試聴について: AI は音を聴けないため、誰も聴いていない(未試聴)。下の「測定値」は機械で測った数字だけで、聞こえ方の良し悪しは判定していない。** 選ぶのは利用者の耳(ブリーフの評価①〜④)。

## 設計(作り手の意図。聞こえ方の確認ではない)
共通: 96 BPM・4拍子・8 小節(1 小節 2.5 秒)。小節 1〜4 は短調、10.000 秒(小節 5 の頭)で同じ主音の長調/平行調の長調へ。小節 4 の後半は弦・合唱・ホルンの表情(CC11)を少し引き、ティンパニのロールは 9.69 秒で止めて「ためる」。10.000 秒にティンパニ+大太鼓+シンバル+金管+全員の和音。小節 7〜8 は主和音を長くのばし、表情を下げて自然に減衰(最後の 0.6 秒だけ残響の尾を 0 に閉じる。14 秒からのフェードはしない)。残響は1種類(1曲として通す)。

### 測定値の読み方(注意)
- **0〜17.9 秒(M1)/0〜18.5 秒(M2)は、RMS の最小が中央値から -15 dB 以内**(途切れの目安を満たす)。それより後は、意図した最後の和音の減衰(余韻)で下回る。曲の途中で -15 dB を下回る窓はない。19.7 秒以降の -60 dBFS 未満は、残響の尾を 0 に閉じる最後の 0.6 秒(19.4 秒〜)の後半。
- 一撃の +6.4 ms は FluidSynth の音の立ち上がり(音符は 10.000 秒ちょうどに置いた)。60 fps の 1 コマ(16.7 ms)より小さい。`audio_measure.py` の「頂点のずれ」(M1 +19.3 ms / M2 +15.3 ms)は、探す範囲(-10〜+20 ms)の中で振幅がまだ上がり続けている(大太鼓とティンパニの山が少し後)ことを示すもので、頭の位置ではない。
- `audio_measure.py` の「飛び出す」(下地より 3〜6 dB を超える)は効果音を BGM に重ねる時の目安。ここでは 10.0 秒の一撃を曲の最大の山にする仕様なので、意図どおりの数字として扱った。映像に効果音を重ねる場合は、10.0 秒で音楽と効果音が重なり過ぎないか別に確かめる。
- 仕上げ: `assemble.sh`(黒い 20 秒の映像を相手に通し、出力の `soundtrack.wav` を使う)で 2 回通しの loudnorm(TP -2)→ 残りの差を直線の音量で -14.0 に寄せた。その前に、正規化した素材の 0.6 を超える頂点だけを tanh で丸めている(一撃の頭が真のピークを決めてラウドネスが上がらないのを防ぐため)。

## 自己点検(機械と作り手の確認。耳では確かめていない)
- 仕様の形(8 小節・96 BPM・小節 5 で長調・10.000 秒の一撃・最後は主和音)を楽譜データで確認。
- 中域の重ねすぎを避けるため、同時に鳴る旋律は1本(主題)+オクターブ下の重ね1本に限った。金管(トロンボーン/トランペット)は小節 5〜6 だけ。
- 未確認・気になる点: ①M2 小節 4 のハープで G4 と F♯4 の余韻が約 0.3 秒重なる(短2度)。②M1 小節 2 は合唱 A と弦・ハープの B♭ で長7度の響き(意図は「遠い光」の色)。③合唱は GM の「Choir Aahs」1 音色なので「オー」の母音は出せない。④サウンドフォントの音色そのもの(弦の立ち上がりの遅さ、合唱の質感)の良し悪しは、聴かないと分からない。

## 再現
```bash
apt-get install -y fluidsynth musescore-general-soundfont-lossless ffmpeg
pip install pretty_midi mido numpy scipy
cd docs/crystal-sky/midi
python3 make_music.py            # M1/M2 の .mid .wav .mp3 と stems/
python3 check_music.py M1.wav M2.wav
echo '{"hit_10s": 599}' > /tmp/cues.json   # 60 fps の 599 コマ+1 = 10.000 秒
python3 ../../../claude-video-skill/tools/audio_measure.py M1.wav --cues /tmp/cues.json --fps 60 --hits stems/M1_hits.wav --bed stems/M1_bed.wav
```
