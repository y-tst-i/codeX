# 音響品質向上プロジェクト — 結果のまとめ(利用者の試聴判定。どれも1回・1人)
映像は「ひとつずつ」15秒(2Dの画面アニメ、架空のアプリ)を再利用し、音だけを差し替えて、名前を伏せて比較した。

| ラウンド | 比べた物 | 利用者の判定 |
|---|---|---|
| 1 効果音 | A 既存(Kenney+MIDI)/ B earshot / C 併用(Kenney+earshot+MIDI) | **C > B > A**。A は「ダメではないが全体的に安っぽい」。BGM は3本とも不評(途切れる・つながりが無い) |
| 2 BGM(MIDI) | F9=前回の BGM / P5=warm(ピアノ+弦+ベース+シェイカー+キック)/ S9=light(ピチカート+マリンバ+指弾きベース+エレピ+軽いリズム) | **S9 > P5 > F9**。F9 は「BGM が突然無くなる・最小になる所が複数」、P5 は「鳴り続けるが曲としてぐちゃぐちゃ」、S9 が一番整っていた |
| 3 BGM(AI 生成 vs MIDI) | S9(MIDI)/ D1〜D4(Audio Studio=Stable Audio 3 small music) | **S9 と D4(ミニマルなシンセのパッド)が良かった**。D1・D2 は問題なし。**D3(ナイロンギター)は「ごちゃごちゃ」**(数値の点検でも低域が重い・調が効果音と合わない音が多い、と出ていた) |

## 分かったこと
1. 効果音は、Kenney の録音(紙・布・本などの手触り)と earshot の効果音バンク(細かいタイミングの UI 音、通過音)の**併用が最良**。earshot の dur・apex・pitch はほぼ指定どおり(ピークの位置 ±2 ms 前後)。earshot の分析のうち、数値(音量・時刻のずれ・クリップ)は信用でき、センス・高級感・ミックス内の音の種類は判断できない(作者の LIMITS.md どおり)。
2. **BGM は切れ目なく1曲として流す**。ほぼ無音の区間は効果音で作る(BGM を落とさない)。
3. **編成を絞るほど整う**。同じ和音の流れでも、楽器と重ね方(編曲)で聞こえ方が大きく変わる。
4. **AI 生成の BGM(Audio Studio)は実用になる**(MIDI の最良と並んだ)。手軽(1案 約40〜57秒)だが、調が指定どおりにならない・終わりがない(フェードで終える)・利用者の PC が必要(Windows はクラウドにつなげない)・ライセンス条件がある。
5. 重さ: 第3ラウンドで5時間枠の約半分を使った。軽い回・重い回で手順を分ける(SKILL.md §4c)。

## 制限(正直に)
- 1回・1人・同じ映像1本。AI は聴いていない(測定のみ)。聴いた順番は評価用紙の1行目の順と仮定して開示した。
- AI 生成の BGM が MIDI より良いとまでは言えない(並んだだけ)。調のずれは聴感では問題にならなかったが、別の映像で同じとは限らない。
