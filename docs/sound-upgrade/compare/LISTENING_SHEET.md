# 試聴の評価用紙 — 「ひとつずつ」15 秒の音、3 本

ファイル: `docs/sound-upgrade/compare/` の **`V2.mp4` `Q7.mp4` `Z9.mp4`**(映像は 3 本とも同じ。音だけが違う)。
名前は無作為の記号です。**中身の対応(`ANSWER_KEY.md`)は、評価を書き終えるまで開かないでください。**

## 聴き方
- 3 本とも統合ラウドネス -14 LUFS、真のピーク -1 dBTP 以下にそろえてあります(大きい方が良く聞こえる、を防ぐため)。再生の音量は 3 本で変えないでください。
- できれば 2 通りで: ① ヘッドホンかスピーカー ② スマホの内蔵スピーカー。
- 順番の影響を減らすため、1 周目は V2 → Q7 → Z9、2 周目は Z9 → V2 → Q7 のように順番を変えてください。
- 1 本を 2 回以上通して見てから付けてください。

### 特に聴いてほしい所(測定では判断できなかった所)
- 0.6〜1.3 s: カード 6 枚の着地の音が機械的な繰り返しに聞こえないか(同じ素材を速さ・音量・左右を変えて使っている)
- 3.77 s(選択のクリック)と 6.87 s(大きいチェック): クリック・確認音が「安いゲームの音」に聞こえないか(earshot の推定ではそう読む本があった。推定は当てにならないので耳で)
- 9.9 s(輪の窓が開ききる)の膨らみの音: 浮いていないか
- 11.6〜12.2 s のほぼ無音 → 12.57 s のタイトル着地: 間が気持ちよいか、着地の音が重すぎ・軽すぎないか
- 13.1 s のアイコンのポップと最後の余韻: 終わり方
