# BGM の監査と作り直し(第2ラウンド)

利用者の判定(1 回・1 人): 3 本とも BGM が不評。「途中途中無音になる」「BGM としての繋がりが無い」。
ここでは、なぜ「つながりが無い」のかを**測定**と**楽譜(スクリプトの音符)**の両方から書き、新しい 2 案の設計を書く。聴感の良し悪しは書かない(AI は聴けない)。

## 1. 監査: 何がつながりを切っていたか
測定は BGM だけの音(A は元の `make_audio.py` を再現したステム、B / C は `score.py` の BGM から C の身振りを除いた物)を、仕上げ後の大きさで測った(`bgm_metrics.py`)。

| 観点 | A(既存) | B / C(第1ラウンドの新しい BGM) |
|---|---|---|
| **ベッドの途切れ**(100 ms RMS の最小 / 中央値からの差) | -46.0 dBFS / -26.6 dB(2.85 s) | **-60.1 dBFS / -39.7 dB**(12.15 s) |
| 同(400 ms RMS) | -45.5 dBFS / -26.0 dB | -46.4 dBFS / -27.0 dB |
| 落とし方(楽譜) | 弦・パッドの包絡を 1.95–2.95 s と 11.45–11.9 s で -30 dB、さらに音楽全体を 2.0–2.95 s と 11.55–11.9 s で -24 dB | 音楽全体の弧を 1.95–2.95 s で -22 dB、11.62–12.2 s で -16 dB。大チェックの前にも -8 dB |
| **場面ごとの楽器の入れ替え** | 全編の土台(弦 48 + パッド 89)は同じ。場面の楽器は合図に 1 音ずつ(ギター 6 音、マリンバ 4、カリンバ 3、ハープのグリッサンド、ピチカート 9、ピアノ、チェレスタ 2) | 場面ごとに丸ごと入れ替え: ピアノ(0–3.75)→ ギター + ベース + シェイカー(3.75–6.5、6.5 で止まる)→ 弦(6.875–10)→ エレピ + キック + ベース(10–11.55、11.55 で止まる)→ 止め → ピアノ + 弦 + 合唱(12.2–)。**同じ楽器が 2 つの場面をまたいで続く所がほとんど無い** |
| **コード進行** | F | Dm7 | Bbmaj7 | Gm7 | C7sus4 | F(2.5 s ごと、絵と無関係) | Ebmaj9 | Abmaj9 | Cm9 → **6.875** Eb/G → 7.5 Abmaj9 → **8.75** Bbsus4 → 10 Abmaj9 → **11.25** Bb → **12.637** Eb add9。合図に合わせたので**小節の途中で変わる**所が 4 つ |
| **主旋律** | 無し(合図ごとの単発の音) | 冒頭の 3 音(G5-F5-D5)とタイトル前の 1 音だけ。曲としての「覚えられる線」が無い |
| **拍の連続**(音の立ち上がりのすき間の最大、librosa) | 1.86 s(11.4 s から) | **2.51 s**(6.94 s から: 弦だけの区間で 4 拍分、新しい音が無い) |
| 拍の推定 | librosa 95.7 BPM | librosa 95.7 BPM(拍の格子は推定できるが、すき間が長い) |
| 効果音との関係 | 合図に楽器の 1 音を当てる = 効果音と音楽が同じ役をして重なる | 合図に合わせて編曲で空けているが、空け方が「止める・落とす」だった |

**まとめ**: つながりを切っていたのは、(1) 静けさを BGM ごと落として作った窓(ベッドの最小が中央値から -27〜-40 dB)、(2) 場面ごとの楽器の総入れ替えと、境で止まるパート、(3) 主旋律が無い、(4) 新しい音が 2.5 s 来ない区間(拍が切れる)、(5) 小節の途中での和音の変化。BRIEF の「場面ごとに楽器の系統を変える」ルールを、**曲の楽器を入れ替える**意味で実装したことも (2) の原因(反対意見として §4 に書く)。

## 2. 作り直しの約束(`projects/hitotsuzutsu/score2.py`、2 案共通)
- 調は Eb メジャー。和声は基本 1 小節(2.5 s = 4 拍)に 1 つで、**4・5 小節目だけ 3 拍目で属和音(Bbsus4)に変わる**: **Eb | Ab | Cm9 | Ab–Bbsus4 | Ab–Bbsus4 | Eb**(I | IV | vi | IV–Vsus | IV–Vsus | I、タイトルの拍 20 = 12.5 s で解決)。半小節で変える 2 か所は、輪の窓が開き始める 8.75 s(拍 14)と今日の棒が着地する 11.25 s(拍 18)という絵の山に属和音を合わせる意図(小節の頭にそろえると、属和音が 7.5 s の「戻り」と 10.0 s の「グラフの始まり」に来て、窓とグラフの頂点で和声が動かない)。属和音は sus4(D を使わない): C の音程の身振り(今日の棒の Eb6)と短 9 度でぶつかるのを避けるため。
- **主旋律 = 4 音のモチーフ**(Bb-C-Eb-○、「ひと・つ・ず・つ」の 4 拍): 1.25 s(一覧が揃った拍 2)で D に開いて終わる → 3.75 s(選んだ拍 6)で C → 7.5 s(戻りの拍 12)で F へ上がる → 10.94 s(棒が揃った後)速く言って F(D は身振りの Eb6 と短 9 度になるので避けた) → **12.19 s から上がって拍 20(12.5 s)で Eb に着地**。チェック(5.0–6.25 s)と棒(10.0–10.8 s)の間は旋律を休み、C の音程の身振り(チェレスタ)に譲る。
- **拍を刻む層(オスティナート)を全編に**。静けさの窓(1.95–2.95 s、11.6–12.2 s)も止めず、上の 2 音だけ・弱く(warm は 4 分、light は 8 分のまま)。BGM の弧の谷は -5〜-6 dB まで。
- 場面の変化は**足し引き**: 入り(ピアノ / ピチカートだけ + 弱いベース)→ 選択から打楽器 → チェックで弦 / ハット → 窓で弦の膨らみ / キック → グラフで最も厚く → 止め(オスティナートだけ)→ タイトル(解決の和音 + 旋律の着地 + 刻みを細くして終わる)。
- **1 つの部屋**(残響 1.3 s)を曲全体に、タイトルからだけ長い響き(2.4 s)を足す。
- 効果音との帯域(ミックスの設計):
  - カードの連打(0.67–1.27 s)の間は 8 分の刻みを始めない(warm は和音を伸ばす + ベースの 4 分、light はピチカートの 4 分)
  - チェック・大チェック・詳細の着地の拍の頭は、オスティナートと打楽器を空ける
  - 低い効果音の瞬間(大チェック・詳細の着地)は、音楽の 200 Hz 未満だけを -15〜-20 dB 下げる(`common.low_duck`)。タイトル着地は解決の主音なので -6 dB・0.12 s だけにし、編曲で空ける(主音を Eb3 か上の和音に置き、低い Eb2 は着地の後の 8 分裏から。前の小節の低音はタイトルで切る)
  - 中域: まず編曲で空ける(効果音の瞬間のオスティナート・打楽器を弾かない、ベースを手前で切る、エレピの和音を短くする・8 分裏に移す)。残りだけ、効果音の頂点の 30 ms で効果音が BGM より 6 dB 上になるよう、足りない分だけ BGM のその帯域を一瞬下げる(`common.band_dip`)。下げる量は下げる前の BGM に対して 1 回だけ求め、時間の重なる窓は 1 つにまとめて上限 -6 dB、立ち上がり・戻り 50 ms。窓の数は重複を除いて 6 と 8。「カードが浮く」布の音(C で -8 dB に絞った、ほぼ聞こえない音)は空けない(空けると BGM の谷の方が目立った)
  - 効果音は C の同じ標本のまま(変えていない)。新しい BGM は「BGM + C の身振り」の統合ラウドネスを C の音楽バスと同じに合わせてから混ぜた(効果音と音楽の釣り合いを C と同じに)

## 3. 2 案の違い
| | 案 warm「温かいピアノと弦」 | 案 light「軽い撥弦とマリンバ」 |
|---|---|---|
| 刻み(拍) | ピアノのオスティナート(Eb3–F4、8 分)、ペダルは小節ごと | ピチカート(1 オクターブ上、8 分)、左右の幅 0.8 |
| 旋律 | ピアノの右手(Bb4–F5) | マリンバ(Bb4–F5) |
| 低音 | アコースティックベース(4 分、グラフで 8 分を足す)。タイトルは Eb3 を拍 20、Eb2 を 8 分裏から 1 音だけ | 指弾きベース(1・2 拍目の裏・4 拍目のシンコペーション。効果音の瞬間にかかる音は手前で切る)。タイトルは Eb2 を 8 分裏から 1 音だけ |
| 和音の支え | 弦(3 小節目から、窓で膨らみ、タイトルで解決) | エレピ(小節の頭、グラフでは 2 拍目の裏にも) |
| 打楽器 | シェイカー 16 分(3.75–11.5 s)+ 弱いキック(1・3 拍目、7.5–11.5 s) | リム(2・4 拍目、2.5 s から)+ ハット(8 分の裏、5.0 s から)+ キック(1・3 拍目、7.5 s から) |
| 静と動 | 入りと止めが静かで、グラフとタイトルで厚い(静と動の差が大きい) | 全編一定の軽い推進力(静と動の差が小さい) |
| 終わり方 | 解決の和音を伸ばし、上の音で 8 分 → 4 分に細くして終わる | エレピの解決の和音 + ピチカートが下へ下がる 8 分で終わる |

## 4. 反対意見・提案
- BRIEF のルール 1「場面ごとに、楽器の系統・空間・帯域の 3 つを変える。隣り合う場面で同じ系統を使わない」は、短い 1 本の BGM では**曲を途切れさせる方向に働く**(今回の (2) の原因)。今回は依頼の範囲外なので変えていないが、「BGM は 1 曲として楽器を引き継ぎ、場面の違いは足し引き・音域・密度・残響で付ける。系統を変えるのは効果音と環境音」と直すことを提案する。人の試聴の結果を見てから判断してほしい。
