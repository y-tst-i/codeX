### 帯域の重なり(効果音が音楽に埋もれていないか)
効果音のエネルギーの 80 % を持つ 1/3 オクターブ帯での「効果音 − 音楽」を、**頂点の 30 ms** と **頭の 120 ms** の 2 つの窓で出す(`qa.json` の `sfx_over_music_30ms_db` / `sfx_over_music_db`)。
- 30 ms で 3 dB 未満: B は 4 件(鉄琴の 1〜3 本目 -1.2・2.9・2.0 dB: グラフの入りの和音と同時。ひとことの着地 -3.2 dB: アイコンに譲るため意図して弱く)、C は 2 件(戻りの布の層 1.9 dB、今日の棒 1.3 dB)。
- 120 ms で 0 dB 未満: B は 33 件中 8 件、C は 28 件中 19 件。C が多いのは、C の音程の身振り(チェレスタ・ビブラフォン)が効果音の 35 ms 後に「音楽」として入るため(意図した重ね)と、カードの紙の音の尾が短いため。120 ms 窓は短い音を薄めて数える。
- 数字は判定の材料で、聞こえ方は人の試聴項目に残す(`LISTENING_SHEET.md`)。

## 2. 比較パックのそろえ方と、既知の手がかり
- **手順**(3 本とも同じ、`finish.py`): AAC 1 世代(A は元の mp4 の AAC 44.1 kHz・約 255 kbps そのもの。B / C も 44.1 kHz・256 kbps の AAC に 1 度符号化して戻す)→ ffmpeg で 48 kHz → ゲインで -14.0 LUFS → 同じリミッター(-2.3 dBTP)→ AAC 192 kbps・48 kHz で映像と結合。
- **A の再符号化と優先順位**: A は元の 44.1 kHz AAC を復号して 48 kHz・192 kbps に符号化し直している(2 世代)。B / C も同じ 2 世代にした。**伏せ方(条件をそろえる)を音質より優先した**。代償は B / C に AAC が 1 世代増えること(比較用の mp4 だけ。B / C の元の WAV は `work/B|C/mix.wav` に残る)。
- **消せた手がかり**: 標本ピークの天井(前の版は B / C が同じ -2.0055 dB、A だけ -2.28 → 今は 3 本とも -2.31 前後、差 0.007 dB)、AAC の世代数。
- **消せなかった手がかり**(`answer_key/ANSWER_KEY.md` にも記載):
  - 15 kHz 以上のエネルギー(全体に対する割合)A -45.2 dB、B -34.8 dB、C -36.4 dB。符号化ではなく**中身の違い**(A の元のミックスは符号化の前から -44.4 dB。A は効果音を 3〜8 kHz で LP している)。そろえるには B / C の高域を削るしかないので、削っていない。
  - MP4 のバイト数が最大 2.4 KB 違う(5,454,952 / 5,455,625 / 5,457,313)。
  - LRA などの測定値は条件で違う。評価者に測定値を見せない。

## 4. この比較の交絡(何が分けられないか)
- A と B / C は **BGM が違う**(B / C は新しい BGM)。A と B / C の差が、音楽によるのか効果音によるのかは分けられない。
- B と C は BGM の土台は同じだが、**効果音の出どころだけでなく置き方も違う**(B は earshot の offset と bed_db、C は「絵 + 1 コマ」と自分で決めた値。C は音程の身振りを MIDI に移している)。B と C の差を「earshot か Kenney か」だけに帰せない。
- 次回の提案(今回は作っていない): 「A の BGM + C の効果音」「B と C で置き方をそろえた版」を足すと、音楽・素材・置き方を分けて聴ける。
