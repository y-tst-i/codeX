### 合図との同期
- **効果音ごとの頂点と絵の時刻の差**(`qa.py`、効果音ステムの 1 ms 包絡の最大): B は -19〜+52 ms(中央値 +0.5 ms。earshot の offset: クリックは -10 ms、カードは -10 ms、ポップは onset を揃えるので頂点が +31〜52 ms)、C は -0.5〜+37.5 ms(中央値 +33 ms = 設計どおり「絵 + 1 コマ」)。
- **earshot timeline(15 の合図)**: 1 コマ以内に新しい立ち上がりがある割合 A 93 %・B 73 %・C 100 %、100 ms 以内 A 100 %・B 93 %・C 100 %、ずれの中央値 A 31 ms・B 15 ms・C 28 ms。B が低いのは earshot の offset(リード)を使った設計の結果で、誤りではない。
- **earshot が検出した画面の切り替わり(4 か所)**: A は 4.20 s・7.77 s(拡大・縮小の最速点)に新しい音が無い。B・C は 12.40 s(タイトルの文字がせり上がる途中)だけ新しい音が無い。これは意図: 音を 0.2 s 後の着地(12.60)に集めた(前の版はここにピアノの 1 音があったが、着地の立ち上がりを弱めていたので抜いた)。
- **既存の `sync_check.py`**(合図の前後 100 ms の RMS の差): 3 本とも全合図の頂点のずれ -0.01〜0.09 s。タイトル着地の立ち上がり A 8.4 dB・B 9.5 dB・C 9.6 dB。立ち上がりが弱い(< 3 dB)と出た合図: A は icon_pop、B は back_click・shrink_land(B は無音にした合図)・count_roll・bar_today_land・icon_pop、C は back_click・count_roll・portal_end・icon_pop。クリックのように短い音は 100 ms の RMS では小さく出る(下の 30 ms の帯域の値では back_click は B 7.7 dB・C 13.6 dB 上)。count_roll は 66 ms 前に別の音がある所、icon_pop は 0.1 s 前にひとこと(tagline)の着地がある所で、この測り方の性質もある。
- **拍**: earshot の推定 A ~99 BPM(明瞭度 0.16)、B ~96 BPM(0.25)、C ~96 BPM(0.30)。映像は 96 BPM。

### 帯域の重なり(効果音が音楽に埋もれていないか)
効果音の頂点の 30 ms で、効果音のエネルギーの 80 % を持つ 1/3 オクターブ帯の「効果音 − 音楽」:
- 3 dB 未満: B は 3 件(グラフの鉄琴の 1 本目 -0.4 dB・3 本目 2.9 dB: エレピの入りの和音と同時。ひとことの着地 -2.2 dB: アイコンに譲るため意図して弱く)、C は 1 件(今日の棒の着地の木 1.9 dB)。他は全部 3 dB 以上。
- C のチェック・大チェックの「音楽」側には、C 自身のチェレスタ・ビブラフォン(35 ms 後)が入る。120 ms 窓で効果音がマイナスになるのはそのため(意図した重ね)。
