## 既知の手がかり(消せなかった物)
- 基準の BGM は、第1ラウンドで聴いた Z9 と同じ音(効果音も同じ)。第1ラウンドを覚えている人には基準が分かる。
- LRA が条件で大きく違う(上の表)。静と動の差の大きさは編曲の違いそのもので、そろえていない。
- ファイルの大きさが数 KB 違う(AAC の結果)。
