## 評価で気を付けること
- D1(`M4`)と D3(`T9`)の ③「効果音と合っているか」は、Eb 長調に固定した身振り(チェレスタ・ビブラフォン)と BGM の調が合わないことを含めた評価になる(プロンプトでは 4 本とも「E-flat major」を指定したが、モデルはその指定どおりにならなかった。調の推定は `AUDIT_ROUND3_BY_PLAN.md`)。

## 既知の手がかり(消せなかった物)
- 基準の `K9` は、第2ラウンドで聴いた S9 と同じ曲。ミックスは第3ラウンドの規則で作り直したので、第2ラウンドの S9 のファイルとはバイト単位では同じではない。第2ラウンドを覚えている人には曲で基準が分かる。
- 生成 BGM(D1–D4)は高い音域がほとんど無い(平均スペクトルが最大から -60 dB になる所: D1・D3 約 7.9 kHz、D2 約 14.0 kHz、D4 約 4.2 kHz。S9 は約 20.9 kHz)。BGM だけの音声では、こもった感じとして分かるかもしれない。
- 生成 BGM 4 本は終わりにフェードを足した(上の表)。S9 は作曲した終わり方(タイトルで Eb に解決して減衰)。
- 動画の音声のビットレートが条件で違う(上の表。最大は `K9` の 198.9 kbps。AAC の指定は 5 本とも 192 kbps で、中身によって実際の値が変わる)。
- LRA・リミッターの量・ファイルの大きさが条件で違う(上の表)。
- 条件ごとの検査の数値は `QA_ROUND3_BY_CONDITION.md`、D1–D4 と S9 の BGM の点検は `AUDIT_ROUND3_BY_PLAN.md`(このフォルダ)。
