## 2. B と C の方針の違い(テンプレートの使い回しはしない)
| | B(earshot 版) | C(ハイブリッド版) |
|---|---|---|
| 効果音の出どころ | すべて earshot(forge の合成 + CC0 録音を fit した物) | 紙・布・本の手触りは Kenney の録音、通過音の形は earshot、クリック・ポップは earshot の fit |
| 音程のある身振り(チェック・棒・アイコン) | 効果音で鳴らす(ui_pop・mallet/glock を Eb の和音の音に合わせる) | **効果音にしない**。MIDI のチェレスタ・ビブラフォン(音楽の中、効果音の 35 ms 後) |
| 置く位置 | earshot launch 型の offset(クリック -11 ms、ポップ +4 ms、着地 +30 ms、通過音の頂点 +37 ms、膨らみ +42 ms)。リードは最大 -20 ms に制限 | このスキルの約束: 頂点を「絵 + 1 コマ(33 ms)」に揃える |
| 大きさ | bed_db(下地に対する相対)。役割ごとの値は `kit_B.json` | 同じ仕組みで、合図ごとに自分で決めた値 |
| 連打の間隔 | `kit.space_run` で最小間隔(カード 100 ms、棒 110 ms)を守る(絵から最大 10 ms ずれる) | 絵の時刻のまま(素材の速さを変えて同じ音の連続を避ける) |
| カード戻り(8.07)と数字(8.13) | 戻りは無音、数字だけ(66 ms で 2 打点を重ねない) | 戻りはごく弱い紙、数字は Kenney の切り替え + earshot の木 |
| タイトル着地 | `cut_hit/sub` を Eb2 に合わせた低い打点 | Kenney の本を閉じる録音を遅く・暗く |
| ひとこと(13.03)| ごく弱いタップ | 無音(0.1 s 後のアイコンと 2 打点を並べない) |

共通: 新しい BGM(`score.py`)、山の前のステップダウン(大チェック -8 dB、B は窓の頂点の前にも -5 dB)、場面ごとの効果音の部屋(音楽と同じ系統)、頂点の上限(下地 + 12 dB かつ仕上げ後 -4 dBFS)。
音を付けない判断は下の表の後に、理由つきで列挙した。

## 3. 表(各キュー: 素材、開始時刻、ピーク時刻、音量、加工、余韻、BGM との関係)
- 「鳴り始め」= 素材の先頭を置いた時刻、「同期点」= 素材の頂点(peak)か立ち上がり(onset)が来る時刻。余韻の長さは素材の長さ(`sound_index.py show <素材>` の t20/t40)と、場面の部屋(`mixer.ROOMS`: 一覧 0.7 s・詳細 0.6 s・大チェック〜窓 1.4 s・グラフ 1.1 s・タイトル 2.4 s)で決まる。
- 「ゲイン」は素材(頂点 -1 dBFS に正規化した物)に掛けた値、「下地」は直前 1 秒の音楽の中央値(仕上げ前、LUFS)。仕上げで全体に同じゲインが掛かる。
