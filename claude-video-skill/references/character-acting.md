# キャラクターの演技と作り方(平面感を減らす)

出典と権利: ClaudeAnimationBase(MIT)の ANIMATION_GUIDE と、lemo-opuscar(MIT)の DIRECTOR の考え方を参考に、自分の言葉で整理し、このスキル向けに数値と部品(`tools/assets/puppet.js`)を足したもの。

## なぜキャラが平面に見えるか
1. 全部の部位が同じ速さで、同時に動く(機械的)。
2. 動きの前の溜め(予備動作)と、止まった後の余韻がない。
3. 一定の速さの直線移動。
4. 表情が切り替わるだけで、変化の過程がない。
5. 影・縁取り・厚みがなく、背景から浮かない。

## 演技の原則(場面カードの「演技」欄に書く)
- **予備動作→動作→余韻**: 大きな動きの前に逆向きの小さい動き(ジャンプ前のしゃがみ、投げる前の振りかぶり、驚く前の目を細める)。動いたあとは、少し行き過ぎて戻る(`ease:"back"`)。
- **オーバーラップ**: 目と頭が先に動き、体、腕、持ち物が遅れてついてくる。部位ごとに0.03〜0.06秒ずらす(`poseAt(keys, t, 1)` の overlap)。
- **つぶれと伸び(スクワッシュ&ストレッチ)**: 着地でつぶし(+0.15〜0.2)、跳ぶ・速く動く時は伸ばす(−0.1〜−0.15)。体積は保つ(横に広がる分だけ縦が縮む)。
- **重さ**: 重い物は、動き出しと止まりに時間がかかり、バウンスは小さい。軽い物は、すぐ反応して、バウンスが大きい。
- **弧の軌道**: 腕や体の動きは直線でなく曲線。ジャンプは放物線(`lift = sin(π·u)·高さ`)。
- **表情は変化の過程を見せる**: 目を閉じる→顔を替える→驚く(テイク)→落ち着く、の順。パッと切り替えない。眉1本で「心配」と「怒り」が入れ替わるので、最終サイズで確認する。
- **ポーズはブレンドする**: キーフレーム間をイージングで補間する。`if` でポーズを瞬時に切り替えない(意図的な1コマのポップは例外)。
- **左右を同期させない**: 両腕や複数キャラが同じ動きだと、双子に見える。位相を少しずらす。
- **持ち物は手の中**: 手のひらの間、腕の間の奥行きに置く。回る物は「距離÷半径」で回転させる。

## タイミングの目安(秒 / 30fps のフレーム数)
| 動作 | 秒 | フレーム |
|---|---|---|
| 予備動作 | 0.1〜0.2 | 3〜6 |
| テイク(驚き) | 0.15〜0.3 | 5〜9 |
| ジャンプ全体 | 0.6〜1.0 | 18〜30 |
| 感情の変化(全体) | 1.2〜1.7 | 36〜51 |
| 振り向き | 0.12〜0.25 | 4〜8 |
| 投げる・振る | 0.15〜0.5 | 5〜15 |
| 小さい・遠い・微妙な動きが読まれるまで | 発見に2〜3コマ、理解に4〜6コマ | |
| 重要な瞬間の後の「余白」 | 次の動きの前に1〜2コマ | |
トランジション: ワイプ0.5〜0.8秒 / アイリス0.3〜0.6秒 / フェード0.2〜0.5秒。

## 「読み」を設計する
各ショットで、観客が理解すべきことを順番に書き出す(例: 「①星が見える ②投げる ③当たる ④反応する」)。2つの重要な読みを**同時に起こさない**。原因を見せてから反応を見せる。

## 手描きらしさ(ボイリング)
- 線を12fpsで微かに揺らす(`jit`: 乱数を floor(t·12) で固定)。静止物にも別のシードを与え、動くものの描画順に影響されないようにする(動くものの後に静止物を描くと、乱数列がずれて静止物が毎フレーム変わる)。
- 純黒・純白を避け、インク色とクリーム色を使う。色は背景と調和させ、キャラが読めるように。
- 大きさ: キャラは画面高さの1/3以上を目安に(小さい・遠い・端に寄るのは失敗)。

## 部品 `tools/assets/puppet.js` の使い方
`bash tools/new_scene.sh <dir> <秒> <背景> --puppet` で埋め込む。
```js
const P = PUPPET.make({ cloth:"#3a5fbf", hair:"#2b2118", u:1.8 });     // u=大きさ
const keys = [
  { t:0,   x:300, y:900, ...PUPPET.walk(phase) },                      // 角度: 腕・脚は「真下=0, 前へ振り上げ=+」
  { t:1.5, squash:0.16, lean:-0.12, armN:[-0.9,0.5], ease:"inout" },   // 予備動作(しゃがむ)
  { t:1.8, squash:-0.14, lift:190, armN:[2.5,0.3], eye:"wide", mouth:"open", brow:-1, ease:"out" },  // ジャンプ頂点
  { t:2.1, squash:0.2, lift:0, ease:"in" },                            // 着地でつぶれる
  { t:2.5, squash:0, mouth:"grin", ease:"back" },                      // 行き過ぎて戻る(余韻)
];
P.draw(ctx, PUPPET.poseAt(keys, t, 1), t);
```
- 歩き `PUPPET.walk(phase)`、走り `PUPPET.run(phase)`(phase=歩数×2π)。`facing:-1` で左右反転。
- 表情: eye=normal/wide/closed、mouth=smile/open/grin/frown/flat、brow=−1(困り)〜+1(怒り)、look=[x,y]、blink=0〜1。
- 限界: 横向き中心の簡易人型(関節は肩・肘・腰・膝)。顔の向き転換や、衣装の揺れ、髪の動きは未対応。必要な場面は、パーツを足すか、別の描き方にする。立体(3D)ではない。

## 確認(自己チェック)
- 重要な動作を0.2秒ごとの連続画像(コンタクトシート)で確認: 予備動作・伸び・着地のつぶれ・余韻が見えるか。
- 表情は最終サイズで確認(眉の向き、目の大きさ)。
- 同じ動作を2回以上使わない(使うなら少し変える)。
