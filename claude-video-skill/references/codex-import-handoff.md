# Claude Codeクラウドへの引き継ぎ

この文書と `codex-skills/` は、GitHubリポジトリを使うClaude Codeクラウド環境向けの持ち込み一式です。作成日：2026-10-28。

## 最初に行うこと

1. リポジトリ内の `codex-skills/business-motion-film/SKILL.md` を読む。
2. その案内に従い、`codex-skills/motion-prompt/SKILL.md` と必要な参照資料を読む。
3. 実写主体の依頼では `codex-skills/direct-cinematic-video/SKILL.md` を主手順にする。
4. `codex-skills/business-motion-film/references/local-integration.md` は、このパッケージではクラウド向けの環境説明に差し替え済み。ローカルPCの設定を引き継いだと仮定しない。

読むだけでは制作、課金、外部アップロードや新規環境構築を開始しない。ユーザーが依頼した制作の範囲で実行する。

## 役割とユーザーの方針

- **business-motion-film**：モーション主体の製品CM、SaaS紹介、短い広告の構成・音設計・独立レビュー。
- **motion-prompt**：モーションの主な選択元。ユーザーが細かく指定しなくてもギャラリーを調べ、実際のID・コード・kitを取得する。適用可能な演出の7〜8割を目安に採用し、合えば全て使ってよい。秒数・発動確率ではなく演出の数の目安。水増しの効果は加えない。
- **direct-cinematic-video**：実写、インタビュー、イベント、採用動画の構成・仕上げ・納品検証。
- テック系CMでは、持続的な画面の活動と意味のある小さな動きへの音付けを基本にする。0.6秒ごとにカットを変える意味ではない。文字を読ませながら補助動作を続け、音は同系統で主役と脇役の強弱を付ける。
- 会話や余韻を主役にする実写には、テック系CMの速さ・音密度を強制しない。承認済みコピー・素材・旧完成版を保持する。
- 完成レンダーを独立した担当が確認し、大きな欠点から直す。実際に見たもの・聴いたものと、計測だけのものを区別する。

## 自動スキル登録を使う場合

`codex-skills/` は受け渡し・参照用の保管場所で、それだけで `/business-motion-film` が登録されるとは限らない。

通常のリポジトリ型クラウドセッションでプロジェクトスキルが使える場合は、既存ファイルと競合しないことを確認し、3つのフォルダをそれぞれ `.claude/skills/<スキル名>/` へ配置してコミットする。参照資料とscriptsも含める。配置だけでは使えると断言せず、クラウド側のスキル一覧で認識を確認する。

公式仕様では、ClaudeのProjects内のクラウドスレッドはリポジトリの `.claude/skills/` を読み込まない場合があり、その場合はclaude.aiアカウントでスキルを有効化する経路が必要になる。自動登録が利用できなくても、この文書の「最初に行うこと」のようにリポジトリ内の実ファイルを明示的に読ませて、制作方針として参照できる。スラッシュコマンドの登録確認と、文書を読むことは別である。

公式説明：https://code.claude.com/docs/en/skills#use-skills-in-cowork-and-cloud-sessions

## 音声生成は別の環境設定

Audio Studio MCPは元のWindows PCで導入・接続・生成を検証したもの。このクラウド環境に導入済みではない。PC内のモデル、音声ファイル、Python環境、MCP登録、Hugging Faceログイン情報は含まれない。

クラウドで音が必要なら、まず使えるMCP・生成手段・提供済みの音素材と予算を確認する。Audio Studioをクラウドに新規導入する場合は、実際のOS、CPU/GPU、RAM、ディスク、通信制限と、ユーザー本人のモデル利用許可・認証を別途確認する。PCのトークンをGitへ入れたり、元PCのパスを使ったりしない。音生成の経路が使えなければ、音の設計は行い、生成・試聴は未検証として報告する。

## 受け渡し・検証の状態

このパッケージはスキルのテキスト・必要な参照資料・補助スクリプト・ライセンスを含む。元PCでのローカル検出と音声MCP接続は以前確認済みだが、クラウドへのインストール・認識・スクリプト実行・制作は、この文書の作成時点では未検証。

GitHubへ置く際は、この文書と `codex-skills/` を同じリポジトリへコミットする。共有されたリポジトリURL・ブランチ名・必要ならコミットIDを使って、Claude側でその版を読む。
