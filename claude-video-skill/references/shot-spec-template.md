# 場面カード(Shot Spec)テンプレート — 技法を「設計書」に落とす

映画の技法(`references/cinematic/` の424件)は、**1場面ごとに「何を・なぜ」選ぶか**を文章で決めて初めて効く。
場面を担当者(サブエージェント)に渡す前に、SCENES.md の各場面へ次の「場面カード」を必ず書く。
書けない欄があれば、その場面はまだ企画が足りない。

> 原則(出典 melies.co の各カテゴリの考え方を再構成):
> - **動きは「最後のコマが、最初のコマに無かった事実を見せる」時だけ**(新しい場所・力関係・画面外にあったもの)。
> - **ショットサイズは文**。サイズを変えるのは、新しいサイズが前のコマに無かった事実を見せる時だけ。
> - **光は影の決定**。光源(窓・ランプ・太陽)を決め、キー側・硬さ・色を書く。目は最も明るい読めるものへ行く。
> - **構図は視線の通り道**。誰が空間を所有し、何が遮られ、縁はきれいか汚れているかを図で言う。
> - **色は時間・場所・光源の約束**。色の変化は「出来事」で、ずるずる流さない。
> - **時間は素材**。ランプ/フリーズはどの拍に当てるかを決める。時間が意味を変えないなら通常速度で撮る。
> - **つなぎは両側を書く**。出ていく絵と入ってくる絵。何も共通しなければマッチではなく、ただの2ショット。
> - **効果は物理的な原因を書く**(ガラス、ピント、二重露光)。「フィルターを重ねる」ではない。
> - **ジャンルルックは光・配色・レンズ・動線の総体**。ジャンル名は最後に付ける。
> - **大気は空気中の物質**。粒を逆光で光らせる。濡れた地面で夜がきらめく。

## 場面カード(1場面ぶん。そのままコピーして埋める)

```
### <場面id> (<秒>s / <フレーム>f) — 「<一言>」
**物語上の役割**: この場面が観客に起こすこと(1文)。前後の場面との関係(対比/連続)。
**世界**: 場所・時間帯・天気・色調(1行)
**カメラ**
  - サイズ: <ショットサイズ>(根拠: 何の事実を見せるために)
  - アングル: <高さ/傾き>(力関係)
  - 動き: <技法名>、開始=<位置/高さ>、方向=<>、速度=<秒・イージング>、終了構図=<>(最後のコマで見える新しい事実)
  - レンズ感: <広角/標準/望遠>(奥行きの圧縮/強調)
**光**: 光源=<>、キー側=<>、硬さ=<硬/軟>、色温度=<>、コントラスト=<>。最も明るい読めるものは何か
**色**: パレット(HEX 3〜5色)、色の「約束」(この場面の光源と整合)、変化があるなら**いつ**起きる出来事か
**構図**: 視線の通り道(例: 左下→中央→右上)。主役の座標(1920x1080のpx)。余白/ヘッドルーム/リードルーム
**時間**: 速度の山(スロー/ランプ/フリーズを当てる拍=フレーム番号)。無ければ「通常」
**効果**: <技法名>=<物理的な原因>(例: 色収差=衝撃でレンズが歪む瞬間の0.2秒)
**つなぎ**: 入り=<前の最終フレームの何を受けるか>。出=<次の最初のフレームに何を渡すか>(**両側の絵を書く**)
**合図(cue)**: 0.00 / 0.50 / ...(音が合わせる時刻。±1フレーム)
**コピー(一字固定)**: ...
**固有技法(この場面だけの専売)**: ...(他の場面と被らせない)
**禁止**: ...
```

## 使い方(手順)
1. 先に**映画全体のリズム**を名前で書く(例: 静 → 対峙 → 爆発 → 余韻 → 高速 → 豪華 → 脱力 → 荘厳)。
2. 各場面で「物語上の役割」を決めてから、**技法は役割に仕える**ものだけを選ぶ(`references/cinematic/INDEX.md` で探す)。
3. 場面の組み合わせを見て、**同じ技法・同じサイズ・同じ動きが続いていないか**を確認(似たカットの連続は最大の失敗要因)。
4. 担当に渡す時は、カードの該当技法の**リファレンス節(`references/cinematic/<ファイル>.md` の該当エントリ)を読むよう指示**する。
5. 仕上がりの審査では、カードと実際のコマを見比べる(「最後のコマで新しい事実が見えているか」「光源と色が整合しているか」)。
