# 編集と遷移(23技法)
> 出典: melies.co/cinematic-techniques(要約・再構成。原文の転載ではない)。HyperFramesでの実装レシピは本スキル独自。

## このグループの選び方ガイド
編集は「何を捨て、何を隣に置くか」の技法。まず**つなぎ目で観客に何をさせたいか**で選ぶ。

| 目的 | 使う技法 |
|---|---|
| 衝撃・対比を叩きつける | スマッシュカット(静けさを作ってから壊す)/ クラッシュカット(最初から衝突)/ フラッシュカット(数フレームの侵入) |
| 時間を飛ばす・圧縮する | ジャンプカット(同じ構図で時間を抜く)/ モンタージュ(別の絵を並べて意味・月日を作る)/ ディゾルブ(柔らかい経過) |
| 2つの絵を「同じ」と読ませる | マッチカット(意味まで対応)/ グラフィックマッチ(形だけ)/ マッチモーション(動きのベクトル)/ アクションつなぎ(同一動作の別アングル) |
| 同時進行・比較 | クロスカッティング(交互)/ スプリットスクリーン(同時に並べる)/ マッチスプリット(境界線が両世界をまたぐ) |
| つなぎ目を見せる/隠す | ワイプ・アイリス・フェード・トランジション(見せる)/ 見えないカット・セットトランジション(隠す・場を書き換える) |
| 音と絵をずらす | J/Lカット |

- 似た技法の見分け: **ハードカットで衝撃=スマッシュ(前に静けさ)/クラッシュ(前触れなし)/フラッシュ(数フレームで戻る)**。**同じ構図で時間だけ飛ぶ=ジャンプ、同じ軸で距離だけ飛ぶ=軸上カット**。**形が似る=グラフィック、意味も対応=マッチ、動きでつなぐ=アクション/モーション**。
- 入門者がまず覚える3つ: **ハードカット+拍(スマッシュ/ジャンプの土台)、ディゾルブ/フェード(柔らかい経過)、マッチカット(形・位置・動きの一致設計)**。
- **本スキルの運用前提(§11)**: 場面は別プロジェクトで無音mp4として作り、`ffmpeg concat` で**ハードカット連結**する。つまり場面間の遷移は、(a) 各場面の「入り/出」を設計書(SCENES.md)にフレーム単位で書いて合わせる、(b) 場面内に遷移を内蔵する(出口に色ブロック/マスクを置く等)、(c) 重なりが要るなら両場面に余白フレーム(ハンドル)を付けて `ffmpeg xfade` で後処理する、のどれかで作る。30fps、150BPMなら1拍=12フレーム、場面長は0.2秒(6フレーム)の倍数に揃える。
- **ハードカットの作り方(共通)**: 同一コンポジション内なら、隣り合う2つの `.clip` の `data-start`/`data-duration` をフレーム整数(n/30秒)で接続する。重なり時間ゼロ=ハードカット。`.clip` に autoAlpha/visibility は tween しない(スキルの地雷)。内部の子要素は `tl.set` で切り替える。
- **実在する既製部品(`npx hyperframes catalog --query` で確認済み)**: ブロック `flash-through-white` `glitch` `light-leak` `whip-pan` `sdf-iris` `cross-warp-morph` `domain-warp-dissolve` `cinematic-zoom`(シェーダー遷移)、コンポーネント `match-cut` `text-match-cut` `type-match-cut` `cut-the-curve` `whip-pan-cut` `iris-reveal` `fade-through` `directional-wipe` `before-after-wipe` `comparison-split`、`editorial-flash-overlay` `organic-light-leak-overlay`、デモ集 `transitions-dissolve` `transitions-radial` `transitions-mechanical` ほか。
- **シーク安全の共通注意**: 遷移は1本のpausedタイムラインに載せる。`Math.random` 禁止(粒子・グレインはseed付きPRNG)。`onComplete` で状態を戻さず `tl.set` を使う(逆再生・シークで壊れない)。

## 技法一覧(エントリ)

### 軸上カット / Axial Cut  (`editing/axial-cut`)
- **一言**: 同じカメラ軸の上で、被写体への距離(ショットサイズ)だけを段階的にカットで跳ばす。角度は変えない。
- **物語での役割**: 気づきが歩みではなく「衝撃の連続」として届く。台所→もっと近い台所→眼窩、と観客の準備が整う前に細部が顔面いっぱいに迫る。
- **使う/使わない**: 日付・傷・銃など「一撃として落ちるべき細部」に2〜3段まで。連続した接近(歩み寄り)を見せたい場面には使わない(それはドリーイン)。
- **よくある失敗**: ズームアニメやデジタルクロップをカメラ移動として見せること。レンズが呼吸する、角度が数度ずれる、被写体が変形して大きくなる。
- **似た技法との違い**: クラッシュズームは時間をかけた連続的な焦点距離変化、軸上カットはスプライス(つなぎ)。ジャンプカットは時間を抜き、軸上カットは距離を抜く。
- **HyperFramesでの作り方**: 2D トランスフォームで十分。1つの「世界」ラッパー(SVG/DOM、できれば図形はベクター)に `transform-origin` を**注視点**(例: 62% 40%)で固定し、段階ごとに `tl.set("#world",{scale:1})` → `tl.set("#world",{scale:2.2},T)` → `{scale:5.5}` と**補間せず**離散的に切り替える(ズームのtweenは絶対に入れない)。段のホールドは各12〜24フレーム(150BPMなら1〜2拍)。クロップ拡大でボケないよう、ラスター素材は最大倍率分の解像度を用意するか、ベクターで描く。設計書には「軸(注視点座標)」「各段の倍率」「切替フレーム」を表で書く。
- **音との合わせ方**: 各段のカットに低音ヒットか心拍を1発ずつ合わせ、段が上がるごとに半音ずつ上げると「一撃ずつ」の効果が出る。
- **難易度/適性**: ★(スケールの離散切替だけ。注視点の設計が肝)。
- **AI動画生成プロンプト**: `Axial cut jumping toward or away from [Subject] along the lens axis, punch-in without a zoom, a snap of scale; same angle, same pose, hard cuts between two or three framings.`

### クラッシュカット / Crash Cut  (`editing/crash-cut`)
- **一言**: 前置きも混ぜもなく、2つの絵をぶつける。つなぎ目そのものが打撃になり、しばしば出来事の最中から始まる。
- **物語での役割**: 柔らかい導入を拒否し、いきなり結果・衝撃から語り始める(in medias res)。リズムの太鼓として機能する。
- **使う/使わない**: 作品の冒頭や、ダウンビートに結果の絵を叩きつける時に。静けさを築いたあとに裏切る場合は「スマッシュ」、2つが似た引きの絵同士なら使わない。
- **よくある失敗**: 長い静けさを前に置いてしまう(それはスマッシュ)。後続が数フレームで消える(それはフラッシュ)。後で時間が戻る時に、タイトルや髪型などで合図を出さない。
- **似た技法との違い**: スマッシュは「築いた状態」を壊す。クラッシュは状態を築く前から衝突として始まり、Bがすでに進行中。
- **HyperFramesでの作り方**: ハードカット+Bを**動作の途中**から始める。B場面のタイムラインは「進行40%の姿勢」から定義する(`gsap.fromTo` の from を途中の姿勢にし、フレーム0から動いている)。A/Bで明度・スケール・内容の差を最大化(A=暗く小さい、B=明るく大きい等)。つなぎ目に混ぜ(opacity)を一切置かない。音も同フレームで衝突させる: 映像のBの第1フレームが音の立ち上がりと一致するよう、音を設計書の「cue時刻」で作る。BのYAVGがAと大きく違うことを `signalstats` で数値確認できる(§11-7)。
- **音との合わせ方**: 音のアタックを映像の第1フレームに揃える(0〜1フレーム以内)。直前に無音を置かない(置くとスマッシュになる)。
- **難易度/適性**: ★(設計が全て)。
- **AI動画生成プロンプト**: `Crash cut on [Subject], two images colliding with no polite blend, B already mid-event, a hard join that should sting; no dissolve, no fade.`

### クロスカッティング / Cross-Cutting  (`editing/cross-cut`)
- **一言**: 2つ以上の場所・行動線を交互に見せ、同時進行(meanwhile)や偽の地理を作る。
- **物語での役割**: 2つの時計が競走する緊張を作る。儀式と殺人を同じ時制で編む、ドアの前の2人が会うと思わせて違う、といった比較や誤誘導。
- **使う/使わない**: 突入と呼び鈴、儀式と犯罪のように「第2の時計」がある時に。第2の時計がなく、ただ未使用素材を挟むだけなら使わない。
- **よくある失敗**: 2線が同じ廊下に見える、第2線に時計がない。誤誘導の時、観客が公正に推理できる手がかり(家番号の一致など)を矛盾させる。
- **似た技法との違い**: モンタージュは完結した絵の衝突で意味・圧縮を作る。クロスカッティングは並行する進行中の行動を生かし続ける。
- **HyperFramesでの作り方**: 場面A・Bを別ファイル(別世界の色・形)で作り、**短くなる尺列**で交互に並べる。例: 30フレーム→24→18→12→8→6と等差で縮め、最後にぶつける(1拍=12フレーム基準で、尺は拍の約数)。2線は色温度・構図の軸を変えて混同を防ぎ、A/Bそれぞれに「時計」(進むバー、秒針、カウントダウン数字)を載せる。同一コンポジション内なら `data-start` を連続させた4〜8個の短いclipで構成。音(鐘・足音・心拍)は線をまたいで連続させて2線を縫う(Jカット/Lカットを併用)。
- **音との合わせ方**: 共通の持続音(ドローン)を下に敷き、尺の短縮に合わせて音程かテンポを上げる。
- **難易度/適性**: ★(並べるだけ。尺カーブの設計が肝)。
- **AI動画生成プロンプト**: `Cross-cutting between [Subject] and a simultaneous other line, suspense by alternation, two clocks racing; two distinct spaces, alternating shots, tightening duration, no morph between rooms.`

### ディゾルブ / Dissolve  (`editing/dissolve`)
- **一言**: 前の絵と次の絵を一定時間重ね、Aの不透明度が下がりBが上がる混ぜで、場面を受け渡す。
- **物語での役割**: 経過・回想・場面の「静かな死」。切断の衝撃を避け、時間や記憶がにじんで移る感覚を作る。
- **使う/使わない**: 回想の入りや、場面を「止める」のではなく「消えさせる」時に。マッチのずれを隠すために使わない(隠れない)。2フレームのディゾルブはただの柔らかいカット。
- **よくある失敗**: 途中で画面が暗くなる(フェードになっている)、AがBに変形する(モーフ)。重なりの中間で2枚の絵が読めない構図。
- **似た技法との違い**: フェードは一度均一な色面になる。ディゾルブは枠が空にならず、Bが最初からそこにある。
- **HyperFramesでの作り方**: 2場面を同座標に重ね、B(下)は不透明度1固定、A(上)だけ `opacity 1→0` にする。**A・B両方を0.5にする対称クロスフェードは中間で暗く沈む**(背景が透けるため)ので、非対称にするのが実用解。尺は12〜24フレーム(0.4〜0.8秒、`sine.inOut`)。回想は 36〜60フレームに伸ばし、軽い `filter: blur(2px) saturate(0.8)` をAの退場側に足すと記憶らしくなる。重なりに共通の形(視線の位置、円)があると読める。別ファイル連結時はA末尾とB頭にハンドルを各12フレーム余分に描き、`ffmpeg -i a.mp4 -i b.mp4 -filter_complex "xfade=transition=fade:duration=0.5:offset=<A長-0.5>"`。デモ集: `npx hyperframes add transitions-dissolve`(各種の確認用)。
- **音との合わせ方**: 音も同じ長さでクロスフェードさせる、または先にBの環境音を入れる(Jカット)と「経過」が自然になる。
- **難易度/適性**: ★(opacityだけ)。
- **AI動画生成プロンプト**: `Dissolve from [Subject] into another time or place, overlapping ghosts, longer than a cut admits; two full shots plus an opacity crossfade, do not morph bodies.`

### フェードイン/フェードアウト / Fade In / Fade Out  (`editing/fade`)
- **一言**: 画面を黒や色の均一な面へ落とす/そこから立ち上げ、世界と「不在」の間に句読点を打つ。
- **物語での役割**: 章の終わり、意識が落ちる、死、始まり。観客が休める間を作る。色(赤・白)にすると感情の面になる。
- **使う/使わない**: 作品の冒頭と終幕、幕の区切り、気絶の暗転に。現代の会話劇で場面ごとに毎回使うと古風な句読点のリズムになるので避ける。2つの絵を重ねたいならディゾルブ。
- **よくある失敗**: 煙や霧で偽のフェードをする(絵が去るのではなく天気が出る)、ディゾルブと混同して中間で2枚が見える。
- **似た技法との違い**: ディゾルブは2場面の重なり、フェードは一度枠を空にしてから次を生む。
- **HyperFramesでの作り方**: 最前面に全画面の色ブロック `#fade`(`background:#000`)を置き、`opacity` を tween。フェードアウトは `0→1`、`power1.in`、18〜30フレーム、黒のホールドを6〜12フレーム(0.2〜0.4秒)置いてからフェードイン(`power1.out`、18〜24フレーム)。色を白/赤にすれば感情の面になる(`#fade` の色を変えるだけ)。最終場面のみ退場アニメ可(オーバービュー規則)。連結した完成mp4への後処理は `ffmpeg -vf "fade=t=out:st=<終了-0.8>:d=0.8,fade=t=in:st=0:d=0.8"` と音の `afade`。既製: `npx hyperframes add fade-through`(1つのレイヤーを落として洗い面を通過し次を出す)。
- **音との合わせ方**: 音が絵と一緒に死ぬか(終わり)、黒の上で鳴り続けるか(気絶・一瞬の無意識)を設計書で決める。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Fade to or from black around [Subject], chapter punctuation, sleep, death, or the start of a world; name the field color; no smoke or fog.`

### フラッシュカット / Flash Cut  (`editing/flash-cut`)
- **一言**: 進行中の絵に、別の絵を数フレームだけ割り込ませて戻る(または畳み掛ける)。
- **物語での役割**: 予知が記憶の顔をして侵入する、トラウマのチック、サブリミナルな脅威。何を見たかは数えられないが、すでに起きてしまっている。
- **使う/使わない**: 心が別の時間を漏らしている時に、1〜8フレームで。トレーラーの飾りには使わない。観客に読ませたい絵ならフラッシュではなくショットにする。
- **よくある失敗**: ただの白い点滅(それはライトフラッシュ)、挿入が居座って新場面になる(それはクラッシュ)。
- **似た技法との違い**: クラッシュは新しい絵に残る。フラッシュは割り込みで、現在に戻る。
- **HyperFramesでの作り方**: 現在場面の上に「挿入絵」レイヤー(高コントラスト、寄り、別の時間)を置き、`tl.set("#insert",{opacity:1},n/30)` と `tl.set("#insert",{opacity:0},(n+k)/30)` で**k=2〜6フレーム**だけ出す(30fpsで67〜200ms)。ディゾルブ・フェードは入れない。連鎖するなら 3f挿入→6f現在→2f挿入のように間隔を不規則にする。挿入絵は1フレームでも意味が拾えるよう、単純なシルエット+強い色対比にする。各挿入フレームに目安の音(短いティック/逆再生ノイズ)を同フレームで。不透明度のtweenは使わない(`tl.set` のみ)。
- **音との合わせ方**: 挿入ごとに無音の「0.5フレーム分」を作るより、1発の短いパーカッションを同フレームに置く方が効く。
- **難易度/適性**: ★(`tl.set` だけ。フレーム数の設計が肝)。
- **AI動画生成プロンプト**: `Flash cut through [Subject], a few frames of another image interrupting, lightning in the edit; name the insert and its duration in frames, no dissolve, return to the present scene.`

### フラグメント(断片編集) / Fragments  (`editing/fragments`)
- **一言**: 出来事を部分的な断片だけで構成し、全体像は観客の頭の中に組み立てさせる。
- **物語での役割**: 直接見せずに衝撃を最大化する。袖、取り落とし、顔、床の陶器、画外の破砕音で、観客が「一撃」を自分で完成させる。
- **使う/使わない**: 暴力・パニック・組み立たない記憶を、直接描写なしで強くする時に。1テイクで合法に見える必要があるデモ(使い方説明など)には使わない。断片に因果の順序がないとコラージュになる。
- **よくある失敗**: 完全な引きの絵がどこかにあって全体が見えてしまう、断片の向きがバラバラで因果が読めない。速いだけで明瞭さがない。
- **似た技法との違い**: クイックカットは速度のパターンで完結した行為を見せ得る。フラグメントは完全な一撃を隠す。
- **HyperFramesでの作り方**: 断片をベクター/シルエット/UIの別ショット(4〜8個)に分け、**スクリーン方向を固定**して因果順(接近→部分→反応→余波)に並べる。1断片は6〜15フレーム、接触の瞬間は描かず、その位置に黒の1〜2フレーム+音のヒットを置く。同一コンポジション内ならclipを連続配置、場面ファイル連結なら断片ごとに別mp4。断片間をつなぐ共通の手がかり(袖の色、同じ影の方向)を入れ、音(衝突・破砕)を断片の最後の1つ後に置いて全体を完成させる。画面の割れ・破片の演出は SVG で多角形を飛ばす(seed付きPRNG)。
- **音との合わせ方**: 画にない接触を音で言い切る(接触を描かない分、音は大きく、1発)。
- **難易度/適性**: ★★(断片設計と因果の整理が要る)。
- **AI動画生成プロンプト**: `Fragments of [Subject], shattered coverage, pieces of a moment, the scene as shards in causal order, no single wide that completes the event, one binding sound.`

### グラフィックマッチ / Graphic Match  (`editing/graphic-match`)
- **一言**: 時間も場所も違う2つの絵を、形・線・色・位置・動きの共有でつなぐハードカット。
- **物語での役割**: 説明なしに「形の跳躍」で時間や場所を越える。排水口→目(円と中心)のように、観客が先に跳躍を感じてから意味に気づく。
- **使う/使わない**: 時計の文字盤→ドーム、叫ぶ口→トンネルのように、形が時間を越えて生き残る時に。共有する輪郭が指させないなら使わない(ただのカット)。
- **よくある失敗**: モーフにしてしまう(AがBに溶ける)、被写体が同じ俳優というだけで一致させる。2枚目が同じ輪郭・同じ位置を占めていない。
- **似た技法との違い**: マッチカットは「意味」も主張する。グラフィックマッチは形だけでもよい。モーフは補間するが、これはしない。
- **HyperFramesでの作り方**: 設計書(BIBLE.md)に**共有アンカー**を書く: `ANCHOR = {cx:960, cy:540, r:300, stroke:24, color:#F5E6C8}`。場面AもBもこの定数で円(SVG `<circle>`)を同じ位置・同じ太さに置き、AはAの中身(排水口)、Bは別の物(目)として描く。最終フレームのA(`n-1`)と最初のフレームのB(`0`)を `hyperframes snapshot --at` か `ffmpeg -vf select='eq(n,K)'` で静止画にし、`ffmpeg -i a_last.png -i b_first.png -filter_complex blend=all_mode=difference` で輪郭がずれていないか確認する。カットはハード、中間にフェードを入れない。柔らかい韻にしたい時だけ6〜8フレームの短いディゾルブ(精度は見えなくなる)。既製: `npx hyperframes add match-cut`(円が加速→ハードスワップ→同じ円が継続)も参照。
- **音との合わせ方**: 形がつながるカットの瞬間に、環境音を断ち切らず低い持続音をそのまま渡すと「ひとつの出来事」に聞こえる。
- **難易度/適性**: ★(定数共有と差分チェックで精度が出る)。
- **AI動画生成プロンプト**: `Graphic match on the silhouette of [Subject], shape echoing shape, circle to circle, same placement and size, objects remain distinct; hard cut, no morph.`

### 見えないカット / Invisible Cut  (`editing/invisible-cut`)
- **一言**: 動き・暗闇・遮蔽・ブラー・幾何の一致で編集点を隠し、ワンテイクに見せる。
- **物語での役割**: 観客に切れ目を意識させず、長回しの連続性や、人物が消える手品を成立させる。
- **使う/使わない**: 劇場・塹壕・通りを1本の歩みでつなぐ時、人物を椅子から消す時に。場面転換の脚本を書かない言い訳には使わない。つなぎ目を見せたいならワイプ等を使う。
- **よくある失敗**: 隠し場所が弱く、粒子・群衆・壁に「ポップ」が出る。照明や露出が左右でずれる。
- **似た技法との違い**: ウィップパンはつなぎ目を隠す絆創膏にも、見せる遷移にもなる。見えないカットは「見つからない」ことが目的。
- **HyperFramesでの作り方**: **画面を埋め尽くす遮蔽物**の最中にハードスワップする。例: 暗い壁パネルが3〜5フレームで画面を覆う(`x: 110%→-10%`、`power3.in`、横方向 `filter:blur(14px)`)→ 完全に覆った 2〜4フレームの間に `tl.set` でA→Bの中身を差し替え→パネルが抜ける(`power3.out`)。覆う前後で速度・方向・ブラー量・ノイズ(grain)を一致させる。ベクターなら共通の背景ノイズ(canvasのseed付きPRNG)を両側で同じに保つ。既製: `npx hyperframes add whip-pan-cut`(A/Bを1本のストリップに載せ、継ぎ目速度が構造的に一致)、`whip-pan`(シェーダー版)。ワンテイクの錯覚は、A末とB頭の動きベクトルをフレーム単位で一致させる。
- **音との合わせ方**: 遮蔽の瞬間に環境音を途切れさせず連続させる(ここで音が変わると偽物が露見する)。
- **難易度/適性**: ★★(遮蔽中の差し替えと、前後のブラー・速度一致の調整)。
- **AI動画生成プロンプト**: `Invisible cut hidden in [Subject]'s whip, a dark wall, or a passing body, the oner illusion; two plates joined at occlusion or blur, locked lighting, no liquid morph.`

### アイリス / Iris  (`editing/iris`)
- **一言**: 円や図形のマスクが動いて、絵を現し/隠す。中心が「ここを見ろ」の指差しになる。
- **物語での役割**: サイレント喜劇の「ウィンク」であり章の閉じ。満足顔→ピアノ上のあくび猫、と絵の一点を指差しながら閉じる。覗き窓などの視覚装置の模倣にもなる。
- **使う/使わない**: 指輪・視線・ギャグを指して終える、場面を演劇的に閉じる時に。カメラが近づく必要がある場面にはカメラを動かす(アイリスで代用しない)。全体を均等に落とすならフェード。
- **よくある失敗**: ズームと取り違える(カメラが寄っている)、全体の露出が下がる(フェード/ビネットになる)、マスク外が単に暗いだけの隅。
- **似た技法との違い**: ビネットは生きた画面の隅の光量低下(遷移ではない)。アイリスは境界が移動して絵が消える/生まれる。
- **HyperFramesでの作り方**: 絵を黒背景の上に置き、`clip-path: circle(r at cx cy)` を proxy tween の onUpdate で設定する(`r` は画面中心から最遠コーナーまでの距離 `hypot(W,H)/2` が全開値、`R→0`が閉)。アイリスアウト: 24〜36フレーム、`power2.inOut`。最後に小さな円(r=40〜80px)で6〜12フレームホールドしてから閉じると「指差し」になる。中心を被写体に追従させるなら、`cx,cy` を被写体座標の関数にする。縁を柔らかくするなら `mask-image: radial-gradient(circle at cx cy, #000 calc(r - 8px), transparent r)`。アイリスイン=B場面を0→全開。カメラは動かさず、マスク内の絵は100%露出を維持。既製: `npx hyperframes add iris-reveal`(円clip-pathが任意の原点から開く)、シェーダー版 `sdf-iris`、図鑑 `transitions-radial` / `transitions-mechanical`。
- **音との合わせ方**: 閉じる時にシャッター音かスライドホイッスルを円の収束に合わせ、円が閉じ切る前に音を止めて「間」を作る。
- **難易度/適性**: ★(clip-pathだけ)。
- **AI動画生成プロンプト**: `Iris in or out on [Subject], a circular mask closing on a face or detail, silent-era pointing or a wink; camera stays still, the mask moves, do not zoom into darkness.`

### ジャンプカット / Jump Cut  (`editing/jump-cut`)
- **一言**: ほぼ同じ構図の中で時間を抜き、不連続をあえて見せる。
- **物語での役割**: 苛立ち・不安定・滑稽な省略・構築された語り口。観客は安心させられず、フィルムが「飛んだ」ことを見せつけられる。
- **使う/使わない**: 待ち時間、延々と続く会話、長いのに短いドライブなどに。見えない連続性が欲しい場面(それはアクションつなぎや見えないカット)、撮っていないカバレッジの代用には使わない。
- **よくある失敗**: 全ショットが別アングルになり、飛んだ感じがしない(それはクイックカット)。構図が変わりすぎて「ふつうのカット」に見える。AI生成で人物の姿勢がモーフする。
- **似た技法との違い**: スマッシュは全く違う絵にぶつける。ジャンプは似た枠の中で時間だけ飛ぶ。軸上カットは距離を飛ぶ。
- **HyperFramesでの作り方**: 固定構図の1つの世界に**「世界時間 w」の不連続**を入れる。proxy `{w:0}` を持ち、すべての動き(時計の針、減っていくコーヒー、積もる吸い殻、人物の姿勢)を `w` の関数で描画する。`tl.to(p,{w:4,ease:'none',duration:4/…})` の後、カット点で `tl.set(p,{w:9})` と**値を飛ばす**。飛びを見せるため、毎回 1〜3%のスケール/位置ずれ(`x:+12px` など)を足す。1ショットは20〜60フレーム、飛ぶ回数は3〜6回、後半ほど短くすると焦燥が出る。時計の針・影の長さ・窓の外の明るさなど「経過が分かる要素」を必ず1つ入れる。
- **音との合わせ方**: 環境音を連続させると飛びが滑らかになり、カット位置で音も途切れさせると不穏になる。どちらかを意図して選ぶ。
- **難易度/適性**: ★(世界時間の関数化がポイント)。
- **AI動画生成プロンプト**: `Jump cut on [Subject], time skipped inside a near-locked framing, same seat, missing frames, anxiety or comedy of waiting; the camera does not move or morph.`

### Jカット/Lカット(絵の設計) / J-Cut / L-Cut (Visual Setup)  (`editing/l-cut-visual`)
- **一言**: 絵と音をずらしてつなぐ。Jカットは次の場の音が先に来る、Lカットは前の場の音が次の絵にはみ出す。
- **物語での役割**: 思考が扉を越えて渡る。聞き手の顔が橋になり、声や音楽が絵に先行/遅行して、皮肉・恐怖・「顔を離さない声」を生む。
- **使う/使わない**: 部屋に入る前に会話へ入る、告白の後も聞き手に留まる、無関係な場面に歌を流し続ける時に。両者が同時に見えなければならない場面にはスプリット、会話の既定のカットにはしない。
- **よくある失敗**: 絵と音を同じフレームで切る(単なる反応ショット)。ずれの意味が決まらないランダムな音楽をL的にただ流す。
- **似た技法との違い**: 反応ショットは絵の側。J/Lはその絵が音とどう出会うかの設計。クロスカッティングは線ごと交互にする。
- **HyperFramesでの作り方**: 本スキルでは**音は別トラックで貼る**(§11-5)ので、絵のカット点と音の開始点を別の時刻にするだけ。`<audio id="b-voice" data-start="…">` を、B絵のスタートより**12〜24フレーム早く**置く(J)。Lは `<audio>` の `data-duration` をA絵の終了より12〜24フレーム長くする。絵側は「ずれを支える顔」を作る: 聞き手の静止的なクローズアップ(まばたきと息だけ、`sine.inOut` の±2pxの呼吸)、歩く背中、空のオフィス。音源の分かる位置(ドアの向こうの声はローパス+リバーブを足す: ffmpeg `lowpass=f=1800` 、`aecho`)にして、重なりが「情報」になるようにする。`<audio>` の `id` を必ず付ける(無いと無音)。ミックスは `hyperframes-audio` スキルを参照。
- **音との合わせ方**: ずれの量は 12〜24フレーム(0.4〜0.8秒)が目安。Bの声を先に入れる時は、Aの環境音を同時にダッキングして混濁を防ぐ。
- **難易度/適性**: ★(絵の設計と音の時刻差だけ)。
- **AI動画生成プロンプト**: `A frame of [Subject] designed as the picture half of an L-cut or J-cut, a listening face holding while another space is already speaking; specify whether B's audio starts under A or A's audio continues under B.`

### アクションつなぎ / Match on Action  (`editing/match-action`)
- **一言**: 1つの連続動作の途中で切り、動きそのものが2つのカメラ位置をつなぐ。
- **物語での役割**: 切れ目が動きの中に隠れる。引きで手がドアノブに伸び、アップで同じ手が同じ速度で回し終える。観客は伸ばす動作を追い、つなぎ目を検査しない。
- **使う/使わない**: ドア・殴打・着席・注ぐ動作で、ショットサイズや角度を変える時に。別の日・別の部屋へ飛ぶ時には使わない(それはマッチモーションや通常のカット)。
- **よくある失敗**: 手が入れ替わる、歩行の向きが反転する、動作が両側で二度繰り返される。動作が着地した後で切る。
- **似た技法との違い**: マッチカットは2つの異なる絵を韻でつなぐ。アクションつなぎは1つの動作を2視点で見せる。
- **HyperFramesでの作り方**: 動作を**1つの関数 `f(u)`(u=0〜1の進行度)として定義**し、AとBの両方がこの同じ `f` で描くのが最も確実。例: 腕の回転角 `θ=f(u)`。Aは `u=0→0.5`、Bは `u=0.5→1` を担当し、カット点(`u=0.5`、加速の最中。着地後ではない)で位置・角度・速度を完全一致させる。両場面ファイル共通の `motion.js`(定数と関数)を置き、設計書に「動作・手・物・向き・カット点 u」を書く。ショットサイズが違うので、スクリーン上の座標だけ別にし、**進行方向(スクリーン方向)を固定**する。速度の連続性のため、カット点で `ease` の導関数が連続なこと(`power2.inOut` なら中点が最速。ここで切るのが最も自然)。カット前後で音の連続(衣擦れ、ドアの軋み)を保つ。
- **音との合わせ方**: 動作音(軋み・風切り)を絵のカットとは無関係に連続させる。音が動作の続きを保証する。
- **難易度/適性**: ★★(動作関数の共有設計)。
- **AI動画生成プロンプト**: `Match on action through [Subject]'s gesture, the motion started in a wide and finished in a close, same hand, same object, same direction of travel; cut mid-motion, do not reverse the hand.`

### マッチカット / Match Cut  (`editing/match-cut`)
- **一言**: 視覚・空間・音・概念の対応で2つのショットをハードカットでつなぎ、つなぎ目そのものが「同じ考え」という文になる。
- **物語での役割**: 2つの絵が同じ観念だと1フレームの時間で着地する。骨→宇宙船、マッチの炎→太陽。前の意味が後で変わる(仕込みと回収)。
- **使う/使わない**: 道具から道具へ、炎から太陽へ、仕込んだ物の再登場で意味が変わる跳躍に。次の部屋へ行くだけの美しい退場には使わない(単純なカットかディゾルブの方が清潔)。2枚目が1枚目の意味を変えないなら使わない。
- **よくある失敗**: モーフにする(液状に溶ける)、概念のない輪郭だけの一致(それはグラフィックマッチ)、同一被写体のIDだけで形が一致しない。
- **似た技法との違い**: グラフィックマッチは形の韻(意味が薄くてよい)。マッチカットは意味・空間・音の対応も要る。アクションつなぎは1動作の別アングル。
- **HyperFramesでの作り方**: **設計書に「前の場面の最終フレームと次の場面の最初のフレームの一致表」を書く**。例:

  | 項目 | A最終フレーム(n-1) | B最初のフレーム(0) |
  |---|---|---|
  | 共有形 | 円 直径320px | 円 直径320px |
  | 中心 | (960, 540) | (960, 540) |
  | 動き | 右へ 40px/フレーム | 右へ 40px/フレーム |
  | 変わるもの | 場所=月(夜空) | 場所=皿(食卓) |

  この定数をBIBLE.mdの共有定数にし、A・Bは別ファイルでも同じ座標・同じ速度(`x`の微分)で描く。ハードカットだけにする(ディゾルブ・フェードなし)。ズレは `ffmpeg … select='eq(n,K)'` で取った2枚を `blend=all_mode=difference` で重ねて輪郭の残りを確認する。既製: `npx hyperframes add match-cut`(円が加速して単フレームで場面スワップし、同じ円が継続)、文字なら `text-match-cut`、見出しが割れて次の面が伸びる `type-match-cut`。
- **音との合わせ方**: 音も包絡を一致させる(ボン→ボンの同音程、あるいは音の尾が次の音の頭に重なる)。
- **難易度/適性**: ★★(一致表と差分チェックの運用が要る)。
- **AI動画生成プロンプト**: `Match cut from [Subject A] to [Subject B], rhyming shape or motion in another time, same screen position and scale, two distinct objects; hard cut, no morph, no dissolve.`

### マッチモーション / Match Motion  (`editing/match-motion`)
- **一言**: 方向と速度をカットをまたいで継続させ、場所・時間・現実が変わっても動きのベクトルでつなぐ。
- **物語での役割**: 体が連続性で、部屋は嘘をついてよい。マットレスへ落ちる→草地へ落ちる、プールへの飛び込み→ベッドへの飛びつき。夢から街へ、追跡から追跡へ、不可能な移行を運ぶ。
- **使う/使わない**: 夢から目覚める、複数の街にわたる追跡、ダンスが別の時代に続く時に。同じ部屋でカメラを変えるだけならアクションつなぎ。体が静止している場合はグラフィックマッチかマッチカット。
- **よくある失敗**: 歩行が途中でリセットされる、速度が変わる、被写体が両側で静止している。顔だけ揃えて動きの位相が一致しない。
- **似た技法との違い**: アクションつなぎは同じ世界の同じ出来事。マッチモーションは世界が変わってもベクトルが保たれる。ウィップはブラーで隠す、これは被写体の動きで隠す(併用可)。
- **HyperFramesでの作り方**: 設計書に「カット点でのスクリーン位置・進行方向・速度(px/フレーム)・姿勢」を固定値で書く。落下なら、位置 `y(t)=y0+v0·t+½g·t²`(単位はフレーム)のような**1つの式**をA/B共通にし、Aは `t=0…k`、Bは `t=k…k+m` を担当する(速度が式の中で連続するので、継ぎ目でガクつかない)。実装は proxy `{t:0}` を `ease:'none'` で動かし、onUpdateで `y(t)` を各場面の要素に設定する。 背景は完全に差し替わる(夜景→草地)が、主役のシルエットはA/Bで同じ座標・同じ姿勢。ブラーは進行方向のみ(`filter:blur`をX方向に近似する場合は SVG `feGaussianBlur stdDeviation="14 0"`)を両側同量。既製: `npx hyperframes add cut-the-curve`(出る側が `power4.in` で加速→ピーク速度でスワップ→入る側が同方向に `power4.out`)、`whip-pan-cut`。
- **音との合わせ方**: 風切り音・落下音を持続させ、世界が変わる瞬間にだけ環境音を差し替える(音の連続が方向の連続を保証する)。
- **難易度/適性**: ★★(速度の数値一致が必須)。
- **AI動画生成プロンプト**: `Match-motion cut on [Subject], direction and speed continuing across the join so the cut rides the movement; matched pose and velocity, the world changes; hard cut, no dissolving body.`

### マッチスプリット / Match Split  (`editing/match-split`)
- **一言**: 画面を分割し、その境界をまたいで同じ線や動きを連続させ、2つの世界を1つの有機体のように見せる。
- **物語での役割**: テーブルの縁が1960年代の台所から現在の食堂へ走る。顔が半分に割れて、左が想像のパーティ、右が現実のパーティ。1本の線、2つの世界。
- **使う/使わない**: 双子・二重生活・期待と現実・同じ道の2つの時間帯に。共有する輪郭がなく単に同時進行なら普通のスプリットスクリーン。
- **よくある失敗**: アイライン・水平線が両パネルで合っていない。別々に撮ったクリップを積んだだけで境界を設計していない。
- **似た技法との違い**: スプリットスクリーンは並べるだけ。マッチスプリットは境界をまたいで形・動きが連続する。マッチカットは順次にフルフレームを置換する。
- **HyperFramesでの作り方**: 左右(または斜め)2つのパネルを `clip-path: polygon(0 0, 50% 0, 50% 100%, 0 100%)` と `polygon(50% 0, 100% 0, 100% 100%, 50% 100%)` で同一の世界座標に重ね、**共有する線(テーブルの縁・水平線・視線)の座標を設計書で一つの値にする**: 例 `LINE_Y=640`、`HORIZON_Y=420`。両パネルの内容は別の絵だが、この線は両側で同じ `y` から出る。動きを連続させる時は、片方のパネルで進む物体が境界を越えた瞬間に、もう片方のパネルで続きを描く(`x` を同じ関数で)。境界線は固定(動かさない)か、14〜24フレームで `50%→35%` のようにゆっくり動かして一方の世界を押し広げる。既製: 境界が動く `npx hyperframes add before-after-wipe` / `comparison-split`(2つの全面パネルを分割線が走る。比較用だが境界設計の足場になる)。
- **音との合わせ方**: 左右のチャンネルを左=世界A、右=世界Bで振り分け、境界で音も溶け合う(中央で混ざる)と1つの線として感じる。
- **難易度/適性**: ★★(共有する線の座標設計)。
- **AI動画生成プロンプト**: `Match split of [Subject], a graphic divide that continues a line or motion into another space, both halves simultaneous, shared horizon or eyeline, stable boundary, no morph across the seam.`

### モンタージュ / Montage  (`editing/montage`)
- **一言**: 完結した絵を順番に並べ、衝突や連なりから意味(論証)や時間の圧縮を生む。
- **物語での役割**: 絵と絵の間に観客が意味を立てる。労働者→屠殺場は論証。汗・縄・階段・息、そして同じ階段を後で駆け上がる体で、鍛錬の月日が1分に畳まれる。
- **使う/使わない**: 数か月を1分に、1つの絵では言えない考えを作る時に(訓練、崩れていく結婚の朝食、都市の到来)。1戦を一撃ずつ追わせるべき場面(それは撮って流す)には使わない。「同時進行」が要るならクロスカッティング。
- **よくある失敗**: 主張のないクイックカット、同じ5秒の20アングル、モーフするコラージュ。比喩を事実の証明であるかのように見せる。
- **似た技法との違い**: クロスカッティングは進行中の複数の行動を交互に生かす。モンタージュは1つ1つが完結した単位で、並びが主張を作る。
- **HyperFramesでの作り方**: まず**推論か時間曲線を一文で設計書に書く**(例:「同じ階段。1か月目は3段で倒れ、6か月目は駆け上がる」)。ショットを `SHOTS=[{el, dur, label}]` のデータ配列にして、ループで `tl.set` と開始時刻を計算する(`start += dur`)。尺は**縮む曲線**(24→18→14→12→10→8→6フレーム)+ピークの後に36〜48フレームの保持(間=ペイオフ)。共通モチーフ(同じ階段・同じ構図)を毎ショットで再利用し、変化する要素(段数のカウンタ、汗の量、服の汚れ)を連続変数にする。ショット間はハードカット。拍に乗せる場合、1拍12フレーム(150BPM)に尺を揃え、全カットを拍に置かず、強拍だけに主要なカットを置く。
- **音との合わせ方**: ビートで刻む音楽1本を通し、カット位置は強拍に合わせるが、全部には合わせない。時間経過のしるし(季節の環境音)を各ショットに入れる。
- **難易度/適性**: ★★(素材量とデータ駆動の設計。ベクター/タイポ/UIでショットを作れば十分実現できる)。
- **AI動画生成プロンプト**: `Montage sequence built around [Subject], time collapsed by images, training or travel or a life in twenty shots; list the ordered images and what the collision claims, no morph between shots, a shortening duration curve.`

### クイックカット / Quick Cuts  (`editing/quick-cuts`)
- **一言**: 息より短いショットを連ねて、持続時間そのものをリズム・圧力・音楽にする。
- **物語での役割**: 加速が物語になる。決闘が体から目へ絞られ、突入が畳み掛け、練習が懲罰に変わる。最後の一撃の前に解放が来るのを観客が体で感じる。
- **使う/使わない**: 決闘・演奏・追跡など、加速や拍が物語を担う時に。会話のように呼吸が要る場面には使わない。休まないと最後の一撃が着地しない。
- **よくある失敗**: 全ショットが同じ長さ・同じサイズで曲線がない、軸が変わらない(ジャンプカットになる)。混沌だけで終点がない。
- **似た技法との違い**: ジャンプカットは似た枠の中で時間を抜く。クイックカットは別セットアップのショットの速度(レート)。
- **HyperFramesでの作り方**: **尺カーブ+サイズ進行**を表にして書く(例: 引き→胸→手→目、尺 18/14/10/8/6/4フレーム)。`SHOTS` データ配列から `tl.set` でループ生成(モンタージュと同じ方式)。各ショットはスケール・アングル・色を変える(同じ軸のまま短くするとジャンプカット)。全カットを拍に合わせず、強拍と裏拍を混ぜる。クライマックスは**計画した1つの保持**(18〜30フレーム止める)で着地させる。1拍12フレームの場合、最短は2〜3フレーム。音声側の拍検出は `npx hyperframes beats`、衝撃の増幅は `beat-accent`(インパクトの閃光と微小スケールパルス、すぐ減衰)を使える。
- **音との合わせ方**: 打楽器に切り替えを合わせ、最後の保持では音も一拍抜く(無音の1拍)と着地する。
- **難易度/適性**: ★(データ駆動、素材の作り分けが仕事)。
- **AI動画生成プロンプト**: `Quick cuts around [Subject], shots shorter than a breath, rhythm as violence or music; a progression of sizes from wide to eyes, a shortening duration curve, one planned pause for the landing, no morph.`

### セットトランジション / Set Transition  (`editing/set-transition`)
- **一言**: カット無しで、カメラの前で場所そのもの(壁・建築)が書き換わり、1つの空間が別の空間になる。
- **物語での役割**: 世界が多孔質になる。楽屋の壁が滑って夜のクラブになる、劇場の扉が街になる。人物は切れていないのに世界が編集する。
- **使う/使わない**: 稽古から本番へ、記憶から街へ、建物から建物へ、編集を認めずに歩く時に。ハードカットやワイプの方が正直で速い場面には使わない。2つ目の空間に新しい内容がないと虚しい技巧になる。
- **よくある失敗**: 人物が溶けてモーフになる、戸口でポップが出る。
- **似た技法との違い**: 見えないカットはつなぎ目を隠すだけ(セットは同じでも良い)。セットトランジションは建築を連続移動の中で書き換える。
- **HyperFramesでの作り方**: 主役(ベクターの人物・小物)は**変えない最前景の1層**にして、位置を連続(`x` を `none` で一定速度)で動かす。背後に「セットA」「セットB」の層(壁・床・照明色の面)を置き、**スライドする壁**: セットAの壁パネルが `xPercent: 0→-100`(1.0〜1.5秒、`power2.inOut`)で抜けると背後からBが現れる。**回転する壁**: 親に `perspective:1400px`、A壁を `rotateY(0→-90deg)`、B壁を `rotateY(90→0deg)`(`transform-origin` を共有する縁に)。照明色も `filter: hue-rotate()`/背景色のtweenで連続的に変える。既製の見本: `npx hyperframes add transitions-3d`(遠近の回転遷移集)、`transitions-cover`。主役の位置と速度は遷移中も変えない。
- **音との合わせ方**: 壁が動く間に両世界の環境音をクロスフェードし、歩行音は途切れさせない。
- **難易度/適性**: ★★(層構成とパースペクティブ)。主役が実写の場合は不向き。代替はベクター人物とパネルの組み合わせ。
- **AI動画生成プロンプト**: `Set transition around [Subject], the location transforming in camera, walls walking, one space becoming another; the camera does not hard-cut, the person stays continuous, no morphing faces.`

### スマッシュカット / Smash Cut  (`editing/smash-cut`)
- **一言**: 画・音・調子・スケール・時間のいずれかを急激に反転させ、築いた状態を柔らかい混ぜなしに壊す。
- **物語での役割**: 偽の終わりを一撃で叩く。夜道の緊張が高まる→バスのドアが開く(怪物ではなく乗り物)で、冗談であり平手打ちでもある。墓参りが落ち着いた直後に、土を破る手。
- **使う/使わない**: 対比が意味になる時、偽の終わりに。毎回の場面転換には使わない。Aが静か・神聖・解決の状態を本当に築いていなければ、Bには壊すものがない。
- **よくある失敗**: ディゾルブでやさしくする、AとBの明度・スケール・調子が近い(何も壊れない)。静けさを築かずただ大きいだけ。
- **似た技法との違い**: クラッシュは築く前から衝突として始まる。スマッシュはAで状態を築いてから壊す。ジャンプは似た枠で時間を抜く。
- **HyperFramesでの作り方**: Aを**最低36〜72フレーム(1.2〜2.4秒)保持**し、低明度・小さなスケール・無音に近い環境音でトーンを築く(**ゆっくりした動きで静けさを演出**: 例 `scale 1.0→1.03`、`sine.inOut`)。Bに切る時は**2軸以上を同時に反転**(明度とサウンド、スケールとトーン)。例: A=暗い室内の小さな人物 → B=白飛びの全画面+巨大タイポの衝撃。ハードカット(`data-start` の接続)、フェードもディゾルブもなし。音は映像Bの第1フレームに合わせて叩くか、**6〜9フレーム遅らせて「見えて→聞こえる」の二段打撃**にする(爆発の遅延)。検証は `signalstats` のYAVGでBの第1フレームの明度ジャンプ、音のRMS立ち上がりを突き合わせる(§11-7)。
- **音との合わせ方**: 直前の0.5〜1秒を完全な無音にしておくと、Bの音の衝撃が倍になる。
- **難易度/適性**: ★(`data-start` の接続と明度設計)。
- **AI動画生成プロンプト**: `Smash cut from [Subject] to a violently different image, silence to noise, prayer to explosion, no polite dissolve; name the outgoing quiet state and the incoming opposite, hold A then hard-cut to B.`

### スプリットスクリーン / Split Screen  (`editing/split-screen`)
- **一言**: 2つ以上の別々の空間を同じ画面に同時に見せる。
- **物語での役割**: 電話で2つの部屋が1つの絵になる。パーティが「望んだ夜」と「得た夜」に割れる。二重の自己・二重の時間・二重の目撃を、パネルそのものが語る。
- **使う/使わない**: 同時進行の電話、双子、期待と現実、1時間の4分割に。1つの会話の普通のカバレッジを飾る壁紙には使わない。「会うと思わせて違う」誤誘導はクロスカッティングの方が向く。
- **よくある失敗**: 窓・扉・鏡など世界内の枠(それはフレーム内フレーム)。1枚の引きに傷線を引いただけ。パネル間でアイラインが合っていない。
- **似た技法との違い**: クロスカッティングは交互、スプリットは同時。マッチスプリットは境界をまたいで線が連続する。
- **HyperFramesでの作り方**: CSS Grid (`grid-template-columns: 1fr 1fr`) か `clip-path: polygon()` でパネルを分け、各パネルは**独立した世界**として内容を作り、両者が同じ世界時間 `w` で動く(同時の保証)。境界は幅4〜8pxの区切り線(`#F5F5F5` など)。登場は、パネルが `xPercent: ±100→0`(12〜18フレーム、`power3.out`)で滑り込む。電話: 両パネルの発話を交互にし、聞き手の反応を相手の発話の途中で見せる。4分割は登場を6フレームずつずらして順に入れると読みやすい。パネル間のアイラインやタイトルは各側に寄せて、境界を越える視線(→)を設計書に書く。既製の足場: `npx hyperframes add comparison-split` / `before-after-wipe`(分割線を持つ2面比較)。
- **音との合わせ方**: 左右のチャンネルを各パネルに振り分け、電話声にバンドパス(`highpass=f=300,lowpass=f=3400`)を掛けると「別の場所」らしくなる。
- **難易度/適性**: ★(レイアウトのみ。2場面分の作画が要る)。
- **AI動画生成プロンプト**: `Split screen with [Subject] in one pane and another life in the other, simultaneous spaces, phone-call cinema or dual identity; two complete shots composited with a graphic divide, not one image torn as a texture.`

### トランジション(設計された遷移) / Transitions  (`editing/transitions`)
- **一言**: つなぎ目を「隠す接着剤」ではなく、見せる身振りとして設計する。ワイプ・マッチ・ディゾルブ・ウィップ・光などの種を選ぶ。
- **物語での役割**: ワイプはページをめくり、マッチは観念を主張し、ディゾルブは思い出し、ウィップは投げる。どう去ってどう入るかが、冗談・主題・章の区切りになる。
- **使う/使わない**: 幕の区切り、世界の跳躍、映画についての冗談に。会話場面の逆ショットのたびに使わない。カメラが変わるだけなら、素のカットが設計。
- **よくある失敗**: 種を選ばず「かっこいい遷移」を指示する。AとBに設計された関係がなく、フィルタが両者をどろどろに混ぜる(モーフ)。
- **似た技法との違い**: このページは「つなぎ目を身振りにする」選択。ワイプ・ディゾルブ・マッチ等はその種。見えないカットは反対の流儀。
- **HyperFramesでの作り方**: **種を1つ選び、物理を守る**。選び方: 継続=クロスフェード、次の論点=プッシュ/スライド、観念=マッチカット、強調=フラッシュ、衝突=グリッチ。エネルギー別の目安は 穏やか 0.5〜0.8秒(`sine.inOut`)、普通 0.3〜0.5秒(`power2/3`)、高 0.15〜0.3秒(`power4`/`expo`)。**主役の遷移を1つ(場面転換の6〜7割)+アクセント1〜2個**に絞り、毎回変えない。CSSは `clip-path`/`mask`/`transform`/`filter:blur` で作り、凝った質感は既製のシェーダー遷移に任せる: `npx hyperframes add flash-through-white`(白く閃光)/ `glitch`(デジタルの乱れ)/ `light-leak`(光漏れ)/ `whip-pan` / `cinematic-zoom` / `cross-warp-morph`。いずれも `npx hyperframes catalog --query transition` で一覧が見られる。重要規則: 遷移中は旧場面を**満たした状態**で始め、退場アニメを先に入れない(遷移が退場)。場面ファイルをffmpeg concatする運用では、遷移は場面の入り/出に内蔵するか、両端にハンドルを足して `xfade` を使う。
- **音との合わせ方**: 遷移ごとにwhoosh/riser/chimeなどの短いSFXを遷移の中点に合わせ、同一の遷移には同一の音を使う(§11-5の同梱SFX)。
- **難易度/適性**: ★〜★★(種による。既製のシェーダーは★)。
- **AI動画生成プロンプト**: `A designed transition around [Subject], the join as a gesture: wipe, match, mix, light, or whip; name both sides and the species of join, generate A and B as complete shots, no "cool transition" filler.`

### ワイプ / Wipe  (`editing/wipe`)
- **一言**: 画面を横切る境界が、前の絵を次の絵に置き換える。境界が見えることが前提の編集。
- **物語での役割**: ページをめくるような、冒険活劇・連続活劇・遊び心のある地図の感覚。村が山道に変わる、地理が「見せかけの編集」で正直に変わる。
- **使う/使わない**: 惑星から惑星、村から道、章から章へ、素早く物語的に切り替える時に。編集を感じさせたくない場面(それは見えないカットやアクションつなぎ)、連続性の誤りを隠す目的には使わない。
- **よくある失敗**: 境界がぐにゃぐにゃ(モーフ)、通りがかりの人が実質の遷移で、それをワイプと呼ぶ(それは遮蔽)。旅人の進行方向と逆にワイプする。
- **似た技法との違い**: アイリスは中心から広がる穴。ワイプは直線・時計針などの移動する境界。ディゾルブは不透明度を混ぜる。
- **HyperFramesでの作り方**: B(上)の `clip-path` を tween する。水平: `inset(0 100% 0 0)→inset(0 0 0 0)`、斜め: `polygon()` の4点を補間、時計針: 多角形の頂点を4象限に分けて順に伸ばす(中心+周辺点で `polygon`)。尺は12〜18フレーム、`none` か `power1.inOut`。**方向は物語の移動方向に合わせる**(人物が右へ歩くなら左→右)。柔らかい縁なら `mask-image: linear-gradient(90deg,#000 calc(var(--p)-6%),transparent var(--p))` で `--p` を onUpdate で更新。モーション付きなら境界に細い色線(4px)を足す。既製: `npx hyperframes add directional-wipe`(パネルが他のパネルの上を滑る)、`chromatic-aberration-wipe`(RGB分離付き)、時計/円は図鑑 `transitions-radial`。連結したmp4への後処理は `ffmpeg -filter_complex "xfade=transition=wipeleft:duration=0.5:offset=<秒>"`(`wiperight/wipeup/wipedown/circleopen/radial` なども可)。
- **音との合わせ方**: ワイプの進行に合わせてスライド音(whoosh)を入れ、境界が画面中央を通る瞬間にピークを置く。
- **難易度/適性**: ★(clip-pathだけ)。
- **AI動画生成プロンプト**: `Wipe replacing [Subject] with the next image, a clean line traveling across the frame, Star Wars grammar or a clock hand; name direction and edge hardness, A and B are full frames with a moving mask, no blending scenery.`

## 組み合わせ例(3〜5個)

1. **「静けさ→衝撃」の幕切れ(30秒広告の最後の落とし)**: 前場面を3秒の低明度・無音寄りで築き(スマッシュカットの前置き)、第1フレームで白飛びの巨大ロゴへ**スマッシュカット**(音は6〜9フレーム遅らせて二段打撃)。その直前0.5秒に**フラッシュカット**(3フレーム)で商品の影を1回だけ差し込むと予兆になる。効果: 落差が倍になり、後続の静止が着地する。

2. **形でつなぐ場面転換(場面ファイル連結運用)**: 場面A(夜の月、円)と場面B(食卓の皿、円)を**マッチカット**で結ぶ。設計書に「中心(960,540)・直径320px・右へ40px/フレーム」を書いて両場面に共有定数として配り、`concat` 後に最終/最初の2フレームを `blend=difference` で差分確認。時間経過を示したい時だけ、前に**ディゾルブ**ではなく**フェード**を置いて黒を挟む。効果: 説明なしに「夜から朝」を跳べる。

3. **訓練の月日(モンタージュ+クイックカット+ジャンプカット)**: 同じ階段の構図で、**ジャンプカット**(世界時間を飛ばし、段数カウンタが増える)を序盤に3回、中盤は**モンタージュ**(汗・縄・足音の別ショット、尺 24→6フレームに縮む)、終盤は**クイックカット**で加速し、最後に18フレームの保持で着地させる。効果: 時間圧縮→加速→解放の3段の曲線になる。

4. **電話の場面(スプリットスクリーン→マッチスプリット→Lカット)**: 2つの部屋を**スプリットスクリーン**で並べ、会話が噛み合う瞬間にテーブルの縁を両パネルで同じ高さに揃えて**マッチスプリット**にする。切り終えた後、相手の声だけ12〜24フレーム、相手の顔の絵に残す**Lカット**。効果: 2人が同じ線の上にいる感覚。

5. **ワンテイクの錯覚(見えないカット+セットトランジション+マッチモーション)**: 主役のシルエットは連続して歩かせ、暗い壁パネルが全画面を覆う3フレームの間に世界を差し替える(**見えないカット**)。壁のスライドで背景を書き換える**セットトランジション**を挟み、世界が変わる瞬間に同じ速度で走り続ける**マッチモーション**を重ねる。効果: カット無しに見える長い歩み・追跡。
