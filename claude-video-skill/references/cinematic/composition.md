# 構図(32技法)
> 出典: melies.co/cinematic-techniques(要約・再構成。原文の転載ではない)。HyperFramesでの実装レシピは本スキル独自。

## このグループの選び方ガイド
構図は「画面のどこに何を置くか=誰が空間を所有するか」の図解。まず下の座標表を頭に入れ、技法ごとに「どこを空け、どこを埋めるか」を決める。

**1920x1080 の基準座標(全エントリ共通)**
- 中心 (960, 540)。三分割線 x=640 / 1280、y=360 / 720。交点 (640,360) (1280,360) (640,720) (1280,720)。
- 黄金比(φ=0.618)の分割線 x≈734 / 1186、y≈413 / 667。
- 安全域(Studio準拠): アクションセーフ=各辺5%内側(x 96〜1824, y 54〜1026)、タイトルセーフ=各辺10%内側(x 192〜1728, y 108〜972)。字幕・重要な顔/文字はタイトルセーフ内。
- 配置は絶対配置+GSAPの `xPercent/yPercent`(CSSの初期transformとGSAPを併用しない)。構図ガイド線はHTMLに入れず、確認は `npx hyperframes snapshot --at <秒>` のフレームで行う。

**目的 → 技法の早見**
- 主役を一目で見せる: 人物/物 → 図と地の分離(Figure-Ground)、視覚的重み(Visual Weight)、トーン対比(Tonal Contrast)。
- 儀式・権威・喜劇・「設計された世界」: 中央構図 / 中央フレーミング / シンメトリー / 一点透視 / タブロー。
- 動き・視線・未来を与える: リードルーム / ルックスペース / 三分割 / 黄金比 / 導線(Leading Lines) / 消失点。
- 孤独・不安・閉塞: ネガティブスペース / ヴォイド / ショートサイディング / ヘッドルーム(余白か圧迫か)。
- 覗き・監視・包囲: ダーティフレーム / ボヤー / 前景の物 / フレーム内フレーム / 窓。
- 奥行きと関係性: レイヤード・デプス / 三角構図 / 反射 / スクリーン・イン・スクリーン。
- 見分け: 「中央構図=場全体を軸に整える」「中央フレーミング=被写体だけ軸」「シンメトリー=左右が鏡」「一点透視=消失点が1つ」は別物。リードルーム(動き・視線の前の余白)とルックスペース(画面外の対象を待つ余白)とショートサイディング(わざと潰す)は余白の向きで区別する。
- 入門者がまず覚える3つ: ①三分割とリードルーム(基本の置き方)、②図と地の分離+視覚的重み(主役を読ませる)、③中央構図/シンメトリー(三分割を意図的に破る手)。

## 技法一覧(エントリ)
### アーキテクスチャ / Architexture  (`composition/architexture`)
- **一言**: 建物の面・格子・素材で画面を埋め、人物をその一部(スケール人形)にまで小さくする。
- **物語での役割**: 人間のドラマより「場所」が主役になる。コンクリートやガラスの帯が語り、人は規模を示してから模様に溶ける。
- **使う/使わない**: 都市への到着、機械の中の労働者、記念碑への視線など、場所が人に勝つ場面で。嘘をつく顔のアップが主題の会話シーンには使わない(建物は目の動きを伝えられない)。
- **よくある失敗**: 大きな顔の後ろに絵はがき程度のファサードを置くだけ。引くか長くして、人を「モジュールの一つ」にするか、ポートレートと割り切る。
- **似た技法との違い**: 反復・パターンは「数えられる単位」、アーキテクスチャは不規則な素材(打放し・汚れ)でもよい。
- **HyperFramesでの作り方**: 素材は繰り返し背景(CSS `repeating-linear-gradient`で板型枠の目地、SVG `feTurbulence`+`feColorMatrix`でコンクリのざらつき)を全面に敷く。人は高さ60〜90pxの黒シルエット(SVG)を (1280, 760) 付近(右下三分割の交点付近)に置き、画面高の6〜8%にする。斜光は `linear-gradient(100deg, rgba(255,240,210,.35) 0 30%, transparent 55%)` を `mix-blend-mode:soft-light` で重ね、凹凸を強調。カメラは背景全体を `scale 1.0→1.08`(8秒、`sine.inOut`)でゆっくり押し、人はその倍率の半分で動かして「建物が人を飲む」感を出す。乱数のテクスチャはseed付きPRNGか静止SVG。
- **難易度/適性**: ★(素材と比率の設計だけ)。
- **AI動画生成プロンプト**: `Architecture as texture around [Subject], facades, grids, and materials filling the frame until the person is a detail of the building.`

### アシンメトリー / Asymmetry  (`composition/asymmetry`)
- **一言**: 主役を中心線から外し、色・光・小さな顔・暗い虚空など別種の重さで釣り合わせる。
- **物語での役割**: 空間の所有が不均等になり、欲望・階級・孤独のような「不公平な部屋」が見える。余白は偶然でなく対重(カウンターウェイト)。
- **使う/使わない**: 会話の力関係がいびつな場面、孤独の場面に。左右が敬礼すべき儀式には使わない。意図のない散らかりをバランスと呼ばない。
- **よくある失敗**: 中央構図の失敗(立ち位置ミス)で、何も答えていない空きがある状態。対重を足すか三分割交点へ寄せるか、中央に戻す。
- **似た技法との違い**: 三分割は特定のずらし方の一つ。アシンメトリーはその上位概念で、「何が反対側の重さか」を決めるのが核。
- **HyperFramesでの作り方**: 主役ブロック(幅約560px)を `left:200px; top:300px`(左寄り)に置き、反対側の重さを (1380〜1720, 160〜420) に配置する。例: 小さく明るい窓(240x320px、`#ffe8b0`、`box-shadow:0 0 120px rgba(255,200,120,.6)`)や赤い壁面(幅400px)。釣り合い確認は、同じ色相・明度の面積×距離で左右の「重心」を計算するスクリプト(`sum(面積×輝度×x)/sum(面積×輝度)`)でx≈800〜1120(中心±160px)に収まるかを見る。動かすときは対重側の要素も反対に5〜10px動かすと呼吸が出る。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Asymmetrical balance with [Subject] offset, counterweights of color or mass, tension instead of mirror.`

### 中央構図 / Centered Composition  (`composition/centered-composition`)
- **一言**: 主役を中央軸に置き、周囲(壁・家具・付き人)も軸に合わせて正面の祭壇のように整える。
- **物語での役割**: 支配・儀式・喜劇・運命。部屋全体が主役に従っている(または従っているふり)ことが伝わる。
- **使う/使わない**: 入場、権力の机、ドールハウス的喜劇に。追跡や盗み聞きなど「見てはいけない」場面には使わない。
- **よくある失敗**: 中央に顔があるだけで、左右に不揃いな植物とドアがある(部屋が敬礼していない)。カメラを背面に正対させ、左右の質量を揃える。
- **似た技法との違い**: 中央フレーミングは被写体だけ軸、中央構図は場全体を軸で整える。シンメトリーほど左右の鏡は要求しない。
- **HyperFramesでの作り方**: 主役ブロックを `left:960px; xPercent:-50`、`top` は縦中心540付近か、やや上(視線を y≈480)にして足元を空ける。左右に同サイズの要素(幅280pxの窓/ランプ)を x=360 と x=1560 に対で置き、背景は正面の壁(消失点なしの平面)。入場演出は主役を `y:+40→0`(1.2s `power3.out`)と、背景の壁を `scale 1.04→1.0` の微かな後退で。カメラ移動はしない(正面固定)ほうが「祭壇」が立つ。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Dead-center composition of [Subject], bilateral symmetry or frontal tableau, Wes Anderson formality, the subject as altar.`

### 中央フレーミング / Central Framing  (`composition/central-framing`)
- **一言**: 人物を光軸の十字線(画面中心)に置く。左右の余白が等しくなり、主役が軸を所有する。
- **物語での役割**: 提示・裁き・崇拝・コミカルな凝視。余白は視線の未来でなく、等しい両翼になる。
- **使う/使わない**: 神、独裁者、子供の仮装、レンズ目線のギャグなど。狩人・逃走者・盗み聞きには使わない(ポスターになってしまう)。
- **よくある失敗**: 三分割のつもりが少しずれて、視線側の余白が頭の後ろより多い。両側の余白を揃えるか、リードルームと割り切る。
- **似た技法との違い**: 中央構図は場全体、中央フレーミングは「身体が十字線上」だけ。散らかった街で顔だけ中央に置いてもよい。
- **HyperFramesでの作り方**: 主役の中心を (960, 540)、顔の目の高さは y=440〜480(上目に置くと威厳、下目に置くと滑稽)。`gsap.set(el,{left:960,top:500,xPercent:-50,yPercent:-50})`。左右の余白を確認するため、主役の `getBoundingClientRect()` から `left` と `1920-right` を比較して差を±8px以内に収めるチェックを制作時に入れる。強調したいときは背景全体に `vignette`(`npx hyperframes add vignette`)で周辺を落とし、中心への集中を強める。カット単位で「中心→中心」の同位置接続をすると儀式性が増す。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Central framing of [Subject], the figure on the optical axis, bilateral weight, a formal altar in the frame.`

### クリーンフレーム / Clean Frame  (`composition/clean-frame`)
- **一言**: 画面の四辺に不用意な物を入れず、ぼかしではなく整頓によって孤立を作る。
- **物語での役割**: 余計なものがなく、画面に残った者が空間の所有者になる。制御・儀式・ポスターのような明快さ。
- **使う/使わない**: 商品、儀式、ポスター的ポートレートに。盗み見るような視点には使わない(掃除された画面は「見せられている」感じになる)。
- **よくある失敗**: 汚い街角を無理にポスター風にする、または照明を落としただけで「虚空」にしてしまう。端の肩・植物をなくすか、ダーティフレームと割り切る。
- **似た技法との違い**: ダーティフレームの逆。ネガティブスペースは「空白が質量」、クリーンは「内容があってもよいが端が整頓されている」。
- **HyperFramesでの作り方**: 安全域の考え方を逆用する。四辺の帯(上下 y 0〜54 / 1026〜1080、左右 x 0〜96 / 1824〜1920)をアクションセーフ外として「何も置かない」ルールにし、背景色を単色か極弱いグラデ(`radial-gradient(ellipse at 50% 45%, #f4efe6, #d8d0c2)`)にする。主役は影を `filter:drop-shadow(0 30px 40px rgba(0,0,0,.25))` で地面に接地。確認は snapshot で四辺を目視し、DOM上でも `getBoundingClientRect()` が端帯に入る要素がないかを検査する。装飾の散らばりは作らない。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Clean frame of [Subject], edges empty, no accidental objects, studio-poster clarity, isolation by tidiness.`

### トーン対比 / Tonal Contrast  (`composition/contrast-composition`)
- **一言**: 最も明るい塊と最も暗い塊をぶつけ、中間グレーを捨てて、主役を明暗の極に置く。
- **物語での役割**: 画面がポスターのように遠目でも読める。善悪の二項、夜の狩りなど「一目で読ませたい」場面。
- **使う/使わない**: 夜の追跡、道徳的二分法、グラフィックなタイトル。肌や食べ物など中間調に情報がある場面には使わない(汗が消える)。
- **よくある失敗**: 顔・壁・コートが同じ明度帯に入った泥のようなグレー。極を決め、他は落とす。
- **似た技法との違い**: ローキーは照明比の話、トーン対比は塊の置き場所の話。シルエットは内部のディテールを捨てるが、トーン対比は目などを残してよい。
- **HyperFramesでの作り方**: 背景を `#0a0a0c`(または `#f2efe9`)の単色にし、主役を反対の極(`#f2efe9` の顔/物)にする。中間調を潰すには、画像・動画なら `filter:contrast(1.6) brightness(.9)` か、SVG `feComponentTransfer`(`feFuncR/G/B type="table" tableValues="0 0 .1 .9 1 1"`)でS字カーブ。ffmpegなら `curves=all='0/0 0.25/0.05 0.75/0.95 1/1'`。主役の位置は三分割交点(1280,360)に置くとポスター性が高い。確認は画面を縮小して見る(スクイントテスト)。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `High tonal contrast composition with [Subject] as the lightest or darkest mass, graphic punch, no mid-gray mush.`

### 対角構図 / Diagonal Composition  (`composition/diagonal-composition`)
- **一言**: 階段・銃・雨・斜めの街路など、セット側の斜線を使って、カメラを水平のまま不安定さとエネルギーを作る。
- **物語での役割**: 暴動・追走・秩序に従わない街。斜線が視線を押し、静かな水平の安定を拒む。
- **使う/使わない**: 階段、街角、雨、戦闘で、水平構図だと場が落ち着きすぎるとき。ない斜線をカメラの傾きで偽造しない(それはダッチアングル)。
- **よくある失敗**: 水平線が傾いているだけで、画面内に斜めの構造物がない。カメラを水平に直し、階段や街角の線を探す。
- **似た技法との違い**: ダッチアングルはカメラのロールで水平線自体が傾く。対角構図は水平線は真っ直ぐで、被写体と構造が斜めに切る。
- **HyperFramesでの作り方**: 画面を「親ラッパーを回さず、中の線要素だけ斜めに置く」。例: 階段や手すりを SVG `<polygon>` で作り、対角線 (0,1080)→(1920,0)に近い約-28°(傾き y=-0.55x)の帯にする。主役は線上の交点(640,720)か(1280,360)に置く。動きは帯の `x` を `-120→0`(1.6s `power2.out`)、雨は幅2px・長さ80px の線を -15° で、seed付きPRNGで位置を決め、`y` を時間tの関数で流す。水平の地平線(`y=720` など)は固定してカメラを傾けない。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Diagonal composition through [Subject], energy on the bias, unstable, rain or stairs as the line.`

### ダーティフレーム / Dirty Frame  (`composition/dirty-frame`)
- **一言**: ピンぼけの肩・ガラス・葉・群衆で画面の縁を食わせ、窓を「占拠された」状態にする。
- **物語での役割**: 縁が汚れた画面は「盗まれた」「混んでいる」「生き延びた」視点。きれいな縁は「与えられた」画。
- **使う/使わない**: 監視、パーティー、街など、見てはいけない・混雑した視点に。商品・儀式的な単独ショットには使わない。
- **よくある失敗**: 偶然の散らかり(ブームや謎のにじみ)。遮蔽物を選び、辺に置き、口元を隠さないようにぼかす。
- **似た技法との違い**: 前景の物は一か所の目立つ近接物、ダーティフレームは縁全体の占拠。フレーム内フレームは硬い内枠で、ダーティは柔らかく不規則。
- **HyperFramesでの作り方**: 縁に4つ程度の遮蔽レイヤを置く。左: 肩のシルエット(黒〜濃紺、幅 360px、x:-120〜240、`filter:blur(18px)`)、下: 葉(SVG、y:900〜1080、blur 14px)、右上: 雨のガラス(`backdrop-filter:blur(10px)` で端の帯だけ)。中央 x 480〜1440, y 240〜840 は必ず空け、顔が読める穴にする。揺らぎは遮蔽レイヤを `x:±6px, y:±4px`(周期3〜5秒、sine)で一本のタイムラインから関数駆動。レイヤはz順で人物より手前(`z-index`)に。blur値は `filter` で直接指定し、実際のぼけ量を決める。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Dirty frame around [Subject], out-of-focus shoulders, glass, foliage, or crowd chewing the edges, voyeur layers.`

### 図と地 / Figure-Ground  (`composition/figure-ground`)
- **一言**: 被写体を背景から1秒以内に読めるよう、明暗・色・ピントのいずれかで切り離す。
- **物語での役割**: 最初の読みは生存条件。観客が主役を探す手間をなくす。逆に、探すこと自体が主題のとき(迷彩、スナイパー)だけ溶かす。
- **使う/使わない**: 人物をすぐ見つけさせたい通常のカバレッジやポスターで標準的に。「部屋に飲まれる」事務員のように溶かしたい人物は分離しない。
- **よくある失敗**: 同系色の服と壁(頭を探す羽目になる)。リムライト・背景明度・衣装・浅い被写界深度のどれかで分ける。
- **似た技法との違い**: シルエットは輪郭だけの強い版。図と地は明暗・色・ピントのどれでもよい分離の総称。トーン対比はその明暗極限版。
- **HyperFramesでの作り方**: 主役レイヤと背景レイヤを分け、①背景だけ `filter:blur(8px) saturate(.7) brightness(.8)`、②主役に `filter:drop-shadow(0 0 2px #fff) drop-shadow(0 0 24px rgba(255,255,255,.35))` でリム、③背景に主役の位置だけ明るくする `radial-gradient(circle at 1280px 520px, rgba(255,255,255,.18), transparent 420px)`。スクイントテストは snapshot を縮小(240px幅)して主役の輪郭が残るか確認。ピント送りは既製部品 `npx hyperframes add focus-rack`(2つの奥行き間でblur/明度/スケールを同期)も使える。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Clear figure-ground separation of [Subject] from background, contrast of tone, color, or focus so the person reads instantly.`

### 前景の物 / Foreground Interest  (`composition/foreground-interest`)
- **一言**: レンズと被写体の間に、花・柵・ガラス・机・体など目立つ近接物を置き、奥行きと入口、または部分的な遮蔽を作る。
- **物語での役割**: カメラの前に「持ち主」がいる画面になる。観客はその場に居る実感を得るか、居てはいけない感じを持つ。鮮明な前景は力の誇示、ぼけた前景は盗み見。
- **使う/使わない**: 力を示す物(机上の銃)、スパイ、部屋に既に物がある感じを出したいときに。決定的な顔・口を隠すときは使わない。例: 花様年華(2000)。
- **よくある失敗**: 意味のない偶然の障害物(口を切るメニューボード)。物を選び、縁の位置とピントを意図して決める。
- **似た技法との違い**: ダーティフレームは縁全体の占拠。前景の物は下三分の一などに置く設計された一物でもよい。レイヤード・デプスは奥の面も働く必要がある。
- **HyperFramesでの作り方**: 前景を最前面の独立レイヤにし、被写体より大きく動かして視差を作る。構成: 前景(下端に植物/柵、y=760〜1080、幅は画面の100%、`blur(12px)` なら「ベール」、`blur(0)` なら「情報」)、被写体、背景。カメラ横移動を proxy tween(`{p:0→1}`、`sine.inOut`、5秒)で動かし、onUpdateで前景 `x = -p*90px`、被写体 `x = -p*30px`、背景 `x = -p*10px`(視差比 9:3:1)。被写体の目や口(例: x 760〜1160, y 380〜600)に前景が入らないよう、前景の不透明領域のマスクを制作時に確認する。既製の奥行き部品: `npx hyperframes add camera-rig-depth-stack`。
- **難易度/適性**: ★★(視差の比率設計)。
- **AI動画生成プロンプト**: `Strong foreground object between lens and [Subject], dirty aperture of flowers, fence, or glass, layered depth.`

### フレーム内フレーム / Frame within Frame  (`composition/frame-in-frame`)
- **一言**: 戸口・窓・アーチ・鏡など、画面の中にもう一つの長方形を作って被写体を囲む。
- **物語での役割**: 見られている・閉じ込められている・絵として切り取られている感覚。敷居をまたぐこと自体が出来事になる。
- **使う/使わない**: 帰宅や別れ、廊下の密会に。誰も通れない飾りのアーチを顔の後ろに置くだけなら使わない。例: 捜索者(1956)。
- **よくある失敗**: 飾りの曲線のようなアーチ(通れない)で、被写体が画面を埋めている。内枠を少なくとも3辺見せ、敷居に役割を与える。
- **似た技法との違い**: ダーティフレームは縁をぼけた物で食う。フレーム内フレームは鮮明な内枠。窓の技法は枠を多数並べる。
- **HyperFramesでの作り方**: 外側をCSSマスクで暗く、内枠を明るい別空間にする。内枠は `left:1180px; top:140px; width:560px; height:800px`(右三分割線 x=1280 を跨ぐ戸口)に枠線(`border:28px solid #1a1410`)と `box-shadow:inset 0 0 120px rgba(0,0,0,.6)` を付け、中の被写体は `clip-path:inset(0)` の内側で動かす。内=暖色 `#ffd9a0`、外=寒色 `#1d2a3a` で露出差を作ると境界が読める。敷居を越える演出は、人物を内枠の `overflow:hidden` コンテナ内で x を動かし、境界を越えたら親コンテナへ付け替える(切り替えは1フレーム、`tl.set`)。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Frame-within-frame around [Subject], doorway, window, mirror, or arch as a second rectangle, nested attention.`

### 黄金比 / Golden Ratio  (`composition/golden-ratio`)
- **一言**: 約8:5(φ)の分割線や対数螺旋に沿って塊を置き、視線が曲線をたどるようにする。
- **物語での役割**: 三分割より静かな秩序。隅から顔、扉、空の余白へと視線が巡る、「宣言しない必然性」。
- **使う/使わない**: 絵画的な静止、道・木・人物が実際に渦を描く風景に。塊が曲線に乗っていないショットに螺旋を上書きしない。
- **よくある失敗**: 三分割に頭を置いて「黄金比」と呼ぶだけ。62%側へ寄せるか、視線が乗れる副次物を並べる。
- **似た技法との違い**: 三分割はより粗く設定が速い(1/3)。黄金比は分割線が38%/62%で、より中心寄り。
- **HyperFramesでの作り方**: 分割線は x = 1920×0.382 = 734 / 1920×0.618 = 1186、y = 413 / 667。主役の目は (1186, 413) か (734, 413) に置く。螺旋は SVG の円弧列(長方形を φ で再帰分割: 1186×667 → 残り 734×667 → …)で位置を計算し、副次物(窓、手、遠景の光)を螺旋上に3〜4点置く。誘導の動きは螺旋に沿って要素を順に 0.4s ずつ `autoAlpha` で出す(最後が目的地)。パンしても螺旋が崩れないよう、全レイヤを同じカメララッパーの scale 1.0→1.06 だけで動かす。
- **難易度/適性**: ★(位置計算のみ)。
- **AI動画生成プロンプト**: `Golden-ratio spiral composition around [Subject], the eye traveling a harmonic curve rather than a grid.`

### ヘッドルーム / Headroom  (`composition/headroom`)
- **一言**: 頭頂からフレーム上端までの余白を、圧迫(狭い)か空気(広い)かを意図して決める。
- **物語での役割**: 縦方向の図。狭ければ思考が詰まる、広ければ空・天井・神が人を上回る。
- **使う/使わない**: 狭いのは部屋が罠・思考に天井がないとき、広いのは土地や空が頭蓋より重い場面。ティルトし損ねた余りを広いヘッドルームと呼ばない。
- **よくある失敗**: 偶然の「沈み」(カメラ操作者がティルトしなかった)。標準ポートレートなら下げて詰め、意図の余白ならネガティブスペースとして顔を低く置く。
- **似た技法との違い**: リードルームは水平、ヘッドルームは垂直。クローズアップは大きさでミスを目立たせる。
- **HyperFramesでの作り方**: 髪の上端 y を測って決める。標準アップ: 頭頂 y=80〜110(ヘッドルーム約8〜10%)、圧迫: y=0〜20(髪が触れる)、空気: 顔を下三分割 y=720 付近に、頭頂 y=560〜600。被写体ラッパーの `top` を直接指定し、ティルトの代わりに `y` を 0→-60px(1.5s `power2.inOut`)で動かす。上の余白の使い道(空・天井)は背景側で `linear-gradient(#cfd8e0 0, #8ea0b0 560px)` のように読ませる。顔に重ねるテロップは安全域(y 108〜972)内に。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Deliberate headroom on [Subject], either tight to the hair (pressure) or generously open (air, God, sky).`

### レイヤード・デプス / Layered Depth  (`composition/layered-depth`)
- **一言**: 前景・中景・背景など少なくとも2つの距離に、意味のある動作を配置する。
- **物語での役割**: 社会的な幾何が一度に見える。手前の大人が契約を交わし、遠くの窓で子供が遊ぶ、といった「同時に成り立つ二つの関係」。
- **使う/使わない**: 二つの関係を1つのホールドで真にする場面(取引と子供、踊りと通話)に。ガラクタを3か所に積んで「演出」と呼ばない。例: 市民ケーン(1941)。
- **よくある失敗**: 全部にピントが合っているだけで、動作は1つ(ディープフォーカスの壁紙)。二つ目の物語を別の面に置くか、一面に簡素化する。
- **似た技法との違い**: ディープフォーカスは光学結果、レイヤード・デプスは配置。前景の物は近景だけ保証し、こちらは遠景も働く。
- **HyperFramesでの作り方**: CSS 3D か疑似3D の多層。親に `perspective:1200px`、近景 `translateZ(300px)`、中景 `0`、遠景 `translateZ(-600px)` を置き、見かけの倍率補正(近景 scale 0.8、遠景 scale 1.5)をかける。各層に「やること」を割り当てる(近: 机の上の手の動き、中: 主役、遠: 窓の中の別の動き)。ピントは近を `blur(0)`、遠を `blur(0)`(全層鮮明)か、ラックで入れ替え: 層ごとの blur を 0↔6px で 1.2s `power2.inOut`。視差カメラは proxy tween で `rotateY ±3°`。既製部品: `npx hyperframes add camera-rig-depth-stack`、ピント送りは `npx hyperframes add focus-rack`。
- **難易度/適性**: ★★(層ごとの動作設計)。
- **AI動画生成プロンプト**: `Three-plane composition around [Subject], foreground, mid, and deep background all carrying information, deep staging.`

### リードルーム / Lead Room  (`composition/lead-room`)
- **一言**: 視線や進行方向の側に、背後より多くの余白を取る。
- **物語での役割**: 水平方向の図が「未来」を割り当てる。鼻先の空気は道・相手・扉、背後の空気は過去か罠。古典的カバレッジの礼儀。
- **使う/使わない**: 歩き、いずれ答えがある視線、前向きの文法に。閉じ込めたい人物には与えない(それはショートサイディング)。
- **よくある失敗**: 横顔が視線側の縁にくっつき、背後に壁紙が余る(意図しないショートサイディング)。視線方向へパンして余白を前に移す。
- **似た技法との違い**: ショートサイディングは視線側を潰す。三分割は結果としてリードルームを作りやすい。ルックスペースは視線の先の画面外対象に焦点。
- **HyperFramesでの作り方**: 左を向く(視線→左)人物なら、顔の中心を x=1280(右三分割線)に置き、左側に 1280px の余白(視線の先)を確保する。右向きは x=640。歩きは進行側の余白を 700px 以上、歩くにつれ主役に `x` を逆方向へ追従パンさせる(カメラ=背景を主役速度の約1.0倍で逆に動かすと余白が保たれる)。proxy tween で `cam.x = walker.x - 640`(右向き)を onUpdate で設定。余白に何も置かないか、遠景の光や扉だけを置き「目的地」にする。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Lead room in front of [Subject]'s look or walk, more space in the direction of attention than behind, forward narrative.`

### 導線 / Leading Lines  (`composition/leading-lines`)
- **一言**: 縁・レール・道・廊下・影・身ぶりを、視線を誘導する矢印として使う。
- **物語での役割**: 線が人物を指せば、その人が終点でありつながりの先。人物を素通りすれば人物は門で、無限が残りを所有する。
- **使う/使わない**: 駅・ホテルの廊下・高速道路・身廊など、場所が本当に指せるときに。何もない部屋に架空の矢印を描いて見せない。
- **よくある失敗**: 中央ポートレートの背後に関係のない建築。線が主役に当たる位置までカメラを動かす。
- **似た技法との違い**: 消失点は平行線が出会う点そのもの。導線は画面内で出会わなくてもよい。一点透視は軸が完全に構成された形。
- **HyperFramesでの作り方**: SVGで収束線を描く。目標点(主役の胸)を (1280, 480) とし、画面端 (0,1080) (0,700) (1920,1080) などから目標点へ直線を引く(`stroke:rgba(255,255,255,.18); stroke-width:2〜6`)。線は `stroke-dasharray`+`stroke-dashoffset` で目標点へ向かって描画(0.8s `power2.out`、起点から順に 0.1s ずつずらす)。着地の瞬間、目標点の主役に `scale 1→1.04`、リング(円)を `r:0→60`、opacity 1→0 で波紋。実線の代わりに、床の格子や道の縁(CSS `linear-gradient` と `transform:perspective(900px) rotateX(70deg)`)を使うと自然。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Leading lines driving the eye to [Subject], rails, corridors, roads, or shadows converging on the figure.`

### ルックスペース / Look Space  (`composition/look-space`)
- **一言**: 視線の前に空気を残し、画面外にある見られる対象を観客に待たせる。
- **物語での役割**: 顔と未使用の余白だけで場面が成立する。空白が見えない対象(入ってくる人、絵、窓)に所有されている。
- **使う/使わない**: 見張り、画家、スナイパー、扉口の恋人など、対象が画面外か入ってくる場面に。レンズ目線のインタビューの隣の死んだ空白を「視線」と呼ばない。例: 裏窓(1954)。
- **よくある失敗**: 視線と逆側が空いている、または次のカットが視線の幾何学と合わない。余白を視線方向に置き、高さと角度を合わせる。
- **似た技法との違い**: リードルームは動きと古典的作法を含み、ルックスペースは特に「視線の先の画面外対象」。POVは見られたもの、これは見ている者。
- **HyperFramesでの作り方**: 人物(横顔)を `left:560px`(約x=560)に置き、視線側の右に x 760〜1920 の余白を作る。余白には何も置かないが、わずかに「何かの気配」を、画面外からの光の移ろい(`linear-gradient` を右端から `opacity 0→.25`、3秒)や、ゆっくり伸びる影で示す。次のPOVカットがある場合、視線の高さ(目の高さ y)を前後カットで揃え、対象側は同じ位置 y±40px に置く。注意: 余白に別の顔を置くと競合するので置かない。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Generous look space for [Subject], the off-screen gaze owning a field of air, tension in what we cannot see.`

### ネガティブスペース / Negative Space  (`composition/negative-space`)
- **一言**: 被写体の周囲に広い空白を残し、空白自体を質量として見せる。
- **物語での役割**: 孤独・不安・待機には余白が要る。空白がもう一人の登場人物になる(砂漠の小さな人、白壁を相棒にした女)。
- **使う/使わない**: 空・天井・壁・雪・海が人間より重い場面に。物語が詰まった場面には使わない。照明を落としただけの空きを「意図した空白」と呼ばない。例: イーダ(2013)。
- **よくある失敗**: 小さな人物の背景に雑多なディテールがあり、競合する。余白を単純化するか、アーキテクスチャとして割り切る。
- **似た技法との違い**: ヴォイドは世界を消す。ネガティブスペースは世界(空・壁・海)が空白を成す。ショートサイディングは視線を潰す。
- **HyperFramesでの作り方**: 背景は単色〜微グラデ(`#e9ecee→#cfd6da`)の1面。被写体を小さく(画面高の6〜12%、60〜130px)、位置は三分割交点の外側か隅(例 (1500, 820)、または顔を y=900 に低く)。空白に意味を持たせるため、極薄の質感(`feTurbulence` baseFrequency .004 の雲、opacity .06、seed固定)を敷く。ゆっくりした背景ドリフト(`x:-30px`、10秒 `none` イージング)で「空白が呼吸する」。人物の動きは最小に。確認は snapshot で「被写体が画面面積の2%未満か」。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Vast negative space around [Subject], the figure small, absence as weight, Antonioni emptiness.`

### 一点透視 / One-Point Perspective  (`composition/one-point-perspective`)
- **一言**: カメラを面に正対させ、奥行きの平行線をただ1つの消失点(多くは中央軸上)に収束させる。
- **物語での役割**: 建築が運命を持つ。歩けば世界が漏斗になり、中央に立てば提示され、半歩の軸外しが事件になる。設計された感じ。
- **使う/使わない**: ホテル、宇宙船、礼拝堂、地下壕など、建築が軸を持つ場に。奥行きの平行線がない部屋や、見つけた感じが欲しい場面には使わない。例: シャイニング(1980)。
- **よくある失敗**: 廊下を隅から撮り、消失点が2つになる(壁が片側にしか後退しない)。軸上に移動するか、二点透視と割り切る。
- **似た技法との違い**: 導線は完全な軸構成でなくてよい。中央構図は軸上だが平面の祭壇でトンネルがない。消失点は出会いの点そのもので軸外でもよい。
- **HyperFramesでの作り方**: 消失点 VP を (960, 480)(地平線 y=480、やや上)に置き、CSS 3Dで廊下を作る。コンテナ `perspective:900px; perspective-origin:960px 480px`。床・天井・左右の壁を4枚のdiv(幅1400×奥行き4000px)に `transform:rotateX(±90deg)` / `rotateY(±90deg)` で配置し、`transform-style:preserve-3d`。前進は proxy tween で全体の `translateZ` を 0→1200px(4秒、`power1.inOut`)。縦は垂直を守る(rotateX を傾けない)。SVGなら VP から放射状の線 `x2=VP` を端から引くだけの2D版も可。主役を VP 上(960,480)に置き、遠ざかる/迫る(scale 0.4→1)で運命感。
- **難易度/適性**: ★★(3D廊下の組み立て)。
- **AI動画生成プロンプト**: `One-point perspective corridor toward [Subject] or through them, vanishing point on axis, Kubrick infinity.`

### 反射 / Reflections  (`composition/reflections`)
- **一言**: ガラス・水・クローム・鏡を使い、見る者と見られる者を1つの面に同居させる。
- **物語での役割**: 見ることと見られることをカットなしで同時に出せる。ディゾルブなしでアイデンティティが分裂する。
- **使う/使わない**: 分裂した自己、向かい合えない会話、窓に重なる街、鏡の中の親に。セットにたまたま鏡があるという理由では入れない。例: パリ、テキサス(1984)。
- **よくある失敗**: 頭の動きに答えない鏡、明るさが合わない貼り付けの二重像。実際に見える光学(反射側が明るい、視線が幾何学的に合う)を作る。
- **似た技法との違い**: フレーム内フレームは硬い内枠、反射は歪み・重ね・完全コピーのいずれもあり得る。窓は多数の枠、反射は同一ガラス上の二つの空間。
- **HyperFramesでの作り方**: 2D: 同じ要素を `transform:scaleY(-1)` で複製し、`mask-image:linear-gradient(transparent 40%, #000)` と `opacity:.35`、`filter:blur(2px)` で床反射。水面は SVG `feTurbulence`(baseFrequency 0.01 0.08)+`feDisplacementMap`(scale 12〜20)を反射側にだけ適用し、ノイズの位相を tの関数で動かす(`seed` 固定)。窓ガラスに街を重ねるなら、街レイヤを `mix-blend-mode:screen; opacity:.4` で顔の上に。鏡の中のキャラは、鏡の位置 (1280〜1700, 200〜800) の `clip-path` 内に、実像と逆向きに `x` を動かす(頭の動きと同期)。既製部品は見つからない。
- **難易度/適性**: ★★(物理的整合を取る必要)。
- **AI動画生成プロンプト**: `Reflections of [Subject] in glass, water, or chrome, observer and observed in one plane.`

### 反復とパターン / Repetition and Pattern  (`composition/repetition-pattern`)
- **一言**: 形・色・線・位置・動作を繰り返し、列や窓や兵士の「系」として読ませ、その破れを物語にする。
- **物語での役割**: 組織・軍・ホテル・工場。人は単位になり、合わなくなった瞬間(空の机、赤いコート、遅れた兵士)がクローズアップなしで主題になる。
- **使う/使わない**: 制度とコピーを描く場面(オフィス、軍隊、合唱)に。破れる要素のない壁紙として使わない。同じ配置を別の日に再現して変化を測らせる「構造の反響」にも使える。
- **よくある失敗**: 物が多いだけで数えられる単位がない。モチーフを1つ選び、タイリングが数えられるようカメラを合わせ、不一致を1つに絞る。
- **似た技法との違い**: シンメトリーは鏡で反復の一種。パターンは鏡を要さない列・場。アーキテクスチャは素材感、パターンは数えられる格子。
- **HyperFramesでの作り方**: 単位をCSS Gridかループ生成。例: 8列×4行の机(各 160×90px、間隔 40px、全体 x 220〜1700, y 180〜900)。`gsap.set` で位置を計算して配置し、入場は stagger(列順に 0.05s ずつ、`power2.out`、`y:+30→0`)。破れ: 1つだけ色 `#c0392b`、または1つだけ `opacity .15`(空席)。破れの位置は三分割交点 (1280, 360) に最も近い単位に。揺らぎは seed付きPRNGで±0。動作の反復なら、全単位が同じ位相で動く中、1つだけ位相を 0.3s ずらす(t関数で駆動)。既製の格子背景: `npx hyperframes add dynamic-grid`(背景の格子用)。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Repeating pattern around [Subject], columns, windows, soldiers, a break in the pattern as the story.`

### 三分割 / Rule of Thirds  (`composition/rule-of-thirds`)
- **一言**: 画面を3x3に分け、重要な塊を線上か4つの交点に置き、地平線を上か下の三分割線に置く。
- **物語での役割**: 力のある交点に置かれた顔は、視線・天候・脅威に大きい方の長方形を渡す。頭の後ろの細い帯は余りで、飾りではない。
- **使う/使わない**: 風景の歩み、画面外を見る単独、占有感のある遠景に。儀式的な正面、罠、秩序のギャグには使わない(全クローズアップに当てはめると意味が消える)。
- **よくある失敗**: 中央に顔を置いたまま「三分割」と呼ぶ。目を交点へずらし、視線側に大きな領域を渡すか、中央フレーミングと割り切る。
- **似た技法との違い**: リードルームは三分割が結果として作る水平の空気。黄金比はより中心寄り(38/62%)。ショートサイディングは逆に潰す。
- **HyperFramesでの作り方**: 交点は (640,360) (1280,360) (640,720) (1280,720)、線は x=640/1280, y=360/720。目を交点に置く: 右を向く人は左交点 (640,360) に目、左を向く人は (1280,360)。地平線は空を見せたいなら y=720(下)、地を見せたいなら y=360(上)。実装は `.eye-anchor{position:absolute;left:640px;top:360px}` を基準に、主役レイヤの「目の位置」(画像内の目の座標)を `transformOrigin` にして `gsap.set(layer,{x:640-eyeX, y:360-eyeY})` で合わせる。ガイド線はHTMLに入れずsnapshotで確認。歩く動きでは線を維持するため背景を逆方向へ動かす。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Rule-of-thirds placement of [Subject] on a power intersection, horizon on a third, breathing room in the look direction.`

### スクリーン・イン・スクリーン / Screen in Screen  (`composition/screen-in-screen`)
- **一言**: モニター・スマホ・テレビ・映画館を画面の中に入れ、「絵を見ている人の絵」にする。
- **物語での役割**: 絵の絵は所有を変える。内側の人は他者(監督、ハッカー、親、神)に既に枠取られている。観客は見る者を見るか、インターフェースが外枠を乗っ取って見る者になる。
- **使う/使わない**: 監視、生中継、ノートPCの検索、映写技師のように、見ることがすでに媒介されている場面に。何も映らない/関係ないテレビは置かない。例: Searching(2018)。
- **よくある失敗**: 読めない文字、溶けるUI、デバイスのない二分割。内側は文字・カーソル動作まで設計された挿入画として作る。
- **似た技法との違い**: フレーム内フレームは建築の枠、これは画像を持つ表示装置。スプリットスクリーンは同時の現在の並置。
- **HyperFramesでの作り方**: HTMLの得意分野。外画面の中に端末を絶対配置: モニター `left:520px; top:160px; width:880px; height:560px`、内側は実際のHTML/CSS(文字は本物のテキスト)で作り、カーソルと打鍵は GSAP の `text`/`clip-path:inset()` でtの関数にする。外から内への入り込み(インターフェースが外枠を乗っ取る)は、モニターを `left/top/width/height` で全画面(0,0,1920,1080)へ 1.2s `power3.inOut` で拡大。画面らしさ: 走査線・周辺減光・3D歪み = `npx hyperframes add yt-screen-warp`、周辺減光は `npx hyperframes add vignette`。ピクセル格子や反射は `mix-blend-mode:screen` の薄い白グラデ。
- **音との合わせ方**: 内側の音はこもらせ(低域カット)、拡大で外の音に切り替えると階層が移る。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Screen-in-screen of [Subject], a monitor, phone, or cinema inside the cinema, nested looking.`

### ショートサイディング / Short Siding  (`composition/short-siding`)
- **一言**: 顔を視線の向かう縁に寄せ、ルックスペースを潰して背後に余白を余らせる。
- **物語での役割**: 寄らずに場面を締め上げる。尋問者、嘘つき、最悪を見た人は、ほぼ何もない方向を見つめる。背後の余白は使えない無駄な土地。
- **使う/使わない**: 尋問、罪悪感、パニック、次の物が届かないと感じさせたい瞬間に。通常のカバレッジには使わない。全クローズアップに使うと罠の意味が消える。
- **よくある失敗**: 急いだパンによる事故的なショートサイド。罠の意図がなければリードルームを与える。意図があるなら補正せず保つ。
- **似た技法との違い**: リードルームの逆(視線の前の空気)。ネガティブスペースは視線を飢えさせずに空白で囲むことがある。
- **HyperFramesでの作り方**: 右を向く人物なら、顔の中心を x=1560〜1680(右端から240〜360px以内)に置き、背後 (x 0〜1300) に余白を残す。左向きは鏡像で x=240〜360。タイトルセーフ(x 192〜1728)内ぎりぎり。次第に締めるには、被写体ラッパーを `x:1380→1620`(3秒、`power1.in` でじわり)に動かし、視線側の空きを減らす。補正のパンはしない。背後の余白には何も置かない(あるいは暗い単色)。縁の圧迫感を足すなら、右縁に `box-shadow:inset -120px 0 100px rgba(0,0,0,.5)` を重ねる。
- **音との合わせ方**: 周囲音を絞り、息づかいや時計音だけ残すと、画面の閉塞と一致する。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Short-sided framing of [Subject], look space crushed, the face near the frame edge they look toward, trapped or urgent.`

### シンメトリー / Symmetry  (`composition/symmetry`)
- **一言**: 垂直の中心線を軸に、左右の視覚的な質量を鏡のように揃える。
- **物語での役割**: 空間は儀式的で、誰も秘密の側を持たない。小さな乱れ(曲がったネクタイ、欠けたランプ、半歩ずれた人)が出来事になる。
- **使う/使わない**: ホテル、礼拝堂、法廷、宇宙船など、秩序の機械である場に。軸のない場所の壁紙としては使わない。例: グランド・ブダペスト・ホテル(2014)。
- **よくある失敗**: 中央に人がいるが、部屋は左にしか窓がない。カメラを建築の軸に移すか、アシンメトリーに切り替える。
- **似た技法との違い**: 中央構図は被写体が軸上、シンメトリーは場の左右が鏡(被写体の有無を問わない)。一点透視はトンネル構成。
- **HyperFramesでの作り方**: 軸 x=960 を境に、左右の要素を対で配置: `left:(960-w/2-d)` と `left:(960-w/2+d)`。同じ要素を `transform:scaleX(-1)` の複製にすれば完全鏡像になる(文字は鏡像にしない)。例: 窓2枚(各 240x420px、x=360 と x=1320)、ランプ2つ(x=140 と x=1780)。乱れを1つだけ入れる: 片方のランプだけ x を +14px ずらす/色を変える/`opacity:0`。入場は左右を同時(同じ0.0秒、`power2.out`)、鏡像の動きは `x` の符号を反転して同じtweenに入れる。カメラ移動は軸上の押し(scale 1.0→1.05)のみ。左右が揃っているかは、画面を左右反転した画像との差分(`ffmpeg -vf "split[a][b];[b]hflip[c];[a][c]blend=all_mode=difference"`)で検査。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Perfect symmetry around [Subject], mirrored architecture, a central axis, obsessive order.`

### タブロー / Tableau  (`composition/tableau`)
- **一言**: 配置された人や物で絵を作り、ほぼ固定のカメラで時間をかけて意味を展開させる。
- **物語での役割**: 観客が自分の速度で、誰がどこに立ち、誰が動かず、誰が仕草を盗むかを読む。静止が小さな動作を大きくする。喜劇・儀式・不安。
- **使う/使わない**: 儀式、喜劇のアンサンブル、行列、カットで指示せず「発見させたい」場面に。意味のない綺麗な配置を長く保持しない。例: プレイタイム(1967)。
- **よくある失敗**: 後で切り刻む前提のマスターショット、関係のない飾りの集合。各人物に役割を与え、ホールド自体をカバレッジとする。
- **似た技法との違い**: スタティック(固定撮影)はカメラの固定、タブローはそれを使う配置された絵。三角構図は内側の幾何学。
- **HyperFramesでの作り方**: カメラ固定で、複数の人物(シルエット/イラスト)を絶対配置し、それぞれ別周期の小さな動き(各 `y:±4px` や仕草)を1本のタイムラインに入れる。例: 左立ち x=480、中央座り x=960、右戸口 x=1500、足元ベースライン y=860 を揃える。動きの起点を 2.0s, 4.5s, 7.0s とずらし、計画した1つの仕草(例: 右の人物が手を挙げる 0.4s)だけを大きな出来事にする。カメラは動かさず、必要なら scale 1.0→1.03(10秒、`none`)の微クリープ。カットしない。
- **難易度/適性**: ★★(人物アニメの用意が要る)。
- **AI動画生成プロンプト**: `Tableau of [Subject], arranged bodies, a living painting, duration instead of coverage.`

### 三角構図 / Triangular Composition  (`composition/triangular-composition`)
- **一言**: 3つの人物や塊を三角形に配置し、頂点を権力・目撃者・欲望の対象とする。
- **物語での役割**: 集団に階層ができる。机と二人、戸口と家族、銃と三人など、誰が図の頂点に座るかが語られる。ルネサンス絵画由来。
- **使う/使わない**: 組長と幹部2人、秘密のある家族写真、交渉の机など階層のある集団に。誰も形作らない第三の塊を形を完成させるために足さない。
- **よくある失敗**: 3人が同じ高さで一列(三人ショット)。1人を座らせ、1人を立たせ、3人目に戸口か椅子を与えて三角を閉じる。
- **似た技法との違い**: スリーショットは3人を撮る大きさの話で、一列でもよい。三角構図はピラミッド形(1つは戸口やランプでもよい)。
- **HyperFramesでの作り方**: 頂点 A(960, 260)、底辺 B(520, 760)、C(1400, 760) を基準に3つのブロックを置く(顔の中心)。位置関係は `left/top` で直接指定。頂点に力点を作る: Aのブロックだけ明度を上げ(`filter:brightness(1.15)`)、底辺は少し暗く。動きは頂点だけ `y:+30→0`(1.0s `power3.out`)で入れて視線を先に奪い、その後に底辺が `autoAlpha` で入る(各0.3s遅れ)。力関係の逆転は、頂点ブロックを B 位置に 1.2s で下ろし、C のブロックを頂点へ上げる(座標のクロス)。三角形がきちんと読めるか、SVGの `<polygon>` を試作時に重ねて確認。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Triangular arrangement with [Subject] at an apex, three masses locking the frame, Renaissance blocking.`

### 消失点 / Vanishing Point  (`composition/vanishing-point`)
- **一言**: 平行線が出会う見かけの一点(線路・道・列柱の終点)を構図の目的地にし、人物をその手前の門か、点そのものに置く。
- **物語での役割**: 点が人物の向こうにあれば「まだ長い道がある」。空間が未来を持ち、人物は敷居。点が顔にあれば、建築が彼らを武器や祝福のように狙う。
- **使う/使わない**: 距離が意味になる場面(道、駅、着陸地、歩いていない人生)に。奥行きの線がない平面の部屋で「消失点がある」と称さない。
- **よくある失敗**: 収束線のない平原の中央に人がいるだけで、プロンプトにだけ「vanishing」と書く。実際の後退する平行線を入れるか、中央構図と割り切る。
- **似た技法との違い**: 一点透視は単一の軸上の点でカメラが正対。消失点は二点透視の街角のように軸外でもよい。導線は画面内で出会わなくてもよい。
- **HyperFramesでの作り方**: 点 VP を決める(例: 地平線 y=540、x=960 の無限遠、または三分割 (1280, 540))。道・レールを SVG polygon で `VP` へ向かう台形にする: 道の底辺 (360,1080)-(1560,1080) → 頂点 VP。枕木は等間隔でなく透視短縮(間隔 `d_n = d0·0.78^n`)で並べ、前進は枕木の位相を t の関数で流す(`phase = t·speed mod 1`)。人物は点の手前 (960, 760)・scale 0.5〜0.7 に置いて「門」にするか、VP 上に scale 0.1 で置いて「目的地」にする。点をカメラ側へ寄せるなら `perspective-origin` を VP に合わせた CSS 3D 床 (`rotateX(75deg)`) でもよい。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Deep vanishing point beyond [Subject], rails or road sucking the eye to infinity, the person as a gate.`

### 視覚的な重み / Visual Weight  (`composition/visual-weight`)
- **一言**: 大きさ・明暗・色・位置・ピント・顔・動きが引きつける注意の量で配置を決める。小さく明るいものが大きく暗い塊と釣り合える。
- **物語での役割**: 図は定規ではなく重さの集合。光の中の煙草がソファに勝ち、小さな顔が山に勝つ。誰が最初の半秒で視線を取り、2回目に何を見せるかを設計する。
- **使う/使わない**: 複数の塊が主役を奪い得る場面(机上の取引、窓の子供、灰色の街の赤いコート)に。全面を均等に照らして台本が指し示してくれると期待しない。
- **よくある失敗**: 均一で礼儀正しい照明(カタログページ)。勝者を決め、他を暗く・柔らかく・小さく・低彩度にして課税する。
- **似た技法との違い**: トーン対比は明暗の極のみ。視覚的重みは色・顔・動きも含む。図と地は主役と場の分離、重みは複数の塊同士の勝敗。
- **HyperFramesでの作り方**: 各要素に重みを割り当てる: 勝者は `filter:brightness(1.2) saturate(1.3)`、敗者は `brightness(.6) saturate(.5) blur(2px)`。位置は上・中央ほど重いので、勝者を (1280,360) 付近に、敗者を下辺に。重みの検証用に、画面を縮小して輝度と彩度の高い位置を数値化する(canvasで `getImageData` はシーク時の検査用のみ、本番描画には使わない)。動きは強力な重みなので、静止した構図に動く物を1つ足すと勝敗が逆転する。動きの切り替えは、勝者の `scale 1→1.06`(0.6s)と敗者の `opacity .6→.3` を同時に。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Composition balancing visual weight around [Subject], a bright small thing equal to a large dark mass, scale of attention.`

### ヴォイド / Void  (`composition/void`)
- **一言**: 闇・白・空白で世界(セット)を消し、人物を何もない場に立たせる。
- **物語での役割**: 世界が消えると社会も消える。家具も階級も天候もなく、人物と不在だけが残る。実存的孤立、異質な部屋、どこでもない尋問室。
- **使う/使わない**: 内面・孤立・どこでもない場所に。場所(扉・階級・天気)を見せたい場面には使わない。ロケを飾れなかった言い訳に使わない。
- **よくある失敗**: 露出不足の部屋(巾木や植物、壁紙の粒が暗闇に残る)。周囲を本当に消すか、空白を設計された壁として扱う。
- **似た技法との違い**: ネガティブスペースは世界が空白を成す(空・壁)。ヴォイドは世界そのものを消す。カメオ照明(人物だけに当てる光)が結果としてヴォイドを作ることもある。
- **HyperFramesでの作り方**: 背景を `#000`(または `#fff`)の純色にし、床の接地線も入れない。主役のみ光らせる: 主役レイヤの周囲に `radial-gradient(ellipse 360px 520px at 960px 540px, rgba(255,235,210,.9), transparent 70%)`。足元は `radial-gradient` の薄い楕円影で浮遊感か接地を選ぶ。ノイズの粒で「黒が死ぬ」のを避けるため、背景に非常に薄い seed固定の粒状(opacity .03)を敷くと、黒の帯域がバンディングしにくい。主役の動きは少なく、画面中央か三分割交点に孤立させる。縁の漆黒を強めるなら `npx hyperframes add vignette`。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Void around [Subject], darkness or blank field eating the world, a figure against nothing.`

### ボヤー(覗き見) / Voyeur  (`composition/voyeur`)
- **一言**: 隠れた位置から、葉・ガラス・格子・遠い窓越しに覗く視点。縁は汚れ、のぞき穴のような構図になる。
- **物語での役割**: 観客が不法侵入者になる。ブラインド越しの恋人たち、広場越しの会話、夜のテント。被写体は提示せず、振り向けば見つかるだろう。
- **使う/使わない**: 浮気、監視、隣人、狩人など、見ることが越境である場面に。登場人物が自覚している近接ショットには使わない。例: M(1931)。
- **よくある失敗**: 被写体が見られていると知っている「ダーティフレーム風」、またはオーバー・ザ・ショルダー。実際の遮蔽物、ありそうな隠れ場所、気づいていない被写体にする。
- **似た技法との違い**: ダーティフレームは縁の文法、ボヤーは隠れるという倫理的位置。POVは我々=登場人物、ボヤーは我々が居てはいけない。
- **HyperFramesでの作り方**: 遠景の被写体を小さく (1100〜1400, 380〜720) に置き、手前に遮蔽物レイヤ(葉/ブラインド)をぼかして重ねる。ブラインドは `repeating-linear-gradient(0deg, rgba(0,0,0,.85) 0 36px, transparent 36px 64px)` を全面にかけ、隙間(28px)から覗く構図に。覗き穴の幅は被写体を横切らせない(主役の顔 x 1100〜1300 が隙間に乗るよう y を合わせる)。ゆらぎは葉を `x:±8px, rotation:±1.5°` の緩い周期。揺れる手持ち感は `npx hyperframes add camera-shake`(ハンドヘルド系プロファイル)。視点の「息」を足すなら、画面全体を `scale 1.0→1.02` で3秒。
- **音との合わせ方**: 被写体側の声を遠く・こもらせ、手前の自分の息や衣擦れを近く置くと隠れている感覚が強まる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Voyeur frame of [Subject], watching from concealment, dirty edges, a view we should not have.`

### 窓 / Windows  (`composition/windows`)
- **一言**: 窓(枠)の集合そのものを主題にする。積み重なる開口、四角に収まった生活、枠の建物。
- **物語での役割**: 夜のファサードは他人の部屋のコンタクトシート。中庭は窓の劇場。四角ごとに空間の持ち主が違う。カットのないモンタージュ。
- **使う/使わない**: 多くの生活が1つの建物を共有する場面、または一つの生活が数ある窓の一つである場面に。他の窓が働かない単一の雨の窓のポートレートには使わない。例: 裏窓(1954)。
- **よくある失敗**: 雨の窓の単独ポートレート、または単なるフレーム内フレームの戸口。窓の格子を見せ、少なくとも1つ他の窓にも生活(ランプと空の椅子だけでも)を与える。
- **似た技法との違い**: フレーム内フレームは1つの内枠。窓は枠を増殖させる。反復パターンは格子を数える技法、窓は各セルの中身が重要。
- **HyperFramesでの作り方**: CSS Gridで格子を作る。例: 6列×4行、セル 220×200px、間隔 24px、全体 x 220〜1700 付近(幅 1500)、y 100〜980。各セルは独立した小シーン(ランプの点灯、人影、空席)。夜: 大半は暗い `#10141c`、数セルだけ暖色 `#ffd9a0`。主役の窓を1つ決め(例 (4列,2行))、そのセルだけ `box-shadow:0 0 80px rgba(255,200,120,.6)`。時間経過は各セルの点灯を `autoAlpha` で seed付き(`mulberry32(7)`)の順序と遅延(0.2〜2.4s)で行い、`Math.random` は使わない。カメラは全体を `scale 1.0→1.15` で主役の窓へ寄せ、他の窓を `blur` で落とす。
- **難易度/適性**: ★★(各セルの小さな物語が要る)。
- **AI動画生成プロンプト**: `Windows as the true subject around [Subject], stacked apertures, lives in rectangles, a building of frames.`

## 組み合わせ例
1. **「権力者の登場」**: 中央フレーミング(顔を (960,480) に)+シンメトリー(左右の窓を x=360/1560 に対で配置)+一点透視(廊下の消失点を (960,480) に)+クリーンフレーム(四辺をアクションセーフの外まで空ける)。入場は廊下を前進(`translateZ` 0→1200、4秒)し、頂点で停止。1箇所だけ左のランプを14pxずらすと「完璧な世界のほころび」を後半で効かせられる。
2. **「尋問/追い詰め」**: ショートサイディング(顔を x=1620、視線は右へ)+ヘッドルーム狭(頭頂 y≈10)+トーン対比(黒背景に白い顔)+ヴォイド(周囲の世界を消す)。3秒かけて顔を `x:1380→1620` に寄せ、背後の左 1300px を黒の余白にする。音は周囲を絞り、時計音だけ残す。
3. **「孤独から再会へ」**: 前半はネガティブスペース(人物を (1500,820) に小さく、背景は単色の空)、後半に視線の先へリードルームの余白(x=640 側に人物、右に 1280px)を作り、遠景に小さな光(扉)を出す。途中で黄金比 (1186,413) の位置へ寄せて静かな到達感を作る。
4. **「監視されている街」**: 窓(6x4の格子)+ボヤー(手前にブラインドの帯)+前景の物(下端に植物をぼかして)+レイヤード・デプス(近=柵、中=窓列、遠=夜景)。窓の1つだけ点灯させて視覚的重みの勝者にし、カメラを5秒かけて `scale 1.0→1.2` で寄せる。視差比は 9:3:1。
5. **「組織の中の一人」**: 反復とパターン(8x4の机)+アーキテクスチャ(オフィスの天井格子)+三角構図(三人の幹部)。1つだけ色や不透明度を変えた机を三分割交点 (1280,360) 付近に置き、破れを物語にする。カメラは真上から固定し、破れの机へだけ最後の1秒で `scale 1.0→1.35` で寄せる。
