# 色・フィルムルックと大気・天候(32技法)
> 出典: melies.co/cinematic-techniques(要約・再構成。原文の転載ではない)。HyperFramesでの実装レシピは本スキル独自。

このファイルは2部構成。第1部は「色・フィルムルック」19技法(画面全体の色と階調の設計)、第2部は「大気・天候」13技法(空気中に何が浮かぶか・何が降るか)。どちらも「画面に載せる層」として実装でき、組み合わせて使う前提で書いてある。

## 第1部 色・フィルムルック(19技法)

#### 選び方ガイド(色・フィルムルック)
- **目的 → 技法**: 世界が過酷・疲弊 → ブリーチバイパス / 色を抜くだけ → 脱彩度 / 色そのものを消す → モノクローム / 冷たい制度・夜 → クールブルー(夜の地形を残すなら昼を夜に、月光の方向を作るならムーンライトジェル) / 家・記憶・誘い → ウォームアンバー / 過去の物 → セピア(茶一色)かヴィンテージ(退色した色)かフィルミックフェード(黒浮き+ハイライト圧縮のみ) / 派手なハリウッド調 → ティール&オレンジ(一般形はスプリットトーン) / 現実の光源の色差 → タングステンバランス / 色が事件 → カラーシフト / 世界を色の掟で縛る → パレット / 嘘をつかない → ナチュラルグレード。
- **似た技法の見分け**: 「彩度」だけ動かすのは脱彩度(弱)・ハイパー彩度(強)。「明暗の置き方」まで動かすのはブリーチバイパス。「色相の偏り」は全体=クールブルー/ウォームアンバー、明暗で別色=スプリットトーン(特殊形がティール&オレンジ)、原色がずれる=クロスプロセス。「静止した色の掟」=パレット、「見ている間に変わる」=カラーシフト。
- **入門者がまず覚える3つ**: ①ティール&オレンジ(影を青緑・光を橙)、②脱彩度+コントラスト(`saturate`と`contrast`を別々に触る)、③フィルミックフェード(黒を浮かせ白を圧縮するだけで「映画の質感」になる)。
- **実装の道具の使い分け**: (a) `<img>`/`<video>`素材 → `data-color-grading`(プリセット/`.cube` LUT、`exposure`・`bloom`も持つ)。`npx hyperframes media-use resolve --type grade --intent "<look>" --project . --json` で作り、`npx hyperframes grade-compare --for <フレーム> --grades grades.json` で候補を並べて選ぶ。(b) HTML/SVG/canvasで組んだ場面 → ラッパー要素に CSS `filter` / SVG `feColorMatrix` / `mix-blend-mode`。(c) 全編まとめて → ffmpeg後処理(`curves`/`colorbalance`/`lut3d`)。
- **共通の注意**: SVGフィルタは既定が linearRGB で CSS と結果が食い違う → `<filter color-interpolation-filters="sRGB">` を付ける。CSS `filter` は左から順に適用される(`saturate`→`contrast`の順で結果が変わる)。`hue-rotate` は明度も動くので精密な色相操作は `feColorMatrix` で。強度の時間変化は proxy tween で CSS変数/属性を動かす(seek安全)。1枚の背景画像をグレードするより、最終合成の1か所にまとめてかける。肌は必ず確認(ffmpegなら `vectorscope` で肌色の線を見る)。

#### 技法一覧(色・フィルムルック)

### ブリーチバイパス / Bleach Bypass  (`color/bleach-bypass`)
- **一言**: 銀を残したまま現像した画のように、彩度を落としつつコントラストと粒状感を上げ、黒を詰めて金属質の中間調にする。
- **物語での役割**: 世界が容赦なく、汚れ、疲れ切って見える。戦争・犯罪・雨の追跡など、色が「罰せられた」感触を作る。
- **使う/使わない**: 戦闘や尋問など慈悲のない場面で、作品の基調として使う。ただ色を抜いただけの絵や、ハリウッド的なティール&オレンジ調の代用には使わない。
- **よくある失敗**: 単なる脱彩度(薄く柔らかい灰色の膜)にしてしまうこと。黒が詰まらず、ハイライトが硬くないと別物になる。
- **似た技法との違い**: 脱彩度は彩度だけを下げる。ブリーチバイパスは「彩度低下+高コントラスト+詰まった黒+硬いハイライト」の組。
- **HyperFramesでの作り方**: 白黒コピーをオーバーレイ合成する方式が最も近い。元の層の上に同じ映像のコピーを重ね、`filter: grayscale(1) contrast(1.4)`、`mix-blend-mode: overlay`、`opacity: 0.6`。ベース層は `saturate(0.5)`。仕上げに `contrast(1.15)` と粒状(`grain-overlay`、`npx hyperframes add grain-overlay`、確認済)。SVGなら `feColorMatrix type="saturate" values="0.45"` の後に `feComponentTransfer` の `feFuncR/G/B type="linear" slope="1.3" intercept="-0.15"`(中点0.5を保つ intercept=0.5(1-slope))。ffmpegなら `split[a][b];[b]hue=s=0,eq=contrast=1.4[g];[a][g]blend=all_mode=overlay:all_opacity=0.6,eq=saturation=0.5:contrast=1.15`。黒を持ち上げない(`brightness`を上げない)こと。
- **音との合わせ方**: 低域を削った乾いた環境音と、無音に近い間(耳鳴り)が質感に合う。
- **難易度/適性**: ★(混合とフィルタだけで再現できる)。
- **AI動画生成プロンプト**: `Bleach-bypass look on [Subject], retained silver, crushed color, harsh contrast, metallic midtones.`

### カラーシフト / Color Shift  (`color/color-shift`)
- **一言**: 色の状態(白黒からカラー、冷から暖など)が観客の見ている前で変わる、色そのものを出来事にする技法。
- **物語での役割**: 別の世界・嘘・記憶への「境界を越えた」感覚を、登場人物と一緒に体験させる。
- **使う/使わない**: 扉を開けた瞬間に世界が色づくなど、変化の瞬間が見える場面で1回使う。章ごとに別パレットを置くだけ(変化が見えない)の場合や、意味のない色相ドリフトには使わない。
- **よくある失敗**: 前後の状態が定義されず、ただ色がふらつくこと。必ず「変化前」「変化後」「越える手がかり(扉・カット・移動するグレード)」の3点を決める。
- **似た技法との違い**: パレットは静止した色の掟。カラーシフトは変化そのもの。
- **HyperFramesでの作り方**: 方式は2つ。(1) 空間境界型: 世界A(グレー)と世界B(カラー)を2層に重ね、上層に `clip-path: circle(0% at 50% 50%)` → `circle(75%)` をproxy tween(power2.inOut、1.2〜2.0秒)で広げる。扉の形なら矩形の `inset()`。(2) 時間連続型: 1つの層に `filter: grayscale(g) hue-rotate(h)` を持たせ、`{g:1→0}` を power2.inOut、2〜3秒で動かしonUpdateで文字列を再設定。冷→暖は `feColorMatrix` の青を 1.15→0.85、赤を 0.85→1.15 に同時に補間。変化前のグレーを暗めに露出しておくと、後の色が映える。既製の比較用部品 `npx hyperframes add grade-split-reveal`(確認済、境界が掃引してグレードが入る)は境界掃引型の下敷きになる。
- **音との合わせ方**: 変化の瞬間に和音が一段開く、または環境音が狭帯域→広帯域に広がる。
- **難易度/適性**: ★(2層+マスクの補間)。
- **AI動画生成プロンプト**: `Color shift across [Subject], hues sliding mid-shot, the world changing temperature in front of us, from monochrome to full color through a doorway.`

### クールブルー / Cool Blue  (`color/cool-blue`)
- **一言**: 影と中間調を鋼色・シアン・月光の青へ寄せ、暖かさは1つの実用光や顔だけに残す。
- **物語での役割**: 冷たい制度、夜、疎外感。病院・オフィス・夜明け前の街に「温もりの無い空気」を与える。
- **使う/使わない**: 冷たい場所の基調として、暖色の実用光を1つだけ残して使う。晴れた昼を青く塗って夜と言い張る用途や、全場面に被せる用途には使わない。
- **よくある失敗**: 肌までシアンにして病人のように見せること、ティール&オレンジ(肌は暖色のまま)との混同。
- **似た技法との違い**: 昼を夜にするのは撮影の技(昼夜変換)。クールブルーは色の偏りだけで、晴天の影の硬さや空は残る。
- **HyperFramesでの作り方**: ラッパーに SVG `feColorMatrix` 行列 `0.82 0 0 0 0 / 0 0.98 0 0 0.01 / 0 0 1.18 0 0.03 / 0 0 0 1 0`(R×0.82、B×1.18、青に+0.03のオフセット)を当てる。または `#1c3a5e` の全面ベタを `mix-blend-mode: soft-light`、`opacity: 0.35`〜0.5で重ねる。肌を守る場合は人物層をグレードの上に置き、暖色の `radial-gradient(#ffb060, transparent)` を `mix-blend-mode: screen` で顔と卓上ランプ位置に1点だけ足す。ffmpegなら `colorbalance=rs=-0.1:bs=0.2:rm=-0.08:bm=0.15:rh=-0.03:bh=0.05`。冷色は彩度を少し落とす(`saturate(0.85)`)と鋼らしくなる。
- **難易度/適性**: ★(色行列1つ+実用光1点)。
- **AI動画生成プロンプト**: `Cool blue grade on [Subject], steel shadows, hospital or moonlight, warmth reserved for one practical if any.`

### クロスプロセス / Cross Process  (`color/cross-process`)
- **一言**: 現像液を取り違えたように原色の関係をずらし、シアンの影・黄やマゼンタの肌・強いコントラストを「化学の事故」として残す。
- **物語での役割**: 90年代のファッション映像やMVのような、ラボの失敗をそのまま様式にした不安定でスタイリッシュな世界。
- **使う/使わない**: MV、90年代風の短編、信用できない夜に、事故の種類を1つ決めて通す。ただ鮮やかにするだけ(ハイパー彩度)や、設計された補色グレード(ティール&オレンジ)の代用には使わない。
- **よくある失敗**: カットごとにずらす色が変わって「ただの色むら」になること。事故は1種類に固定する。
- **似た技法との違い**: ハイパー彩度は正しい色を大きくするだけ。クロスプロセスは色が隣の色相へすべる。
- **HyperFramesでの作り方**: チャンネルごとのトーンカーブで実装する。SVG `feComponentTransfer` で `feFuncR type="table" tableValues="0 0.08 0.5 0.92 1"`(強いS字)、`feFuncG tableValues="0 0.2 0.55 0.9 1"`、`feFuncB tableValues="0.12 0.35 0.5 0.68 0.88"`(青は黒を持ち上げ白を下げる=シアンの影・黄ばんだ光)。ffmpegなら `curves=r='0/0 0.25/0.15 0.75/0.9 1/1':g='0/0 0.5/0.55 1/1':b='0/0.1 0.5/0.45 1/0.85'`。肌が緑〜黄に倒れるのが正しい挙動なので、肌を守る処理はしない。全カットに同じフィルタを使い回し、強度だけ `opacity` で調整する。
- **難易度/適性**: ★(カーブ3本)。
- **AI動画生成プロンプト**: `Cross-processed look on [Subject], skewed primaries, cyan shadows, magenta skin shift, music-video chemical accident.`

### 昼を夜に / Day for Night  (`color/day-for-night`)
- **一言**: 昼の光を夜に見えるよう露出・空・ハイライトを操作して撮り、夜でも地形が見える画を作る。青く塗るだけでは成立しない。
- **物語での役割**: 砂漠や牧場など、本物の夜では見えない広い土地を「偽の月光」で見せ続ける。
- **使う/使わない**: 夜を待てない、または夜でも地形を見せたい屋外で使う。晴れた街路に青いLUTを被せて太陽が写ったまま使うことはしない。
- **よくある失敗**: 白い空・短い真上の影・太陽の円盤が残って「青く塗った昼」に見えること。
- **似た技法との違い**: クールブルーは色の偏り。昼を夜にするのは、昼の手がかり(空・影・太陽)を消す処理が本体。
- **HyperFramesでの作り方**: 3段で作る。(1) 露出: `filter: brightness(0.45) contrast(1.15) saturate(0.55)`、ffmpegなら `eq=brightness=-0.18:contrast=1.1:saturation=0.5`。(2) 昼の手がかりを消す: 空の領域に濃紺 `linear-gradient(#050a1a, transparent 45%)` を `mix-blend-mode: multiply`(opacity 0.85)で被せ、太陽は素材から外すか黒く潰す。ハイライトを `curves=all='0/0 0.5/0.35 1/0.8'` で抑える。(3) 色: `colorbalance=bs=0.25:bm=0.2:rm=-0.1` で月光の青、`vignette` で周辺を落とす。ベクター場面なら空を濃紺グラデ、地面を暗い青灰、月は光源側から薄い縁光(`drop-shadow`)にする。
- **難易度/適性**: ★★(昼の手がかりを消す設計が要る)。
- **AI動画生成プロンプト**: `Day-for-night treatment of [Subject], underexposed daylight, blue wash, skipped-over sun, moonlight as a lie that reads.`

### 脱彩度 / Desaturation  (`color/desaturation`)
- **一言**: 色相は残したまま彩度を下げ、世界を冬の埃のような静かな色にして、残った色にだけ意味を持たせる。
- **物語での役割**: 抑えられた感情、疲れた土地。残った赤いテールランプや青白い顔が、控えめだからこそ語る。
- **使う/使わない**: 難民の道や冬の街など、世界の色を引いて見せたい場面で、残す色を1つ決めて使う。白黒にしてしまう場面や、ブリーチバイパスの代用には使わない。
- **よくある失敗**: 金属質の詰まった黒と硬い粒状感までつけてブリーチバイパスにしてしまうこと、色相が全て消えて白黒になること。
- **似た技法との違い**: ブリーチバイパスは脱彩度の上に銀のコントラストを足したもの。脱彩度はコントラストを独立に決める。
- **HyperFramesでの作り方**: ラッパーに `filter: saturate(0.5)`(0.4〜0.65が目安。0.3以下は白黒に近づく)。コントラストは触らないか `contrast(1.03)` 程度。残す色は選択的に: グレード済みの層の上に、残したい物(赤い外套など)だけを `clip-path`/`mask` で切り抜いたフルカラー層を重ねる。ベクターなら、残す物にだけパレット色を使い、他は低彩度の灰緑・灰褐色を指定する(最初から色を引いて作るのが最も綺麗)。ffmpegは `eq=saturation=0.5`。肌が肌と認識できる最低限(0.45前後)を保つ。
- **難易度/適性**: ★(`saturate`1つ+残す色のマスク)。
- **AI動画生成プロンプト**: `Desaturated palette on [Subject], chroma pulled back, dusty, wintered, emotion in leftover color accents.`

### フィルミックフェード / Filmic Faded  (`color/filmic-faded`)
- **一言**: 黒を真っ黒より少し浮かせ、ハイライトをクリップさせず滑らかに圧縮し、プリントのような階調にする。
- **物語での役割**: 映写機を通したような柔らかさ。影に空気があり、窓は白飛びではなくクリーム色に抜けるので、回想や恋愛に合う。
- **使う/使わない**: 現代の色のまま「映画の質感」にしたい夏の記憶などに使う。黒を詰めたい画やHDR的な鋭さが要る画には使わない。
- **よくある失敗**: 黒が茶色く濁ったり、霧がかかったように全体が白っぽくなること。ハイライトの圧縮(肩)が無いと単なる「白浮き」になる。
- **似た技法との違い**: ヴィンテージは染料の退色まで含む時代の化学。フィルミックフェードは階調曲線(黒の浮きと白の肩)だけ。
- **HyperFramesでの作り方**: トーンカーブで作る。SVG `feComponentTransfer` で `feFuncR/G/B type="table" tableValues="0.05 0.28 0.52 0.74 0.90 0.95"`(黒=0.05、白=0.95、肩をなだらかに)。ffmpegなら `curves=all='0/0.06 0.5/0.5 0.85/0.85 1/0.95'` か `colorlevels=romin=0.05:gomin=0.05:bomin=0.05:romax=0.95:gomax=0.95:bomax=0.95`。CSSだけなら、黒浮きは `#141418` のベタ全面を `mix-blend-mode: lighten`(各画素の最大値を取る)、白の圧縮は `#f2efe8` のベタを `mix-blend-mode: darken` で重ねる。彩度は `saturate(0.9)` 程度に留め、色相は残す。仕上げに弱い粒状(`grain-overlay`)を足すと印画らしくなる。
- **難易度/適性**: ★(カーブ1本)。
- **AI動画生成プロンプト**: `Filmic faded grade on [Subject], lifted blacks, rolled-off highlights, print-emulation, slightly expired romance.`

### ハイパー彩度 / Hyper-Saturation  (`color/hyper-saturation`)
- **一言**: 記録された以上に色の強度を上げ、赤が漆のように、緑が毒々しく見える、事実より感情が大きい色にする。
- **物語での役割**: 世界が「塗られた」ものになり、色そのものが感情になる。悪夢の廊下、武侠の砂漠、極彩色の恋。
- **使う/使わない**: 感情が事実より大きい場面(悪夢・伝説・恋)で、色の強い美術を前提に使う。ドキュメンタリー的な主張や、肌を守る補色グレードの代用には使わない。
- **よくある失敗**: 美術に無い色を後から塗ってプラスチックに見えること、色相がずれたクロスプロセスとの混同。
- **似た技法との違い**: クロスプロセスは色がずれる。ハイパー彩度は本来の色相のまま強まる。
- **HyperFramesでの作り方**: ラッパーに `filter: saturate(1.7) contrast(1.08)`(1.5〜2.0が目安、2.2超は階調が潰れて破綻)。SVGなら `feColorMatrix type="saturate" values="1.8"`。特定の原色だけ強めたい時は、その色の要素にだけ高彩度のパレット色を直接指定するのが最も安全。ffmpegは `vibrance=intensity=0.8,eq=saturation=1.5:contrast=1.08`(vibranceは既に高彩度の色を守る)。肌を守るか一緒に熱くするかを最初に決める。
- **難易度/適性**: ★(`saturate`だが、元の美術の色設計が必要)。
- **AI動画生成プロンプト**: `Hyper-saturated color on [Subject], Velvia intensity, reds like lacquer, a dream or a fever, not documentary.`

### モノクローム / Monochrome  (`color/monochrome`)
- **一言**: 色相をなくし、明暗・質感・輪郭だけで画を成立させる。
- **物語での役割**: 画が「素描」になり、衣装と光が階級と意味を担う。肌は灰色、血は濃度になる。
- **使う/使わない**: 告白、格闘、史実の記録など、素描として見せたい場面に使う。残した色の差し色で感情を運ぶ場面や、茶色い記憶調(セピア)には使わない。
- **よくある失敗**: 影に青が残ったり、茶色い被せで「白黒」と称すること。色相が完全にゼロで、グレースケールの段階に分離があること。
- **似た技法との違い**: 脱彩度は色を弱めるだけで色相が残る。モノクロームは彩度ゼロ。
- **HyperFramesでの作り方**: `filter: grayscale(1) contrast(1.2)`。階調の質は変換の係数で決まる。SVG `feColorMatrix values=".3 .59 .11 0 0  .3 .59 .11 0 0  .3 .59 .11 0 0  0 0 0 1 0"`(標準)に対し、赤フィルタ風は各行を `.8 .2 0 0 0` にすると空が暗く唇が明るくなる(オルソ風は逆に青を強める `.1 .3 .6`)。ffmpegは `hue=s=0` か `colorchannelmixer=.8:.2:0:0:.8:.2:0:0:.8:.2:0:0`。階調の分離は `contrast(1.15)`+軽い粒状+周辺減光で。顔・帽子・空が同じ灰色にならないよう、色で分けていた境界は明るさで分け直す。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Monochrome treatment of [Subject], silver highlights, deep blacks, no chroma, shape and light only.`

### 月光ジェル / Moonlight Gel  (`color/moonlight-gel`)
- **一言**: シアンや鋼緑のジェルをかけた大型の冷たい光を月の代わりに上から当て、夜を方向のある彫刻的な画にする。
- **物語での役割**: 空に光源があると感じさせる、銀色の縁光と暗い地面。焚き火や窓の暖色と対にして、夜の中に居場所を作る。
- **使う/使わない**: 森・雪原・小屋など、夜がなお造形的であるべき場面で使う。昼を青くしたもの、まんべんなく青い均一フィルには使わない。
- **よくある失敗**: 光の方向がなく、全体が均等に青いこと。月光は1方向で、フィルは暗く落とす。
- **似た技法との違い**: クールブルーは全体の色の偏り。月光ジェルは光源の位置と縁光を持つ照明設計。
- **HyperFramesでの作り方**: 層で作る。(1) ベース全体を `brightness(0.35)` まで暗くし、`feColorMatrix` で青緑へ。(2) 上方斜めに大きな光 `radial-gradient(ellipse at 70% 0%, rgba(140,220,235,.55), transparent 60%)` を `mix-blend-mode: screen` で足す(シアン〜青緑)。(3) 人物・樹木の縁に光が当たる側へ `filter: drop-shadow(2px -2px 0 #9fe3f0)` の細い縁光(逆光側の輪郭に)。(4) 木漏れ影は `feTurbulence baseFrequency="0.012 0.03" seed="7"` をしきい値処理(`feComponentTransfer type="discrete"`)したマスクを乗算で掛け、ごくゆっくり平行移動。(5) 暖色の実用光(小屋の窓)を `screen` の橙グラデで1点だけ置く。光の方向は全層で1つに統一する。
- **難易度/適性**: ★★(光方向の統一が要る)。
- **AI動画生成プロンプト**: `Moonlight gel on [Subject], cyan-green night, a single cool key as the moon, deep underexposure, silver edges.`

### ナチュラルグレード / Natural Grade  (`color/natural-grade`)
- **一言**: 肌を忠実に保ち彩度を抑え、場所が本来持つ色をそのまま信じさせるため、色で語ることを控えるグレード。
- **物語での役割**: 「様式は嘘になる」場面で、観客に場所そのものを信じさせる。記録的なドラマ、本当の陽光の村、醜いままの蛍光灯の店。
- **使う/使わない**: 様式が嘘になる記録的な場面や、日常の記憶が日常のままであるべき場面で使う。設計されたパレット、熱病的な色、ポスター的な補色には使わない。
- **よくある失敗**: 薄いティール&オレンジやフィルミックフェードのLUTを「自然」と称して残すこと。影がシアンに寄っていたら自然ではない。
- **似た技法との違い**: ティール&オレンジやスプリットトーンは色相を編集する。ナチュラルグレードは編集しないことが仕事。
- **HyperFramesでの作り方**: 「足さない」のが実装。素材には `data-color-grading` を付けない(既定は無加工)。補正は白色点・露出だけに限る: `exposure` ±0.3以内、`filter: saturate(0.95) contrast(1.03)` 程度。白色点は、灰色であるべき壁やシャツが灰色になるよう `feColorMatrix` のR/G/Bの倍率(各0.95〜1.05)で合わせる。検証は ffmpeg `vectorscope=mode=color3` で肌色が肌色の線上にあること、影にシアン/緑のかぶりが無いことを見る。ベクター場面では、パレットを実物の写真から取った低彩度の色に限り、補色の壁を作らない。
- **難易度/適性**: ★(手を加えないための規律。失敗は検証で見つかる)。
- **AI動画生成プロンプト**: `Natural grade on [Subject], faithful skin, restrained saturation, no stylized split, the location's real color science.`

### 露出オーバー / Overexposed  (`color/overexposed`)
- **一言**: 白を意図して飛ばし、ハイライトの情報を焼き切る(明るいが情報が残るハイキーとは別物)。
- **物語での役割**: 光が媒体の許容量を超えていると感じさせる。啓示、忘却、クラブ、死、直視できない子供時代の太陽。顔が消える。
- **使う/使わない**: 眩しい扉の向こうなど「白飛びが文」になる瞬間に、何を残すか(目、シルエット)を決めて使う。ただ明るく綺麗な画や、偶発的な白飛びの流用には使わない。
- **よくある失敗**: 暗部を潰して「その逆」と呼ぶこと。飛ぶのは上側(白)であり、明るい画に衣服の質感が残っているならハイキーで、露出オーバーではない。
- **似た技法との違い**: ライトフラッシュは編集上の一瞬の白。露出オーバーはショット自体の露出が白に飛ぶ。
- **HyperFramesでの作り方**: 3層で作る。(1) 本体 `filter: brightness(1.6) contrast(0.9)`(brightnessは乗算なので上側が先にクリップする)。SVGなら `feFuncR/G/B type="linear" slope="2.2" intercept="-0.1"`。(2) ブルーム: 同じ映像のコピーに `filter: blur(24px) brightness(1.5)`、`mix-blend-mode: screen`、`opacity: 0.7`。(3) 光源側に `radial-gradient(circle at 70% 30%, #fff 0%, rgba(255,255,255,0) 60%)` の白を重ねる。`<video>`/`<img>` なら `--hf-color-grading-exposure` を 0→1.5 へ、`--hf-color-grading-bloom` を 0→1.5 へtween(power2.in、1.0〜1.5秒、元の style に初期値を書く)。ffmpegは `eq=brightness=0.18:gamma=1.4`。残したい目や輪郭は上の層で暗く戻す。
- **音との合わせ方**: 白に向かって高域のサイン波が上がり、頂点で無音に落ちると「焼ける」感触が出る。
- **難易度/適性**: ★(係数とブルーム)。
- **AI動画生成プロンプト**: `Overexposed [Subject], values clipping toward heaven or fluorescent hell, information burned on purpose.`

### パレット / Palette  (`color/palette`)
- **一言**: 美術・衣装・照明・グレードにわたって、限られた数色だけを掟として使い、場所や物語の状態を色で区別する。
- **物語での役割**: 観客が色の規則を学び、それが破られる時に感じる。黄色い砂漠の章、赤い布の嘘、ミントのホテル。色で「いまどの筋か」が分かる。
- **使う/使わない**: 色が多すぎるとノイズになる作品や、筋ごとに色で見分けさせたい作品で使う。変化を見せたい(カラーシフト)場面や、色の掟のない雑多な素材をグレードだけで揃えることには使わない。
- **よくある失敗**: 画面内に余計な色(通りがかりの派手な看板)が混ざること。グレードは最後で、まず美術側を揃える。
- **似た技法との違い**: スプリットトーンは明暗の曲線を塗る。パレットは世界の物(壁・衣装)に許す色を決める。
- **HyperFramesでの作り方**: 最も得意な技法。`:root` に `--c1`〜`--c3` の3色(+中立の黒/白/灰)だけを定義し、全ての `fill`/`background`/`border`/`box-shadow` を `var(--cN)` 経由に限る(直書きのhex禁止)。筋・場所ごとに `[data-palette="A"]` で変数セットを切り替え、場面の最初に1回だけ宣言する。素材写真は `filter: grayscale(1)` に `mix-blend-mode: multiply` で背景色を掛ける(duotone化)と掟に収まる。検証: `npx hyperframes snapshot` のフレームを見て、規定外の色相が無いかを確認する(許容は各色の色相±15°)。掟を破る瞬間は、1要素だけ規定外の色を `--break` 変数で出す。
- **難易度/適性**: ★(CSS変数の規律。再現は容易で、設計が価値)。
- **AI動画生成プロンプト**: `Restricted palette on [Subject], a few chosen hues doing all the work, design as law, only [Color A], [Color B] and [Color C].`

### セピア / Sepia  (`color/sepia`)
- **一言**: 灰色の階調を銀色ではなく茶金色に写像し、白は古い紙へ、黒は焦げ茶へ寄せる。過去を化学の色として扱う。
- **物語での役割**: すでに起きた話の色。写真、記憶、時代の章。観客がアルブミン紙やトーニング写真から学んだ「過去」の色。
- **使う/使わない**: 記憶の挿入、見つかった写真、プロローグなど「終わった話」に使う。暖色の現在(ウォームアンバー)や、全編が黄土色でも赤や緑が残る場面には使わない。
- **よくある失敗**: フルカラーの現代グレードの上に茶色を被せること(緑の木や青いジーンズが残る)。シアンやクリーンな白を残さない。
- **似た技法との違い**: ウォームアンバーはフルカラーが残る。セピアは彩度がほぼ無く、茶金の階調のみ。
- **HyperFramesでの作り方**: 一度グレースケール化してから、トーンマップで茶金へ。SVG: `feColorMatrix`(輝度化 `.3 .59 .11 0 0` を3行)の後に `feComponentTransfer` で `feFuncR tableValues="0.16 0.50 0.86 0.98"`、`feFuncG tableValues="0.10 0.38 0.72 0.92"`、`feFuncB tableValues="0.06 0.24 0.52 0.74"`(黒=焦げ茶、白=紙の黄)。手軽には `filter: sepia(1) saturate(0.8) contrast(1.05) brightness(0.95)`。ffmpegは `colorchannelmixer=.393:.769:.189:0:.349:.686:.168:0:.272:.534:.131:0`。仕上げに粒状(`grain-overlay`)と軽い周辺減光を足す。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Sepia tonality on [Subject], brown-gold memory, faded whites, the past as a color, not a filter sticker.`

### スプリットトーン / Split Toning  (`color/split-tone`)
- **一言**: ハイライトに1つの色相、シャドウに別の色相を割り当て、階調全体を2色の世界にする。
- **物語での役割**: 光と影が別の神に属するような世界の掟。金と青緑、マゼンタと緑、鋼と琥珀。画の全体に一貫した色の法則が生まれる。
- **使う/使わない**: 夜のドライブや未来都市など、明暗が別の色相であるべき場面で、色の組を宣言して使う。実在のランプの色差の代用(タングステンバランスや実用光)には使わない。
- **よくある失敗**: 「スプリット=ティール&オレンジ」と決めつけること。色の組は何でもよく、組を宣言して一貫させる。
- **似た技法との違い**: ティール&オレンジはスプリットトーンの特殊形(補色+肌の保護)。
- **HyperFramesでの作り方**: 2枚のベタ層で作れる。(1) シャドウ側: 暗い色 `#0a2a33`(青緑)のベタを `mix-blend-mode: lighten`、`opacity: 0.8` で重ねる(最大値合成なので黒だけが持ち上がる)。(2) ハイライト側: `#ffd9a8`(暖色)のベタを `mix-blend-mode: multiply` で重ねる(白だけが暖色に染まり、黒は変わらない)。交差点(中間調)は肌が汚れないか確認する。SVGなら `feComponentTransfer` で `feFuncR tableValues="0.02 0.3 0.7 1.0"`、`feFuncG "0.12 0.38 0.68 0.88"`、`feFuncB "0.16 0.42 0.62 0.72"`(影=青緑、光=橙)。ffmpegは `colorbalance=rs=-0.15:gs=0.05:bs=0.15:rh=0.15:gh=0.03:bh=-0.15`。色の組は2色に限る。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Split-toned grade on [Subject], highlights one hue, shadows another, for example gold over teal, a two-color world.`

### ティール&オレンジ / Teal and Orange  (`color/teal-orange`)
- **一言**: 影や空・背景を青緑に、肌と暖色の光源を橙側に置く、肌を保護した補色の分割グレード。
- **物語での役割**: 補色が振動して画に迫力が出つつ、顔は見つけやすいまま。現代のスタジオ作品らしい「映画の看板」の絵になる。
- **使う/使わない**: 夜の街で暖色の肌を青緑の空気に立たせたい場面で、肌を保護して使う。銀色で疲弊した戦争・犯罪の世界や、全ての夜景に同じ壁として使うことはしない。
- **よくある失敗**: 肌まで青緑になる(クールブルー)、逆にハイライトに橙が残らない。半顔だけ橙・半顔だけ青緑にするのも、光源が無ければ不自然。
- **似た技法との違い**: スプリットトーンは任意の2色の一般形。ティール&オレンジは補色の組と肌の保護がセット。
- **HyperFramesでの作り方**: ffmpegなら `colorbalance=rs=-0.18:gs=0.02:bs=0.12:rm=0.06:bm=-0.06:rh=0.2:gh=0.05:bh=-0.2`(シャドウ=赤を引き青を足す/ハイライト=赤を足し青を引く)。肌の保護は層分割で行う: 背景層と人物層を分け、背景層には強いティール(影に `#0f4a55` を `lighten`、`opacity .35`)、人物層には弱い暖色のみ(`#ffb070` を `soft-light`、`opacity .25`)をかける。実写素材は `npx hyperframes media-use resolve --type grade --intent "teal orange blockbuster" --project . --json` で LUT 付きの `data-color-grading` を作り、`lut.intensity` を 0.6〜0.85 に抑える(強すぎると肌が崩れる)。候補は `grade-compare` で並べて選ぶ。ベクターなら、空・壁を青緑系、人物と光源を橙系のパレットで描く。
- **難易度/適性**: ★★(肌の保護の層設計が要る)。
- **AI動画生成プロンプト**: `Teal-and-orange grade on [Subject], skin staying warm, shadows and skies pushed cyan, complementary split.`

### タングステンバランス / Tungsten Balance  (`color/tungsten-balance`)
- **一言**: ホワイトバランスを約3200Kに合わせ、電球色の光は中立〜暖色に、昼光や冷たい光は青に写し、光源ごとの色差を残す。
- **物語での役割**: 部屋は暖かく、外の世界は冷たい。内と外が、説明なしに窓ガラス一枚で分かれる。ホテルの廊下、雪のホテルのパーティ。
- **使う/使わない**: 暖かい室内と冷たい窓を同じ画に置く場面で、実在のランプを画に入れて使う。光源の無い補色グレードの代用や、全てのランプを同じ白に揃える用途には使わない。
- **よくある失敗**: 室内全体が均一な蜜色になる(ウォームアンバー)。顔を、光源の無い橙と青緑の半々に塗ること。
- **似た技法との違い**: ウォームアンバーは全体に掛けるグレード。タングステンバランスは複数光源の色の関係。
- **HyperFramesでの作り方**: 場面を「内」と「外」に分けて作る。室内層は `radial-gradient(circle at 30% 40%, rgba(255,190,120,.55), transparent 55%)` を `mix-blend-mode: screen` でランプ位置に置く(約3200Kの橙)。窓の領域は別層にして `feColorMatrix` で R×0.7、B×1.25(`0.7 0 0 0 0 / 0 0.95 0 0 0 / 0 0 1.25 0 0.04 / 0 0 0 1 0`)の冷色に。窓の外の景色を `#8fb4ff` 寄りのベタ+`mix-blend-mode: multiply` にしてもよい。窓から室内へ漏れる冷光も、窓の輪郭に沿った淡い青の `box-shadow`/グラデで足す(光源と一致させる)。ffmpegで一括なら、窓の矩形をマスクにして冷色コピーを `overlay` で合成。
- **難易度/適性**: ★★(光源を画面内で整合させる設計)。
- **AI動画生成プロンプト**: `Tungsten-balanced interior on [Subject], 3200K warmth, windows going cold blue, mixed sources telling inside versus out.`

### ヴィンテージ / Vintage  (`color/vintage`)
- **一言**: 退色した染料、柔らかいコントラスト、ハレーション(光のにじみ)など、フィルムの経年変化の化学そのものを再現する。
- **物語での役割**: 画面が「すでに起きたこと」を告白する。白は映像の白ではなく、染料がさまよう。時代の静止画、記憶の中のシットコム。
- **使う/使わない**: 画そのものが時間の産物として見えるべき場面に使う。現代の話にレンズの味だけを足したい場面、傷の重ね貼りだけで終わらせることはしない。
- **よくある失敗**: 鮮明な現代のコントラストに傷とホコリを貼って「古さ」とすること。経年変化は染料とにじみで作る。
- **似た技法との違い**: フィルミックフェードは階調曲線のみ。ヴィンテージは染料の退色とハレーションまで含む総合。
- **HyperFramesでの作り方**: 4要素を重ねる。(1) 退色: `filter: saturate(0.75) contrast(0.9)`+黒浮き(`#16130f` を `lighten`)。(2) 染料のずれ: `feColorMatrix` で R×1.06、B×0.88(青緑が先に抜ける想定)。(3) ハレーション: コピー層に `filter: blur(14px) brightness(1.5) sepia(1) saturate(3) hue-rotate(-20deg)`、`mix-blend-mode: screen`、`opacity: 0.35`(明部だけ赤橙ににじむ)。(4) 粒状と揺れ: `npx hyperframes add grain-overlay`(確認済)、メモリ的な場面転換には `npx hyperframes add organic-light-leak-overlay`(確認済)を短く使う。全体の鮮鋭度は `blur(0.4px)` で落とす。傷やゴミは主役にしない。
- **難易度/適性**: ★★(複数要素のバランス)。
- **AI動画生成プロンプト**: `Vintage treatment of [Subject], faded dyes, halation, the past as chemistry, not a sticker.`

### ウォームアンバー / Warm Amber  (`color/warm-amber`)
- **一言**: 中間調とハイライトをタングステンの蜜色・ろうそくの色へ寄せ、家庭的で安心できる温かい世界にする。
- **物語での役割**: 室内が蜜色になり、肌がランプの色を拾う。「ここにいていい」と言う画。夜の台所、記憶の食卓、おとぎ話のホテル。
- **使う/使わない**: 家・記憶・招待の場面で、色(衣装や壁)を残したまま使う。茶一色の過去(セピア)や、冷酷であるべき犯罪現場には使わない。
- **よくある失敗**: 色が全部茶色になってセピア化すること、肌が黄疸のようになること(緑が強い時は緑を引く)。
- **似た技法との違い**: セピアは彩度のない茶金の階調。ウォームアンバーはフルカラーが残る。
- **HyperFramesでの作り方**: 色行列で作る: `feColorMatrix` に `1.08 0 0 0 0.01 / 0 1.0 0 0 0 / 0 0 0.82 0 0 / 0 0 0 1 0`(R×1.08、B×0.82)。または `#ffb347` のベタを `mix-blend-mode: soft-light`、`opacity: 0.3`で重ねる。ffmpegは `colorbalance=rm=0.12:gm=0.03:bm=-0.15:rh=0.08:bh=-0.1`。ランプやろうそくの位置に `radial-gradient(#ffc070, transparent 60%)` を `screen` で置き、その不透明度を seed付きの低周波ノイズで `0.25±0.05` 揺らすと灯りが生きる(例: `0.25 + 0.05*Math.sin(t*7.3 + 1.7) + 0.03*Math.sin(t*13.1)`、tの純関数)。白は紙の白に潰さず、ハイライトを抑える。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Warm amber grade on [Subject], tungsten honey, candle and practical glow, safety or nostalgia in the mids.`

#### 組み合わせ例(色・フィルムルック)
1. **雨の夜の追跡(ネオ・ノワール)**: 脱彩度(`saturate(0.55)`)+ ブリーチバイパス(白黒コピーのオーバーレイ)で世界を疲弊させ、赤いテールランプだけをマスクで残す。黒は詰め、粒状(`grain-overlay`)を足す。第2部の「雨」「濡れ路面」を上に重ねると、画面の質が一気に揃う。
2. **回想→現在への扉**: 回想側はセピア+フィルミックフェード(黒浮き・粒状)+ヴィンテージのハレーション。現在側はナチュラルグレード。2層を `clip-path: circle()` の拡大で扉の向こうの現在に切り替える(カラーシフト、1.5秒、power2.inOut)。色が変わる瞬間に音を一段広げる。
3. **夜のホテル廊下(窓の外は雪)**: タングステンバランス(室内を橙のラジアル、窓を `feColorMatrix` の冷色)で内と外を分け、全体に弱いウォームアンバー。人物は暖色に保ち、窓外の雪(第2部)だけ青白く。
4. **都会アクションの1カット**: ティール&オレンジ(背景層だけにティール、人物層は暖色)+周辺減光+弱いブルーム。爆発の瞬間は露出オーバー(`exposure` を 0→1.5)に切り替えて白へ抜け、次カットでナチュラルグレードに落として「冷め」を作る。
5. **悪夢の廊下(感情が事実より大きい)**: パレットを赤・緑・黒の3色に限定し、ハイパー彩度(`saturate(1.8)`)で漆のようにする。クロスプロセスは混ぜない(色が隣に滑るのは別の事故)。ムーンライトジェルの縁光を使うなら、色を1つだけ(緑)に統一。
