# ジャンルルックとバイラルルック(71技法)
> 出典: melies.co/cinematic-techniques(要約・再構成。原文の転載ではない)。HyperFramesでの実装レシピは本スキル独自。
> 構成: 第1部「ジャンルルック」27技法(通常の密度、見た目を要素に分解)/ 第2部「バイラルルック」44技法(流行のAI画像・動画スタイル。短く)。

## このグループの選び方ガイド
- 第1部(ジャンル)は「映画ジャンルの見た目の文法」。第2部(バイラル)は「SNSで流行したスタイルの型」。どちらも**配色・ライティング・構図・文字・質感・動き・音の束**として分解して組み立てる。ジャンル名だけ(「ノワール風」)では見た目は決まらない。
- HyperFrames では、(a) 素材映像・画像に **フィルタ+重ね層**をかけて近づける方式と、(b) **ベクター(SVG/CSS)・canvas・文字だけで構築**する方式がある。映画の撮影そのもの(実写の被写界深度、本物の雨)は再現できないので、色・コントラスト・質感・UI要素で「そう見える」ところまで寄せる。
- フォントは `@font-face` でローカルファイルを指す(日本語は Noto Sans JP が無難。それ以外は使う文字だけサブセット化して同梱)。粒子・ノイズは Math.random 禁止、seed付きPRNG か feTurbulence の `seed` を `Math.floor(t*12)` で更新する。

## 第1部 ジャンルルック(27技法)

#### 第1部の選び方ガイド(目的 → 技法)
- **犯罪・罪悪感の夜**: 白黒の銀と影=フィルムノワール。色つきの現代=ネオノワール。未来の画面が光源=テックノワール。原色のガラス窓と黒手袋=ジャッロ。
- **歪んだ心理・恐怖**: セットそのものが傾く=ドイツ表現主義。スケールと幾何が人間を無意味にする=コズミックホラー。湿気と腐敗=サザンゴシック。空っぽの記憶の部屋=ドリームコア。低解像度の不気味さ=ウィアードコア。
- **本物らしさ・記録**: 一般的な証拠の語り=ドキュメンタリー。光も構図も整えず場に入る=シネマ・ヴェリテ。劇中の人物が撮ったテープ=ファウンドフッテージ。フィクションを街で撮りジャンプカット=ヌーヴェルヴァーグ。撮影現場を見せる=BTS。わざと下手=スタイリスティック・サック。
- **静けさ・額縁・豪華・過剰**: 空白と待つ時間=アートハウス。1枚の写真=フォトグラフィー。ポスター級の光沢=ブロックバスター。模様と色の過密=マキシマリズム。
- **地域の神話**: 荒野・太陽・目のアップ=スパゲッティウェスタン。霧・竹林・絹=武侠。ピンクとシアンの懐古=ヴェイパーウェイブ。日常の中の一つの奇跡=マジカルリアリズム。
- **構築された世界**: 図としての光と動き=アニメーション。ドットの格子=ピクセルアート。操作できる空間=ビデオゲーム。体制が敵=ディストピア。
- **似たもの同士の見分け**: ノワール系は「銀/色/未来の画面」で分ける。ドリームコア(やわらかい空間)とウィアードコア(劣化したデジタル)とヴェイパーウェイブ(パステルの商業的郷愁)は解像度と小道具で分ける。ファウンドフッテージ(劇中のカメラ+日時表示)とスタイリスティック・サック(映画自身の下手さ)とシネマ・ヴェリテ(撮影者が現場に居る)はカメラの持ち主で分ける。
- **入門でまず覚える3つ**: 白黒ノワール(コントラスト+粒子+ビネット)、ファウンドフッテージ(HUDとノイズ)、ピクセルアート(縮小して拡大するだけ)。コードで特に得意なのはピクセルアート・ビデオゲーム・ヴェイパーウェイブ・ウィアードコア・アニメーション。

#### 共通パーツ(各エントリで「共通P1」のように参照)
- **共通P1 粒子**: `npx hyperframes add grain-overlay`。自作なら全面divに SVG `feTurbulence type="fractalNoise" baseFrequency="0.85" numOctaves="2"` + `feColorMatrix type="saturate" values="0"` を敷き、`mix-blend-mode: overlay; opacity: .15〜.3`。コマごとの揺らぎは `seed` 属性を `Math.floor(t*12)` で更新(Math.random禁止)。
- **共通P2 ビネット**: `npx hyperframes add vignette`。自作は `radial-gradient(ellipse at 50% 45%, transparent 50%, rgba(0,0,0,.65) 100%)` を最上層に。
- **共通P3 白黒高コントラスト**: 素材に `filter: grayscale(1) contrast(1.5) brightness(.85)`。ffmpeg なら `-vf "hue=s=0,curves=all='0/0 0.25/0.12 0.75/0.88 1/1'"`。
- **共通P4 走査線/ゲート揺れ**: `repeating-linear-gradient(0deg, rgba(0,0,0,.18) 0 1px, transparent 1px 3px)` を重ねる。フィルムゲートの揺れは translate ±1px を24fps相当で seed付きPRNG から決める。
- **共通P5 ハンドヘルド**: `npx hyperframes add camera-shake`(手持ち用プロファイルを小さい振幅で)。自作は2〜3周波の sin 合成を t の純関数で translate/rotate(±6px、±0.4deg)に与える。

#### 技法一覧(エントリ) — ジャンルルック

### アニメーション(設計された光と動き) / Animation  (`genre-looks/animation`)
- **一言**: 光と動きを「撮る」のではなく「設計して描く」見た目。グラフィックな立体感、設計された光、描画としての動き(スミア、止め、コマ落とし)で世界を作る。
- **物語での役割**: 現実のレンズの物理に縛られず、感情に合わせて形・色・動きを決められる。観客に「これは作られた世界」という約束を最初に渡す。
- **使う/使わない**: 世界を一から構築する場面に使う。実写素材に「アニメ風フィルタ」を被せるだけの用途や、ピクセルアート/ストップモーションを狙う場面には使わない(別の構築法)。
- **よくある失敗**: 写実的なボケ(50mmのバケ)や実写っぽい被写界深度が混ざる。媒体(セル、ハーフトーン、木炭)を指定しないので曖昧になる。
- **似た技法との違い**: ピクセルアートは離散サンプリング+固定パレット、ストップモーションは物理的な人形を1コマずつ動かす。アニメーションはそれらを含まない「図としての光と動き」。
- **見た目の分解**: 配色=少数のベタ塗り+影は2階調(例: 紺 #1B1464 / マゼンタ #FF2E93 / シアン #19E6FF / 黄 #FFE600)。光=光源を物語で決める(置いた実在ランプに縛られない)。構図=大胆な図形、シルエット優先。質感=ハーフトーン網点・紙のざらつき。動き=2コマ打ち(12fps)、スミア、静止の「溜め」。音=動きの頭に打撃音を合わせる。
- **HyperFramesでの作り方**: SVG/CSSでベタ塗りのキャラ・形を作り、**時間を量子化**して全モーションに通す(`const tq = Math.floor(t*12)/12` を使い、全プロパティを tq の純関数にする)。既製品: `npx hyperframes add stop-motion-cadence`(コマ止めの時間則の手本)。影は `radial-gradient(circle,#000 30%,transparent 31%) 0 0/6px 6px` を mask にしてハーフトーン化(`halftone-field` も参照可)。スミアは進行方向に scaleX 1.25〜1.4 + 残像コピー2枚(opacity .35, .15)を1〜2コマだけ。実写風のブラーは使わない。
- **音との合わせ方**: 動きが止まる「溜め」の頭で効果音(ヒット)を打つ。コマ落としの動きには12fpsの拍(スネア)が合う。
- **難易度/適性**: ★★(絵柄の設計次第。素材絵がある前提)。
- **AI動画生成プロンプト**: `Animated treatment of [Subject], graphic volume, designed light, motion as drawing rather than photography. Name the medium (halftone, charcoal, cel, graphic CG).`

### アートハウス / Arthouse  (`genre-looks/arthouse`)
- **一言**: 三脚で固定し、窓の自然光だけ、少しずれた headroom と空白のある画面で「考える余白」をつくる見た目。
- **物語での役割**: 観客が退屈する手前の時間で、人物の内面に入り込ませる。ポスター的に売り込まない。
- **使う/使わない**: 間と空気が必要な場面に使う。アクションの地理を説明する場面や、画面をポスターとして売る場面には使わない。
- **よくある失敗**: 背後からのリムライトや完璧な中央ポートレートにしてしまう(ブロックバスターやフォトグラフィーになる)。
- **似た技法との違い**: フォトグラフィーは決定的瞬間の「額縁」、アートハウスは決定的瞬間を拒み、少し不格好なまま時間が流れる。
- **見た目の分解**: 配色=くすんだ自然色(壁 #C9C2B0、影 #2E3330、窓 #E9EEF2、肌 #B89A86)。光=窓の1灯のみ、フィル無し。構図=人物を端に寄せ、上下左右のどこかに使わない空気を残す。文字=ほぼ無し(出すなら細い明朝で小さく)。質感=ごく薄い粒子。動き=ほぼ無し。音=環境音のみ、音楽なし。
- **HyperFramesでの作り方**: 素材は固定。三分割の外に被写体を置く(画面の1/4程度に小さく)。窓光は `linear-gradient(100deg, rgba(233,238,242,.35), transparent 45%)` を左から。`filter: saturate(.8) contrast(1.05)`、共通P1 を opacity .08 で。動かすなら scale 1.00→1.015 を20秒かけるだけ(ease none)。タイトルは `Noto Serif JP` 300、26px、letter-spacing .25em、画面隅。ポスター的なテキスト演出は入れない。
- **音との合わせ方**: 部屋の空気音(環境音)とカトラリー音など生活音のみ。BGMを入れない。
- **難易度/適性**: ★(足し算をしない設計が難所)。
- **AI動画生成プロンプト**: `Arthouse still of [Subject], patience, odd headroom, natural window light, the frame willing to be empty, static camera, duration implied.`

### ブロックバスター・グロス / Blockbuster Gloss  (`genre-looks/blockbuster-gloss`)
- **一言**: 高コントラスト、輪郭を縁取るリムライト、クリーンな空、光芒、ティール(青緑)とオレンジの色分離で、ポスターのサイズでも読める「金のかかった」画面。
- **物語での役割**: 冒険とスケールの約束。観客に「これは大作だ」と一瞬で信じさせる。
- **使う/使わない**: 小さなサムネイルでもシルエットが立つべき場面に使う。静かな室内、素の取材、朽ちたポーチには使わない。
- **よくある失敗**: ティール&オレンジのグレードだけ掛けてリムライトがない、空に偶然の汚れが乗る。
- **似た技法との違い**: ティール&オレンジは色のグレードだけ、ボリュメトリックライトは光芒だけ。グロスはリム・規模・清潔さのパッケージ。
- **見た目の分解**: 配色=影 #0B4A57(ティール)、中間 #1C2B33、ハイライト #FFB070、肌 #E8A27A、空は純色 #6FA8D8。光=強い背面リム+haze の光芒。構図=広角で地平線がクリーン、被写体はシルエット優先。文字=Cinzel 700 の大文字、間隔 .3em、銀グラデ #E6EEF2→#7A8B94。質感=粒子ほぼ無し、清潔。動き=ゆっくりした押し込み。音=低音ヒット+ライザー。
- **HyperFramesでの作り方**: 素材に `filter: contrast(1.25) saturate(1.15)`、その上に `mix-blend-mode: soft-light` で上半分に #0A6C7A、下半分に #FF9A4D の面を重ねる。リムは被写体のマスク複製に `drop-shadow(0 0 2px #FFD2A0)` と `blur(1px)` を掛けて少しずらす。光芒は斜めの `repeating-linear-gradient` を `mix-blend-mode: screen; opacity .2` で、x を t で漂わせる。レンズフレアは `npx hyperframes add vfx-anamorphic-flare`。カメラは scale 1.00→1.06、power1.inOut、4〜6秒。
- **音との合わせ方**: 映像の頭にサブ低音のヒット、ライザーは3〜4秒でタイトル出現に合わせる。
- **難易度/適性**: ★★(リム分離は素材のマスクがあると楽)。
- **AI動画生成プロンプト**: `Blockbuster gloss on [Subject], expensive contrast, clean skies, heroic rim, volumetric haze, IMAX-scale finish, adventure poster in motion.`

### メイキング映像 / BTS (Behind the Scenes)  (`genre-looks/bts`)
- **一言**: スタンド、旗、セットの端、スタッフを同じ画面に入れ、作り物の世界の舞台裏を見せる見た目。
- **物語での役割**: 虚構の継ぎ目が見える。面白さ、親密さ、残酷さのどれにもなる。観客を「現場」に連れ込む。
- **使う/使わない**: 撮影現場を見せたい時に使う。現場の装置が画面に一つもない場面にBTSと名乗らない。
- **よくある失敗**: きれいな現場スチルになる、スタッフにも映画のリムライトを当ててしまう。
- **似た技法との違い**: シネマ・ヴェリテは現実の人生に撮影者がいる。BTSは装置(機材・人・セットの欠け)が映ることが条件。
- **見た目の分解**: 配色=シーン側は温かいキー #FFD9A0、現場側は寒色のワークライト #CFE3FF と暗いグレー #2A2D31。光=二つの光の世界を並べる。構図=広めの固定、セットの切れ目が見える。文字=Courier Prime のスレート文字(SCENE/TAKE)。動き=観察的なハンドヘルド。音=ざわめき、「アクション」の掛け声。
- **HyperFramesでの作り方**: 画面を2領域に分ける。中央にシーン枠(明るい暖色)、その外側は暗いグレーのスタジオ。SVGで C-stand(三脚+アーム)、黒い旗(矩形)、ブームマイク、カチンコをシルエットで描き、枠の外に置く。カチンコは上板を rotate 0→-28→0 に 3コマで落とす。観察感は共通P5で小さく。スレートは `Courier Prime` 700、タイムコードは等幅。
- **音との合わせ方**: カチンコの閉じる瞬間(2〜3コマ)に「パチン」を合わせ、直前に「ロール」「アクション」の声。
- **難易度/適性**: ★★(SVGの小道具作りが手間)。
- **AI動画生成プロンプト**: `Behind-the-scenes look at [Subject], crew, C-stands, and the set edge visible, the fiction leaking, worklight mixed with the scene key.`

### シネマ・ヴェリテ / Cinéma Vérité  (`genre-looks/cinema-verite`)
- **一言**: 手持ち、現場の光だけ、ズームで瞬間を探し、撮影者の存在が出来事を動かす記録の見た目。
- **物語での役割**: 演出ではなく「その場で起きた」手触り。画面が遅れる・ずれることが信頼の証になる。
- **使う/使わない**: 整った映像が嘘になる場面に使う。三点照明のある台本シーンに揺れだけ足す用途には使わない。
- **よくある失敗**: ファウンドフッテージ(日時表示・恐怖)や、リムのあるきれいなインタビューになる。
- **似た技法との違い**: ドキュメンタリーは広い語りの総称、ヴェリテは「現場の光+ズームで探す+撮影者が触媒」の方法。
- **見た目の分解**: 配色=窓の寒色 #BFD4F2 とタングステン #E8B070 を混ぜたまま、やや低彩度。光=現場光のみ、窓は白飛び。構図=遅れてピントとズームが追い、中心がずれる。文字=ほぼ無し(出すなら小さな白Sans)。質感=16mm粒子を強め。動き=ズームの探り。音=現場音+画面外の質問。
- **HyperFramesでの作り方**: 素材に `filter: saturate(.85) contrast(1.1) brightness(1.1)`(窓を飛ばす)、共通P1 を opacity .3、共通P4 のゲート揺れ。**ズームの探り**を proxy tween で: scale 1.0→1.28(power2.out、0.5秒)→ 1.22 に戻して止まる、と同時に `blur(0→3px→0)` でピント探し。共通P5(手持ち)を常時。色温度はスクリーン領域ごとに `mix-blend-mode: soft-light` の冷色/暖色面を左右に重ねる。
- **音との合わせ方**: 現場音を主にし、ズームの探りの瞬間に息継ぎのような無音を作らない。
- **難易度/適性**: ★★(素材の撮り方に左右される)。
- **AI動画生成プロンプト**: `Cinéma vérité treatment of [Subject], available light, unpretty frames, zooming to find, mixed color temperature, life unstaged.`

### コズミックホラー / Cosmic Horror  (`genre-looks/cosmic-horror-look`)
- **一言**: 人間が無意味に見える超ロングショット、少し「ありえない」幾何、下からの光、見せすぎる明るさで恐怖を作る見た目。
- **物語での役割**: 敵が「人」ではなく、スケールや知識そのものになる。見ることが害になる感覚を作る。
- **使う/使わない**: 脅威が人間にならない時に使う。覆面の殺人鬼や、家族の腐敗を描く場面には使わない。
- **よくある失敗**: 人間の悪役が画面を占める。ただの霧。
- **似た技法との違い**: ドイツ表現主義はセットを「心」として歪め、コズミックホラーは歪みを「宇宙の事実」として扱う。
- **見た目の分解**: 配色=氷 #DCEBF2 / #9FB8C4、虚空 #05080C、異質な赤 #7A0C14 または異星の青緑 #3CF2D0。光=下からのアンダーライト、または明るすぎる光源。構図=人物は画面高の3%以下、地平線がズレる。文字=細いSansの座標表記。質感=極薄の粒子。動き=極めて遅い。音=30〜40Hzのドローン。
- **HyperFramesでの作り方**: 人物シルエットを下1/3に小さく置き、背景の構造物は CSS 3D(`perspective:800px`)で面ごとに別の消失点になるよう `rotateX/rotateY` をずらす。顔の下から `linear-gradient(0deg,#C8FFF2,transparent 60%)`。「明るすぎる」啓示は白い radial-gradient の opacity を 0→1(power3.in、4秒)。地平のゆらぎは SVG `feTurbulence baseFrequency="0.01 0.04"` + `feDisplacementMap scale="8"` を seed固定で。カメラは scale 1.00→1.03 を12秒。
- **音との合わせ方**: ドローンを徐々に上げ、光が頂点に達した瞬間に完全な無音に落とす。
- **難易度/適性**: ★★(幾何のズラしは調整が要る)。
- **AI動画生成プロンプト**: `Cosmic horror framing of [Subject], scale wrong, geometry slightly illegal, under-lit face or a brightness that reveals too much, human irrelevance.`

### ドキュメンタリー / Documentary  (`genre-looks/documentary-look`)
- **一言**: 観察、インタビュー、資料映像の語りで「証拠を見せている」ふりをする、飾らない見た目(フィクションが借りるとモキュメンタリー)。
- **物語での役割**: 人が言うことと、カメラが「証明」するように見えるもののズレで、真実味にも笑いにも不安にもなる。
- **使う/使わない**: きれいさが嘘になる時、インタビューと観察の対比で笑いや皮肉を作る時に使う。無意味な揺れ足しや、録画テープの設定には使わない。
- **よくある失敗**: 日時表示つきの恐怖映像、ハリウッドのヘアライトが当たったインタビュー。
- **似た技法との違い**: ヴェリテは方法、ドキュメンタリーは語りの形式(インタビュー+観察+資料)。
- **見た目の分解**: 配色=くすんだ中間色 #D9D2C3、影 #8C97A3、混合色温度。光=窓のキー、ヘアライト無し。構図=目線の高さ、聞き手は画面外。文字=Noto Sans JP 500 の名前テロップ(白、細い下線)。質感=軽い粒子。動き=ゆっくりズーム。音=部屋の音+インタビューの肉声の上に別の映像(Jカット)。

### ドリームコア / Dreamcore  (`genre-looks/dreamcore`)
- **一言**: 空っぽの部屋、プール、郊外の廊下を、少し狂った子供時代の照明で包む、やわらかく低コントラストの「記憶の部屋」。
- **物語での役割**: 懐かしさから安全を抜く。何も起きないが、部屋が現実の場所として解決しない不安だけが残る。
- **使う/使わない**: 空っぽの室内で郷愁が不穏に変わる場面に。JPEG的な低解像度の恐怖や、サイケな歪み表現には使わない。
- **よくある失敗**: 低解像度やキャプションを足してウィアードコアになる、軌跡や色ズレで幻覚表現になる。
- **似た技法との違い**: ウィアードコアは劣化したデジタル+キャプション、ドリームコアは解像度が連続したやわらかい空間。
- **見た目の分解**: 配色=パステル/プールのシアン #BFE6E0、ピンク #F3D9E4、蛍光灯の黄緑 #DDE8B9、黒は持ち上げ #3A4A4A。光=蛍光灯、安い電球、白飛びした窓。構図=広角で目線の高さ、固定、中景を空にする。質感=やわらかい粒子、にじみ。動き=進んでも着かない遅い前進。音=蛍光灯の唸り(120Hz)、遠いプールの反響。
- **HyperFramesでの作り方**: 素材に `filter: contrast(.8) brightness(1.1) saturate(.7)`、黒を持ち上げる層(`#9FB8B0` を `mix-blend-mode: lighten; opacity .2`)。窓のブルームは同じ素材の複製に `blur(18px)` + `mix-blend-mode: screen; opacity .5`。にじみは `drop-shadow(2px 0 0 rgba(255,0,80,.2))`。無限の廊下は `npx hyperframes add gallery-tunnel`、または CSS 3D のパネル列を translateZ で20秒かけて ease none で進め、決して着かせない。
- **音との合わせ方**: 蛍光灯の唸り、遠いオルゴール、水の反響。突然の音は入れない。
- **難易度/適性**: ★★。
- **AI動画生成プロンプト**: `Dreamcore image of [Subject], liminal rooms, soft fluorescent or blown window, childhood lighting gone wrong, low contrast, a memory that will not resolve.`

### ディストピア / Dystopian  (`genre-looks/dystopian`)
- **一言**: 体制そのものが敵になる、使い込まれた建築、霞、階級、看板で構成された「汚れた未来」の見た目。
- **物語での役割**: 単一の悪役ではなく、制度が街と人を押しつぶす感覚。昼でも夜でも成り立つ。
- **使う/使わない**: 制度が街に見える必要がある場面。灰色なだけの無個性なSFや、夜のネオン犯罪(テックノワール)には使わない。
- **よくある失敗**: きれいな空にリムライト、つるつるの未来。
- **似た技法との違い**: テックノワールは濡れた夜と調査、ディストピアは昼でも成立する市民スケールの汚れ。
- **見た目の分解**: 配色=灰 #8E8A82、コンクリ #5B5E5F、煙のオレンジ #C46A2B、警告の赤 #B3262B。光=平板な曇天、またはオレンジの霞。構図=左右対称の巨大建築+米粒のような列。文字=Oswald 600 大文字+番号(B-4471)の標識。質感=汚れ、レンズのよごれ。動き=ゆっくりした手持ち。音=サイレン様のドローン、拡声器。
- **HyperFramesでの作り方**: 奥行きの層を手前→奥に重ね、遠いほど明るく橙に(`linear-gradient(#C9A27A,#7C766E)` を奥の層に)。群衆は SVG の短い矩形を繰り返して行列に。素材には `saturate(.45) contrast(1.35)`(ブリーチバイパス風)、汚れは feTurbulence を `mix-blend-mode: multiply; opacity .3`。標識は Oswald 600、`letter-spacing:.15em`、`#B3262B` の細枠。カメラは共通P5を弱く+ゆっくり押し込み。
- **音との合わせ方**: 低い警報様ドローン+拡声器の声にリバーブ。
- **難易度/適性**: ★★。
- **AI動画生成プロンプト**: `Dystopian view of [Subject], civic scale gone cold, haze, signage, and rank, used surfaces, a future that already feels worn.`
