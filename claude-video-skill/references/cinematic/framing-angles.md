# ショットサイズ・フレーミングとカメラアングル(44技法)
> 出典: melies.co/cinematic-techniques(要約・再構成。原文の転載ではない)。HyperFramesでの実装レシピは本スキル独自。
> 構成: 第1部 ショットサイズ・フレーミング(25技法)/ 第2部 カメラアングル(19技法)。各部に「選び方ガイド」「技法一覧」「組み合わせ例」がある。

## 共通の約束: 座標系と frame() 関数(第1部・第2部の数値はすべてこれが前提)

以降の数値は、**1920×1080(16:9)のステージ**に、主人公シルエット `hero.svg`(viewBox 520×900、右向きの横顔、金のリムライト付き)を `width=520 height=900` で置いた場合のもの。縦動画(1080×1920)なら、画面高 H が 1.78倍になるので、下の「scale」も同じ倍率で掛ける(画面高に対する占有率はそのまま)。

**hero.svg の目印(SVG座標・単位は「u」)**: 頭頂(髪)y=34 / 目 (280,170) / あご y=217 / 肩線 y≈250 / 胸骨 y≈340 / ベルト y≈520〜546 / 太ももの中ほど y≈640 / 足裏 y=874 / 体の中心 x≈254。後ろの拳 (156,498) がガンベルト高さ、前の拳 (452,267)。

**クロップの計算**: 切り取りたい帯 [上 T, 下 B](SVG座標)を、画面高の k 倍に収めるなら `scale = k × H ÷ (B − T)`。帯の中心 (cx, cy) を画面の狙う位置に置く関数が次の frame():

```js
const W=1920, H=1080;
// (cx,cy)=SVG上で画面に置きたい点, s=scale, (ax,ay)=その点を置く画面上の比率(0〜1)
const frame=(cx,cy,s,ax=.5,ay=.5)=>({x:W*ax-cx*s, y:H*ay-cy*s, scale:s});
// #hero は transform-origin:0 0 にしておく。寄りサイズの切替は tl.set('#hero',{...frame(...)}, tShot) の「ハードカット」で行い、
// サイズを動かす(プッシュイン)ときだけ proxy tween で frame の値を補間する。
```
**ショットサイズ早見表(1080p基準)**

| サイズ | クロップ帯 T→B (u) | 画面高比 k | scale | 画面上の見え方 |
|---|---|---|---|---|
| 極端なロング(ELS) | 全身 34→874 | 0.03以下 | 0.03〜0.04 | キャラ高 約30px。点 |
| ロング(LS) | 全身 | 0.20〜0.30 | 0.26〜0.38 | キャラ高 220〜320px。地面と空が主役 |
| ワイド(WS) | 全身(複数人・場所込み) | 0.35〜0.45 | 0.45〜0.58 | キャラ高 380〜480px。扉・道が読める |
| 全身(Full Body) | 34→874 | 0.80 | 1.03 | キャラ高 864px。頭上と足元に各10%の余白 |
| カウボーイ | 20→640(太もも中) | 0.92 | 1.60 | 後ろの拳(ベルト線)が画面中央より下に入る |
| ミディアム(MS) | 20→550(腰) | 0.92 | 1.87 | 腰で切る。ベルトは画面下端ぎりぎり |
| MCU(胸から上) | 20→345 | 0.92 | 3.06 | 胸骨で切る |
| クローズアップ(CU) | 20→275(頭+肩の上) | 0.92 | 3.9 | 頭頂〜あごが画面高の約65% |
| チョーカー(BCU) | 118→218(額の生え際〜あご) | 1.00 | 10 | 顔が画面高いっぱい。頭頂と耳は画面外 |
| 極端なクローズアップ(ECU) | 148→192(目と眉だけ) | 1.00 | 24 | 目のスリットが画面幅の約半分 |

**拡大時の落とし穴**: scale が3を超えると、`stroke-width:2.5` の縁取りが太くなりすぎる。`vector-effect:non-scaling-stroke` を付けて線幅を px で固定するか、寄るほど stroke-width を `2.5/scale×(望むpx)` に補正する。SVGはベクターなのでぼやけない(ラスタ画像の寄りは解像度が足りなくなるので、寄るなら元画像を2〜3倍で書き出しておく)。シルエットのhero.svgには顔の細部がないため、ECU(目・口・指先)は**寄り専用のSVGパーツを別に描く**(目のスリット+眉+睫毛だけ、など)。

**seek安全の共通ルール**: タイムラインは1本の paused タイムライン。揺れ・粒子・ランダムは seed 付き PRNG(例: mulberry32)で、時刻 t から毎回同じ値を出す。`Math.random()` と `Date.now()` は禁止。ショット切替は `tl.set()` か display/visibility の切替で行う。

## 第1部 選び方ガイド(ショットサイズ・フレーミング)

- **「サイズ」は何を見せたいかで決める**。顔の中の細部 → ECU / 顔全体の逃げ場なし → チョーカー / 表情の読み取り → CU / 会話 + 体の動き → MCU / 手と顔のバランス → MS / 手(銃・ベルト)と立ち姿 → カウボーイ / 衣装・歩き方 → 全身 / 人と世界の関係 → ロング / 地図としての場所 → ワイド / 規模そのものが感情 → ELS。**切る位置の目印**: 生え際・あご・肩・胸・腰・太もも・足元。ひとつ下げれば隣のサイズになる。
- **「サイズ」ではなく「役目」の技法**: マスターショット(場面の骨組み)、エスタブリッシング(いつ・どこ)、インサート(筋に関わる物)、カットイン(すでに映っている物に寄る)、カットアウェイ(いったん場面を離れる)、リアクション(受け手の顔)、ジェスチャー(体の小さな動き)。名前が似ていても「寄ったのか、離れたのか」で見分ける。
- **人数で選ぶ**: 1人 → シングル / 2人の関係 → ツーショット / 3人の力関係 → スリーショット / 4人以上のまとまり → グループ / 手前の肩+奥の顔 → OTS。
- **特別なスタイル**: インタビュー(視線がレンズの少し横)、ビデオポートレート(動かさず長く見せる)、プロダクト(物を人物のように撮る)。
- **入門者がまず覚える3つ**: ①ワイド(またはマスター)で場所と配置を見せる ②MS〜MCUで会話を撮る ③CU/インサートで「ここを見て」を示す。この3段を行き来すれば場面は成立する。サイズを変えるのは、新しい事実が出たときだけ。
- **HyperFramesでの考え方**: サイズ変更は「同じキャラのscaleとクロップを変える」だけ。上の早見表の scale を `tl.set()` でハードカットするのが基本。連続して寄る/引くときは scale を power2.inOut で補間し、背景は別層で小さく(遠いほど少なく)動かす。

## 第1部 技法一覧(ショットサイズ・フレーミング 25技法)

### チョーカー(ビッグクローズアップ) / Choker Shot (BCU)  (`framing/choker`)
- **一言**: 額の生え際からあごまでだけを画面いっぱいに切り取る、顔全体のぎりぎりのアップ。肩と背景はほぼ消える。
- **物語での役割**: 人物を自分の顔の中に閉じ込める。ジェスチャーも襟も逃げ場がなく、感情は目・口・その周りの小さな筋肉だけで起きる。
- **使う/使わない**: 告白・崩壊・逃げ場のない睨み合いに使い、証明写真のように感じる前に切る(1シーンに1〜2回)。肩や手の動きが必要な場面、目や口だけが主題の場面には使わない。
- **よくある失敗**: 目だけのECUや肩が入ったCUになってしまうこと。広角のまま寄って顔が歪むこと。生え際とあごが両方入っているのが目印。
- **似た技法との違い**: ECUは顔の一部だけ、CUは肩まで入る。チョーカーはその間で「顔は全部あるが体はない」。
- **HyperFramesでの作り方**: 2Dトランスフォーム。hero のクロップ帯を 118→218u に取り `frame(254,168,10,.42,.5)` で画面いっぱいにする(scale≈10、顔の幅が約900px)。頭頂と耳は画面外に出てよい。線幅は `vector-effect:non-scaling-stroke` で2〜3pxに固定。寄り専用の顔SVG(目・口・眉つき)に差し替えると表情が出せる。ゆっくり寄るなら前のサイズから scale を power2.out で8→10(1.5〜2秒)。背景は `vignette`(`npx hyperframes add vignette`)で周辺を落とし、背景層はほぼ見せない。
- **音との合わせ方**: 環境音を落として息・衣擦れ・鼓動だけにすると「逃げ場のなさ」が増す。
- **難易度/適性**: ★(寄り専用の顔パーツを描けば簡単。シルエットのままだと表情が出ない)。
- **AI動画生成プロンプト**: `Choker shot of [Subject] from hairline to chin, almost no background, 85mm, locked head.`

### クローズアップ / Close-Up (CU)  (`framing/close-up`)
- **一言**: 頭と肩の上までを収める、表情を読ませる標準のアップ。
- **物語での役割**: 嘘・決断・ためらいなど、顔に起きた新しい事実を読ませる。肩が少し残るので、人間としての体の感覚は失われない。
- **使う/使わない**: 重要な台詞の瞬間に使う(1シーンに2〜3回)。全部の台詞に使う「壁紙」にはしない。情報が胸より下(手・銃)にある場面にも使わない。
- **よくある失敗**: MCU(胸まで入る)やチョーカー(肩がない)との取り違え。顔のアップなら何でもCUと呼んでしまうこと。
- **似た技法との違い**: チョーカーは肩を切り、MCUは胸から入る。CUは「頭+肩の上」だけ。
- **HyperFramesでの作り方**: 2Dトランスフォーム。クロップ帯 20→275u を画面高の0.92に合わせ `frame(254,147,3.9,.42,.5)`(scale≈3.9、頭頂〜あごが画面高の約65%)。hero は右向きなので、顔の向く右側に余白を取るため x=画面の42%位置に置く(ルックスペース)。背景層は scale 1.0〜1.15 の別層にして、ぼかし `filter:blur(6px)` + 暗転で「浅い被写界深度」を表す。MS→CUのつなぎは scale を3.9へ proxy tween(power2.inOut、0.6〜1.0秒)でプッシュインする。
- **音との合わせ方**: 台詞の直前に環境音を半歩引くと、表情に意識が向く。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Tight close-up of [Subject], head and upper shoulders, 75mm, shallow depth of field.`

### カウボーイショット / Cowboy Shot  (`framing/cowboy-shot`)
- **一言**: 太ももの中ほどから上を収め、ガンベルト高さの手と立ち姿を入れる中間のロング寄りサイズ。
- **物語での役割**: 手が筋の主役になる場面で、顔と脅威・余裕を同時に見せる。立ち方そのものが台詞になる。
- **使う/使わない**: 立ったままの対峙・武器・ぶら下がった手に使う(対決の頭に1回)。足元や歩き方が情報の場面、テーブル越しの会話には使わない。
- **よくある失敗**: 腰で切って(MS)手が消える、足まで入れて全身になる。ベルトだけの切り方や、座ったMSを「カウボーイ」と呼ぶこと。
- **似た技法との違い**: MSは腰で切るのでホルスター線がない。全身は足まで入る。
- **HyperFramesでの作り方**: 2Dトランスフォーム。クロップ帯 20→640u を画面高の0.92に合わせ `frame(254,330,1.60,.42,.5)`(scale≈1.6)。後ろの拳 (156,498) がベルト線なので、画面の下から約35%に来る。下端でマントと脚を切るだけ(clip-path は不要、ステージの `overflow:hidden` で切れる)。緊張を作るときは、手の部分(`.backarm`)だけを GSAP で小さく(±2px、0.4Hz)震わせる。頭を揺らさない。
- **音との合わせ方**: 革・金具の擦れ音を1つだけ入れ、無音の中で「手が動くかも」を作る。
- **難易度/適性**: ★(クロップの数値を合わせるだけ)。
- **AI動画生成プロンプト**: `Cowboy shot of [Subject] framed mid-thigh up, hands visible at the holster line, American shot.`

### カットイン / Cut-ins  (`framing/cut-ins`)
- **一言**: 広い画の中にすでに写っている細部へ、同じ向きのまま寄る。
- **物語での役割**: 広い画では証明できなかった事実(手元・スマホ・傷)を、観客を瞬間移動させずに示す。「新しい情報」ではなく「確認」の感覚になる。
- **使う/使わない**: 広い画に写っていた物に寄る(1つの見せ場に1回)。広い画に存在しなかった物への切り替え(それはインサート)や、別の壁・別の角度に飛ぶことには使わない。
- **よくある失敗**: カメラ位置が変わって別のセットアップに見える(軸がずれる)。広い画に無い物を出す。
- **似た技法との違い**: カットアウェイは場面を離れる。カットインは同じ場所・同じ軸でより近づく。
- **HyperFramesでの作り方**: 2Dトランスフォーム。広い画と同じ1つのシーン要素に対して、`frame()` の中心点を対象物(例: 後ろの拳 (156,498))に変えて scale を 1.0→2.5〜3.5 にするハードカット(`tl.set`)。広い画と寄りは**同じ層・同じ座標**に置くこと(別素材に差し替えない)。滑らかに寄るなら power3.inOut、0.5〜0.8秒の proxy tween。UIの細部に寄るなら `npx hyperframes add ui-focus-zoom` が使える。寄り先の周りを暗くしたいなら `yt-feather-highlight` も使える(`catalog` で存在確認済み)。
- **音との合わせ方**: 寄りの瞬間に環境音を少し下げ、細部の音(紙・氷・スマホの振動)を1つ立てる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Cut-in on a detail of [Subject] already visible in the master shot, tighter on the same axis, showing a fact the wide cannot prove.`

### カットアウェイ / Cutaway  (`framing/cutaway`)
- **一言**: 主な動きをいったん離れ、同じ世界にある別の物・人・景色を見せてから戻る。
- **物語での役割**: 時計・やかん・聞いている人などで関係を足し、緊張を逃がしたり、時間の経過をにおわせたりする。つなぎのごまかしにも使える。
- **使う/使わない**: 議論の最中に時計や窓外を見せるなど、場面に「コメント」を足したいときに1回。手に持つ物(それはインサート)や、あり得ない場所の映像(偽の時間を作る)には使わない。
- **よくある失敗**: 戻ったときに動作が巻き戻る(握手が最初から)。関係のない綺麗な風景を挟むこと。
- **似た技法との違い**: インサートは筋に関わる物へ寄る。カットアウェイは「離れた」と分かる。カットインは同じ場所でさらに寄る。
- **HyperFramesでの作り方**: シーン切替(ハードカット)+短い独立シーン。主要な動きの timeline とは別に 0.8〜1.5秒の小シーン(時計の針・湯気・窓外のSVG)を用意し、`tl.set` で表示を切り替える。**戻るときは、動きを少し進めた位相から再開**する(元の位置に戻さない。主シーンの proxy を t で進め続け、見えない間も時間を進める)。色味・環境光は主シーンと揃える。切替が硬いなら 2〜3フレームのクロスフェード。
- **音との合わせ方**: 環境音と会話の声を切れ目なく流し続けると「同じ時間」にいる感覚が保てる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Cutaway from [Subject] to a related detail in the same world, a clock or a kettle, a pressure-release beat.`

### エスタブリッシングショット / Establishing Shot  (`framing/establishing-shot`)
- **一言**: 場所・時間帯・天気・社会的な背景を最初に宣言するショット。サイズではなく「役目」。
- **物語での役割**: カバレッジ(寄りの連続)に入る前に、観客に「いつ・どこ」を与える。場面が離れたあとの再提示にも使える。
- **使う/使わない**: 場面の頭に1回、または時間が飛んだあとに。毎回入れる、場所の変わっていない場面での繰り返し、場面の中身を演じるマスターの代わりには使わない。
- **よくある失敗**: 次のカットに関係のない風景のポストカード。広いだけで時間帯や位置関係が読めないこと。
- **似た技法との違い**: マスターは場面の動きの骨組み、エスタブリッシングは場所と時間の宣言。
- **HyperFramesでの作り方**: 2Dレイヤー+テキスト。ワイド(キャラ高35〜45%の scale 0.45〜0.58)で、遠景(空)→中景(建物)→近景(地面)の3層を用意し、時間帯は空のグラデと `feColorMatrix` の色味で出す。環境の小さな動き(雲・煙・旗)を、毎フレーム t の sin で 0.3〜0.5Hz に。2.5〜3.5秒保持。場所名を出すなら 左下に小さく(`lt-clean-bar` などの lower third が `catalog` に実在)。ゆっくり引くなら背景だけ scale 1.05→1.0(4秒)。
- **音との合わせ方**: 次の場面の環境音(街・鳥・風)を、映像が出る少し前から流しておくと場所が先に伝わる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Wide establishing shot of [Subject] and the location, time of day and spatial relations declared before coverage begins, small ambient motion.`

### 極端なクローズアップ / Extreme Close-Up (ECU)  (`framing/extreme-close-up`)
- **一言**: 目・口・指先・引き金など、ごく小さな一部だけで画面を埋める。
- **物語での役割**: 「この断片こそが場面」と言い切る。目から目への切り返しで、視線を物理的な対決にもできる。
- **使う/使わない**: 瞳が決意する瞬間のように、細部が出来事の場面に短く(1〜2秒を数回)。普通の会話や、人物全体の演技が必要な場面には使わない。
- **よくある失敗**: 顔がまだ全部見える(チョーカーやCU)、広角のまま寄って鼻が膨らむ。
- **似た技法との違い**: チョーカーは顔全体、ECUは顔の中の一部。インサートは物語上の物で、ECUは大きさ。
- **HyperFramesでの作り方**: 2Dトランスフォーム。hero の目のスリット(帯 148→192u)を `frame(280,170,24,.5,.5)` で画面幅の約半分に。線幅は `vector-effect:non-scaling-stroke`。**寄り専用の目SVG(白目・瞳孔・睫毛)を別に用意して差し替える**ほうが綺麗。瞳の収縮は瞳孔の r を 0.4秒で 30→18(power2.in)、まばたきは scaleY 1→0.05→1(0.14秒)。陰影は周辺を落とす `vignette`、被写界深度は目以外のレイヤーに `blur(8px)`。
- **音との合わせ方**: 音を一点に絞る(金属が鳴る、息を呑む)。他の音は落とす。
- **難易度/適性**: ★★(寄り専用パーツの描き込みが必要)。
- **AI動画生成プロンプト**: `Extreme close-up of [Subject]'s left eye filling the frame, pores and texture, tighter than forehead-to-chin, 100mm.`

### 極端なロングショット / Extreme Long Shot (ELS)  (`framing/extreme-long-shot`)
- **一言**: 人物が点になるほど引き、環境・規模・孤独を主役にする。
- **物語での役割**: 畏怖・無力さ・孤独・野心といった「大きさ」自体が感情になる。小さな人物が尺度になる。
- **使う/使わない**: 規模が感情の場面(荒野を行く馬、巨大な建物の足元)に1回。台詞をカバーする目的や、基準物(人・車)がない画には使わない(ミニチュアに見える)。
- **よくある失敗**: 人が読める全身のまま(それはロング)。奥行きの手がかりがなく、模型のように平らに見える。
- **似た技法との違い**: ロングは全身が人として読める。ELSは「点」。エスタブリッシングは役目で、このサイズをよく使う。
- **HyperFramesでの作り方**: 2Dトランスフォーム+多層。hero を scale 0.035(キャラ高 約30px)で、画面の下から約30%に置く。奥行きは層で作る: 遠景(山・薄い青)、中景、近景(濃い地面)で彩度と明度を変え、手前ほど多く動かす視差(横移動 +40px / +20px / +8px を5秒で)。点の人物が見つかるように、点の近くに小さく動く物(砂塵・足跡)を置く。1〜2秒でも読めるよう、点は周囲より暗く or 明るくする。引く動きなら背景は scale 1.0→0.9、hero は 0.05→0.035 で。
- **音との合わせ方**: 風の音だけ。人物の足音や台詞は入れず、広さを聴かせる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Extreme long shot of [Subject] as a speck against vast terrain, infinite depth of field, landscape as the true subject.`

### 全身ショット / Full Body (WS)  (`framing/full-body`)
- **一言**: 頭から足元までを収め、人物が画面高の大部分を占める。
- **物語での役割**: 衣装・立ち方・歩き方・ドアまでの経路を見せる。人物が主役で、世界は縁取りにとどまる。
- **使う/使わない**: 新しいコートで歩く、戸口に立つなど、体を丸ごと見せたいときに(登場のときに1回)。風景が人物を圧倒する場面や、顔だけが主題の場面には使わない。
- **よくある失敗**: ロング(人物が小さい)やカウボーイ(足がない)との混同。24mm相当で近づきすぎて足が大きくなる。
- **似た技法との違い**: カウボーイは太ももで切る。ロングは人物が世界の中で小さい。全身は人物がまだ大きい。
- **HyperFramesでの作り方**: 2Dトランスフォーム。クロップ帯 34→874u を画面高の0.80に合わせ `frame(254,454,1.03,.5,.5)`(キャラ高 約864px)。頭上と足元に各10%の余白を残す。足元に影の楕円(rx=130u,ry=14u,opacity .35)を置くと床が読めて「全身」と分かる。歩きなら hero の `.legs` を 0.9秒周期でスイング(rotate ±8°)、画面上のx位置は固定し、背景だけを逆方向に流す。
- **音との合わせ方**: 足音(靴の種類で性格が出る)を歩きに同期させる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Full-body shot of [Subject], head to toe, figure complete in frame, environment readable around the silhouette.`

### ジェスチャー / Gesture  (`framing/gesture`)
- **一言**: 手・視線・重心移動など、表現的な体の小さな動きを主題にしてサイズと長さを決める。
- **物語での役割**: 顔でも物でもなく、触れそうで触れない指のような「動作」自体が出来事になる。動きには始まり・頂点・収まりがある。
- **使う/使わない**: 指の動きに筋がある場面に(動きの頂点を含めて1〜2秒)。動かない物の説明(それはインサート)や、動きが見えないほどの広い画には使わない。
- **よくある失敗**: 動かない物を撮ってしまう、広すぎて手がノイズに埋もれる、動作の途中で切る。
- **似た技法との違い**: インサートは「物」が事実。ジェスチャーは「体が何をするか」が主題。
- **HyperFramesでの作り方**: 2Dトランスフォーム+パーツアニメ。動かす部位(hero の `.arm` / `.fistg`)に寄る(クロップ帯 240→560u を画面高0.9に合わせ scale≈2.0)。動きは「予備動作(−10%戻す、0.15秒)→本動作(power3.out、0.35秒)→収まり(0.4秒)」の3段で GSAP に。例: `.armrect` を rotate(−6°→+14°→+10°)。体の元(肩)が見える範囲を残すこと。動きの途中に `yt-feather-highlight` で周りを少し暗くすると視線が集まる。
- **音との合わせ方**: 動きの頂点に小さな布・金属音を1つ。
- **難易度/適性**: ★★(動きの設計が肝)。
- **AI動画生成プロンプト**: `Gesture close on [Subject], the meaning in a hand, a glance or a weight shift, one motion with a settle.`

### グループショット / Group Shot  (`framing/group-shot`)
- **一言**: 家族・乗組員・陪審など、少人数の集団を「関係の単位」として収める。
- **物語での役割**: 誰が座り、誰が立ち、誰が明るく、誰が端にいるかで序列が一目で伝わる。
- **使う/使わない**: 4〜8人のまとまりを見せるとき(場面の頭に1回)。主役が2〜3人の場面や、動きを追う場面にはマスターを使う。全員を同じ明るさで並べるのはやめる。
- **よくある失敗**: 3人しかいない(それはスリーショット)、広すぎて顔が読めない。全員が同じ光で卒業写真になる。
- **似た技法との違い**: スリーショットは主役3人、グループは4人以上。マスターは場面の動き全体を押さえる。
- **HyperFramesでの作り方**: 2Dレイヤー。人物を前景(座り・大きい scale 1.1)/中景(立ち 0.9)/後景(戸口 0.6)の3層に置き、奥ほど暗く・小さく。hero のコピーを使うなら `.cape` の色を変えて個性を出す。光は1人にだけ金のリム(`filter:drop-shadow`)を強く当てて序列を作る。誰かが一歩下がる動き(x を 30px、0.6秒、power2.inOut)だけで序列が入れ替わる。引き気味なので hero の scale は 0.5〜0.9。
- **音との合わせ方**: 全員の息づかいや椅子の音を薄く重ね、1人の声だけ浮かせる。
- **難易度/適性**: ★★(人物素材の数が要る)。
- **AI動画生成プロンプト**: `Group shot containing [Subject] among several figures, ensemble blocking, who owns the frame by position and light.`

### インサートショット / Insert Shot  (`framing/insert`)
- **一言**: 筋に関わる物・手の動作・画面・文字を、実寸の感覚で近くから見せる。
- **物語での役割**: 広い画では証明できない事実(筆跡・掛け金・震えるグラス)を示し、「あとで効く物」を指さす。
- **使う/使わない**: 鍵・手紙・震えるグラスなど、筋に戻ってくる物に(1つの物につき1回)。二度と出ない飾りの物や、商品写真のような艶出しには使わない。
- **よくある失敗**: 別の部屋の時計(それはカットアウェイ)、場面の光と合わない商品写真風のライティング。
- **似た技法との違い**: カットアウェイは場面を離れる。カットインは広い画にすでにあった物。インサートは筋に関わる物を新しく指さす。
- **HyperFramesでの作り方**: 別シーン(ハードカット)。物は SVG で描き、場面の光と同じ向きに影・リムを付ける(金のリム `#ffd34d`、影は同じ方向)。サイズは画面の30〜50%、手を出すなら実寸比を守る(物の幅に対し指が太くなりすぎない)。動きは小さな物理変化を1つ(震え ±1.5px 5Hz、親指がかかる、など)。寄りの導入は 0.3秒の scale 1.15→1.0(power2.out)で「覗き込む」感覚を足せる。UI画面なら `ui-focus-zoom`。
- **音との合わせ方**: 物の接触音(カチ、紙の擦れ)を1つだけ大きく。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Tight close-up of an object that carries the plot near [Subject]: a glass, a letter, a latch. Hands at real scale, matching the room's key light.`

### インタビュー / Interview  (`framing/interview`)
- **一言**: 画面の少し横にいる聞き手に答える、安定したトーキングヘッドの構図。
- **物語での役割**: 観客は聞こえない質問への答えに「同席している」感覚を持つ。視線がレンズに当たると別の契約(直接語りかけ)になる。
- **使う/使わない**: ドキュメンタリーの証言、フェイク・ドキュの告白、ドラマ内の語りカットに。2人のキャラが同じ場面にいるとき(OTSかツーショットを使う)や、うっかりレンズを見たときには使わない。
- **よくある失敗**: サイズが揺れ続けて証言がMVになる、視線がレンズに入ってしまう。
- **似た技法との違い**: MCUはただのクロップ。インタビューは「視線が少し外れ、聞き手が暗に存在する」点が違う。第四の壁は視線がレンズの中心。
- **HyperFramesでの作り方**: 2Dトランスフォーム。MCU〜ゆるいCU(`frame(254,175,2.6,.38,.5)`、scale 2.5〜3.1)で固定。hero は右向きなので、画面の左38%に置いて右に顔1つ分の余白(ルックスペース)を残す。背景は暗めにボケ(blur 8px)+小さな実用光の丸(オレンジ、blur 14px)。**サイズを動かさない**(呼吸のような scale 1.00→1.015 を6秒かけて、が上限)。名前表示は `npx hyperframes add lt-clean-bar`(lower third。`catalog` に実在)。
- **音との合わせ方**: 質問者の声は小さく・遠く(ローパス)、答える声を近く。部屋の音を薄く敷く。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Interview frame of [Subject], talking-head distance, eyeline just off lens, a listener implied, look space on the left.`

### ロングショット / Long Shot (WS)  (`framing/long-shot`)
- **一言**: 全身と、それを取り巻く広い環境を一緒に見せ、人が世界の中で小さく見えるサイズ。
- **物語での役割**: 人を、人がいなくても続く世界の中に位置づける。まだ人として読めるが、場所のほうが優勢。
- **使う/使わない**: 尾根の馬、プラットフォームのコートなど「世界の中の体」に。まぶたを読ませたいとき、頭からつま先のポートレートを撮りたいときには使わない。
- **よくある失敗**: 人が画面高を埋めている(それは全身)、人が点になっている(それはELS)。
- **似た技法との違い**: 全身は人物が大きく地面は縁だけ。ワイドは場所の地図。ELSは点。
- **HyperFramesでの作り方**: 2Dトランスフォーム+背景。hero の scale は 0.26〜0.38(キャラ高 220〜320px、画面高の20〜30%)、画面の下から約35%に足をつける。地面と空を画面の7割にして、地平線を画面の下から40%に。背景は2〜3層に分け、奥の層を scale 1.05 で小さく動かして遠近を出す。人物の動き(歩き)は全身の0.9秒周期、背景のスクロール量は hero の歩幅と合わせて足滑りを避ける。人物が風景に溶けないよう、人物だけにリムの金線を残す。
- **音との合わせ方**: 足音を小さく、環境音(風・遠くの街)を主役に。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Long shot of [Subject] small in a large environment, full figure plus geography, identifiable as a person.`

### マスターショット / Master Shot  (`framing/master-shot`)
- **一言**: 場面の動きと空間配置をひとつの画で最後まで押さえる、骨組みのショット。
- **物語での役割**: 誰がどこに座り、どの経路でドアに行けるかが分かる。寄りがすべて失敗しても場面が成立する保険。
- **使う/使わない**: 会議・パーティーなど、動線が重要な場面に(場面ごとに1つ)。外観の紹介(それはエスタブリッシング)や、誰も使わない空虚な広い画には使わない。
- **よくある失敗**: 重要な扉や小道具が画面外に切れている、広すぎて顔や小物が読めない。
- **似た技法との違い**: エスタブリッシングは場所と時間、マスターは「この場所で何が起きるか」。ワイドはサイズ、マスターは役目。
- **HyperFramesでの作り方**: 2Dトランスフォーム。ワイド(キャラ高 380〜480px、scale 0.45〜0.55)〜ゆるいツーショットで、場面に出る全員・扉・テーブルを1つの層構成に置く。**この1つの構成を、全カットの共通の「ワールド」にする**: 寄りはカメラ(ワールド全体の frame)を動かして切り出すだけにすると、位置関係が絶対にずれない。1本の paused タイムラインで全員の動きを書き、カメラのコンテナに `scale/x/y` を入れる。マスターを画面に出す尺は場面の頭と、要所で再提示する数秒。
- **音との合わせ方**: 部屋の音(room tone)をワールド全体にひとつ流し続け、寄りのカットで声だけ近づける。
- **難易度/適性**: ★★(全員の動線を1つのタイムラインで設計する必要がある)。
- **AI動画生成プロンプト**: `Wide master of [Subject] with all blocking visible, the skeleton of the scene in one continuous frame, coverage can cut in later.`

### ミディアムクローズアップ / Medium Close-Up (MCU)  (`framing/medium-close-up`)
- **一言**: 胸から上を収め、顔と肩、胸の高さの手が読める会話の距離。
- **物語での役割**: 考えが顔に出て、肩のすくめやグラスを持つ手も読める。テーブル会話の標準で、部屋は「地図」ではなく「切り取り」。
- **使う/使わない**: 体の動きを残したい会話(2人のテーブル、片手の空いた電話)に。腰まで必要な手の動き、銃のベルトには使わない。
- **よくある失敗**: CU(体がなくなる)やMS(腰が入る)との取り違え。宙に浮いた首だけの画。
- **似た技法との違い**: CUは頭+肩の上。MSは腰から。MCUはその間(胸から上)。
- **HyperFramesでの作り方**: 2Dトランスフォーム。クロップ帯 20→345u を画面高0.92に合わせ `frame(254,182,3.06,.42,.5)`(scale≈3.1)。胸骨で下を切る。手が上がる動き(`.arm` を y −40u)があれば入るので、手前の小物(グラス)を前景層に置く。背景は肩の後ろに細い帯だけ見せる(blur 6px)。会話の相手が切り返しで来る場合、相手は mirror(`scaleX:-s`、x に +520·s)で反対向き。同じ scale・同じ高さに合わせる。
- **音との合わせ方**: 台詞中は部屋の音を-6dB、手の動き(グラス・布)を小さく立てる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Medium close-up of [Subject] from chest up, dialogue distance, shoulders and hands still readable, 65-75mm.`

### ミディアムショット / Medium Shot (MS)  (`framing/medium-shot`)
- **一言**: 腰から上を収め、顔と手の動きのバランスをとる、カバレッジの主力サイズ。
- **物語での役割**: 人は手で話すので、グラス・電話・ノートが腰と顔の間で動く。背景も少し(窓・ブース)残り、場所の感覚が失われない。
- **使う/使わない**: 重なる会話、ブースでの対話、スーツケースの取っ手を持つ待ち姿に。歩き・全身の衣装・顔だけを見せたい場面には使わない。ずっとこのサイズだとラジオ劇になるので、情報が変わったら寄る/引く。
- **よくある失敗**: カウボーイ(膝や太ももが入る)やMCU(ベルトがない)との取り違え。何でも会話はMSにする。
- **似た技法との違い**: MCUは胸から。カウボーイは太ももで切るので手が入る。MSは「腰」。
- **HyperFramesでの作り方**: 2Dトランスフォーム。クロップ帯 20→550u を画面高0.92に合わせ `frame(254,285,1.87,.42,.5)`(scale≈1.87)。ベルト(y 520〜546u)が画面下端ぎりぎり。背景は2層(奥の窓・手前の家具)で、カメラ移動時に奥を 0.5倍、手前を 1.0倍動かして視差を出す。寄り/引きを足す場合は scale 1.87→3.06(MCU)を power2.inOut 0.8秒で。
- **音との合わせ方**: 台詞と小物の音(カップ・紙)を同期させて、手の存在感を出す。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Medium shot of [Subject] from the waist up, conversational distance, 50mm, gesture and face in balance.`

### オーバー・ザ・ショルダー / Over-the-Shoulder Coverage (OTS)  (`framing/over-the-shoulder-frame`)
- **一言**: 手前に相手の肩や頭の一部を置き、奥の顔にピントを合わせる会話の切り返し構図。
- **物語での役割**: 近い画でも相手が物理的にそこにいる感覚(空間の接着)が残る。肩の大きさ・遮り方で、見る側が支配的にも、親密にも、閉じ込められているようにも見える。
- **使う/使わない**: 食堂・尋問・ガラス越しのインタビューなど、関係を画に残す会話の標準に。相手を消して孤立させたい場面(クリーンなシングル)や、両方の顔を等しく見せたい場面(ツーショット)には使わない。
- **よくある失敗**: 180度ラインを越えて、奥の人物がレンズを見たり、切り返しで同じ向きを向く。両方の顔が同じ鮮明さになる。
- **似た技法との違い**: ツーショットは2人とも主役。シングルは手前の肩がない。OTSは「手前は断片、奥が主役」。
- **HyperFramesでの作り方**: 2Dレイヤー合成。手前のキャラ(hero)を scale 3.4 で画面左端に置き、肩〜後頭部だけを見せる(`frame(300,230,3.4,0.04,0.78)`)。`filter:blur(10px) brightness(.6)` で「ボケた暗い肩」にする。奥のキャラは `scaleX:-s` の鏡像(左向き)で scale 2.2(MCUより少し引き)、画面の右寄り62%に置いてシャープに。**切り返しでは役割を入れ替える**: 手前=相手(右側、鏡像)、奥=最初の人(左側、元の向き=右向き)。必ず「左の人は右向き、右の人は左向き」を保ち、ラインを越えない。フォーカスの移し替えは `npx hyperframes add rack-focus` / `focus-rack` が使える。
- **音との合わせ方**: 手前の人の声は少し小さく・こもらせ、奥の人の声を前に出す。
- **難易度/適性**: ★★(切り返しの向きと scale を揃える設計が要る)。
- **AI動画生成プロンプト**: `Over-the-shoulder framing of [Subject], near shoulder soft in foreground, far face sharp looking toward the near shoulder, 180-line held.`

### プロダクトショット / Product  (`framing/product`)
- **一言**: 物を、ポートレートのように照明し、ヒーローの角度で撮る商品映像。
- **物語での役割**: ロゴの面・材質・エッジ・金属やガラスの反射を読ませ、物自体を主役にする。背景は消える。
- **使う/使わない**: 商品、時計、瓶を台座に置いて見せるとき(1つの物に3〜5秒)。筋の中の小道具(散らかった部屋の血のついた手紙など。それはインサート)には使わない。
- **よくある失敗**: 背景に部屋の雑然とした物が残る、反射が制御されていない、速く回しすぎて形が見えない。
- **似た技法との違い**: インサートは部屋の光に合わせる筋の物。プロダクトは物がそのものとして主役で、反射も設計する。
- **HyperFramesでの作り方**: 2Dレイヤー+CSS/SVGグラデ。背景は黒または白の無地(`radial-gradient` で床の反射を足す)。物はヒーローの3/4角度の SVG か `rotateY(−25deg) rotateX(8deg)` の平板(perspective 1200px)で置き、ハイライトは大きな面光源=細長い白の `linear-gradient` を物の上で `background-position` を動かして通過させる(2秒、power1.inOut)。床には反転コピー(`scaleY(-1)`、opacity .25、グラデの mask)。回して見せるなら Three.js で1周 6秒、イージングは linear か sine.inOut。
- **音との合わせ方**: 静かな低音+物が置かれる/光る瞬間の1音。
- **難易度/適性**: ★★(質感の作り込みに時間がかかる。3Dモデルがあれば簡単)。
- **AI動画生成プロンプト**: `Product hero of [Subject], catalog clarity, controlled reflections, black sweep background, the object as the only subject.`

### リアクションショット / Reaction Shot  (`framing/reaction-shot`)
- **一言**: 出来事・台詞・見えない刺激を受けた人物の反応を見せる。サイズではなく役目。
- **物語での役割**: 銃声や侮辱が何を意味したかを、それを受け取った顔から知る。前後のカットの組み合わせで意味が生まれる(クレショフ効果)。
- **使う/使わない**: 重要なのは「見ていること」の場面に(ひとつの出来事に1回)。毎文節のあとに挟む、感情を大げさに演技させて観客に答えを教えることには使わない。
- **よくある失敗**: 話している人のCUで終わる、眉で説明しすぎる。
- **似た技法との違い**: CUは大きさ、リアクションは「なぜその顔を見せるか」。カットアウェイは物でも可、リアクションは人の反応。
- **HyperFramesでの作り方**: 2Dトランスフォーム。CU〜MCU(scale 3.0〜3.9)で、視線の向きは出来事の来る方向に(右向きの hero なら右側に余白)。動きは**小さく**: まばたき(scaleY 1→0.08→1、0.14秒)、息(胸の y +3px、1.2秒)、喉(.head の y +2px)のいずれか1つだけ。前のカットの音(銃声)が鳴ってから0.3〜0.6秒の「間」を置いて動かす。見せる尺は 1.5〜2.5秒。前のカットとの意味の接続は、タイムライン上で音のタイミングを共通のラベルにして管理する。
- **音との合わせ方**: 出来事の音を先行させ、顔に切り替わった瞬間に音を一段落とす(耳鳴り・沈黙)。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Reaction close-up of [Subject] receiving news they cannot speak yet, the face as the cut, eyeline offscreen.`

### シングル / Single  (`framing/single`)
- **一言**: 主要人物1人だけを収めるカバレッジ。他の人物は画面外か、端にかすかに入る程度。
- **物語での役割**: 会話中に人を孤立させ、聞き手に私的な瞬間を与える。タイミングによっては、相手が消えたような感覚を作る。
- **使う/使わない**: 相手が部屋にいても孤立させたい瞬間に。最初から全部を単独で撮ると卓球になる。関係を見せたいときはOTSやツーショットを使う。
- **よくある失敗**: 手前の肩が構図として入っている(それはOTS)。ワンカット長回し(ワンテイク)と混同すること。
- **似た技法との違い**: OTSは手前の肩が構図要素。ツーショットは2人。シングルは「1人だけが占有」。
- **HyperFramesでの作り方**: 2Dトランスフォーム。hero を MCU〜CU(scale 3.0〜3.9)で、**画面端に相手の要素を置かない**(クリーン)。ダーティなら画面端 20〜40px に相手の暗い塊(blur 20px)だけを置く。相手の向いている方向に顔を向け、余白を画面の向きの側に取る。背景は同じ部屋の同じ色味で、切り返しと明るさ・高さ・scale をそろえる(同じ frame の値を使う)。
- **音との合わせ方**: 相手の声はオフ(画面外)で小さく残すと、「同じ部屋にいる」感覚が保たれる。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Clean single of [Subject], one person, no foreground shoulder, the frame belonging entirely to them.`

### スリーショット / Three-Shot  (`framing/three-shot`)
- **一言**: 3人の主要人物を1つの画に収め、同盟と「はみ出した1人」を配置で読ませる。
- **物語での役割**: 三者には力関係が生まれる(2対1、中間の人、途中参加)。単独カットの切り返しだと、誰が取り残されているかが見えない。
- **使う/使わない**: 3人の銃・評決・「いてはいけない人」がいる場面に(場面に1〜2回)。4人以上(それはグループ)や、2人に絞られた場面には使わない。
- **よくある失敗**: 同じ高さ・同じ光で3人を並べて警察の面通しのようになる。ツーショットに1人が切れている。
- **似た技法との違い**: ツーショットは2人、グループは4人以上。スリーショットは3人の三角形。
- **HyperFramesでの作り方**: 2Dレイヤー。3人を三角形に配置(例: 左 x=28%・手前 scale 0.9 / 右 x=70%・手前 scale 0.9 / 中央奥 x=50%・scale 0.7)。1人を「はみ出し」にして、他の2人から 15%離す、または高さを変える。光は主役の1人にだけ強いリムを。誰かが一歩下がる(x −40px、0.6秒、power2.inOut)だけで力関係が変わる。2人を鏡像(`scaleX:-s`)で向き合わせ、残る1人は正面に近い向きにする。
- **音との合わせ方**: 3人の声をL/C/Rに少しパンさせると、配置が耳でも分かる。
- **難易度/適性**: ★★(人物素材が3つ必要)。
- **AI動画生成プロンプト**: `Three-shot of [Subject] in a triangular group, alliances and the odd one out readable in blocking.`

### ツーショット / Two-Shot  (`framing/two-shot`)
- **一言**: 2人の主要人物を1つの画に収め、距離や姿勢を比べられるようにする。
- **物語での役割**: 関係そのものがショットになる。単独に切る前に、2人の間の距離・のけぞり・広がる隙間を、編集なしで見せられる。
- **使う/使わない**: 食堂のテーブルや歩きながらの会話、共有する沈黙に。1人を孤立させたいとき、3人目が政治的に場にいるときには使わない。広すぎて演技が見えないのもだめ。
- **よくある失敗**: OTS(1人+肩)や、2つのシングルをつなげただけ。2人が小さすぎて関係が読めない。
- **似た技法との違い**: OTSは手前が肩。ツーショットは両者が画の主役。スリーショットは3人。
- **HyperFramesでの作り方**: 2Dレイヤー。左に hero(右向き)、右に鏡像(`{x:X+520*s, scaleX:-s, scaleY:s}`、左向き)を、同じ scale(0.9〜1.4、MS〜カウボーイ寄り)・同じ足元の高さに置く。2人の間隔(例: 画面幅の30%)が演技になる: 距離を power2.inOut で ±8%、2秒かけて変えるだけで「近づく/遠ざかる」が見える。層違い(片方が手前 scale 1.2、奥が 0.9)にすると序列が出る。背景は両者の後ろ全体を覆う1枚。
- **音との合わせ方**: 声を左右にパンし、距離が変わるとき、足音や衣擦れで裏付ける。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Two-shot of [Subject] with a second figure, the space between them doing narrative work, 50mm, shared frame.`

### ビデオポートレート / Video Portraits  (`framing/video-portraits`)
- **一言**: 動かさず、長く、1人の顔を「ほとんど静止しているが生きている」状態で見せる。
- **物語での役割**: 長さそのものが親密さになる。まばたき・呼吸・喉の動きが内容になる。動く絵画のような感覚。
- **使う/使わない**: 顔ひとつで足りるとき(スクリーンテスト、肖像)に、数秒〜十数秒。台詞のカバレッジ(切り返しが必要)や、カメラの移動のあるツアーには使わない。思いついたところで切らない。
- **よくある失敗**: 完全な静止画(死んだ写真)や、1つの要素だけがループする(それはシネマグラフ)。カメラが動く。
- **似た技法との違い**: CUは使ったら切る。シネマグラフは1つの要素以外が凍る。ビデオポートレートは「人物が小さく生きている」。
- **HyperFramesでの作り方**: 2Dトランスフォーム。CU〜MCU(scale 3.0〜3.9)で固定し、時刻 t の純関数で「微小な生命」を重ねる: 呼吸(胸と肩の y を `sin(2π·t/4.5)·3px`)、まばたき(3〜6秒の間隔で scaleY 1→0.08→1、0.14秒。間隔は seed 付き PRNG)、頭の揺れ(rotate `sin(t·0.7)·0.3°`)。光は固定の1灯(リム)。ゆっくり寄るなら `npx hyperframes add push-in`(`catalog` に実在。極めて遅く、10秒で scale 1.0→1.04)。10秒以上保持し、字幕・BGMで説明を足さない。
- **音との合わせ方**: 部屋の音と息だけ、音楽は入れないか極小に。
- **難易度/適性**: ★(動かさない勇気が要る)。
- **AI動画生成プロンプト**: `A long held portrait of [Subject], tiny life in the face, almost still, locked camera, no camera travel.`

### ワイドショット / Wide Shot (WS)  (`framing/wide-shot`)
- **一言**: 人物が小さく、場所が語り続ける、環境を前面に出すカバレッジ。
- **物語での役割**: 誰が扉に行けるか、道がどこへ続くか、天気が何をしているかの地図になる。早く孤立させると地図を失う。
- **使う/使わない**: まだ孤立させたくないとき(扉まで届くか、2組が互いに見えるか)に。顔・ホルスター・頭からつま先の衣装を見せたい場面には使わない。
- **よくある失敗**: 全身ポートレートをワイドと呼ぶ、場面の動線と関係ない空のポストカード。
- **似た技法との違い**: 全身は人物が大きい。ロングは人+地理。ELSは点。エスタブリッシングは場所と時間の役目。
- **HyperFramesでの作り方**: 2Dトランスフォーム+背景多層。hero を scale 0.45〜0.58(キャラ高 380〜480px)にして、扉・道・窓など動線に関わる要素を画面の中に残す。背景は3層(奥:空と遠景/中:建物/手前:地面)で、カメラ移動時の視差は 0.3倍/0.6倍/1.0倍。小さな動き(人物の歩き、遠くの煙)を入れて、静止画にしない。場面のマスターとしても使えるよう、扉の位置は固定座標でシーン共通にする。
- **音との合わせ方**: 環境音を厚く、人物の声は小さく遠く(リバーブ多め)。
- **難易度/適性**: ★。
- **AI動画生成プロンプト**: `Wide shot of [Subject] in full environment, bodies small enough that place still speaks.`

## 第1部 組み合わせ例

1. **登場から対決まで(ワイド→全身→カウボーイ→CU→ECU)**: 荒野の町の入口に主人公が現れる場面。ワイド(scale 0.5、場所を見せる)→ 全身(scale 1.03、歩き)→ カウボーイ(scale 1.6、後ろの拳をベルトの高さに)→ CU(scale 3.9)→ ECU(目のスリット scale 24)。「場所 → 体 → 手 → 顔 → 目」と、情報の単位を絞りながら寄る。全てハードカット、各カットは最長2秒。最後のECUだけ0.4秒のプッシュイン。
2. **食堂の会話(マスター → OTS切り返し → リアクション)**: マスター(scale 0.5、2人と扉)で位置を見せ、OTSで切り返し(手前の肩 blur 10px、奥の顔シャープ)、重要な台詞で相手のリアクションCU(scale 3.9、音は無音+息)。向きは「左は右向き・右は左向き」を終始守る。
3. **小道具の見せ場(MS → カットイン → インサート)**: MSで人物が手紙を持つ。同じ層で手元にカットイン(scale 1.87→3.5)。次に、筋に関わる文字を読ませるインサート(別シーン、物の影は場面と同じ向き)。最後にMSに戻し、手の震え(±1.5px)を足す。カットインで「確認」、インサートで「新しい事実」と使い分ける。
4. **孤独の演出(ELS → ロング → ビデオポートレート)**: ELSで荒野を行く点(scale 0.035)、ロングに寄り(scale 0.3)、最後に動かないビデオポートレート(CU、10秒)。「世界の大きさ → 人 → 顔」と寄り、最後は何も足さず保持する。ELSは音を風だけに。
5. **三者の力関係(スリーショット → シングルで孤立 → ツーショット)**: スリーショットで全員の位置関係を見せ、1人だけを孤立させるシングルで「取り残される」を作り、残り2人のツーショットで同盟を示す。人物は同じ層配置のまま、カメラ(ワールド全体の frame)だけを動かして切り出す。
