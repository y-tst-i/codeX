# 質感と奥行き(のっぺり対策)

ベタ塗りの Canvas 2D が「安っぽい・平ら」に見えるときに読む。部品は `tools/assets/depth.js`(`DEPTH`)。
どれも時刻 t の純関数で、乱数は seed 付き。並列書き出しでも同じ絵になる(1 worker と 3 workers の PNG が一致することを確認済み)。

## 1. のっぺりに見える原因
| 原因 | 見え方 | 効く手 |
|---|---|---|
| 面が1色 | 切り紙を貼っただけに見える | 擬似法線の陰、光の帯、縦グラデ |
| 物が浮いている | 床と物の関係が分からない | 接地影、床への映り込み |
| 背景が均一 | 空間の広さが出ない | スポット背景、周辺減光 |
| 層が同じ色・同じ速さ | 書き割りが1枚に潰れる | 空気遠近、視差 1:3:9、層の落ち影 |
| 画面がデジタルに平滑 | CG くささ、バンディング | 粒(紙・フィルム) |
| 光が止まっている | 静止画を動かしているだけに見える | 光そのものをゆっくり動かす |

## 2. 効く手法と数値
- **粒**: 画素の約1%(1080p で約2.5万点)、1〜2.4px、濃さ α0.03〜0.08、白と黒を半々。模様は 12回/秒だけ入れ替える(毎コマだとうるさい)。最前面に置く。手描き・切り絵・紙の絵柄ではほぼ必須。ピクセル絵・ベクター調では入れない。
- **周辺減光**: 中心から 45% までは素通し、外へ s^2.2 で濃く。黒なら 0.35〜0.6。夕景・紙は暖色(例 `#3c1400`)にする。
- **スポット背景**: 放射の中心を画面の上寄り(高さの 30〜40%)に置くと「撮影台」になる。床は別の縦グラデ(奥を明るく)。
- **接地影**: 芯(濃く小さい)と裾(薄く広い)の2重の楕円。縦は幅の 0.17 倍。床から離れるほど小さく・薄く(浮いた高さが幅の半分のとき、濃さ約 1/4・大きさ約 0.8 倍)。
- **床への映り込み**: 上下反転して α0.16〜0.2、200〜260px で消える(消え方は (1−s)²)。本体より先に描く。
- **球の陰**: 円内の位置から法線 (nx, ny, √(1−nx²−ny²)) を作り、光との内積で 暗→地→明 を混ぜる。**陰は黒を混ぜず、同系色を暗くして少し青へ**、明るい側は暖かい白を 40% 混ぜる。境目を柔らかくする wrap 0.3、縁の照り返し(リム)0.35、鏡面の点 0.35。トゥーンは2〜3段に量子化。
- **空気遠近**: 遠い層ほど彩度を落とし、空の色へ寄せる。式は `c' = mix( mix(c, 灰(c), 0.5·d), 空, 0.7·d^1.2 )`(d=0 手前〜1 最も遠い)。遠景は少しぼかしてもよい(最大 2〜4px)。
- **視差**: 遠景:中景:近景 = 1:3:9。近景だけカメラと同じだけ動かす。揺れ幅も手前ほど大きく。
- **光を動かす**: 帯の位置を範囲 0.15〜0.85 の間で sin でゆっくり往復(0.5〜1 rad/秒)。缶・ガラス・窓光・ステンドグラスなど「光の当たり方が変わる」と止まった物が生きる。
- **紙の層の厚み**: 層ごとに落ち影(ぼかし 10〜14px、下へ 3〜5px、色は黒でなく濃い紺 α0.35 前後)。層の中の図形同士で影が重ならないよう、1枚にまとめてから影を付ける。
- **光の原則**(lemo-opuscar の考え方): 明るい環境光で全体を照らすより、柔らかい主光+弱い環境光+後ろからの冷たいリムのほうが本物らしい。カメラと光は毎フレーム滑らかに動かし、キャラはコマ打ち(12fps)でもよい。

## 3. 部品の使い方
埋め込み: `scene-lib.js` の後に `depth.js` を連結する(depth.js の先頭コメント参照)。重ねる順は 奥→手前:
`spot/floor → 遠景(hazeLayer・paperLayer) → reflection → contactShadow → 主役 → lightSweep → DEPTH.vignette → grain`

| 関数 | 一言 |
|---|---|
| `grain(ctx, t, {density, alpha, size, seed, fps})` | 紙・フィルムの粒。fps 回/秒で入れ替え(キャッシュあり) |
| `vignette(ctx, a, {color, inner, power})` | 非線形・楕円の周辺減光。色指定可。`DEPTH.vignette` と書く |
| `spot(ctx, x, y, r, color, a, {base})` / `floor(ctx, y, top, bottom)` | スポット背景 / 床の縦グラデ |
| `contactShadow(ctx, x, y, w, {alpha, lift})` | 2重楕円の接地影。lift で縮む |
| `reflection(ctx, drawFn, groundY, {alpha, fade, blur})` | 床への映り込み |
| `shadeSphere(ctx, x, y, r, base, {light, rim, steps, squash})` | 擬似法線で陰を付けた球 |
| `hazeColor(c, d, sky)` / `hazeLayer(ctx, drawFn, d, sky, {blur})` | 空気遠近(色だけ / 層ごと) |
| `parallaxLayers(cam, [1,3,9])` | 層ごとのずれ [[dx,dy],…] |
| `lightSweep(ctx, t, {clip, x,y,w,h, speed, alpha})` | 動く光の帯。戻り値 u を `cylinderFill` に渡すと照りが揃う |
| `cylinderFill(ctx, x0, x1, base, u)` | 缶・柱の横グラデ(金属感) |
| `paperLayer(ctx, drawFn, {shadowBlur, dy})` | 切り絵の層の厚み |
| `icosphere(level, {seed, jitter})` / `drawMesh(ctx, mesh, {...})` | 簡易3D(下の節) |
| `rgb / mix / css / darkOf / brightOf / ramp` | 色の道具 |

```js
const D = DEPTH, GROUND = 800;
function draw(t) {
  D.spot(ctx, 960, 380, 900, "#8fa3d8", 0.5, { base: "#1d2236" });
  const off = D.parallaxLayers(t * 140);   // [[遠],[中],[近]]。far/mid/near は自分で用意する層
  [far, mid, near].forEach((L, i) => D.paperLayer(ctx, (g) =>
    D.hazeLayer(g, (g2) => L.draw(g2, off[i][0]), L.depth, "#8fa3d8", { amount: 0.55 })));
  D.floor(ctx, GROUND, "#3b3f55", "#14151d");
  const p = (t * 1.3) % 1, lift = 4 * p * (1 - p) * 240, y = GROUND - 110 - lift;  // 跳ねる球
  D.reflection(ctx, (g) => D.shadeSphere(g, 660, y, 110, "#e0643c"), GROUND, { alpha: 0.18, fade: 200 });
  D.contactShadow(ctx, 660, GROUND, 230, { lift, alpha: 0.5 });
  D.shadeSphere(ctx, 660, y, 110, "#e0643c", { light: [-0.5, -0.65], rim: 0.35 });
  D.lightSweep(ctx, t, { clip: (g) => g.arc(660, y, 110, 0, 7), x: 550, y: y - 110, w: 220, h: 220, alpha: 0.25 });
  D.vignette(ctx, 0.5);
  D.grain(ctx, t);
}
```
- `drawFn` を受け取る関数(reflection / hazeLayer / paperLayer)は、内部の作業キャンバスに描いてから重ねる。drawFn は渡された `g` に、本体と同じ座標で描く。
- `shadeSphere` は (半径・色・光) ごとに1回だけ画素計算する。半径を毎コマ変えると毎コマ計算になる(半径に比例して重くなるので、大きな球は半径を固定し scale で動かす)。潰れは `squash` で。
- 1080p・1秒(30コマ)の比較場面(左: 部品なし / 右: 全部入り)で書き出し約9秒(ソフトウェアGL)。

## 4. 簡易3D(Three.js なしで立体を出す)
`icosphere(level)` + `drawMesh` の要点:
1. 正二十面体(12頂点・20面)を1回細分して 80面。頂点を球面へ戻し、半径を seed 付きで ±12% 乱すと「石・惑星・宝石」になる。縦を 0.9 倍前後に潰すと落ち着く。**面が少ないほど作品らしい**(level 0〜1 推奨、2 は丸すぎる)。
2. Y 軸→X 軸の順に回す(X は 0.3〜0.45 で少し見下ろす)。
3. 面法線を外積で出し、重心と同じ向きにそろえる。**画面の奥を向いた面(n.z ≤ 0)は描かない**。
4. 重心の z で並べて奥から塗る(画家のアルゴリズム)。
5. 面の明るさ = 環境 0.12 + 光との内積。色は 暗→地→明 の3点ランプ(黒を混ぜない)。
6. 面と同じ色で 0.7〜1px の線を引き、面の継ぎ目のすき間を消す。
7. 接地影と映り込みを足すと「置いてある」物になる。光の向き `light` をゆっくり回すとさらに生きる。
凹んだ形・面の交差がある形は画家のアルゴリズムでは破綻する。その場合は Three.js(`hyperframes-animation` の Three.js アダプタ)へ。

## 5. 限界(後処理では作れない物)
- **本当の被写界深度・回り込む陰(AO)・映り込み**: 2D の層ぼかし・接地影は「それらしく」まで。物の形に沿ったボケや隙間の暗がりは Three.js(DoF・GTAO)の領分。ただしソフトウェアGLでは非常に重い。
- **屈折・布・液体・写真に近い 3D**: Blender など専用の道具で作って素材として使う。
- **本物の水彩・粘土・紙の繊維**: 実物を撮って合成するほうが早い。粒と multiply 合成は「気配」まで。
- **写実の人物・表情・手**: シルエット・線画・切り絵にするか、撮影素材を使う。
- **ffmpeg の後処理で足せるのは画面全体に一様な物だけ**(粒・色補正・周辺減光)。接地影・映り込み・陰・空気遠近は物の位置を知っている描画側でしか付けられない。粒を後処理(`noise`)で足すと圧縮は効きやすいが、粒の濃さを場面ごとに変えられない。
