# 見た目の型(スタイル)索引

43 個のスタイル。原文は `lemo/<slug>.md`(英語、lemo-opuscar より MIT で同梱。README.md 参照)。
この索引は私たちの要約で、原文の訳ではない。

## 使い方

1. 場面カードの「絵柄」欄に **スタイルのスラッグを1つ** 書く(例: `絵柄: risograph`)。迷ったら下の表から選ぶ。
2. 担当には、そのスタイルの **「不変の要素」だけ** を読ませる:
   `python3 tools/style.py risograph` → 原文 §1〜§9(本質・素材と描き方・色・文字・動き・カメラ・音・得意技・落とし穴)を表示。
   - 原文に「不変の要素」という見出しは無い。原文のテンプレートでは「このファイルはそのスタイルの全作品に共通する物だけ」と定めており、
     §1〜§9 がそれに当たる。§10(Engine: 手元に無い `demo/*.js` の説明)と §11(作品ごとに変える幅)は既定では出さない。
     全文は `style.py -a <slug>`。
3. **1スタイルずつ**。43 個を全部読ませない(1個 約12KB ≒ 3千トークン。全部で 50 万字超)。
   混ぜたい時も「主スタイル1つ+借りる技法を1行」で書く。
4. 探す: `style.py -s 紙`、`style.py -s horror`(この索引と原文冒頭を検索)。一覧: `style.py -l`。
5. 原文の参考作品名は「文法の参考」。作品内で名前を出さない・写さない。LemoLab の署名・商標も入れない。

難易度欄: **Canvas2D** = 2D だけで可 / **+WebGL2** = 2D で描いて最後にシェーダで合成・後処理 / **three.js** = 3D 必須。
three.js は `tools/fetch_three.sh` で取得、後処理は `tools/assets/three/post.js`。のっぺり対策の一般論は `references/depth-and-texture.md`。

## のっぺり感を避けるのに特に効く上位10(質感の型)

光・素材・紙の物理を「描き方の規則」として持っているもの。迷ったらここから。

| 順 | スラッグ | 効く理由(盗むべき技法) |
|---|---|---|
| 1 | `glass-product` | 環境を「帯状の発光面」で作り、透明物の輪郭を光で描く。分散・コースティクス・床の映り込み。黒背景でも立体が出る |
| 2 | `brick-toy` | クリアコート+指紋/傷のラフネス、面取りのハイライト、接触影、ソフトボックス3灯、浅い被写界深度。「本物の机の上の物」に見せる型 |
| 3 | `paper-lantern` | 層ごとに上縁の光・下縁の暗帯、奥ほど明るく冷たく、層間の柔らかい影。2D の紙を数枚重ねるだけで奥行きが出る |
| 4 | `stained-glass` | 「逆光×透過率×素材」の1つの式で全要素を照らす。床に落ちる色光、光の筋とほこり |
| 5 | `shadow-puppet` | 透過光の乗算(重なりは暗く、穴は最も明るい)、ランプの揺らぎ、布目。2D で光の物理が出せる |
| 6 | `impasto` | 高さ場に斜光(レイキングライト)。ストロークごとの稜線・めくれ。明度設計を先にやる規律も有用 |
| 7 | `paper-popup` | 実寸+HDRI+マクロ DoF+厚紙の縁。2D の切り絵を 3D 空間で「物」にする |
| 8 | `hd-2d` | 平面スプライトが光を受けて影を落とす、霧・光の筋・ブルーム・ボケ帯。平らな絵に空気を足す型 |
| 9 | `crayon-book` | 紙目への付着(凹みに色が入らない)と最後のエンボス。紙の歯がワールドに固定され、寄っても嘘にならない |
| 10 | `risograph` | 1版=1チャンネルで描いてシェーダで「刷る」。重ね刷りの第3色、網点・粒・版ずれのドリフト。印刷物の質感の基本形 |

次点: `ink-wash`(にじみ・飛白)、`engraving`(線だけで階調)、`woodcut`(彫って現す)、`lowpoly-island`(光で時間を語る+AO)、`cel-anime-80s`(透過光とハレーション)、`halftone-dossier`(網点の乗算と紙)。
逆に **意図的にフラット** なもの: `game-show` `swiss-motion` `pictogram-motion` `dark-keynote` `one-line`(質感でなく構成・リズムで見せる。のっぺり対策には使わない)。
