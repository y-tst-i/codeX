# 音のパレット(効果音・BGMの幅を出すための早見表)

**考え方**: コードで作った音を禁止するのではなく、**目立つ形で多用しない**。特に「純音(サイン波)の単発ピン」「サイン波のスイープ(ピューン)」は、AIが作った動画の定番の音として視聴者に見抜かれる。
使うなら (1) 1本に最大2回まで (2) 必ず実音・雑音とレイヤーする (3) 同じ音を別の場面で使い回さない。

## 目的 → 避ける作り方 → 代わりに使うもの
| 目的 | 避ける(定番すぎ) | 代わり(無料で出せる) |
|---|---|---|
| 場面転換の風切り | サイン波スイープ(ピューン) | ピンクノイズを帯域で動かした通過音(`whoosh_pass`)、リバースシンバル(GM 119)、同梱 whoosh サンプルを重ねる |
| 雫・水滴 | 2kHz前後の純音ピン | カリンバ(GM 108)の弱い実音、ミュート弦、水の粒のノイズ(帯域を絞った短いバースト) |
| きらめき・光が差す | 高い鐘/ping/sparkle を単発 | ハープのグリッサンド(GM 46)、合唱の膨らみ(GM 52)、弦のハーモニクス。音を「出す」より和音を「開く」 |
| UI・クリック・ハンコ | サイン波クリック | サイドスティック/ウッドブロック(GM ドラム 37/76)、マリンバ(GM 12)、ノイズの短いタップ |
| 衝撃・ヒット | サイン波キックだけ | ドラムキット(GM) + オケヒット(GM 55) + ブラス(GM 61) + クラッシュの重ね。スロー区間は音を**抜く** |
| ネオン・機械のうなり | 単一周波数のサイン波 | 倍音(120/240/360Hz...)を重ねてゆらがせたブーン + 細かいノイズ(`neon_buzz`) |
| 雨・風・環境音 | 白色ノイズ(全域シャー) | ピンクノイズを帯域で絞る + 水滴の粒。**場面ごとに明るさと粒の粗さを変える** |
| 足音・動き | 同じ足音の繰り返し | 速度・強さ・左右を少しずつ変える(ランダム seed) |
| 余韻・夜明け | 長いリバーブをかけた単音 | 広い響きのピアノ/弦/合唱 + 鳥(GM 123)など実音の環境 |
| BGM | サイン波パッドだけ | GM 楽器の MIDI(ピアノ/弦/ブラス/太鼓/ドラム/ハープ/フルート/エレピ/ビブラフォン)、場面ごとに系統を変える |

## 幅を出すための決めごと
1. **音の設計書**に場面ごとの「楽器の系統・空間(残響の長さと暗さ)・帯域」を書く。隣り合う場面で楽器の系統を被らせない。
2. 1本の動画で**使う楽器・音色の種類の目標**: 15秒で8種類以上、30秒で12種類以上(同じ音色の使い回しはカウントしない)。
3. 合成音の割合は全体の**3割以下**を目安(足音・環境音・低域のうなりなど、実音の代わりが効かない所に限る)。
4. 仕上げの確認は数値で: 場面ごとのスペクトル重心・高域比・RMS、スペクトログラム。全部同じなら質感が同じ。最終判断は人の耳(Claudeは聴けない)。
5. 道具: `tools/midi_render.py`(無料の楽器音源)、`tools/audio_instruments.py`(合成。ping/sine_sweep は上記の制限つきで使う)。
