## 1. 概要
| 項目 | 内容 |
|---|---|
| 題材 | 架空のゲーム『LUMIWAKE(ルミウェイク)』。浮遊島の夜空を、光の気流に乗って荷物(灯り)を届ける配達人のアクション |
| 遊びの核(1文) | 琥珀の「光の気流」に乗って加速し、嵐の稲妻と乱気流をぎりぎりでかわして、島へ灯りを届ける(届けると島が点灯する) |
| 主役 | **灯りの精**(光を運ぶ小さな配達役。人型ではない)。炎のしずくの体に、光のリボンの尾、朱の房、青緑の葉の羽、吊り下げた小包。作りは `src/lib/spirit.js`(案P「ともしび」を推薦、案Q「提灯ちゃん」は不採用の候補)。人型のミオ(`courier2.js`)は、ユーザーの判断で廃止(比較用に残す) |
| 尺・画面 | 30秒 = 900コマ、1920×1080、30fps、横 |
| 用途 | ゲームの宣伝ティザー(疑似プレイ演出のコンセプト映像)。無音で見ても分かること |
| 表記 | 「架空のゲームのコンセプト映像です。発売の予定はありません。」を最後の画面に出す。発売日・価格・ストア名・機種は書かない |
| 禁止 | 人物写真、AI 生成のフラット PNG の貼り合わせ、3D、実在の作品・商標に似せること、既製フォントそのままのロゴ |

## 2. 30秒の構成(Suno の曲の区間に合わせて組み直した版)
前提: 冒頭0〜3秒に「行動+危険+結果」/スタジオロゴは冒頭に置かない/情景は2枚まで/説明の板は作らず行動→反応→結果→HUD の数字の因果で見せる/主張は2つまで/ロゴと架空表記は最後の1枚/15秒の引き延ばしにせず「失敗・再挑戦・報酬」を足す。
曲の区間(実測。`audio/sync_map.json`): 0〜1s 前の余韻 / 1〜7.5s 音量が下がる谷 / **7.56s 最大のアクセント** / 7.56〜20.5s 持続する推進 / 20.5〜24.6s 山場 / 24.6〜30s 余韻(減衰)。

| 区間 | 秒(コマ) | 役割 | 中身 | 曲との対応 |
|---|---|---|---|---|
| フック | 0–3(0–90) | 行動+危険+結果 | 灯りの精が気流を駆け、稲妻をかわして NEAR MISS(SF1) | 前の余韻。1.0s で谷へ |
| 谷 | 3–7.57(90–227) | 静かな緊張・目的地・主張1 | 暗い灯台島と迫る嵐。「嵐を抜けて、灯りを届けろ。」 | 谷。音の無い動きだけで見せる |
| 点火 | 7.57–10(227–300) | 最大の見せ場の開始 | 灯りの点火、気流に飛び込む | **7.56s の最大のアクセント=227** |
| ルール | 10–14(300–420) | 操作と因果 | 光の粒を拾い、ゲージが満ち、加速 | 推進の刻み |
| 失敗 | 14–16.9(420–507) | 危険が本物 | 嵐が荷物をかすめ、PARCEL 3→2 | 強いアクセント 435・455 |
| 再挑戦 | 16.9–20.33(507–610) | 立て直し | 嵐の目をめぐる門を4つ通る | 門ごとに 539・559・578・591 |
| 山場 | 20.33–24.1(610–723) | 最大の見せ場と報酬 | PERFECT、ヒットストップ、STREAK ×12、灯台へ | 山場。610 と STREAK の5連 |
| ロゴ | 24.1–30(723–900) | 名前を覚える | 灯台の点火+ロゴ着地、航路の光、主張2、架空の表記 | 低音の一撃 723、余韻 |

主張は2つだけ: ①嵐をかわして届けるアクション ②届けると世界(夜空の地図)が変わる。特徴の箇条書きは出さない。映像のヒットは対応するアクセントのコマと±1コマ以内(`SHOTS.md`、`SYNC_TABLE.md`)。

## 2b. 曲と権利
- 曲: **Suno『Hopeful Bittersweet』**(ユーザーが Suno の無料プランで生成)の 159.84〜189.84 秒を切り出した30.000秒(-14.6 LUFS、真のピーク -2.6 dBFS)。2曲のうち、測定結果(谷→最大のアクセント→山場→余韻の形が映像構成に合う)から A を採用。
- **音声ファイルはリポジトリに入れない**(`audio/*.mp3` は .gitignore)。入れてあるのは測定結果の `audio/sync_map.json` と、映像側の台帳 `audio/cues.json` だけ。
- **権利(公開前に利用者が Suno の規約で確認すること)**: 無料プランの曲は、個人・非商用で、Suno への表記(クレジット)が条件になると報告されている(第三者の解説で、こちらでは規約を確かめていない)。この動画を公開・商用に使う前に、現在の Suno の利用規約・プランの条件を確認し、必要な表記(Suno の曲であること)を動画の説明などに入れる。映像側の注記は架空のゲーム表記のみ。

## 6. 書体とライセンス
- ゆうたONE パック(英字のみ): ロゴ=Y1FullmoonMarch、HUD=Y1Vectura。利用者がフォロー済みで商用条件を満たす(利用者の申告)。**フォントファイルはリポジトリに入れない**(`assets/fonts/` は .gitignore)。ロゴは字形をパスにして加工した物。字形の輪郭データ(`src/lib/logo-glyphs.js`)もフォント由来なので**リポジトリに入れない**(`.gitignore` 済み。`src/tools/glyph_paths.py` で、手元のフォントから作り直す)。原型を保ったロゴの商標登録はしない。
- 和文: Zen Old Mincho、Noto Sans JP(どちらも SIL OFL 1.1、`@fontsource` の npm パッケージ 5.3.1 から取得)。`src/jp_text.txt` の字だけにサブセット化(`src/tools/subset_jp.py`)。サブセットもリポジトリには入れず、`src/tools/setup_fonts.sh` で作り直す。

## 7. 第2段階への申し送り(まだ実装しない)
- 枠組み: HyperFrames(SKILL.md §2)。`<canvas>` 1枚に、止めたタイムラインの時刻から `src/lib/*.js` で描く。スタイルフレームの関数はすでに時刻 t の純関数(乱数は seed 付き、同じ引数で同じ画素になることを2回描いて md5 一致で確認)。
- 動き(motion-prompt のギャラリー、`search` で見つけた候補。`get` はまだ): #121 予備動作(S3 の跳び移り)、#122 余韻(マフラーの揺れ戻り)、#011 つぶしと伸ばし(着地)、#024 衝撃の揺れ(S4 の被弾・S8 のロゴ着地)、#040 フリーズフレーム(ヒットストップの考え方)、#108 流し撮り(S1 の背景の流れ)、#035 FPV(S5 の周回)、#022 光の帯(ロゴ)。ゲーム固有の動き(被弾の点滅、数字のポップ、HUD の2段ゲージ)はギャラリーに無いので自作になる見込み。
- ヒットストップの式: 資料の型 `f<h ? f : f<h+n ? h : f-n` は n=2 のとき 92,93,94 の3コマが止まる(手元で計算して確認)。止めるコマ数を n にするなら `f<h ? f : f<h+n ? h : f-n+1`(この場合、以降の動きは n−1 コマ遅れる)。1/2/4 コマを比べて決める [試験値]。
- ヒットストップは 610 から 2 コマに決定(1/2/4 を書き出して比較。`frames/film_hitstop_1_2_4.jpg`、REVIEW_STAGE1.md 追加4)。
- 曲は Suno の30秒(上の 2b)。BGM は切らず、効果音は `audio/cues.json` の `sfx_plan` の3発だけ。映像のヒットの検査は、書き出し後に `tools/sync_check.py`(skill 側)等で実測する。
