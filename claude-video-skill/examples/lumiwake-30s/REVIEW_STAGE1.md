## 機械的に確かめたこと
- 3枚とも 1920×1080。同じ URL で2回描いて md5 が一致(sf1・sf3 で確認。乱数は seed 付き、時刻 t の純関数)。
- 効果を切っても構図・主役・危険・数字は残る(fx_compare)。
- 540px でも主役・稲妻・PERFECT・ロゴは読める。HUD の小さいラベル(PARCEL、灯台島まで)は 540px では読みにくい。
- シルエットだけでも主役は「板に乗った人+後ろにたなびく布+背中の箱」と分かる。SF2 では稲妻のシルエットが主役の胸の前を横切って重なる。

## 前回の初稿と比べて良くなった点(見た目の判断は利用者に任せる)
1. **主役がいる**: 画面の高さの約4〜5割の配達人。3トーン(地・月光の明・青寄りの陰)+灯り箱からの琥珀のリム。前回は約120px の記号だった。
2. **ゲームプレイの因果が1枚で読める**: SF1 は「行動(駆け上がる)+危険(稲妻)+結果(NEAR MISS +150 ×4)+HUD」。SF2 は「回り込み→ヒットストップ→PERFECT +800→STREAK ×12・LUMI 満タン」。前回は特徴の説明板(メーター・見出し・説明文)だった。
3. **奥行き**: 背景は 空/星と月/遠い雲海/遠い島/嵐/中景の雲/中景の島/気流/手前の岩とぼかした雲/光の粒 の8〜10層。遠いほど彩度を落として空の色へ(大気遠近)。前回は2〜3層の平塗り。
4. **局所光**: 灯り箱・家の窓・空板のひれ・稲妻・嵐の目が、それぞれ周りを照らす。色に意味がある(琥珀=味方、白青と紫黒=危険)。
5. **ロゴ**: 字形をパスにして、反らし・i を灯りに置換・スウッシュで下端を切り欠き・押し出しと縁の光。白黒版でも読める。スウッシュの先端に主役を乗せて、物語の終わりとつないだ。
6. **架空の表記**: 発売日・機種を書かず、「架空のゲームのコンセプト映像です。発売の予定はありません。」と明記。

## まだ弱い点・気になる点(厳しめに)
1. **ロゴは元の書体の形がまだ強い**(加工は反らし・灯り・切り欠きの3点で、字形そのものは FullmoonMarch のまま)。「独自感」が足りるかは利用者の判断。灯りの i は小さく、540px では白い点に近い。
2. **嵐の塊(SF1 左上)が「紫の岩」に見えやすい**。縁が硬く、雲らしい千切れ・薄い端がない。SF2 の渦は帯の重ねで雲らしさが出たが、帯が「触手」にも見える。
3. **キャラの作画**: 手が丸い玉で、手袋・指の形がない。胴が細長く、腰から下の比率が大きい。SF1 は板の傾きに体ごと乗っているので、体が後ろに反って見える瞬間がある。横顔の目と口は小さく、表情はほぼ無い。アニメーションで関節がどう見えるかは未確認。
4. **HUD の書体**(Vectura): 0 に斜線が入り、M・W が独特。「NEAR MISS」の単語間が広い(Canvas の wordSpacing で詰めたつもりが効いていない)。小さいラベル(22〜26px)は 540px で読めない。
5. **雲の量**: SF1 と SF3 で中景の雲海が画面の下半分を広く占め、のっぺりした灰青の面に見える所がある(こぶの明暗はあるが、形の変化が少ない)。
6. **画面の情報量**: SF2 は渦・稲妻2本・気流・白い輪・放射線・PERFECT・HUD 4か所で、見る所が多い。動画では一瞬なので許容範囲かもしれないが、静止画では騒がしい。
7. **稲妻の閃光**は静止画では強い。動画で白青の閃光が続くと光過敏の目安(1秒に3回)に触れうるので、第2段階で数える。
8. **SF3 の主張文と小さな配達人**: 配達人(0.3倍)は 540px では点に近い。主張文の字間(6px)は明朝には広い。
9. 2D の「描いた絵」の質感の上限: 筆のむらはノイズの明暗で、実際の筆致ではない(depth-and-texture.md §5 の限界どおり)。

## 汎用とゲーム専用に分けた所見
### 汎用(どのジャンルの宣伝にも効く)
- **「ずらしたシルエット」で陰と光を付ける方法**(`src/lib/paint.js` の `shade`): 形のパスを1つ書けば、光の向きにずらした差分で「陰の帯・明るい帯・逆光のリム」が自動で付く。手足・マフラー・岩・家・雲・ロゴの全部に同じ関数で効いた。平塗り対策として最も効果が大きかった(前回の弱点1・2)。スキルの `depth-and-texture.md` は球と層の部品だけで、任意の形の陰影の作り方は書かれていない。
- **色に意味を固定する**(味方=琥珀、危険=白青/紫黒、背景=藍〜青緑): 1枚で「何が良くて何が悪いか」が読める。
- **スタイルフレームを先に作る順番**: 静止画の段階で、主役の不在・ロゴの読みにくさ(スウッシュで U が II に見えた)・HUD とロゴの重なり・月と HUD の重なり・PERFECT が主役を隠す、を見つけて直せた。アニメーションの後では直しが重い。
- **効果を切った版と、シルエットだけの版を同じコードで出す**(`?fx=0`、`?sil=1`): 描画関数ごとに「効果か形か」を分けておくと、確認の版が無料で出る。
- **白黒でロゴの字形を先に確かめる**: 質感の前に読みやすさの事故(切り欠きで字が欠ける)が分かった。
- **主役をロゴの画面まで持ち越す**(スウッシュの先端に乗せる): business-motion-film の「1つの主役を通す」の具体例。
- 道具: `src/tools/glyph_paths.py`(文字→SVG パス)、`src/tools/subset_jp.py`(@fontsource の分割ファイルから必要な字だけ取り出して unicode-range 付きの CSS)、`src/tools/render_still.mjs`(HTML の canvas を PNG に。ページのエラーで止まる)。どれもジャンルを問わず使える。
### ゲーム専用
- 疑似プレイの因果(行動→反応→結果→HUD)と、数字の流れをショット表で先に固定する(距離・耐久・STREAK・ゲージ)。
- NEAR MISS / PERFECT / STREAK のような「結果の言葉」を主役のそばに出す(HUD の隅ではなく)。
- ヒットストップは静止画では「白い輪+放射線+背景の流れの停止」で表した。動画での見え方(1/2/4 コマ)は第2段階で比べる。式は BRIEF.md §7(資料の式は1コマ多く止まる)。
- motion-prompt のギャラリー(192件)には、ゲーム固有の動き(被弾の点滅・数字のポップ・HUD の2段ゲージ・ボス登場)が無い。予備動作・余韻・衝撃の揺れ・フリーズフレームは使える見込み。

# 追加: 配達人キャラクターの作り直し(ユーザーの返事「スタイルフレームの感じは悪くないけど、キャラをどうにかして」)

作り手本人の点検で、独立レビューではない。見た目の良し悪しは利用者が判断する。環境が作り直されていて、ゆうたONE のフォントファイルが手元に無かったため、**このセクションの画像の HUD の文字は代用の書体(Chakra Petch、OFL)**。比較する新旧 sf1 は同じ代用書体で描いている(`frames/sf1.png` は元のまま、Vectura)。ロゴ(`logo-glyphs.js`)には触っていない。

## 1. 旧キャラが「安っぽい・魅力がない」原因(sf1〜sf3 の実際のコマを見て)
1. **プロポーション**: 約5頭身で、頭が体の大きさに対して小さい。ゲームの主人公に多い「大きい頭・大きい手足」ではなく、顔が表情を担えない(目と口が小さく、表情がほぼ同じ)。
2. **シルエット**: 縦長の長方形の胴+細い脚+小さな箱で、輪郭に特徴がない。マフラーは細いリボン1本で、暗い背景では線にしか見えない。シルエットだけにすると「板に乗った人」止まり。
3. **手足の形**: 腕・脚が同じ太さの管で、手は丸い玉、靴は小さい。関節の曲がり(膝・肘)が弱く、手の形で気持ちを出せない。
4. **色の面積と明るさ**: 上着の青緑が背景の雲の青緑に溶け、ズボンの濃い紫は夜空に沈む。主役が背景から「明るさで」抜けておらず、頼りは縁の琥珀の細い光だけ。
5. **装備の形**: 背中の灯り箱が小さい。板は白い細長い楕円で、特徴がない(雪板や波乗り板に見える)。
6. **顔の情報量**: ゴーグルと耳当ては付いているが小さく、表情の差(きりっ/おどろき/にっこり)が付く作りになっていない。
7. **動かしたときの作り**: 二次運動はマフラーだけ。支点・節の構造がなく、ケープや髪を足しにくい。姿勢は手で数値を決めており、補間できなかった。

## 2. 作り直し(`src/lib/courier2.js`)
共通の作りと、3案の違い。
- **作り**: 体は頭身を下げ(3〜4頭身)、頭と手足を大きく。腕・脚は2関節の IK(足は板の上に固定、膝は前、肘は下)。手はミトン+親指、靴は大きなつま先。表情を3種(きりっ/おどろき/にっこり)。板は葉の形・反った先端・上面は象牙で下面は紺・中央に琥珀の象嵌+琥珀のひれ。
- **二次運動の部品構造**: `chain(支点, 向き, 節の長さ[], t, {振幅, 速さ, 位相のずれ, たれ})` が、時刻 t だけから点列を返す純関数。マフラー2本・ケープ2枚・コートの裾・アンテナ・提灯の吊り・旗は全部これ(支点: マフラー=首元、ケープ=肩、裾=腰、アンテナ=帽子の頂点、提灯=杖の先、旗=荷物の上)。乱数・状態なし。
- **姿勢**: `POSES`(ride / dodge / deliver)と `poseMix(a, b, k)` で補間。k を時刻から決めれば、ショットの中で ride→dodge→deliver がつながる。
- **描画順(奥→手前)**: 後ろの二次運動 / 板 / 後ろの腕 / 後ろの脚 / 荷物 / 胴 / 前の脚 / 後ろへ流れるマフラー / 頭 / 前の腕 / 手に持つ物 / 結び目。

| 案 | 名前・頭身 | 一目で覚える特徴 | 色 | 狙い |
|---|---|---|---|---|
| **A** | 提灯のミオ・3頭身 | ①手の提灯(杖の先で揺れる) ②額の大きな丸ゴーグル ③象牙色のケープ+朱のマフラー | 青の上着、象牙のケープ、茶の靴、琥珀=提灯 | 琥珀=味方の灯りを「持ち物」にして、シルエットに前へ突き出る形を作る |
| B | 背負い灯のミオ・4頭身 | 頭より大きい背負い灯り箱(窓が光る、旗が揺れる)+配達帽+朱の二枚マフラー | ミント色の上着、茶の箱、象牙の靴 | 「配達人」が最も一目で分かる。箱が大きく、シルエットが強い |
| C | 兜灯のミオ・3.5頭身 | 頭の上の灯り(アンテナの先で揺れる)+朱の燕尾コート+クリーム色の兜 | 朱のコート、クリームのズボン | 頭の灯りで画面のどこにいても場所が分かる。コートの裾が二次運動の見せ場 |

## 3. 比較して分かったこと(`frames/character_sheet.png`: 3案×3姿勢、シルエット、540px 縮小)
- 3案とも旧キャラより頭と手足が大きく、表情が読める。540px でも顔の向きと手の位置は分かる。
- シルエットは **A(ケープ+提灯+ゴーグル)と B(大きな箱)が別の形として覚えやすい**。C は頭の灯りが離れた点に見え、体の形は一般的(兜と細い体)。A の提灯は細い杖につながり、シルエットでも「持っている」と分かる。
- 暗い背景からの抜け: A と B は明るい面(象牙のケープ、ミント、象牙の靴)があり、旧キャラより抜ける。C のコート(朱)も抜けるが、ズボンのクリームと兜が白に近く、小さくなると白い塊に見える。
- **推薦: 案A**。理由: ①琥珀=味方の約束を「持ち物の提灯」で最も直接に表せる ②シルエットの個性が3つ(ケープ・提灯・ゴーグル) ③ケープとマフラーで二次運動が多く、動かしたときに見映えが出る ④B は強いが箱が胴を隠し、ヒットストップや回避のポーズで体の動きが読みにくい(sheet の②)。B は「配達人らしさ」を最優先するなら次点。
- 利用者が案を選んだら、sf2・sf3 も更新する(今回は sf1 のみ)。

## 4. 動かす前提の簡易確認(`frames/character_motion_check_A.png`)
- 別時刻 t=0, 0.1, 0.2, 0.3 秒の ride: ケープ・マフラー・提灯が連続して揺れ、ポップや破綻は見えない。
- 姿勢補間 ride→dodge→deliver(k=0〜1.0、0.5 刻み): 脚の IK が板から外れず、腕・顔の向きもつながる。表情は補間せず、k の途中で段階的に切り替える(`Math.round`)。
- 同じ指定で2回描いて画素が一致(`sf1_v2_A.png`、`character_sheet.png`、それぞれ md5 が3回とも同じ)。
- アニメーション(連続した動き)として確かめたわけではない。コマ単位の静止確認のみ。

## 5. 新 sf1(`frames/sf1_v2_A.png`、新旧の並び: `frames/sf1_compare_old_vs_new.jpg`)で良くなった点
- 顔が見える(目の大きさ・ゴーグル・表情)。主役が画面で最初に目に入る。
- 提灯の光が主役のそばに局所光を作り、琥珀=味方の約束が絵に出る。
- ケープの白が夜空・雲から抜ける。

## 6. まだ弱い点(厳しめに)
1. **sf1 のポーズ**: 気流の斜面に板を合わせると体が後ろへ反って見える。ケープとマフラーが胴と脚を隠し、足の位置が読みにくい。もっと前傾(`lean`)と脚の開きを調整するか、カメラの傾きを緩める必要がある。
2. **頭が大きすぎる可能性**: 3頭身は「可愛い」寄りで、NEAR MISS の危機感や、嵐のある世界の格好よさとは方向が違うかもしれない。ここは利用者の判断(4頭身の B 寄りにする、頭を 10〜15% 小さくする、など)。
3. **顔**: 眉が太く、きりっの表情が少し怒って見える。口の線が短い。横顔に近い向きで目が1つなので、3/4 の顔の立体感は弱い。
4. **ケープの形**: 平らな板状で、布の折れ・しわがない。端の斜め切りが硬い。裾のスカラップや縁の厚みが無い。
5. **手**: ミトンは丸く単純。杖の握りが見えない。指の形はない。
6. **板**: 前の反りが大きく、紺の下面は暗い背景では見えにくい。琥珀の象嵌は良いが、板の側面の厚みの陰影が薄い。
7. **回避ポーズ**(sheet の②): 腕が顔を隠し、表情が見えない。腕を下げるか、もう片方の手で提灯を庇う形にする案がある。
8. **IK の限界**: 膝が曲がりすぎるポーズで足首の角度が変わらず、靴が板にめり込んで見える場合がある(未確認の姿勢)。
9. **ゴーグルと提灯が同じ丸い光る物**で、小さくなると見分けにくい(540px でゴーグルはほぼ点)。
10. 実際のアニメーション(連続した動き)・他の角度・他の距離での見え方は未確認。

## 7. 汎用(どのジャンルでもキャラを描くとき効く方法)とゲーム専用
### 汎用
- **シルエットで先に決める**: 3案を同じ3姿勢でシルエットにし、540px に縮めて比べる。色や陰影を付ける前に、案の違いが「形」で出ているか確かめられた。
- **特徴は1〜3個に絞り、輪郭に出す**(提灯=前に突き出る、ケープ=後ろに広がる、箱=背中に大きい)。小さな模様や装飾は縮小で消える。
- **頭と手足を大きくする(頭身を下げる)**と、表情と手の形で個性が出せる。小さい顔では表情の違いが出ない。
- **背景から明るさで抜く**: 衣装の面の明るさ(値)を背景と離す。色相の違いだけでは、青緑の上着が青緑の雲に溶けた。
- **部品構造**: 関節(IK)+鎖(chain)+姿勢の名前と補間、の3層にすると、姿勢と二次運動を別々に付けられる。二次運動は「支点・向き・節の長さ・時刻」だけの純関数にして、seek-safe にする。
- **姿勢は名前付きの数値表にして補間する**。表情だけは補間せず段階で切り替える。
- **機械でできる確認**: 別時刻のコマ、姿勢補間の途中のコマ、2回描いての画素一致。
### ゲーム専用
- 主役の持ち物を、ゲームの核(ここでは光=琥珀=味方)の具体物にする(提灯、灯り箱、頭の灯り)。ロゴ・HUD・味方の色と同じ意味が1枚に揃う。
- 「行動(乗る)・危機(かわす)・達成(差し出す)」の3姿勢を、キャラ案の比較の基準にする。ゲームの宣伝でキャラが担う3つの場面に対応する。
- 小包や灯りを差し出す姿勢(deliver)は、報酬の場面(SHOTS の S6)に直結する。
