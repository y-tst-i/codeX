# 追加指示の記録(送った順。資料と同じく「コマ番号+見えた物+数値」)

最初の版は PROMPT.md だけから作った。振り付け(6回のホップ・設備・嵐・雷・吹き飛び・巻き戻し・PLAY)は最初から全部入っていた。

## 映像
1. 0・50コマで島の右端(6日目の足場)が画面から切れ、見下ろしすぎて画面の大半が空っぽの海。280コマで雲が画面の上に切れる。
   → 仰角 27°→17°(嵐で 13°)、距離 27→33(寄って 29)、注視点を y 1.6(嵐で 3.2)へ。雲を y 7.5–9.7 → 5.6–7.4 へ下げる。雷の始点も 6.2 へ。
2. 0・215コマでまだ島の端が切れる。285コマで嵐の暗い空に暗い文字が乗り、日の一覧が読めない。雲のボクセルが真っ黒で建物に見える。
   → 住人を追う量 25%→15%、距離 33→36(寄って 32)。日の一覧の後ろに明るい下地(F6F3EC、不透明度 0.86、角丸 18)。雲の色 3A424C→66717D。
3. 全コマ検査の1回目: 58 項目中 13 項目が不合格。着地のつぶれ(1〜5日目)が出ていない: 次のしゃがみが着地のコマに始まり上書きしている(6日目だけ合格)。
   設備が着地の1コマ後に生える(ばねが 0 から始まる)。吹き飛ぶボクセル同士が 2145 件触れる。数字の向きが最大 27°。
   → つぶれからしゃがみへ混ぜる(しゃがみが進むほどつぶれを減らす)。生え始めを1コマ前に。散る向きを設備の中心から外へ。数字が向く時刻を物語 306 コマになる実時間で解く。
4. 2回目: 2 項目が不合格。接触 567 件はすべて縦に積んだ列(塔・壁・電柱)の中: 列の中では向きがそろう。数字の向きは回転が速すぎ(0.1 秒で最大 2 回転)、1コマずれると 36° ずれる。
   → 散る向きを番号ごとに黄金角(約 137°)ずつ回す。それでも触れる組は、飛ぶ前に軌道を計算し、触れたら向きを 0.9 rad 回して解き直す。余分な回転をなくし、向きの検査は正確な時刻で行う。
   → 59 項目すべて合格。
5. 検査は 59 項目すべて合格したのに、304・308・330コマで吹き飛ぶボクセルが1個も映っていない(資料の教訓どおり「数値は合格、見ると変」)。
   原因: 速すぎて一瞬で画面の外へ。さらに調べると、雷の点から外への向きのベクトルが、前の計算で長さ 12〜18 に書き換わっていた(意図の十数倍の速さ)。
   → 向きを取り直し、速さを抑える。検査に「飛んでいる間、全部のボクセルが画面の中」を足す。飛び方の解き直しにも画面の範囲を入れる。
6. 画面の検査で 188 件、左端(1・2日目)のボクセルが左へ出る。解けないボクセルが 11 個。外接球(半径 0.35)で判定すると、0.4 間隔で隣り合うボクセルは動き始めで必ず「接触」になる。
   → ボクセルを 0.34 にして 0.06 の隙間(資料のキーキャップと同じ)。遠いボクセルは住人を避ける力を掛けない。向き 24 × 強さ 7 × 上向き 5 を総当たりして最初に条件を満たすものを使う。
   → 61 項目すべて合格、42 個すべて解けた。
7. 308〜330コマ(雷の後)が暗すぎてボクセルが沈む。→ 嵐の間の空の光 0.55→0.85。

## 音(全部、デコードした音の測定から。聴いていない)
1. 着地が下地より 16〜17 dB 上(下地が小さすぎ)。雷の一番大きい山が 19ms 後ろ(厚い爆発音が割れより大きい)。60Hz 未満が 26%。PLAY の後がほぼ無音。
   → 下地 +10 dB、うなりと爆発音の帯域を上へ(70〜320 / 55〜900Hz)、爆発音を割れの後から、ピチカートを1オクターブ上、静かなパッドを PLAY の 6コマ前から。
2. 雷が下地と同じ大きさ(うなりが雷の1コマ後まで鳴っていた)。リミッターが 9.7 dB(383 コマ = 巻き戻しの音が下地の +10 dB に乗っていた)。
   → うなりを雷の 1コマ前で切る。巻き戻しの音は別の線にして自分の音量で鳴らす。
3. リミッターが 6〜7 dB(211 コマ)。打撃の線だけで +1.4〜+2.7 dBFS: 木の音・マリンバ・砂ぼこりの頂点が同じ数 ms に重なる。左右に ±0.6 振ると片側が +2.6 dB。
   → 下地の音の頭を 6ms に丸める、左右は ±0.3、砂ぼこりを 8ms 後ろへ、着地のコマの小さな音を1つ抜く、木の音 0.6→0.26。
4. リミッターが 4.6 dB(295 コマ = 嵐のうなりの雑音の頂点)。雷の頂点が 8.9ms 後ろ(割れが雑音なので一番大きい所が偶然)。
   → うなりを tanh で丸める。雷の頭に cosine 位相の短い「パチッ」を置いて頂点をコマ+1に固定、爆発音を 12ms 後ろへ。
   → 8 つの合図すべて頂点のずれ 1ms 以内・下地より 3.9〜5.4 dB、-14.2 LUFS、-2.6 dBTP、60Hz 未満 1.1%。リミッターは最大 2.4 dB(目安 1.5 を少し超える)。
