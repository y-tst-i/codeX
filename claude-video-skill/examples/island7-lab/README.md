# ISLAND 7 LAB — 資料の全要素を1本で使った見本

`references/motion-lab.md` の元になった資料2つ(Florence の X 記事「Opus 5.5 Motion Lab」と配布 PDF「PROMPT PACK: CTRL+Z」)の、
**作り方の要素を全部**使って作った 8 秒ループ。完成度を判断できるように、指示書・追加指示・全コマ検査・測定値を全部残している。

島の住人が 7 日分の足場を跳ねて毎日1つ設備を建て、7日目の雷で全部吹き飛び、VHS の巻き戻しで最初に戻る。
1080x1080、60fps、480 コマ、継ぎ目のないループ。three.js の HTML 1枚(`anim.html`)、音は numpy だけ(`sound.py`)。

## 作り方(順番どおり)
```bash
bash setup.sh                                   # three.js と Noto Sans JP を取る(リポジトリには入れない)
python3 -m http.server 8767 --bind 127.0.0.1 &  # ES モジュールは file:// で読めない
node lab.mjs stills 1 0 120 300                 # 確認: 1 サンプルで速く静止画
node lab.mjs state && python3 check.py          # 全コマ検査(CHECKS)
python3 views.py                                # 速度グラフ
node render.mjs 0 3 6 & node render.mjs 1 4 7 & node render.mjs 2 5   # 本番: 3 並列、止まっても続きから
python3 sound.py                                # 音
bash finish.sh                                  # つなぐ・粒・MP4・GIF・音の測定・機械チェック
```
