# MV系モーショングラフィックス自律制作 — 調査・設計・Claude Code引継ぎパッケージ

調査日：2026-10-30　対象：Claude Code × HyperFrames × GSAP × HTML/SVG/Canvas/three.js

## 目的
楽曲とテーマから、独自のアートディレクションを持つ2D/2.5D音楽PV風モーショングラフィックスを自律的に制作する技術基盤を設計する。TEMACAの公開講座は**制作工程の参照資料**とし、個別の商用MVの模写・複製を目的としない。

## 同梱ファイル
- `01_RESEARCH.md` — 作者の公開情報、実装技術、比較、数値と出典、権利、失敗例
- `02_ARCHITECTURE_AND_ROADMAP.md` — アーキテクチャ、ショットDSL、マイルストーン、品質ゲート、障害時の対策
- `03_CLAUDE_CODE_HANDOFF.md` — Claude Codeに渡す実行指示書（このファイルを最初に渡してよい）
- `04_QA_SCORECARD.md` — ルーブリック、合格条件、Human reviewのテンプレート
- `05_BENCHMARK_SPEC.md` — 著作権上安全な10秒オリジナルMVの制作試験仕様
- `examples/shot_spec.example.json` — ショット仕様のサンプル。設計例であり実装済みソフトではない
- `06_ENGINEERING_RECIPES.md` — 技術別の実装メモ・seek-safe疑似コード・CLI検査例
- `examples/validate_shot_spec.py` — ショットの欠落・重複・区間不整合を検査する実動作する簡易バリデータ
- `examples/audio_beats_example.py` — 任意の権利処理済み音声で拍を抽出する試験コード（librosaが必要）
