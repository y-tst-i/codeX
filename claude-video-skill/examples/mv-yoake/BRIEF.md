# MV『夜明けの回路』 企画(第1段階: 美術方向・歌詞時刻・スタイルフレーム)

2D モーショングラフィックスの MV(53.0秒、1590コマ、30fps、1920×1080)。**この段階は静止画と設計まで**。アニメーション実装・書き出し・音の合成は、ユーザーが静止画と歌詞時刻を承認してから(第2段階)。

## 1. 一言で
- **何か**: 夜の「回路の街」を走る一つの光(信号)が、歌詞の文字をなぞって灯し、最後に夜明けの地平へ抜ける、文字が主役のMV。
- **見終わって残るもの**: 「暗い所を走ってきた光が、文字になって、朝になった」。
- **主役(非人型)**: 光の信号(ミント色の光の線)。全ショットを通して同じ物が走る(前回の教訓: 人型はコードで描くと質が下がる → 人物は出さない)。
- **舞台**: 基板がそのまま街になった世界。配線=道、チップ=建物、チップの小さな灯り=窓(歌詞の外の部分「眠らない街の端っこで」「切れたはずの配線を 指でなぞって 繋ぎ直す」から)。LUMIWAKE の空・雲・島・灯台の世界とは別。

## 2. 曲の構成と映像の起承転結

## 4. 美術方向の3案(選んだのは B)
| | A「蛍光版画」Riso Night | **B「光跡と黎明」Trace & Dawn(採用)** | C「余白の墨」Sumi Margin |
|---|---|---|---|
| 一言 | リソグラフ印刷の夜。2色の蛍光インクのずれと網点 | 基板の街を走る燐光の線が文字をなぞり、緑青の夜から薔薇色の朝へ | 白い紙に墨の明朝、朱を一点。夜は墨が紙を満たす |
| パレット | 濃紺の紙 #14163a、蛍光ピンク #ff4fa0、蛍光ティール #19c8c0、朝は生成り #f3ead8 | 夜: 黒 #020506・緑青 #265a54/#5a9a8e・燐光ミント #8cffe0・白 #f4fffb、火: 朱 #ff5a36・薔薇 #ff4f8b、朝: #120f2a→#3a2560→#8a3f7c→#e4677a→#ff9c76→#ffc48e→#ffd7a2、文字の朝の色 濃い紫 #2a1438 | 紙 #f4f1ea、墨 #111、朱 #d8352a |
| 書体 | Dela Gothic One(極太)のみ | Zen Old Mincho 900(歌詞の主)、Dela Gothic One(「止まらない 止まれない」の打撃)、Zen Kaku Gothic New 700(英字の副題) | Zen Old Mincho 600/900 |
| 密度 | 高い(網点・ずれ・模様) | 中〜高(盤の配線 2600本・チップ・粒。ただし文字の後ろは暗く静める) | 低い(余白が主) |
| 質感 | 網点・版ずれ・紙の繊維 | 金属(緑青の銅)・ガラスの字・霧・粒・色収差・光の筋 | 墨のにじみ・紙の繊維 |
| カメラ | ほぼ平面、拍で切る | 2.5D: 透視の地面の上を低く進む/俯瞰/真上/正面の放射/一人称の疾走/引き | 固定、ゆっくり寄る |
| 文字の見せ方 | 色面に大きく叩きつけ、版ずれ | 光が輪郭をなぞって灯る/字の面に回路を刻む/朝は濃い紫で静かに | 一画ずつ書かれる |
| 弱点 | 「夜明け」の光の移り変わりを表しにくい(2色の制約)。曲名の「回路」と結びつきが弱い | ネオン・サイバーの定番に寄る危険(→ 緑青の金属・明朝・夜明けの暖色で差を付ける)。描画が重い | 迫力(利用者の「上手い人の動画」の基準)に届きにくい。ボカロ系の速い曲と温度が合わない |

**B を選んだ理由**: ①曲名の「回路」と「夜明け」を、そのまま絵の物(配線の街・光の線・地平の朝)にできる ②主役(光の線)がコードの得意な表現(光・グロー・線・加算)で、人型の弱点を避けられる ③夜(緑青と燐光)→朝(薔薇・桃)の色の変化が、曲の起承転結の山と一致する ④文字の見せ方を3種類(なぞる/刻む/静かに置く)に分けられ、同じ処理が6秒以上続くのを避けやすい。LUMIWAKE の紺〜琥珀(空・雲・灯り)とは、色(緑青・ミント・薔薇)も材質(金属の基板)も別。
**A を選ばなかった理由**: 版画の質感は強いが、2色の制約で「夜が明ける」の光の変化を出しにくい。**C を選ばなかった理由**: 速い曲の迫力に合わず、利用者の不満(見映え・迫力)に応えにくい。ただし C の「朝の文字は濃い紫で静かに」は B の結に取り入れた。

## 5. 数値の約束(第2段階の指示書の元)
- 文字: 歌詞は Zen Old Mincho 900、1行の主の字は 150〜380px、副は 118px 以上、英字の副題 34px 以上(Zen Kaku Gothic New 700、字間 14px)。強い行(止まらない/止まれない)は Dela Gothic One。行は歌の語頭の **2〜3コマ前**から出し始め、語頭のコマで読める状態にする(第2段階で比べて決める)。
- 文字の描き方: 輪郭は glyph の点列(`src/lib/glyphs.js`、`glyph_lines.py` で作る)から描く。なぞりは字ごとに語頭から 6〜22 コマ。塗りもこの点列のパスで行い、`fillText` を使わない(フォントの読み込み待ちが絵に出ない)。
- 光: 全面の白い板は使わない。閃光は加算(lighter/screen)と局所の glow。ブルームは閾値(夜 0.5、サビ 0.7、朝 0.8)より明るい所だけ。全面の衝撃は 769・784・1340 の3回まで。
- 黒帯: 0〜769 は 2.0:1(上下 60px)、769 で開く(山1の解放)。朝は全面。
- 仕上げ: 色収差(端ほど強い、最大 1.4〜3.4px)、周辺減光 0.32〜0.5、粒(コマごとに変わる hash、強さ 9〜11)、暗部の色(夜は緑、朝は紫)。
- 禁止(名指し): 波形・スペクトラムの棒を主役にする、HUD・数字・小さいラベル、画面全体の白フラッシュ、レンズフレアの多用(朝の3つだけ)、同じ処理を6秒以上、毎拍のカット、人物・顔、実在のロゴ・ブランド、`Math.random`・`Date.now`、`fromTo` の `immediateRender:false`(開始前のコマで見える欠陥)。
