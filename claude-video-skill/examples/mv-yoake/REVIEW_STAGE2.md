## 目視(作り手の目。画像で見た物だけ)
- **カット境界 ±1 コマ**(407・669・769・862・1000・1171・1340): 飛び・空白のコマなし。769 はディップ(直前 3 コマを 4 割暗く)→ はじけ、1171 はホイップ(横ぶれ)で入れ替え、1340 は字から開く円で朝へ。
- **540px**: 歌詞は全部読める。英字の副題(34px)はかろうじて読める程度(第1段階と同じ)。
- **無音で見る**: 夜の街 → 光が字をなぞる → 上昇して灯りが増える → 真上で点が繋がって字になる → 吸い込まれて、はじける → 火 → 消えかけた声が光になる → 疾走 → 街が消えても字は残る → 夜明け → 題、の流れは画だけで追える。
- **効果を切った版**(`fx_compare.jpg`): 構図・主役・字・明暗の層は残る。効果ありで「止まらない」の字が少しにじむ(光のにじみが強め)。

## 良くなった点(第1段階・前回の LUMIWAKE と比べて)
1. 全ショットで視点が違い(低い地面/上昇/真上/引き/正面の壁/横長の低い視点/一人称/一点透視のドリーズーム/空から地平)、色の流れ(緑青 → 朱 → 薔薇 → 緑青 → 群青 → 薔薇・桃)が曲の山と重なる。
2. 音ハメ 18 個が全部 ±1 コマ以内(実測)。歌詞の出現も JSON から駆動し、機械で照合した。
3. 全面の衝撃は 769・784・1340 の 3 回だけ。白い板は使わず、露出(絵を自分に足す)なので色が抜けない(review_checks の白フラッシュ 0)。
4. 字の見せ方が 9 種類(なぞる/点く/盤に刷られる/配線として引かれる/回路の字が叩きつけ/火が灯る/ふるえて欠ける/光の線が集まる/横・縦から叩きつけ)になり、6 秒を超えて同じ処理が続かない(S4 の真上は 8.7 秒だが、途中で字と点の出来事が変わる)。
5. 歌詞の時刻が直っても、JSON を直して区間だけ書き直せばよい作り(境目も句の頭から計算)。

## まだ弱い点(厳しく)
1. **「Xの上手い人の動画」の水準かは分からない**。コードの図形・グラデーション・加算の光の範囲で、手描きの線の強弱、写真や 3D レンダラーのような光の回り込み(反射・影・空気)はない。特に**夜明け(S10)の街は黒い箱のシルエットで平板**、盤も紫の面に細い線が乗るだけ。結びの画として一番弱い。
2. S6 の回路の壁は、コアから十字に伸びる 4 本の太い束が強く、**画面が記号的**(基板の写真のような不規則さが足りない)。
3. S4〜S5 の真上の場面が約 12 秒続き、背景の絵柄は同じ(出来事は変わるが、絵の印象は似る)。
4. S2 の字の列の背後を暗くする下地が、街の上で「黒いもや」に見える所がある。「暗闇の数だけ」は 274 で粒にほどけるので、句全体が読めるのは約 0.9 秒(字は歌に合わせて順に出るので、追って読める)。「夜が明ける」も句全体は 0.6 秒(同じ理由)。
5. 「止まらない」は効果ありで光のにじみが強く、字の輪郭が少し甘い。
6. 最初の 3 秒は暗い(夜の街。意図だが、SNS の頭で弱い可能性)。
7. 1302〜1338 のフリーズ(曲のブレイク)は、字の光が強まるだけなので、間が長く感じる可能性(要視聴)。
8. 書き出しは 1 区間 約 1.5 分(全 11 区間で約 18 分)。ブルームと仕上げを毎コマ画素で回すため重い。

## 汎用(どのジャンルにも効く)と MV 専用の所見
### 汎用
- **時刻の正本を JSON に置き、描画は名前で引く**(`Y.word("闇")`)。ショットの境目も句から計算し、台帳に無いアクセント番号はエラーにする。時刻の直しが「JSON を直して区間を書き直す」だけになる。
- **描画のコード自身に「どの字がどの濃さで出たか」を記録させる**(`TYPE.mark` → `lyric_check.py`)。画素では揺れや光に埋もれて測れない字の出現も、確実に照合できる(画素の実測 `measure_sync.py` と両方で見る)。
- **区間書き出し(5 秒ずつ・再開可)**: 1 区間 約 1.5 分。直した区間だけ消して再実行できる。クラウドでの中断に強い。
- **集中線は「奥へ向かう平行線」から生まれる**: トンネルの壁の配線でも同じに見えた。正面に壁を置き、0/45/90 度で折る方が回路らしい(作ってから見て直した)。
- **奥行きの帯ごとに線の太さと濃さを変える**: 遠くの線が一つの塊に光るのを防ぐ。
- 画素の比較で「区間の継ぎ目の不具合」を疑った時は、継ぎ目でない隣のコマと差を比べる(細い線と粒のある絵は、圧縮だけで PSNR が 15〜20 dB まで落ちる)。
### MV 専用
- 叩きつける字は「着地のコマ」を語頭に、なぞる字は「なぞり始め」を語頭に、点く字は「語頭の 2 コマ前から 4 コマ」で読める状態にする。測り方も種類で変える(着地=変化の増え方が最大のコマ、出現=最大値の 35% を超えたコマ)。
- 句の頭でカットするショットは、句の頭の 2 コマ前で切ると、字が語頭で読める。
- 冒頭と結びを同じ街・同じ低い視点にすると、色(夜 → 朝)の変化がそのまま物語になる。
