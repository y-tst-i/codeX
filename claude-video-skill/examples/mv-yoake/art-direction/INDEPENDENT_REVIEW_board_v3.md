## 0. 判定(先に結論)

**条件付きGO。** 必須修正は3つ。効き目の大きい順に並べた。

動きの本制作を始めてよい。ただし、夜明け(1380〜1560)と S6・S8 は、必須1と必須3が通るまで動かさない。

### 必須修正(効き目の大きい順)

**1. 夜明けに「信号」と「この町」を戻す。年賀状の定型から離す。【動かす前に直す】**

- いまの問題: 1380〜1560 では、回路と溝が1本も出てこない。0〜46秒ずっと運んできた「信号」が、曲の行き着く所で消えている。
  - v2 では、地平に回路の線が残っていた。元版でも、地面の回路が光っていた。
  - テーマは「信号が夜明けを呼ぶ」なのに、v3 の夜明けは「ただの日の出」になっている。
- 町も別の町に変わっている。
  - S2〜S4 は、煙突・給水塔・煉瓦の建物・坂の家が並ぶ工業の町だった。
  - 夜明けでは、寺のような反りの屋根と松の枝になっている。
  - S10 の「松+昇る日+薔薇色の空+太い字」の組み合わせは、ひと目で年賀状やお正月のポスターに見える。
- 直し方:
  - (a) 1380・1430 の火の見櫓から延びる**電線を、信号の道にする**。S9 の読点から下へ落ちた溝が電線に乗り、琥珀が線の上を走って、地平の太陽の縁に届く。いま画面にある電線を使えばよく、新しい物は要らない。
  - (b) S10 では、その溝が「明」の**日**に入って終わる(字の中の日に信号が届く)。
  - (c) 松の枝は外す。代わりに、S2 の煙突か給水塔を手前の大きな影として入れる。
  - (d) 終わり(1560)には、S2 で最初に灯った**煉瓦の建物の窓**を小さく残す。冒頭と結末が1つの町で結ばれる。
  - (e) 終わりの太陽のふちの細いクリームの線(ベクターの円の縁取り)と、端のなめらかな葉巻形の霞をやめる。太陽も霞も、丸刀で彫り残したような不揃いなふちにする。

**2. ぼかし摺りの「デジタルの砂目」をやめる。【動かしながら直してよい】**

- いまの問題: 藍の空(S2・S3・S4)と夜明けの空(1430・S10・1560)のぼかしを2倍に拡大すると、4px ほどの四角い粒が一面に均一に散っている。白色ノイズを拡大したときの見え方で、紙の粒にも、ばれん摺りのむらにも見えない。
  - S2 の空の上には、等間隔の細い横線(木目のつもりの線)が走査線のように見える。
  - 1080p ではいちばん目に付く「安っぽさ」で、いまのボードで最大の質感の傷。
- 直し方:
  - ぼかしの地は、なめらかな濃さの勾配にする。
  - そこに、大きな斑(数十〜数百 px の低い周波数のむら)と、向きのある紙の繊維を、ごく弱く掛ける。
  - 明るい側ほど粒を消す。
  - いちばん確実なのは、CC0 の和紙かばれん摺りのスキャンを1枚、版の濃さに掛ける方法(§4)。
- これは全カットに共通する「刷り」の層の直しで、構図とも動きとも別に進められる。だから動きと並行してよい。ただし最終の書き出しより前には必ず直す。

**3. S6 と S8(サビの2カット)の主役を、版画の言葉で読めるようにする。【動かす前に直す】**

- S6 の問題:
  - 「火」を囲むクリームの雲形の縁取りが、シールか吹き出しに見える。
  - まわりの細い楔は、漫画の効果線になっている。
  - 墨の回路は 45 度に折れた「かぎ括弧」の形で「回路に」を囲み、図形として浮いている。
  - 全面の琥珀に明暗を逆にすること自体は、良い判断(§3)。ただし描き方の文法が、このカットだけマッチ箱のラベルや昭和のポスターになっている。
- S6 の直し方:
  - 「火」の縁取りは、雲形の線をやめる。丸刀で彫り残したクリームの面にして、外のふちを欠く。
  - 効果線は、太さの違う楔 6〜9本(白い丸刀)にする。
  - 墨の回路は、「回路に」の「路」の字画から出て「火」へ入る溝 3本だけにする。囲む形はやめる。
- S8 の問題:
  - 明暗の3段(空・町明かり・水)は通った。
  - しかし琥珀の「列車」は、斜めの1本の刀にしか見えない。桁も脚も、黒の上の黒で読めない。540px では「琥珀の斜線と横線と字」になる。
  - v2 の高架と列車のほうが、物として読めた。この点は後退している。
- S8 の直し方:
  - 列車は、桁の傾きに沿って**窓の琥珀の四角 8〜12個を、間を空けて並べる**。列車と読める最小の記号にする。
  - 桁の下の腹に、白い刀を数本入れて厚みを出す。
  - 「止まらない」の下を通る桁の線は、字から 20px 以上離す。いまは取り消し線か下線に見える。

## 3. v2 から v3 で新たに生じた問題

1. **夜明けで信号が消えた。町が別の町になった。**(必須1)
   - 53秒の物語の結びが切れている。v3 で最も重い後退。
2. **見た目の文法が、3つに分かれた。**
   - (A) 墨の版木に白い刀の木目: S1・S5・S7・S8・S9
   - (B) 黒い影絵に、ぼかしの空: S2・S3・S4・夜明け
   - (C) 全面の色に、シールと効果線: S6

## 4. 「主役の輪郭だけ人の手の SVG や和紙のスキャンにする」方式は必要か

結論: **和紙とばれん摺りのスキャンは使う価値が高い(推奨)。人の手の SVG は、いまは要らない(後回し)。**

- **和紙・ばれん摺りのスキャン(CC0 を1〜2枚)**
  - 必須2の砂目は、コードの粒の式でも直せる(大きな斑+繊維+明るい側ほど粒を消す)。
  - ただし、本物の紙の不規則さを式で出すには調整が長くかかる。CC0 のスキャン1枚を版の濃さに掛ければ、すぐに届く見込みが高い。
  - 権利も CC0 なら軽い。`asset_ledger.csv` に1行足すだけ。
  - これは「コードだけでも届くが、スキャンのほうが速くて確実」という種類の判断。
- **主役の輪郭を人の手の SVG にする**
  - いまのボードの弱さの順は、(1) 結びの意味(信号が消えた)、(2) 定型の図像(松・丸い太陽・シール)、(3) 粒、(4) 形の手描き感。(4) は4番目。
  - 1〜3 を直す前に輪郭だけ人の手にしても、「手で描いた年賀状」になるだけ。
  - S4 の家・1380 の屋根・櫓も、コードの中で家ごとに軒・窓・角度を変え、ふちの刀を手で座標指定すれば、23〜25点の帯には届く。
  - 26点以上(公開水準の上の帯)を狙う段になって、それでも形が切り絵に見えたら、そのとき SVG を入れる。対象は2〜3の形(1380 の屋根と櫓、S6 の火の縁)に絞る。
  - 「人の手」と言うなら、本当に人が描いた物(利用者か、権利のはっきりした作家)にすること。Claude が SVG を手で打っても、それはコードの別の形でしかない。
- まとめ: 結びの意味と図像を直す(必須1・3)のは、コードだけでできる。質感の最後の一段(必須2)には、スキャンを使うのがいちばん効率がよい。
