### 必須修正(5つ。効き目の大きい順)

1. **夜明けを「1枚の決め絵」として描き直す(1380〜1560)。**
   - 地平線に影が一列に並ぶ帯(看板のような並べ方)をやめる。画面の端で切れる大きな手前の影を1つ入れて、手前・中・奥の3層にする。例: S4 の坂の家の屋根や火の見櫓を、画面の高さの40%以上で左端に置く。

   - 7秒のあいだに構図を最低2つ見せる。例: 1380〜1430 は引きの絵、1470 からは太陽に寄った絵。
   - 水の墨の線は、長さ・太さ・間をそろえない。
2. **「回路の線」も刀で彫った線にする。**
   - 太さが均一で、端が丸い点(基板の端子)で終わる線をなくす(S1・S2・S4・S5・S7・S10)。
   - 回路は「彫った溝」で表す。根元が太く先が細り、ふちが欠け、木目を横切る線にする。
   - S7 の扇形(同じ形の線14本+丸い端子)は描き直す。「て」の字画の1本が、太さの違う溝3〜5本にほどけて、S4 の窓の灯りへ向かう、くらいが目安。

3. **S8 と S3 の明暗を組み直す(540px で主役が1つに見えること)。**

4. **文字組みを直す。**
   - Shippori Mincho B1 の字形を点列(折れ線)にした所で、曲線が角ばっている。「まだ」の「ま」の輪、「る」「つ」などで目立つ。点を細かく取るか、刀の面として長さの不揃いな切り口に意図して描き直す。

   - 版木のふちから最低6%離す。「止まれない」「を灯して」はふちに近すぎる。
   - S6 の「を」の後ろの黒い丸は消す。
   - 字幕のように小さく置くだけの行(S5「夜明けの」、S3 左下)には、置き場所の理由を持たせる。
5. **版の素材感を統一する。**

   - 全カットを囲む紙のふちを続けるかを決める。続けるなら S6 と夜明けだけは全面(ふちなし)にする。全カットにふちがあると、動きを付けても「版画のスライドショー」に見える。

## 2. 全体

### 53秒としての流れ
- 筋の設計は良い。版木 → 一刀 → 灯 → 欠片で増える → 彫り始めの火 → 爆発 → 声が光にほどける → 列車 → まだ、 → 彫り取られて朝。「信号が夜明けを呼ぶ」を「刀が版を彫り、版が増えて朝が刷られる」に置き換えた比喩は作品にしかないもので、元版にはなかった。
- 弱い所が3つある。
  - 0〜46秒(全体の約87%)が、紺の版+クリームの横線+少しの琥珀という同じ見た目のまま。カットの違いは構図と字だけで、見た目の拍が平らになる。途中で1カット、明暗を逆にする(クリームが主の版に墨の線)か、S6 を琥珀が主の全面にするかで、山を作るべき。
  - 40〜46秒の S9 は、ほとんど何もない画が長く続く。動きの設計が要る。
  - 46〜53秒の夜明けは、1つの構図に版を足していくだけ。曲の行き着く所として弱い(必須1)。

### カット間の重複・色替えの量産
- 箱型ビルのように同じ物を量産している所はなくなった。S2 の町の点列を使うのは1回だけ。
- 1380/1430/1470/1560 は「彫りの量と版の数が違う」という制作者の説明は事実。ただし**構図は4枚とも同じ**で、ボードとして見ると同じ絵が4枚並んでいる。1本の連続したショットとして見るなら、そのショットの決め絵が弱いことになる。どちらで見ても直す必要がある。
- 新しく出てきた重複: 横の破線のハッチが、S3・S8・1380〜1560 の空と水のすべてで、ほぼ同じ規則で作られている。「同じプリミティブの反復」が、箱から線に移っただけになっている。

### 主役の明確さ(540px)
- はっきりしている: S2(灯った窓と「暗」の日)、S5(火)、S6(火と回路に)、S9(まだ、)、S10(太陽。ただし小さい)。
- 弱い: S3(主役なし)、S8(帯が重なっていて、列車の窓だけはかろうじて読める)、1380・1430(主役なし)。
- 字は13枚とも読める。

### 文字組みの質
- 良い所:
  - 書体を Shippori Mincho B1 の1つに絞り、ふちを荒らして版の字にした。全編で一貫している。
  - 縦組みと横組みの使い分けに意味がある。縦は「暗闇の数だけ」「を灯して」「まだ、」「題」で、落ちる・とどまる言葉。横は「止まらない」「光に変えて」で、走る言葉。
  - 字の一部だけを琥珀にする(暗の日・明の日・灯の火)のは、この作品の署名と言える。
- 悪い所:
  - 点列にした字形の曲線が角ばっている。ここだけ「ポリゴン」が字に戻ってきている。
  - 字間が不ぞろい。S4 は広く、S6 は詰まり、S10 は所々が開いている。
  - 置き場所の型が左上か左下に偏り、字幕のような小さな行がある。
  - ふちに近すぎる字が2か所ある(「止まれない」「を灯して」)。

### 色の流れ(暗 → 琥珀 → 黒 → 朝)の説得力
- 数値(`stats_v2.jsonl`): 琥珀の量は S2〜S5 で約1%、S6 で6.5%、S8 で約1%、S9 で0。そのあと淡黄31% → 薔薇+淡黄で約50%。山の位置は正しく、28秒の山 → 40秒の黒 → 朝の開き、という形は説得力がある。
- ただし琥珀は、S2〜S8 でずっと同じ色相・同じ少ない量のまま。「灯りが増えていく」物語なのに、色の量が増えていかない。S2 → S3 → S4 で 0.5% → 1% → 2% のように段を付けるべき。
- 茄子紺から薔薇・淡黄への移りは、版の「ばれん摺り」の比喩として筋が通っていて、良い。

## 3. 元版よりポリゴンくささ・安っぽさが解消したか(正直に)

- **ポリゴンくささ: 解消した。**
  - 直方体のビル、同じ形の窓の格子、奥へ集まる発光線、Bloom 頼み。この4つは全部なくなった。
  - clean(FX なし)でも全カットが成り立っている。元版は FX を抜くと成り立たなかった。
  - 作品にしかない視覚言語は、元版の「どの SF にも置き換えられる」状態から、はっきり上がった。
  - 例外が1つある。字形の曲線が角ばっている所(必須4)。
- **安っぽさ: 半分だけ解消した。** 安っぽさの原因が別の物に置き換わっている。
  1. 太さが均一なベクターの回路線と丸い端子。基板のクリップアートで、刀の世界観と食い違う。
  2. 空と水を埋める横の破線のハッチが、手続きの規則で均質。人の手で彫ったリズムがない。
  3. なめらかなグラデーション(エアブラシ)と横のデジタルのぶれ。版画なのに、デジタルのフィルターに見える。
  4. 夜明けの町が、物の見本帳のように一列に並んでいる。
- この4つを直せば、「安い」から「作家性のある版画風」へ届く。

## 4. 完成MVとして人に見せられる水準に届く見込み

- **見込み: 中くらい。** 必須修正の5つが通れば、X に公開しても恥ずかしくない「グラフィックな歌詞MV」の水準に届く可能性は十分ある。方向(木版+字の中の日)は、元版よりはるかに作品らしい。S2・S5・S6・S9 はすでにその水準に近い。
- **届かない場合の最大の原因: 刀の跡が「手続きで作った模様」に見えること。** 版画の魅力は、一刀ずつの太さ・向き・欠けに判断があることにある。いまは横の破線、楔の放射、輪郭のふちの揺れのどれもが、乱数の幅で揃っていて、高品質な作品と比べると「版画風のフィルター」に見える。動きを付けると、この均質さはもっと目立つ。刀が毎コマ同じ規則で増えていくと、パターンに見えるからだ。
  - 対策: カットごとに「主役の刀」を3〜10本、手で座標を決めて描く(形・太さ・終わり方を1本ずつ決める)。乱数の刀は、背景の地紋にだけ使う。
- 2番目の原因は、山場の絵の弱さ(必須1)。最後の7秒が忘れられる絵だと、53秒全体の印象が下がる。

1. 第一印象: 紺の版木に彫られた夜の町と字。最後に版が増えて朝が刷られる。1秒で「版画のMV」と分かる。
