# ART DIRECTION FIRST — Claude Code × HyperFrames 制作スキル強化パッケージ

作成：2026-11-10 JST / 対象：既存の2D/3D/MV制作スキル全般

## 核となる決定
**高品質な映像 ≠ リアルな3D。** 作品のテーマ・感情・画面構成に最適な表現方式を選択し、完成静止画を審査してから動かす。WebGL、SVG、CSS、Canvas、画像素材、2.5D、実写、Blenderは手段であり、最初の選択肢を固定しない。

『夜明けの回路』の課題：繰り返された直方体状の建物・均質な窓・回路模様が、コンセプト美術ではなく簡易な3Dテストの印象を与える。ポリゴン数やBloom強度を上げるだけでは根本解決にならない。

## このパッケージに含まれるもの
- `01_RESEARCH.md`：公開一次情報、クリエイター投稿、実装・権利の注意
- `02_YOAKE_DIAGNOSIS.md`：アップロード済み映像の特定時刻に基づく観察
- `03_ART_DIRECTION_SYSTEM.md`：表現方式の選択、アートディレクション、技法より先に美術を審査する仕様
- `04_ROADMAP.md`：既存環境を監査し、短い比較試験を経て汎用スキル化する開発ゲート
- `05_CLAUDE_CODE_HANDOFF.md`：**最初にClaude Codeへ渡す正式指示書**
- `06_REVIEW_SCORECARD.md`：主観美術評価と技術品質検査の分離
- `07_BENCHMARK_DIRECTIONS.md`：現行MVで比較する、絵柄が本質的に異なる3方向
- `templates/*`：frame.md案、提出書式、素材ライセンス台帳
- `examples/*`：美術案、ショットマニフェストのJSONデータ例
- `scripts/*`：ショット範囲・候補案の整合検証、MP4の技術情報、代表フレーム抽出
- `tests/*`：検証用テストケース
- `baseline/*.jpg`：元映像から抽出済みの代表フレーム5枚（8,16,28,40,49秒）。元MP4を変更していない。

## 完了したことと、まだしていないこと
**完了**：公開文献の確認、旧制作指示書との統合方針、映像の実フレームレビュー、体系設計、工程・合否条件、検証スクリプトの作成とローカルテスト。

**未実施**：利用者のWindows側Claude Codeプロジェクト本体の監査・改修、HyperFrames上での3案描画、制作後の美術合否判定、53秒の再レンダリング。現行ソースがこの環境にないため、これらの実施を装わない。

## Claude Codeへの渡し方
1. ZIPを展開し、Claude Codeの既存動画プロジェクトから本フォルダを参照させる。
2. `05_CLAUDE_CODE_HANDOFF.md` を正式指示とし、`00_START_HERE.md` と各資料を読むよう伝える。
3. **Step 0のAuditを必須**にする。すでに公式HyperFramesが持つ機能を重複開発してはいけない。
4. 最初の出力は既存機能の棚卸しと、3種類の独立した静止画。いきなり53秒フルレンダリングをしてはいけない。

## 信頼度の記号
- 【確実】公式文書・実ファイル・検証した手元のプログラムで確認
- 【作者報告】作例作者の公開説明。内部ソース・実際のすべての工程は未検証
- 【設計仮説】このプロジェクト向けの提案。実レンダリングと人間の比較レビューで検証する

## 重要な非目標
- 画像生成AIや外部アセットを必須化しない。SVG/CSSで優れた美術が成立する作品を排除しない。
- ローポリ・フラット・幾何学表現自体を禁止しない。**意図しない手抜き表現**を不合格にする。
- TEMACAやX掲載作品の固有の画面、著作物、音源の複製をしない。
- 自動スコアだけで「美術的に高品質」と判定しない。
