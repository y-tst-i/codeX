# 03 Art Direction First — スキルの設計仕様

## コア原則
1. **制作技術の先に美術表現を決めない**。コンセプト→見た目→実装の順序を守る。
2. **「2Dか3Dか」ではなく「何を感じさせたいか」で選ぶ**。写実性は品質の必要条件でも十分条件でもない。
3. **一枚絵が弱いなら動かさない**。画面の意味・構図・文字・色が成立するまで静止画を比較。
4. **「同じ絵柄の別色」しか出さない場合は3案未提出**。形・主役・画面構造・モチーフの解釈が異なる候補を作る。
5. **目的のない簡易プリミティブを禁止、意図したミニマルを許可**。極端に平らなデザインでも完成度は成立する。
6. **映像の意味を動作へつなぐ**。カメラの動きではなく、ショットで起きる変化をデザインする。
7. **批評と制作を分離**。作品を作った役割に自己採点だけで合格させない。人間レビュー未実施は未合格と報告する。

## アートディレクションを構成するデータ
`brief` → `direction_candidates` → `art_decision` → `frame.md` → `styleframes` → `animatic` → `motion implementation` → `review` → `release`。

### Briefに必須の要素
- 目的、誰に何を感じてほしいか、視聴デバイス、尺、画面比、音源の権利
- 世界観（例：回路が暗い街に朝をもたらす）
- 許容素材（コードのみ / 所有素材 / ロイヤリティ確認済素材 / 許諾済画像生成）
- 制約（既存の強いショット、ブランドルール、避ける表現）
- 制作後の受入者と審査の方法

### Direction候補に必須の要素
- `concept`: 1行の映像の主張
- `expression_mode`: editorial-2d / illustrated-2p5d / typography-led / 3d-authored / footage-composite / mixed 等
- `visual_metaphor`: 画面上の物体や文字が何を意味するか
- `focal_subject`: 視線の主役
- `design_grammar`: 形の輪郭、密度、余白、光、筆致、文字の関係
- `color_script`: 序盤→中盤→終盤の色変化
- `typography`: 書体、詰め、縦組み/横組みの基準、文字の役割
- `motion_signature`: 独自の動きの特徴。無関係なパーティクルは禁止
- `asset_plan`: どの素材をコード生成し、どの素材を利用するか、その権利
- `risk`: 制作コストと品質上のリスク
- `anti_patterns`: 採用しない見た目を具体的に記載

## まず比較すべき代表的な表現ルート【設計用分類】
| 方式 | 強み | 苦手・注意 | 典型的な美術上の失敗 |
|---|---|---|---|
| Typography-led 2D | 日本語歌詞、形・余白、衝撃、音との同期 | 書体選びが凡庸なら安っぽい | 字面を発光させるだけ |
| Editorial / Print 2D | 版画、紙、網点、文字の物質感 | 画面が動かずスライド化 | 一律グレイン・スタンプ乱用 |
| Illustration / matte 2.5D | 景色や感情を画として描ける | 素材制作・権利とレイヤー分離 | 1枚絵をズームするだけ |
| Cutout / collage | 手作り・不規則・記号性 | エッジ/素材の統一 | テンプレ的スクラップ |
| Pure vector abstract | 抽象、ロゴ、回路、幾何の精密さ | ストーリーが薄いと図解 | 無意味な円と線を配置 |
| Authored 3D | 光、奥行き、カメラ、立体主役 | 造形のコスト | プリミティブを並べただけ |
| Footage + motion | 現実味、人の表情、製品PR | 素材権利、補正、一体感 | テロップを上に貼るだけ |

この分類の名前・評価は本プロジェクトの提案であり、公式HyperFramesの分類名ではない。

## 3案の生成・選定手順
1. 同じBriefから3案を出す。**1案ごとに技術方式、視覚の主役、カメラ/構図の作法を変える。**
2. それぞれ1枚ずつ、同じ歌詞/意味/16:9の候補フレームを作る。`clean` と `final-look` の両方で確認。
3. スコアカードを使い、①美術の意図 ②構図 ③造形の完成度 ④文字 ⑤固有性 ⑥実現性を比較。**合計点だけで決めず、重大な失敗を先に指摘。**
4. 最も適切な案を選び、そのルールで8/16/40秒の3枚へ展開。26〜28/49秒の良さが維持できない場合は再検討。
5. 同じ美術ルールで6秒のモーション試作を出し、視覚のタイミングを検証。
6. 既存の53秒全体へ統合するのは、その後。追加の静止画・動画の大規模制作は許可を要する場合があるのでユーザーの指示範囲を超えない。

## 「安いコード背景」を予防する自動ルール
### 危険信号（自動判定ではWARN）
- 形の種類が`BoxGeometry`, `CylinderGeometry`, 直線、同一窓グリッドのみ
- 世界観の主題を抽象的な名詞（都市、回路、未来）から単純な幾何に一対一置換
- 20%以上の複数ショットが同一消失点・同一カメラ方向で、主役だけ変更
- 文字と背景が互いに影響せず、テキストがただoverlaidされている
- 美術への批評なしでシェーダー・グロー・粒子の導入が繰り返される

### 警告を無条件でFAILにしない
- 明確な意図をもったローポリ映像、抽象絵画、ミニマルな文字MVは許す。
- 3Dモデルの内部構造だけで美術の良し悪しは判定できない。
- エッジ密度や色数だけでは美的な完成度は決められない。

## 技術基盤：公式機能を再利用する
- 現行環境に `hyperframes-creative`, `design-picker`, `frame.md`, `general-video` 等があれば、二重開発禁止。
- 新規部分は `art-direction-review` という**オーケストレーション層**とし、候補・選定根拠・レビュー・差分だけ保持。
- インストール済みHyperFramesの仕様に合わせる。最新版READMEを無条件に現在環境へ適用しない。
- GSAP、SVG、Canvas、three.js等の各アダプターは既存を優先。新規導入は比較試験とライセンス確認が必要。

## 品質ゲート
- G0 現行環境の監査：`CURRENT_AUDIT.md` 完了。既存資産の破壊なし。
- G1 Brief：作品の意味、主役、避ける表現が明記。
- G2 3-way Styleframe：3案の造形差が視認でき、主観レビューがある。
- G3 Selected Lookdev：3つの重要時刻が美術として成立し、元作品より主役が明確。
- G4 Animatic：6秒の動きが楽曲や歌詞と関係しており、時刻seekが再現できる。
- G5 Integration：53秒の制作物と他ジャンルの回帰検査。
- G6 Generalization：別ジャンル2例で自律制作品質を評価する。

## 批評者の独立性
- 生成したコードの動作が正しいことは、造形の美しさを証明しない。
- Art Reviewerは意図、形、焦点、文字、反復の5点を批評し、証拠画像と秒数を示す。
- 重大な美術問題が残ったまま、完成版と呼ばない。
- ユーザーの意見と異なる場合は、具体的なトレードオフを説明して選定。無条件で賛成しない。
