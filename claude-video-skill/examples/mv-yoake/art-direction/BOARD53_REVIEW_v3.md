## 3. 残る弱点(重い順。正直に)
1. **ぼかし摺りの粒が「デジタルの砂目」に見える所がある**(S2・S4 の空の明るい側、夜明けの淡黄)。中間の濃さを紙の粒で割る式が均一なため。版木の木目は入れたが、ところどころ走査線のように見える(S2 の空の上)。直し方の案: 粒を2段(繊維の向きのある粒+まばらな大きい斑)にし、明るい側ほど粒を消す。
2. **形の手描き感がまだ足りない**: S4 の家・夜明けの中の町は手で座標を決めたが、輪郭は直線と単純な曲線で、絵本・切り絵に寄る。審査 §6 の代替案(主役の輪郭だけ人の手の SVG)を使えば上がる見込みが高い。
3. **S6 の火のまわりのクリームの縁が「シール」に見える**、墨の回路が回路図の形のまま(45 度の折れ)。溝としては彫り跡になったが、図形として記号的。
4. 夜明けの雲・霞の帯が葉巻形(太さのゆれはあるが輪郭が単調)。松の葉が放射の星形。
5. S3 の舟の船体、S8 の桁の下(脚の上半分)が黒の中で読めない(黒の上の黒)。
6. 夜明け C の太陽が大きな丸い琥珀で、霞と合わせて浮世絵の定型(と国旗の連想)に寄る。
7. S1 の節は年輪を詰めて崩したが、まだ同心円の印象が残る。

## 7. 利用者に判断してほしい点
1. S6 を「明暗を逆にした全面の琥珀」にした方式でよいか(放射の楔は旭日旗の連想が強く出たので外した)。
2. 夜の空を藍のぼかし摺りにした(S2・S3・S4)。0〜27秒の見た目が v2 の「紺の版+クリームの横線」から変わる。

4. 質感の残り(§3-1・2)を、主役の輪郭だけ人の手の素材にする方式(§4)で詰めるか。
5. 動きの本制作に進むなら、乱数の直しは済んだので、BOARD53_REVIEW_v2 §5 の 2(S5→S6)から。
