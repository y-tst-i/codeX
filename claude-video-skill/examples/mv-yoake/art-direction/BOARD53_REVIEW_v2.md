## 3. 1枚ずつの審査文(06 の型を短く)
- **S1** 第一印象: 黒い木の板に1本の白い道。良い: 木目が節をよけて流れ、刀の線が木目を横切る(回路=彫った線、をここで約束)。悪い: 節の年輪が整った楕円で、540px では「目」や水の輪にも見える。見当の印は意味が伝わりにくい。原因(コードで確認): 節の輪は楕円に ±12% のゆれだけ。最小の改善: 節を1つにして大きく、芯の黒を太く、年輪をもっと崩す。代替: 木目を刀の線でなく「杢摺り(墨のむら)」にすると木らしさは増すが、clean で消える。
- **S3** 第一印象: 夜の川に、右の町の灯りが長く揺れて映る。良い: 映りの欠片の数が距離で変わり、根元だけ琥珀で先が白い。悪い: 向こう岸の町は屋根の線の帯で、540px で読みにくい。小舟は 540px で細い線。左下と中央が大きく暗い(意図した「暗闇」だが、主役が右上に偏る)。最小の改善: 岸の空をもう少し明るく、舟をもう一回り大きく。
- **S5** 第一印象: 黒い版木に彫られかけの巨大な「火」、芯が琥珀。良い: 切り回しの白い輪郭+芯から外への丸刀で「彫っている途中」が一目で分かり、28秒の放射の予告にもなる。悪い: 琥珀を入れたので、v1 の色の流れ(S5 は琥珀 0 の落ち込み)から変わった。琥珀の量は 1.1% で 28秒(6.5%)より十分小さく、山は 28秒のまま。
- **S6** 第一印象: 大きな字と、火から出る楔の放射。良い: 刀の太さ・長さ・途中の切れが不揃いで、機械の集中線より版画の太陽の放射に近い。悪い: 長い刀が画面の右下まで届き、「を灯して」の近くが混む。放射そのものが漫画の記号である点は変わらない。代替: 放射をやめ、火のまわりを同心のぼかし摺り+短い刀の欠片だけにする(元版の「線の束が集まる」骨格は弱くなる)。
- **S8** 第一印象: 見上げた夜の高架を、灯った列車が走る。良い: 手前が大きく奥へ小さい桁と脚、不揃いな径間で、反復の印象が消えた。悪い: 脚の間の明るい水が横の帯の積み重ねで四角い塊に見える所がある。列車の窓の刀は手前で白い帯に溶ける。奥へ細る桁と窓の刀は、BRIEF_ART の避ける物「奥へ収束する光の線」に少し近い(消失点は画面の外の右で、画面の中心へ集まる形ではない)。最小の改善: 脚の間の水の刀の長さを不揃いにし、窓の刀の手前の数を減らす。
- **S10** 第一印象: 朝の空に、火の見櫓や電線の町の影、太陽と映り。良い: 太陽の上を渡る電線(町の左右をつなぐ回路)、薔薇の版だけの遠い町が太陽の前に立つ奥行き。悪い: 全部の影が同じ地平の線の上に一列で、手前と奥の重なりが少ない。水の墨の横線が均質。
- **1380 / 1430** 良い: 同じ場所で「彫り→版が増える」が順に見える。悪い: 1380 の彫りの境目の丸刀の跡は雲にも見える(彫っているのか雲なのかが曖昧)。1430 の太陽の縁は小さい。
- **1560** 良い: 題箋・印で「1枚の版画が刷り上がった」で閉じる。悪い: 題箋と印は浮世絵の型そのもので、土産物の版画に寄る危険がある。印の字「灯」は私が決めた(歌詞の中の字)。

## 4. 残る弱点(正直に、重い順)
1. **動かすときの乱数のずれ(技術、動きの本制作の前に必須)**: `dawn(f)` などは刀の配置を順番の乱数(`rng` を呼んだ順)で決めている。f で彫る範囲が変わると呼ぶ回数が変わり、**隣のコマで刀の位置が全部入れ替わってちらつく**。静止画としては決定的(§6)だが、動画にする前に、刀の乱数を位置の `hash` で引く形に直す必要がある。
2. S6 の放射は「記号としての放射」を残している(本数と形は直したが、構図の記号は同じ)。
3. S8 の脚の間の明るい水が四角く、奥へ細る線の扱いが避ける物に近い。
4. S10 の町が一列。手前の大きな影(画面の端にかかる近景)がない。
5. S3 の向こう岸の町が 540px で弱い。S1 の節が目/水の輪に見える。
6. S2・S4・S7 は v1 のまま。S3・S8 に新しく入った「明るい水の刀」と比べると、S2 の川面の刀が細かく見える所がある(並べての差は小さいと判断して触らなかった)。

## 5. 動きの本制作の作業順(案)
1. **乱数を位置の hash に直す**(cand_a4 の全カット。§4-1)。直した後、静止画の見た目がほぼ同じかを比較画像で確かめる。
2. **S5→S6(669〜864)**: 切り回しが輪郭を回る(669〜735)→ 755 で芯から粗彫り → 769 衝撃1 で彫り上がり琥珀が刷られる → 784 で「回路に」→ 812 で火が灯る、の順に、S5 と S6 の静止画を F=∞ の終わりの形として動かす。
3. **S9→S10(1340〜1590)**: `dawn(f)` はすでに f の関数。1340 衝撃3 で空を彫り始め、1400 淡黄、1415 太陽の縁(低音 0.70)、1448 薔薇、1456 字、1500 題箋。版はばれんで全面に1回で刷る(ワイプにしない)。
4. S1(0〜141): 一刀が 10・38(最強)で走り、57・85・113 で木目がわずかに彫り足される。
5. S3・S8(水の映りの揺れ、列車の窓の刀が流れる)→ S2・S4・S7 → 通し。53秒の書き出しは利用者の承認の後。
6. 1カットごとに 0.2秒刻みのコンタクトシートと 540px を作り、利用者の目視を1回。
