## 3. 各案のレビュー(06 の7項目)

### 案A「彫って灯す」
1. **第一印象(無音・1秒)**: 紙に刷った黒い版画。右の大きな縦書き「暗闇の数だけ」がまず読め、川べりの町の向こうの地平が明るい。窓が1つだけ橙。
2. **良い所**: ①右の縦書き: Shippori Mincho B1 の輪郭を刀の面(折れ線)にして彫ったので、等倍で見ると活字ではなく「彫った字」に見える(`frames/style_a_08s_look.png` 右上)。②町のシルエット: 給水塔の脚の斜めの筋交い、煙突、アンテナの横棒、切妻が、白い刀の縁で黒い空から切り離されている。箱の反復ではない。③川: 空の明るい所の真下だけ彫りが太く密になり、映り込みに見える。④clean と look の差は 15%(差が10を超える画素)で、ほとんどが紙の繊維とインクのむら。**効果に頼っていない**。
3. **悪い所**: ①琥珀の窓が小さく(46×54px の枠、540px では約 13px)、唯一の色なのに視線の終点として弱い。②空の弧が横に長い楕円になって地平の光の層に見えるようになったが、右上の細い弧は均一な間隔で「模様」に見える。③字の周りの黒(彫らない余白)が、字の列の左右で縦の帯の境目になっている(`の`〜`数` の横)。④町の建物の芯は四角(事務所・団地・アンテナの建物)。刀の縁と窓の彫りで救っているが、寄ると単純。
4. **原因**: (コードで確認した事実)①窓の大きさは `cand_a.js` の `litWindow()` の 2×2 の区切り 16〜17px。②弧の間隔は `sky()` の `rad += 10 + rad*0.016 + r()*4` で、遠い弧ほど規則的。③字の周りは `keepOut()` の線幅 34px の黒で、空の彫りを上から消している(彫りの端が刀の抜きにならず、切れて止まる)。(見た目からの推測)④四角い芯は、私が手で決めたシルエットの点列が直角中心だったため。
5. **最小の改善案**: ①窓の枠を 1.5 倍にし、色版の範囲を壁の彫りの広がりと一緒に 1.3 倍(`litWindow()` と色版の楕円)。②`sky()` の弧の間隔に低い周波数のゆらぎ(±30%)を足し、上の弧は途中で切る率を上げる。③`keepOut()` を消しゴムでなく「彫りを避けて刀を抜く」にする(弧の点列を字の周りで途切れさせ、`cut()` の抜きで終える)。④建物に屋上の小物(手すり・室外機・物干し)を2〜3個ずつ足す。
6. **代替案**: 版画の媒体を「木版」から「リノカット(白黒反転、太い刀)」に替えると力強さは増すが、細い回路の線が彫れない。「銅版(エングレービング)」に替えると線の美しさは増すが、黒が主役の「暗闇」から白地の絵に変わり、意味が逆になる。→ 木版のまま。
7. **再審査**: この回の中での改修: v1(空の中心が字と競合、窓の色版が欠けて黒い半円 = ノイズ表の範囲外参照の不具合)→ v2(空の中心を町の後ろへ、上を彫らない)→ v3(弧を横長の楕円に、地平に近いほど明るい)→ v4(窓を大きく、色版を建物の面だけに)→ v5(字の刀の面を強く、刷り残しの点を減らす)。利用者の承認: **未**。

### 案B「夜明け前の電線」
1. **第一印象**: 夜の住宅地の電柱と電線、団地の窓が2つ灯る。右の空に縦書き。よく見る絵。
2. **良い所**: ①近景・中景・遠景の明度の段(電柱と屋根が最も暗く、遠い家並みが青く明るい)で奥行きが読める。②屋根のテレビアンテナと電柱の碍子・変圧器の細部で、実在の街の物に見える。③地平の街の灯の暖色の刷毛が、夜明けの色の予告になる。
3. **悪い所**: ①固有性が弱い(§1)。②団地の板はまだ「四角い箱」で、ベランダの帯の線も規則的。③縦書きは、電線が手前を横切っても、絵の出来事(灯りが増える・線がつながる)と関係していない。④刷毛はコードの楕円の重ねで、人の描いた背景美術の筆致・情報量に届かない(特に空の上半分は均一なノイズに見える)。
4. **原因**: (事実)空の筆は 1500 本の横の刷毛を高さの色から明度だけずらしている(`cand_b.js` `sky()`)。色相・筆の大きさの層(大きい面→小さい筆)の手順がない。(推測)背景美術の質は「描き込みの密度の差(見せ場だけ細かい)」で決まるが、コードの描画は全体に均一になりやすい。
5. **最小の改善案**: ①字のある空だけ筆を大きく少なくし、地平近くだけ細かく(密度の差)。②団地を2棟にして角度を変える。③字の位置を電線の束の「つながる所」(電柱の上)に置き、字と回路を物語で結ぶ。どれも固有性の問題は直らない。
6. **代替案(方式の切り替え)**: §6。人の描いた絵(利用者が Codex で作る画像)を層に分けて使えば、筆致と情報量は上がる。犠牲: 素材づくり・権利の記録・層の分け方の手間と、決定性(画像は固定なので問題は少ない)。
7. **再審査**: v1(地平の下が黒い帯、団地の窓の格子)→ v2(地平の下を塗る、窓の格子をやめ灯る窓だけ、屋根とアンテナ)→ v3(高い電線2本が字の手前を横切る)。利用者の承認: **未**。

### 案C「暗闇の中の日」
1. **第一印象**: 夜の地平に巨大な「暗闇」の字が建っていて、字の中の「日」だけが内側から橙に灯っている。右下に小さく「の数だけ」。
2. **良い所**: ①字の解剖(暗=日+音、闇=門+音)が、説明なしに絵で分かる(灯っているのは日の中だけ)。②Kaisei Tokumin の起筆・うろこ・はらいが、巨大にしても箱にならない。③大小の差(700px と 112px)で、読む順と奥行きが同時に決まる。④clean(平らな橙)でも成立する。
3. **悪い所**: ①「暗」の左の日が全部灯ると、字の読みが「日」に引っぱられる(暗の字としての重さが減る)。②足もとの町は細い帯で、大きさの物差しとして弱い。③上の4割の空は空いたままで、暗い虚空に近い(ただし字は地に立っている)。④道の線(回路)は細くて意味が伝わりにくい。
4. **原因**: (事実)カウンター(字に囲まれた空き)は字の塗りから外を塗りつぶして求め、`SUNS` の範囲の空きを全部灯している(`cand_c.js` `counters()`・`sunHoles()`)。(推測)灯りの面積が大きすぎる。
5. **最小の改善案**: ①8秒では「暗」の日を1つだけ灯す(歌の語頭ごとに1つずつ増やす=「輝きは増す」)。②町を2段(遠い低い帯・手前の屋根)にして、窓を1つ置く。③空の上に、次の行「輝きは増す」の字を極めて薄く予告する、か、何も置かず暗闇のまま(どちらも試していない)。
6. **代替案**: 字の真上からの眺め(夜の街の灯りの道が字の形になる空撮)に替えると「文字が都市に変わる」に近づくが、初稿 16 秒の真上の盤と語彙がかぶる。
7. **再審査**: v1(Dela Gothic One+階の線+窓の点 → 読めない・箱のビル)→ 改修1(地平の空を明るく → 読めるが箱の印象)→ 改修2(書体を Kaisei Tokumin に、階の線と窓をやめ、カウンターだけ灯す → 成立)。`frames/process/c_local_fixes.png`。利用者の承認: **未**。

## 5. 推薦: 案A(木版画)+ 案C の「字の中の日」を色版の使い道として取り込む
**理由**
1. **歌詞の主張が媒体の規則と一致する**: 「暗闇の数だけ 輝きは増す」=彫るほど明るい。夜→朝を「版木が彫り取られて紙が現れる」1本の規則で53秒通せる(`frames/color_shape_script_A.png`)。B は色の時間変化に、C は1つの仕掛けに頼る。
2. **初稿の失敗の原因を構造で避ける**: 箱・窓の格子・光の線の総量・グローの代わりに、刀の跡の向きと太さで光と形を作る。clean でも絵が残る(他の2案より look との差が質感だけに限られる)。
3. **26〜28秒・49秒とつながる**: 色版は「燃える物に1色だけ」の規則なので、8秒の窓 → 28秒の「火」 → 49秒の2版目の薔薇色、と色の出番が曲の山と一致する。
4. **案C の強み(字の解剖)を取り込める**: 案A の彫った字の「日」の内側にだけ色版を刷る(28秒の「火を灯して」、49秒の「夜が明ける」の「明」の日)。C 単独より53秒で使い回しが効く。
5. 実装・権利が最も軽い(コードのみ、外部素材なし、決定性確認済み)。動きも媒体から決まる(彫られて現れる・刷られる・版ずれの切り替え)。

**他の案と違って良い点**: B と違い作品固有の規則がある。C と違い1枚の仕掛けで終わらず、世界(町・川・空)を持てる。
**弱い点(正直に)**: 1枚の版として強いぶん、似た横長の版が続くと単調になる。26〜28秒の「回路に」は初稿の強い文字の構図(字の面に回路を刻む)を、彫った字+色版に置き換えることになり、初稿の良さ(巨大な文字の迫力)を保てるかは描いて確かめる必要がある。
