## 1. 2.5D の比較試験(最初にやった。結果: **採用。ただし3カットだけ**)

### 1-1. 作り方
- **Canvas 2D の層ごとの平行移動・拡大だけ**(`src/cand_a7_cam.js` の `A7_CAM`)。CSS3D・three.js は使わない(資料 02 §6・03「両方を無条件で統合しない」。今の絵は1枚の canvas に版のマスクと色版を描いてから画素ごとに刷る作りなので、DOM の 3D 変換に載せ替えると刷りの層が使えない)。
- 投影: `x' = fx + (x − fx)(1 + push·z) + pan·z`(y も同じ)。z = 0 は無限遠で動かない、z = 1 が最も手前。係数は `RESEARCH_2D_DIGEST` の試験値(遠 0.12/中 0.35/主 0.70/前 1.00)をそのまま使った。
- **焦点を地平の上に置く**(夜明け A は鉄塔の根元 (1017, 700))→ どの層でも地平の線は上下に動かず、層の継ぎ目が地平で割れない。
- **層をまたぐ物は点ごとに z を変えて投影**(電線・信号の道は 1.0 → 0.35、S8 の桁・列車・橋脚は x で 1.0 → 0.25、S8 の水は y で 0.12 → 0.9)。これで「薄い板が何枚か重なって滑る」紙人形風にならず、1本の線・1本の桁の中で遠近が連続する。
- **刷った紙はカメラに固定**: 紙のスキャン・ばれんのむら・墨の木目は `print` の画面座標のまま(毎コマ新しく刷った紙で、刷った紙そのものは動かない)。版木のふち(額縁)も動かない=版木の窓の奥で絵が動く。
- **字**: 原則カメラに固定(S4 の空の字・「繋がってく」、S8 の「止まれない」)。S8 の「止まらない」だけは桁の腹に彫った字なので桁と一緒に動かす(意図: 止まらない物の上に書いてある)。
- カメラの状態はコマ番号だけで決まる(`A7_CAM.set` をカットの関数がコマごとに呼ぶ)。切ると恒等変換で、第1段の画素と同じ(1340 の cam 0/1 の md5 一致で確認)。
- registry: `npx hyperframes catalog --tag camera`・`--query parallax` を確認。`camera-dolly-zoom`・`camera-rig-depth-stack`・`parallax-zoom`・`scroll-camera-story` などは DOM 要素(カード・レイヤー)に CSS の 3D 変換を掛ける部品で、1枚の canvas に画素ごとに刷る今の作りには載らない。ドリーズームの「距離×tan(画角/2)=一定」のような考え方だけ参考にし、コードは流用していない。

### 1-3. 判定(自分の目で、0.2 秒刻みと 540px と等倍で見た)
| | 夜明け A | S8 |

**結論: 採用。ただし「信号(つながり)を追い、届いたら止まる」動きとしてだけ使う。**

### 1-4. 採用のルール
1. **使うカット(3つ)**: 夜明けの構図 A(押し込み)、S4 の「繋がってく」(横移動。下)、S8(横移動、止まらない)。
2. **動かす理由と止まり**: カメラは信号・溝の行き先へ動き、**届いたコマで止まる**(夜明け A 1402・S4 652)。S8 だけは歌詞が「止まらない」なので最後まで止まらない(唯一の例外)。
3. **拍**: 動き始めはカットの頭の衝撃・灯りの直後(1341・500)、止まりは届いた事象のコマ。動きの途中の拍は、彫り・刷りの方が担う(カメラは拍に合わせて揺らさない)。
4. **層と量**: 遠 0.12/中 0.35/主 0.70/前 1.00。押し込みは前景 6% まで、横移動は z = 1 で 120〜170px まで(1コマ 2px 以下)。傾き・ズーム・横移動は同時に使わない。
5. **字**: カメラに固定が原則。物に彫った字(S8「止まらない」)だけ物と一緒に動かす。
6. **使わないカット**: 字が主役の平らな版(S1・S5・S6・S7・S9)、決めの絵を読ませる所(夜明け B「明」、C の題と余韻)、S2・S3(灯が増えることが主役。カメラが動くと灯の数の変化が読みにくくなる)。
7. **紙・刷りの層はカメラに固定**。版木のふち(額縁)も固定。
8. 刀の入れ替わり(ちらつき)の検査は cam=0(層を止めた同じ絵)で測る。カメラの動きは別に、1コマの移動量(式から)で見る。
