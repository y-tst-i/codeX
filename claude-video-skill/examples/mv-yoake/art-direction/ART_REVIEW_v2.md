## 5. 各フレームのレビュー(06 の7項目)

### 8秒 f240(A+C)
1. **第一印象(無音・1秒)**: 紙に刷った黒い版画の夜の川べりの町。右の縦書き「暗闇」の字の中に橙の四角が2つ見え、町の真ん中の建物の窓が橙に灯っている。
2. **良い所**: ①「暗」の日偏と「闇」の門の中の日だけが琥珀(`style_ac_08s_look.png` 右上)。字は紙の色のまま形が変わらないので、読みは「暗闇」のまま、意味だけ足される。②窓は十字の桟が 540px でも読め(`check_540_v2.png` 右上)、照らされた壁の彫りに色版が乗って「灯り」になった。③空は平たい弧の筋になり、左上は暗闇に溶ける(初版は画面いっぱいの同心円)。
3. **悪い所**: ①琥珀が3か所(字の日2・窓)になり、0.5秒の焦点が字の日に寄る。窓が「視線の終点」として勝つかは利用者の目で確認したい。②地平の右側(窓の右〜字の列の左)は、平たくしても弧が下へ曲がって集まり、放射の線にまだ見える。③町の建物の芯は初版のまま四角(今回は直していない)。
4. **原因**: (コードで確認した事実)①色版の面積は 0.19% → 0.60%。字の日2つで 0.3% 近く、窓より大きい(`sunPlate()` と `WIN[4].plate`)。②右側の下がる弧は、楕円の端(角度 2π 付近)を `steep` で間引いても、中心に近い小さい弧は端が地平に近く明るいので残る(`sky2()`)。(推測)③は初版の審査と同じ(手で決めた点列が直角中心)。
5. **最小の改善案**: ①闇の中の日を U1 の版(暗の日偏だけ)に戻すか、字の日の色版の濃さを 70% にする(`letterPlate` の塗りの不透明度)。②楕円の端の角度を `a ∈ [π+0.25, 2π−0.25]` に限る(弧の本数は同じ)。
6. **代替案**: 字の日を「刷る」のでなく、日のカウンター(内側の空き)を細く彫って刷る(C の灯り方に近い)。字の中が光って見えるが、字の重さが減り、C で起きた「暗が日に読める」危険が戻る。
7. **再審査**: A初版 → 窓5案・空3案・日2案を比べて W4/S2/U2(`frames/process_v2/`)。v2 のコードで初版の値(win=0&sky=0&sun=0)を描くと初版と同じ md5(§7)。利用者の承認: **未**。

### 16秒 f480「ひとつ、またひとつ」(A+C、新規)
1. **第一印象**: 夜の坂の町。2軒の家の窓が橙に灯っていて、窓と窓が白い線でつながっている。空に「ひとつ、/またひとつ」。
2. **良い所**: ①字の段差と窓の位置が対応する(「ひとつ、」の下に窓1、「またひとつ」の下に窓2)。歌の語の数=灯りの数。②窓1 → 斜面 → 窓2 の線と、窓2 から右へ彫りかけで止まる線(刀の抜き)で、次の「繋がってく」(540コマ)を予告する。③尾根の逆光の横の筋で、家が黒いシルエットとして立つ(屋根の光の側に瓦の筋、右の壁に短い横の彫り)。④窓は 2×2 と 1×2 で大きさも区切りも違う(格子にしない)。
3. **悪い所**: ①左下の約1/4が彫りの無い黒。②家は五角形の輪郭が単純で、寄ると箱に近い(白い枠をやめて救っている)。③彫った割合が 8秒より低い(§1)。④石段(`stairs()`)は線に重なって見えない。
4. **原因**: (事実)①斜面の彫りの明るさは `smooth((x − 150)/1500)` で右ほど明るく、左は下限 `0.5·(1 − dy/380)` しか無い。②家の形は `housePoly()` の 7 種類の点列のみで、軒の出・下屋・戸袋などの部品が無い。③空の明るさの中心(`GLOW`)が右端にあり、画面の大半は弱い。(推測)「近くの町」にしたので、8秒の川のような大きな明るい面が無い。
5. **最小の改善案**: ①斜面の左下に、坂を下りる道(白い刀の帯1本、幅 10〜18px)を彫る=暗い面を分け、彫りの割合を上げる(目標 12% 以上)。②家に軒の出(屋根を壁より 8〜12px 張り出す)を足す。③石段は消すか、線と離す。
6. **代替案**: 斜面をやめ、坂の上から見下ろす(屋根の連なりを上から)構図にすると、屋根の瓦の彫りで明るい面が増えるが、初稿 16秒の真上の盤と視点が近くなる。
7. **再審査**: v1(家を白い枠+黒で並べた → 浮いた箱+点の窓に見えた)→ v2(白い枠をやめ光の側の縁だけ、土台を斜面に埋め、尾根の逆光)→ v3(空と斜面の彫りを強め、窓の光を広く)。利用者の承認: **未**。

### 40秒 f1200「まだ、」(A+C、新規)
1. **第一印象**: ほぼ真っ黒の版。右寄りに大きな縦書き「まだ、」、読点だけ橙。下に町の屋根の輪郭が細く見え、読点から1本の細い線が屋根へ落ちている。
2. **良い所**: ①色版が読点だけ(0.06%)。最も黒い版の中で、1つだけ燃え残っている(歌詞「光は消えない」の直前の「まだ、」)。②読点から真下の屋根へ落ちる1本の線と刺した丸(ビア)で、「切れていない回路」を1本だけ残す。③町は 8秒と同じ給水塔・煙突・のこぎり屋根で、灯りが全部消えた同じ町と分かる(韻)。④clean では空の細い線の中間調子に対して町が黒い塊で立つ(`check_540_v2.png` 右下)。
3. **悪い所**: ①look では町の縁が細く途切れ、540px で弱い(§1)。②空の細い線が、刷りのかすれで点線になり、走査線や雨に見える。③左上の大きな黒の意味は、絵だけでは伝わりにくい。
4. **原因**: (事実)look の刷りは、彫りのマスクを 0.9px ぼかしてから、閾値をノイズ(±0.21)で揺らす(`print()`。8秒と同じ関数)。幅 1.3〜2px の刀はこの処理で途切れる。町の縁の幅は 1.0〜3.8px(`rim()`、線の落ちる所から遠いほど細い)。(推測)8秒・16秒は刀が太いので同じ処理で問題が出ないが、40秒は細い刀だけでできているので刷りの質感の影響が大きい。
5. **最小の改善案**: ①空の細い線と町の縁の最小幅を 2.2px に上げる(刷りで消えない幅)。②町の縁は線の落ちる所から遠くても途切れさせない(今は 10% で抜く)。
6. **代替案**: 「暗い中間の調子」を細い線ではなく、版木の木目(刷りの濃淡)で出す=空を彫らず、刷りのインクを薄くする。木版の規則(黒は彫り残し)からは外れないが、clean では消える(FX OFF で町が見えなくなる)。
7. **再審査**: v1(遠い町の細い輪郭線だけ → 心電図の波形に見えた)→ v2(近い町の上の縁だけ → 虚空に線が浮く)→ v3(空を細い線の中間調子に、町を黒い塊に)。利用者の承認: **未**。

## 8. 2度の局所改修で改善しない点 → 方式の切り替え候補
- **40秒の町(3版作って、look で弱いまま)**: 細い刀だけで町を立たせる方式に限界がある。切り替え候補: ①町の手前に川か広場の大きな彫りの面を入れ、黒い町を手前の明るい面で立たせる(8秒の構図に近づく危険)②**町を描かず、字と読点と1本の線だけの版にする**(暗い虚空の危険を、字の大きさで受け止める。初稿 40秒の「まだ、」の良さ=余白を保つ)③細い線の刷りの処理だけ変える(look の閾値のノイズを、細い刀では弱める)。推薦は③(最小)→ それで駄目なら②。
- **16秒の彫りの割合(2回強めても 8.4%)**: 「近くの坂の町」という構図では明るい大きな面が作りにくい。切り替え候補: 坂の下に川か道の大きな彫りの面を入れる(§5-16 の①)、または窓の数で明るさを語り、彫りの割合の規則を「16秒では色版が増える」に読み替える(規則の変更なので利用者の判断)。
- 8秒は2つの局所改修(窓・空)で改善が目で分かるので、方式は替えない。
