# BRIEF_ART — 『夜明けの回路』8秒付近の美術ブリーフと3つの美術方向(Phase 1)

対象: 曲の 53 秒区間の **240 コマ(8.0 秒)**。歌は「暗闇の数だけ」(141〜291 コマ。「だけ」の語頭 238)、次の行「輝きは増す」は 291 から。初稿の同じコマ: `frames/baseline/yoake_f0240.jpg`。
機械可読の版: `CANDIDATES.json`(資料の `validate_art_packet.py` で検査済み)。描いた絵: `frames/style_{a,b,c}_08s_{clean,look}.png`、審査: `ART_REVIEW.md`。

## 1. 作品が感じさせたいこと(1文)
**暗闇は光を消すものではなく、光を数えられる場所で、切れた線を自分の手で一本ずつ繋ぎ直した先に、朝が来る。**
(歌詞「暗闇の数だけ 輝きは増す」「ひとつ、またひとつ 繋がってく」「夜明けの回路に 火を灯して」「まだ、光は消えない」、企画にある歌詞の外の言葉「切れたはずの配線を 指でなぞって 繋ぎ直す」から。)

8秒の役目: 歌が始まって最初の主張。**「暗闇が多いほど、光が増える」という逆説を1枚で見せる**。光はまだ少なく、数えられるほど。

## 3. 3案の作り方の決め方
- 設置版 HyperFrames の `story.md` §2(3案は world / device / form の違う3本の映画。1つは自分なら選ばない大胆な案)と、`spec.md`「A look built from a medium」(見た目はパレットではなく、1つの媒体の部品の規則)を使った。
- 資料の例(A 光の版画 / B イラストの 2.5D / C 文字が都市)をそのまま使わず、**意味の違いを先に決めて、媒体はその意味から選んだ**。
- 前回の第1段階の3案(`../BRIEF.md` §4: 蛍光版画 / 光跡と黎明 / 余白の墨)は、主役も構図も同じ「光の線が字をなぞる」で、違いは色と質感だった。しかも B しか描かなかった。今回は**主役・構図・造形の方式・書体を全部変え、3案とも描く**。

| 資料の例 | 採否 | 理由 |
|---|---|---|
| A エディトリアル・光の版画 | **置き換えた → 案A「彫って灯す」(木版画)** | 「光る線」を版画に載せると、結局グローの線になる。木版は「黒=彫り残した版木、白=刀で彫った所」で、**彫るほど明るくなる**。歌詞の「暗闇の数だけ輝きは増す」が媒体の規則そのものになる(意味から媒体が決まる) |
| B イラスト背景の 2.5D 映画美術 | **採用して具体化 → 案B「夜明け前の電線」** | 回路を「基板の模様」ではなく、街に実際に張られている配線(電柱・電線・変圧器)に置き換えた。実在の物で回路を言い換える案 |
| C 文字が都市に変わる | **採用して作り替えた → 案C「暗闇の中の日」** | 「字画が道になる」は図解になりやすい。字の解剖に意味を見つけた: **暗 = 日+音、闇 = 門+音、音 = 立+日。暗闇の字の中に、もう「日(太陽)」と「音」が入っている**。この作品でしか成り立たない |

## 4. 3つの美術方向

### 案A「彫って灯す」— 木版画(凸版)の夜
- **expression_mode**: editorial-print-2d(木版画)
- **一言**: 夜は彫る前の黒い版木。光は、刀で暗闇を彫り取った跡にだけ生まれる。
- **視覚の主役・象徴物**: 版木に彫り込まれた縦書きの歌詞「暗闇の数だけ」と、そこから土手を伝って町の一つの窓へ彫られた1本の線(回路)。その窓だけに色版(琥珀)が刷られる。
- **余白・シルエット・形・筆致・色の物語**: 余白は「彫り残した黒」。町は箱ではなく、給水塔・煙突・アンテナ・切妻・団地の段で輪郭に意味を持たせ、刀の白い縁で黒い空から切り離す。空は地平の下の一点(49 秒の太陽の位置)から横長の弧で彫り、地平に近いほど太く(明るく)、上は彫らない(暗闇)。川面は空の明るさを映す横の彫り。刀の跡は入りが鈍く、抜きで細る(`references/styles/lemo/woodcut.md` §2)。色は黒と紙の2値+燃える物に1色だけ(8秒は1つの窓、28秒は「火」、49秒で初めて2版目の薔薇色)。
- **タイポグラフィのルール**: Shippori Mincho B1 ExtraBold(800)。理由: 明朝体は木版の彫りから生まれた書体で、横画が細く縦画が太い彫刻刀の論理を持つ。字の輪郭を折れ線にして(刀の面=ファセット)版木に彫る。縦組み、「暗闇」を大きく(170px)、「の数だけ」を小さく(122px)。字の周りは彫らずに黒を残し、字を立てる。文字は版の一部で、上に重ねない。
- **視線経路**: 右の縦書き(最も明暗差が大きい)→ 下へ「数だけ」→ 字の足もとの丸い彫り(ビア)から土手の線を左へ → 唯一の色(琥珀の窓)。
- **自己批評(実装しやすいから選んでいないか)**: 木版の質感を「画素の後処理(粒・むら)」で足すだけなら、それは安易な効果。この案では**彫りの量・向き・太さを形と光の規則として描き**、後処理(インクのむら・木目・版ずれ)は look だけ。clean でも絵が成立するかで確かめる。危険: 同心の弧が「レコードの溝」の模様に見える(初回の描画で起きた。楕円にして地平に沿わせ、上を彫らないで直した)。
- **エンジン/素材・費用・権利**: Canvas 2D(彫りのマスク → 紙とインクに刷る画素の処理)。外部素材なし。書体 OFL-1.1。動き(Phase 4)は「彫られて現れる」「刷られる」「版ずれ」で、GSAP の止めたタイムラインの時刻から描ける(woodcut.md §5)。費用: 低〜中。

### 案B「夜明け前の電線」— ガッシュ画の背景美術(2.5D の層)
- **expression_mode**: illustrated-2p5d
- **一言**: 街の本当の回路は、電柱から電柱へ張られた電線。暗い窓を数える夜に、灯っている窓は2つ3つしかない。
- **視覚の主役・象徴物**: 手前の太い電柱(腕木・碍子・変圧器・足場ボルト)と、そこから右へ遠ざかる電線の束。中景の団地の灯った窓。
- **余白・シルエット・形・筆致・色の物語**: 空が画面の6割(余白)。近景(電柱・屋根)は最も暗い群青の黒、中景(団地)は一段明るく、遠景の家並みは空気で青く明るい(空気遠近)。筆致は横の刷毛(かすれ・端の細り)と、形の中の刷毛のむら。地平の街の灯の反射だけが暖色(朝の太陽より先にある人の灯り)。屋根のテレビアンテナ=街の小さな受信の回路。
- **タイポグラフィのルール**: Zen Kaku Gothic New Medium(500)。理由: 街の掲示・駅の案内の静かなゴシック。絵が主役なので、字は細めで字間を広く(1.2)、空の層に置き、高い所を渡る電線が字の手前を横切る(字が絵の奥行きの中にある)。
- **視線経路**: 左の電柱の暗い縦の塊 → 電線に沿って右へ → 空の縦書き → 電線を下って団地の灯った窓。
- **自己批評**: 「アニメの背景で見る、電柱と夕暮れ」の定番に寄る危険が最も大きい(固有性が弱い)。コードの刷毛は「デジタルのイラスト」に見え、人の描いた背景美術の情報量(光の回り込み、細部の描き込み)には届かない。文字は電線が横切っても「空に置いた字幕」に近い。
- **エンジン/素材・費用・権利**: Canvas 2D の刷毛(コードだけ)。足りない所は**利用者が Codex で作る背景画像の指示文**(`ART_REVIEW.md` §6)で補う案を出した(実行はしない。使うなら生成物の権利・利用条件を台帳に記録)。動きは層の控えめな視差と、窓の灯りの増減。費用: コードだけなら中、画像を使うなら素材づくりと層の分け方が重い。

### 案C「暗闇の中の日」— 字の記念碑(タイポグラフィが主役)
- **expression_mode**: typography-led
- **一言**: 暗闇という字の中には、もう太陽(日)が入っている。
- **視覚の主役・象徴物**: 地平に立つ巨大な「暗闇」の字(夜の記念碑)。字の中の「日」の内側(カウンター)だけが内側から灯る。続く「の数だけ」は遠い街並みとして小さく霞む。足もとには小さな町(大きさの物差し)。
- **余白・シルエット・形・筆致・色の物語**: 上の4割は暗い空(暗闇)。字は字形のまま変形せず、空より暗いシルエット。明るい所は「日」の中だけ。色は群青の夜+琥珀の「日」の2色。1本の細い道(回路)が遠い「の数だけ」の足もとから手前へ来て、「暗」の日の下で止まる(0/45/90度の折れ、ビアの丸)。
- **タイポグラフィのルール**: Kaisei Tokumin ExtraBold(800)。理由: 明朝の起筆・はらい・うろこが、巨大にしても「箱」にならない輪郭を作る(極太ゴシックで作った初稿は箱のビルに見えた)。横組み、大小の極端な差(700px と 112px)で読む順と奥行きを作る。
- **視線経路**: 巨大な2字 → その中の灯った「日」→ 右下の小さな「の数だけ」→ 足もとの道。
- **自己批評**: 最初は Dela Gothic One の極太で字を「ビル」にし、階の線と窓の点を足した → **初稿と同じ「箱のビル+点の窓」に戻った**(`frames/process/c_local_fixes.png`)。字の意味(日・音)は強いが、1枚の仕掛けとして強いぶん、53 秒を通すと同じ手が繰り返しになる危険。
- **エンジン/素材・費用・権利**: Canvas 2D(字形の点列、カウンターは塗りから求める)。外部素材なし。書体 OFL-1.1。動きは「日」の灯りの増減・字の出現(建つ)・道の線。費用: 低。

## 5. 3案が「色違い」ではないことの確認
| | 案A | 案B | 案C |
|---|---|---|---|
| 主役 | 彫られた歌詞+1本の彫りの線+1つの色の窓 | 電柱と電線(実在の物) | 字そのもの(字の中の日) |
| 造形の方式 | 彫り(マスク)→ 刷り | 刷毛の筆致+層 | 字形の塗り+カウンター |
| 構図 | 横長の版。町は左、字は右、川が下 | 低い視点、左の縦の柱から右へ遠ざかる線 | 正面の立面。下 2/3 に巨大な字 |
| 書体 | Shippori Mincho B1 800(彫る) | Zen Kaku Gothic New 500(街の字) | Kaisei Tokumin 800(記念碑) |
| 組み方 | 縦1列、大小 | 縦2列、字間広め | 横、極端な大小 |
| 色 | 黒+紙+琥珀1版 | 群青の層+暖かい窓 | 群青+琥珀の「日」 |
| 光の表し方 | 彫った量(形) | 塗りの明暗(空気遠近) | 字の内側だけ |
