## 3. 共通の動きの仕組み(`cand_a7.js` の MO)
- **フレーム番号だけで決まる関数**: `A7_DRAW(ctx, {f, look})`。乱数は v6 と同じ位置の hash(PR)で、引く順番も v6 のまま(時刻は別の hash から決めるので絵は変わらない)。`Math.random`・`Date.now`・前のコマの状態は不使用。
- **v6 との同一性**: `cand_a7.js` は v6 の共通部品の写し+追加で、同じ引数なら同じ画素(`?legacy=1` で f60・240・370・950・1430 の md5 が v6 のページと一致)。カットの最後のコマ(紙の取り替えを切った `sheet=0`)と v6 の静止画の比較: **S1 は md5 一致**、S2 1.01%・S3 0.68%(足した空の筋の分)、S4 2.45%(空の筋・「繋がってく」・3つ目の窓・溝②の太さ)。
- **動きの語彙は3つ**: ①彫る(刀・溝は全部を描いた形のうち刃先が通った所だけ出す=`cutT/cutP`・`grooveT/grooveP`・`lensT/lensP`・`wedgeT`。字は粗彫り→仕上げの帯=`carveT`、空の上の字は色版を彫り抜く=`holeT`)②刷る(ばれんの1回で 0/1 に刷る=`baren`。透明度の時間変化は無い)③刷り替え・版ずれ。フェード・グロー・粒子・カメラ移動は使っていない(B の太陽も段で刷り直すだけで滑らせない)。
- **6秒試作の残課題の対策**:
  1. 中ほどの静止 → 空の筋(藍の版を細い刀で少しずつさらう `skyStreaks`)、節のまわりの木目、坂の面の刀、影の中の白い刀をアクセントごとに1本、夜明けでは雲を横の刀でさらう・水の光の刀・光の縁を彫り足す。**ただし区間 A の後半はまだ足りない(§5-1)**。
  2. 粗彫りのバーコード縞 → 帯の幅を島ごとに ±25% 揺らし、帯を島ごとに少し斜めに(傾き ±0.18)。帯の本数も字の大きさで変える。
  3. カットの移り → **新しい紙に刷り替える**: 紙のスキャンを左右・上下に返した別の紙(`sheet` 0〜3)+色版をばれんで刷る(頭のコマで 62%、次で 92%、その次で刷り終える。インクの乗りのむらは付けない=最初に付けたら雪の粒に見えた)。版ずれは **1340 の衝撃だけ**(墨の版だけが紙と色版から 14px → 6px → 0)。
- カット境界は `audio/cues.json` のショット表(S1 0 / S2 141 / S3 291 / S4 409 / S5 669 / S10 1340)。夜明けの中の構図の切り替えは A 1340 / B 1431 / C 1520(v6 は B が 1460。歌詞「夜」1431 で字を出すため語頭に合わせた)。
- 時刻はコマ番号を直書きせず、`motion1/tools/gen_timing.py` が `audio/lyric_timeline.json`・`audio/sync_map.json`・`audio/cues.json` から作る `M1_TIMING` と規則(「語頭+20〜次の語頭の手前の最強のアクセント」など)で決める。例外は統括の指定 1402(信号が鉄塔に届く)と、構図 C の頭 1520。
