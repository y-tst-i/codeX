## 6. 自己レビュー(06 の7項目。動き)
1. **第一印象(無音・1秒)**: 黒い版木に白い線で彫られた夜の川べりの町。右上で字が刀で彫られていく。
2. **良い所**: ①字が「彫られて現れる」: 粗彫りの帯の間に細い黒が残り、2〜3コマ後に仕上げで消える(`events_zoom.png` 上段の前)。フェードで出る字とは別物。②日の色版が、ばれんの1回で上から下へ、むらを残して乗る(189〜192)。③琥珀を時間差で出した: 字の日(189)→ 84コマ後に線が窓へ届き(264)→ 窓を彫り(265)→ 窓に刷る(273)。視線は「字の日 → 線 → 窓」の順に動く設計。④283 の一撃で空が地平から外へ彫られ、291 で同じ筋が太る(本数は増えない)。⑤FX OFF でも全部残る。
3. **悪い所**: ①**中ほど(曲 194〜250、約2秒)は、字の彫りと町の小さい刀だけで、画面の左2/3がほとんど止まって見える**(汎用の静止の検査で FAIL)。歌は長く伸ばすブリッジなので「間」とも言えるが、「字だけが動く」に寄る危険がある。②粗彫りの帯が等間隔なので、3〜4コマの間、縦縞(バーコード)に見える瞬間がある。③版ずれ(319・320)で、窓の桟が白く戻り、琥珀が右の壁に乗る。「次の刷り」より「刷り損じ」に見える可能性がある。④8秒の静止画の弱点(町の芯の四角さ・右側の弧の集まり)はそのまま。⑤180(0.72)のアクセントで何も起きない。
4. **原因**: (コードで確認した事実)①町の光の側の刀は幅 1.4〜3px、窓は 9〜15px で、画面に対して小さい。空の明るい筋は 283 まで出さない設計。②帯の幅は島の幅を 14px で割った等分(`letterPlan`)。③版ずれは色版だけを動かす(`print()` の shift)ので、桟の上の琥珀が外れる。(推測)③は動画で 2コマなので、通しで見ると一瞬の揺れにしか見えないかもしれない。
5. **最小の改善案**: ①間を残すなら `holds.json` に理由つきで登録する。埋めるなら、空の中くらいの明るさの筋(tone 0.3〜0.55)を 198〜250 に少しずつ彫る(283 の一撃は残す)。②帯の幅を島ごとに ±25% 揺らし、帯の向きを島の形で斜めにもする。③版ずれを「色版だけ」から「墨版ごと 2px+色版 7px」にする、または版ずれをやめて 321 の次のカットで新しい紙を刷る。
6. **代替案**: 字を粗彫りなしで「刃先が字の画をなぞる」彫り方にすると縞は消えるが、字形のデータに筆順が無いので、輪郭を回る彫りになり「なぞり書き」に近づく(初稿の「光が字をなぞる」に戻る危険)。
7. **再審査**: この回で直した点 → 空の一撃が町の陰で見えず 286 にずれた(初稿)→ 見える筋を 283 に揃えた。色版が刷るコマの1コマ前に少し乗っていた → 直した。利用者の承認: **未**。

- **採用した技術**: Canvas 2D(静止画と同じ彫りのマスク→刷りの画素処理)を HyperFrames の canvas に、止めた GSAP のタイムラインの時刻と `hf-seek` から描く。刀の跡は「刃先までの帯」(幅の式は全長で決め、伸びても形が変わらない)。字は島ごとの粗彫り→仕上げの帯をその島の輪郭で切り抜き、最後に字全体で切り抜く(カウンターを彫らない)。色版はばれんの進みとむらで 0/1。時刻は歌詞とアクセントの表から規則で決める。音は書き出し後に ffmpeg で切り出して付ける。WebGL・シェーダー・粒子・グローは使っていない。
- **motion-prompt**: スキルを呼び、ギャラリーを「文字 書き順 なぞる」「stamp print press ink」「wipe reveal mask」で検索した。候補(#006 タイプライター、#005 マスクリビール、#045 ワイプ、#133 テキストマスク など)は、木版の工程(彫る・刷る・版ずれ)と合わず、ワイプ・マスクは提案の禁止事項(フェード・カメラだけの変化)に近いので、**使っていない(ギャラリー由来の動き 0 件)**。動きは全部この作品の工程から作った。
- **改善できた点**: 静止画の版を壊さずに動かした(最後のコマが静止画と差 0)。字が語頭で彫られ始め、+5〜+9 コマで読める。琥珀3か所を 84 コマの時間差で出し、8秒の静止画の「焦点が字の日に寄る」問題を順番で解いた(視線の実測ではなく設計と目視)。強いアクセント 189・255・265・274・283・291 に 0〜1 コマで合った。40秒の細い線のかすれ。
- **改善できなかった点**: 中ほどの静止(§6-3①)、粗彫りの縞の機械っぽさ、版ずれの見え方、40秒の町の弱さ、180 のアクセント。
- **未検証**: 利用者の目視と耳(美術・音ハメの最終判断)。独立した審査役の判定。スマホの実機(540px の縮小で代用)。53秒の中に戻した時の前後のつながり(前の間奏 S1 と、次の 321 以降)。HyperFrames の `--docker` での書き出し(ローカルの Chrome のみで確認)。「暗」141・「輝きは増す」291 の時刻(要確認のまま)。
