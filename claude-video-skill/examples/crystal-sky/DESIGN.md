# 水晶の空(Crystal Sky)— 設計書と cue 表

20.000s / 600f / 1920x1080 / 30fps。three.js 1本(`proj/index.html`)で全カットを描く。音楽 96BPM・4拍子(1拍 0.625s = 18.75f、1小節 2.5s = 75f、8小節)。
映像は1本。音は M1(荘厳)と M2(冒険的)を差し替えて W版・R版を作る。両方とも 10.000s に最大の一撃、最後は長い余韻(測定: 10.00s で約 +10〜12 dB の立ち上がり、19.5s 以降は -40 dB 以下へ減衰)。

## BIBLE(共通ルール)
- 世界: 夜明けの空。雲海(高さ y≦0)の上に浮遊島群、中央の「祭壇の島」の上に巨大な水晶(高さ約24)が浮かぶ。人物は出さない。
- 既存作品の名前・ロゴ・紋章・曲は使わない。魔法陣の文字は乱数で作った架空の記号(意味なし)。タイトルは「水晶の空」と小さな「CRYSTAL SKY」のみ。
- 色: 前半は青紫の空+桃色の地平(夜明け)、水晶はシアン。山場は白〜水色の光。後半は金色の朝。
- 光: 太陽は水晶の向こう側(逆光)。発光体は HDR(色×4〜10)で Bloom の閾値を超えさせる。
- 技術: 時刻 t の純関数 `update(t)`。乱数は mulberry32 の seed 固定。post = DoF(32タップ)+ Bloom + 色補正 + **GTAO**(全カット)。`composer.render(0)`。rAF・Clock・Date は使わない。仕上げのグレインは ffmpeg。
