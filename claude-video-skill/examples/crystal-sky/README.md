# 水晶の空(Crystal Sky)— 20秒の3D音楽PV風映像

three.js の本物の3D(浮遊島・巨大な水晶・雲海・魔法陣・光の柱・紋章)。Bloom / DoF / GTAO、全コマが時刻 t の純関数(seek 安全)。人物なし。既存作品の名前・ロゴ・曲は使っていない。

- `DESIGN.md`: 先に作った cue 表(2.5秒の区切りと 10.000秒のヒット)と共通ルール。
- `proj/index.html`: シーン本体(HyperFrames)。`proj/assets/post.js` はスキル同梱版に `aoFar`(遠く・霧の中の AO を弱める)と NaN/Inf の除去を足したもの。
- `make_audio.py`: 曲に効果音2つ(風・ガラスの響き)を重ね、-14 LUFS にして映像に載せる。
- `crystal-sky_W_v2.mp4`(M1 荘厳)/ `crystal-sky_R_v2.mp4`(M2 冒険的): 同じ映像で音だけ違う2本(v2 = 島を作り直した版)。v1 の mp4 はリポジトリから外した(git の履歴には残っているので、古いコミットを取り出せば見られる。その分リポジトリの容量は減らない)。
- `cues.json`: 同期の測定用の合図(秒)。

## 作り直す手順
```bash
bash ../../tools/fetch_three.sh proj/assets      # three 0.181.2(リポジトリには入れていない)
cp ../../tools/assets/gsap.min.js proj/assets/
cd proj && npx hyperframes render --workers 1 --output ../out/video_raw.mp4   # ソフトウェアGLで約 1 時間(v2 は 59分50秒)
cd .. && ffmpeg -i out/video_raw.mp4 -vf "noise=c0s=2:allf=t" -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p -an out/video.mp4
python3 make_audio.py <M1.mp3> out/video.mp4 crystal-sky_W_v2.mp4
python3 make_audio.py <M2.mp3> out/video.mp4 crystal-sky_R_v2.mp4
```

## v2: 島の作り直し(2026-10-30)
指摘「空・雲は良いが、島が低ポリ感」に対して、島まわりだけを直した。空・雲・カメラ・cue の時刻・水晶・魔法陣・タイトル・音は v1 のまま(音は v1 とバイト単位で同じ)。
- 面: `flatShading` をやめ、頂点を共有する球から作って法線を滑らかにした(v1 は頂点が面ごとに別だったので、分割を増やしても角張って見えた)。
- 分割: 約 700 三角形/島 → 近景の島 13万〜18万(祭壇の島・C1b 手前・飛翔と引きの手前)、中景 3.4万〜8.4万、遠景のシルエット 4,500。
- 形: 大きな形は v1 と同じ式のまま、地層の段(1.7u ごと)・縦の崖のすじ(リッジ)・割れ目・細かい凹凸・底の垂れ下がる岩を頂点と色に足した。上面は草の濃淡・土・岩の出っ張り・草のふち、側面の上は苔と土、縁から垂れる草。島の底から根(先が細くなる管)が垂れる。
- 木: 円すい1個 → 幹+丸い葉の房6つ(下が濃く上が明るい、1本ずつ色を少し変える)。高さは島の上面に合わせた。上面に草むらと小岩を足した。浮かぶ岩も滑らかな形に。
- シェーダー: 島・木・岩に微細なノイズで法線と色を揺らす処理(画素より細かくなる遠景では自動で弱める)。
- 祭壇の真下(半径 0.76R の内側)は v1 と同じ高さにして、魔法陣の見え方を変えないようにした。乱数の並びも v1 と同じにして、木や岩・雲の配置を保った。
- 書き出し: 600 コマ 59分50秒(v1 は 48分12秒、約 +24%)。

## 作る途中で踏んだこと
- t=10.8s(f324)だけ画面全体が真っ黒になった(どこかの画素の NaN/Inf が Bloom で全体に広がった)。`post.js` の最初のパスで NaN/Inf を 0 にして解消。書き出し済みの映像は、そのコマだけ直した版で差し替えた(全体は書き直していない)。
- GTAO は不透明な物の深度で計算され、半透明の雲を描いた後の色に掛かるので、霧や雲の奥の木が灰色の影として透けた → 距離で AO を弱める `aoFar` を足した。
- 書き出し: ソフトウェアGL・GTAO 入りで 600 コマ約 46 分(約 4.6 秒/コマ)。v2 は約 60 分(約 6 秒/コマ)。
