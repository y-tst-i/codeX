# HOP LOOP(`references/motion-lab.md` の見本)

ゼリーの塊が「HOP!」の文字の上を跳ねて1文字ずつ点け、宙返りで最初に戻る4秒ループ。1080×1080、60fps、240コマ。
映像は Canvas 2D の HTML 1枚、音は numpy の合成だけ(録音素材なし)。外部への通信なし。この環境(GPU なし)で作れる。

## 作り方
```bash
node render.mjs anim.html 240 60 out/frames        # 0〜239コマを PNG に(約20秒)
python3 sound.py                                    # out/mix.wav(継ぎ目なしのマスター)ほか、cues.json
ffmpeg -framerate 60 -i out/frames/%04d.png -i out/mix_single.wav -c:v libx264 -profile:v high \
  -pix_fmt yuv420p -crf 16 -c:a aac -b:a 192k -shortest -movflags +faststart out/hop-loop.mp4
python3 ../../tools/audio_measure.py out/hop-loop.mp4 --cues cues.json
python3 ../../tools/audio_measure.py out/mix.wav --cues cues.json --hits out/hits.wav --bed out/bed.wav
```
- `anim.html?t=2.5` で 2.5 秒のコマに止まる。そのまま開くと再生する。
- 3回通しの確認用: `-stream_loop 2` で絵を3回、音は `out/mix_x3.wav`。

## 指示書の型との対応
| 行 | この見本での値 |
|---|---|
| TIME | 4s × 60fps = 240コマ、120BPM(1拍30コマ)、着地は拍の上(30, 60, 90, 120)、大きな着地は 210 |
| MOTION | しゃがみ 8コマ(1.18×0.78)、離陸で 0.84×1.24、着地で 1.26×0.72 から減衰比 0.45・3.2Hz で戻る。文字は sin で始まる弾み(着地のコマで飛ばない) |
| CAMERA | 動きの中心 (480, 600) を 1.15 倍。再生ヘッドは一定速度で各着地の拍に文字の下を通る |
| CHECKS | renderAt(t) の純関数、seed 付き乱数、最後の12コマで揺れを0へ(継ぎ目で位置と速度が一致)、呼吸は1ループに2周期 |
| 書き出し | 1コマ内で4サンプル、後ろ向きの半コマシャッター。色の切り替えはコマ単位(サンプルごとに変えると混ざって濁る) |

## 測定値(最終)
- 全体 -14.2 LUFS、スマホの帯域 -16.0 LUFS、真のピーク -2.6 dBTP(WAV)/ -2.4 dBTP(MP4)、直流 0。
- 各着地の頂点は「コマ+1」から +0.2〜+0.5ms(ミックスでも、AAC にした MP4 でも同じ)。
- 打撃音は下地より 3.4〜5.7 dB 上(目安 3〜6)。
- リミッターの最大の削り量 1.7 dB(目安 1.5 を少し超える。1つ目の着地)。
- `review_checks.py`(3回通し): 合格9・注意2(静止 0.22 秒が2か所=着地の後の間、LRA 0.1 LU=4秒ループで起伏が測れない)。
- ループの継ぎ目: 239→0コマ目の差 0.047(隣り合うコマの差 0.04〜0.07 と同程度)。

## 直した記録(コンタクトシートと測定から)
映像 3回:
1. 着地のコマで主役が二重に見え、文字の色が茶色に濁った → シャッターを後ろ向きに、色の切り替えはコマ単位に、着地直前の伸びを半分に。
2. 全体が小さい → 1.15 倍に寄る。寄った結果、出発点の主役が左端で切れた → 中心を 480 に。
3. 文字の弾みが着地のコマで 16% 一気に飛ぶ → cos でなく sin で始める。

音 約10回(全部測定から。聴いていない):
1. 割れていた(+6.9 dBFS)→ 先読みのリミッターと全体の音量。
2. -14 LUFS にすると頂点が 21 dB 上で、リミッターが 10 dB 削る計算 → 下地(パッド・ベース)を厚くし、打撃音の尾を長く。
3. 打撃音が下地に埋もれた(-1〜-5 dB)→ 打撃音と下地の比を調整。
4. リミッターが 5 dB 削る:木の音とマリンバの頂点が同じサンプルに重なる → マリンバを sine の位相に。大きな着地の 70Hz を短く。
5. 頂点を上げずに頭60msの量を足す → 帯域を絞ったノイズの「埃」を着地に重ねる。
6. 大きな着地が下地と同じ大きさ(ベースの頭がぶつかる)→ 大きな着地の間だけ下地を 6dB 下げる。
7. ミックスでは最大の山が 5〜11ms 後ろ(木の音の2周期目とマリンバが重なる)→ 木の音の頭を 3.5ms で 65% まで落とす。
8. 1つ目の着地だけ埋もれる → 着地の拍のベースを弱く、全着地で下地を 2.5dB 下げる。

最後の判断は人の耳で。
