# TikTok Motion Studio

TikTok用の縦型モーショングラフィックス動画を、**企画 → 台本 → 日本語ナレーション → 映像 → MP4書き出し** まで一気通貫で作る、自分のPCで動かすツールです。

- **看板キャラクター**：アカウントの顔になるキャラを登録。**パーツで組み立てる**（頭・体・耳・腕・目・口の透過PNGと関節位置の rig.json をZIPで読み込み、口パク・まばたき・耳ピク・首かしげ・腕のポーズ・バウンスを自動で動かす）、**画像で作る**（画像生成AIで作った口違い・表情違いの画像を登録し、ナレーションの音量で切り替えて口パク。白背景は自動で透明化。複数画像やZIPをドラッグ＆ドロップでまとめて登録でき、ファイル名から表情・口を自動で振り分け。ポーズが並んだキャラクターシートも背景を消して1体ずつ切り出せる）か、**コードで描く**（Canvasの描画コード。腕のポーズも動く）を選べる。動画のClaudeには、シーンごとに位置・大きさ・表情を変える演出を指示
- **ネタ帳**：ジャンルに合ったネタをClaudeが15本ずつ提案。使ったネタは次から出ないので、毎日ネタに困らない
- **台本**：勝ちパターン（フック→本題→意外な展開→呼びかけ→ループ）で、Claudeが台本を作る
- **音声**：Gemini TTSで日本語ナレーションをシーンごとに生成し、**実際の音声の長さ**でタイムラインを確定
- **映像**：そのタイムライン・スタイル・配色・フォント・TikTokのセーフエリア・書き出し用の技術仕様を全部詰め込んだ「プロ仕様のプロンプト」を自動で組み立て、Claudeが1つのHTML（Canvasアニメーション）として実装
- **演出の道具箱（window.MGK）**：動画HTMLに自動で入る演出部品。動く背景9種・カメラ（手持ち揺れ・ズームパンチ・シェイク）・転換7種・1文字ずつ動く文字・立体文字/3Dカード・カラオケ字幕・吹き出し・パーティクル・光漏れ/ビネット/グレイン・背景画像のケンバーンズ・Lottie再生
- **素材**：背景イラスト・小物（透過PNG）・Lottieアニメを登録して動画で使える。ChatGPTに素材をまとめて作ってもらう依頼文を自動作成
- **効果音・BGM**：10種類の効果音をその場で合成（著作権フリー）して映像の動きに合わせて入れる。BGMは声の間だけ自動で音量を下げる
- **母音の口パク**：VOICEVOX / AivisSpeech の声なら、あ・い・う・え・お に合わせて口の形が変わる
- **表紙**：好きなコマに大きなタイトルを重ねたカバー画像を書き出し
- **検証**：生成されたHTMLが書き出せるか（決定性・サイズ・エラー・描画速度・画が止まっている時間）を自動チェック。ダメなら修正プロンプト
- **批評→磨き込み**：完成した画を0.5秒ごとに並べたコンタクトシートを「別のClaude」に見せて辛口に批評してもらい、その指摘で磨き込む
- **書き出し**：1フレームずつ描いてエンコードするので、重い演出でもコマ落ちなし。1080×1920・30fps・H.264＋AAC のMP4。モーションブラー付き
- **育て方**：アカウント設計・投稿・分析・30日ロードマップのガイド付き（[docs/TikTok育成プレイブック.md](docs/TikTok育成プレイブック.md)）

## 使い始める

必要なもの：Node.js 22以上、Chrome または Edge

```powershell
cd tiktok-studio
npm ci
npm run dev
```

ブラウザで http://localhost:5180 が開きます。

**2回目からは、`tiktok-studio` フォルダの中の `起動.bat` をダブルクリックするだけ**で起動します（初回の `npm ci` も自動）。右クリック →「ショートカットの作成」でデスクトップに置いておくと便利です。黒い窓はアプリを使っている間は開いたままにし、閉じると終了します。

**最新版にするときは `更新.bat` をダブルクリック**するだけです（自動でダウンロードして上書きします。設定・APIキー・ネタ帳・音声はブラウザに保存されているので消えません）。アプリを起動したままでも大丈夫で、終わったらブラウザでF5を押してください。

### APIキー（なくても使えます）

| キー | 用途 | 入手先 |
|---|---|---|
| Anthropic APIキー | 台本・映像をボタン1つで生成 | https://console.anthropic.com |
| Gemini APIキー | 日本語ナレーション | https://aistudio.google.com |

- キーがなくても、各プロンプトを「コピー」して claude.ai に貼り、返ってきたJSON / HTMLを貼り戻せば全部の機能が使えます
- キーはこのPCのブラウザ（localStorage）にだけ保存され、各社のAPIに直接送られます。**このツールを公開サーバーに置かないでください**

## 無料で声を作る（VOICEVOX / AivisSpeech）

③音声で「VOICEVOX」か「AivisSpeech」を選ぶと、自分のPCで動く無料の音声合成ソフトで読み上げます（回数無制限）。
アプリ（公式サイトから無料）を起動したままにして、このツールを `起動.bat` で開いてください（ツールが中継してつなぎます）。
声ごとの利用規約に従い、投稿の説明文にクレジット（例「VOICEVOX:ずんだもん」）を入れてください。

## 別のPCで使う

1. 別のPCにも Node.js を入れて、このフォルダ（tiktok-studio）を置き、`起動.bat` で起動する（最新版は `更新.bat`）。
2. 元のPCで「設定」→「📦 別のPCに引っ越す」→「バックアップを保存」。設定・プロジェクト・ネタ帳・音声・看板キャラが1つのZIPになる（APIキーは含めないのが標準）。
3. 別のPCで「設定」→「バックアップを読み込む」でそのZIPを選ぶ。
4. 書き出した動画（MP4）は普通のファイルなので、Googleドライブなどで移す。

## 作り方の流れ

1. **① 企画**：ジャンル・ターゲット・テーマ・尺・フックの型・映像スタイル・配色・フォントを選ぶ
2. **② 台本**：Claudeで作る →シーンごとにセリフ・画面の大きな文字・強調語を手直し。読み間違いしそうな語は「読み上げ用」にひらがなで
3. **③ 音声**：声と演技指示を決めて全シーン生成（1シーン目だけ作って聴き比べるのがおすすめ）
4. **④ モーション**：「Claudeで映像を生成」→ 自動チェック →「磨き込み」で好きなだけ改善。「デモHTMLで試す」でサンプルも見られます
5. **⑤ 書き出し**：プレビュー（セーフエリア表示つき）で確認して MP4 を書き出し → 投稿キット（投稿文・タグ・カバー文字）をコピーしてTikTokへ

> 音声を作り直したら、タイミングが変わるので④の映像も作り直してください（チェックで尺のズレを警告します）。

## 生成されるHTMLの約束（技術仕様）

Claudeへのプロンプトで次を約束させ、ツール側で検証しています。

```js
window.MG = {
  width: 1080, height: 1920, fps: 30,
  duration,        // 秒
  ready,           // フォント等の準備が終わるPromise
  render(t) {}     // 時刻tの1フレームを <canvas id="stage"> に描く純粋関数
};
```

`render(t)` が「同じtなら必ず同じ絵」なので、プレビューは音声の再生位置に完全同期し、書き出しは1フレームずつ正確に行えます。単体でブラウザで開くとループ再生されます（`window.__MG_HOST__` が無いとき）。

## 開発

```powershell
npm test          # ユニットテスト
npm run typecheck
npm run build
```

| ファイル | 役割 |
|---|---|
| `src/lib/knowledge.ts` | フックの型・映像スタイル・配色・フォント・声など「ノウハウ」のデータ |
| `src/lib/prompts.ts` | 台本／映像／修正／磨き込みプロンプトの組み立て |
| `src/lib/timeline.ts` | 音声の実測長からシーン・字幕のタイミングを計算 |
| `src/lib/geminiTts.ts` | Gemini TTS呼び出し（再試行つき） |
| `src/lib/claude.ts` | Claude API呼び出し（ストリーミング） |
| `src/lib/mg.ts` | 生成HTMLの読み込み・検証 |
| `src/lib/exporter.ts` | WebCodecs（mediabunny）でMP4書き出し |

新しいフックの型やスタイルを足したいときは `knowledge.ts` に追記するだけで、UIとプロンプトの両方に反映されます。
