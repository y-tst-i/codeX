# TikTokアカウント育成プレイブック

ノウハウゼロから「再生される・伸びる」アカウントを作るための実践ガイドです。このスタジオの各機能は、このガイドの考え方に沿って作られています。

> 大前提：TikTokは「フォロワー数」より「1本ごとの見られ方」で配信が決まります。フォロワー0人でも、最後まで見られ・繰り返し見られ・保存やシェアされる動画は、どんどん多くの人に配られます。

## 1. 最初に決める3つのこと（アカウント設計）

### ① ジャンルは1つに絞る
- 「この人は◯◯の動画を出す人」と一瞬で分かるのが最強です。雑学もお金も歴史も…と混ぜると、TikTokが「誰に届ければいいか」を学習できません
- 迷ったら、モーショングラフィックス＋ナレーションと相性の良い **解説・雑学系** がおすすめ（顔出し不要・量産しやすい・保存されやすい）
- 例：お金の雑学／1分でわかる歴史の裏話／心理学／日本語の語源／宇宙のスケール比較

### ② 「毎回同じ」を作る（シリーズ化）
- **同じ声**（③音声で選んだボイスを固定）、**同じ色とフォント**（①企画のパレット・フォントを固定）、**同じ冒頭の型**
- 見た瞬間に「あのアカウントだ」と分かると、2本目以降も見てもらえ、フォローにつながります
- シリーズ名をつける：「知らないと損するお金の話 #12」のように番号をつけると、過去の動画も見てもらえます

### ③ プロフィールで約束する
- アカウント名：ジャンルが分かる名前（例：「1分お金図解」）
- 自己紹介：「毎日◯時に、◯◯を1分で解説」— **誰が得をするか** を書く
- アイコン：動画と同じ色・フォントで作ると統一感が出ます

## 2. 伸びる動画の設計図

TikTokが見ている主な指標は、**視聴維持率（最後まで見られたか）・リピート再生・シェア・保存・コメント・フォロー** です。このスタジオの台本とモーションは、これを最大化するように作られています。

### 最初の1秒（フック）がすべて
- 挨拶・自己紹介・「今回は」は **禁止**。1文目で結論の手前まで言い切る
- 画面は **0フレーム目から完成していて動いている**（黒からのフェードインは離脱の原因）
- 音を消して見ている人も多いので、**画面の大きな文字だけで意味が伝わる** ように
- 使えるフックの型：衝撃の数字／知らないと損／常識の否定／答えたくなる問い／ランキング逆順／ストップ呼びかけ／物語の途中から／二択比較

### 中盤は「2〜3秒ごとに新しい何か」
- 情報・画面の構図・色・カメラのどれかを2〜3秒ごとに変える（パターンインタラプト）
- 「でも実は」の意外な展開（twist）を後半に置き、答えは最後まで引っ張る

### 最後は「ループ」させる
- 最後のセリフが最初の1文に自然につながると、2周目に入る人が増え、リピート再生が稼げます
- 映像も最後の0.5秒で最初の構図に戻す（このスタジオのプロンプトに組み込み済み）

### 尺の目安
- 最初は **20〜35秒**。短いほど完走率を取りやすい
- 慣れて視聴維持率が安定してきたら、45〜60秒の「保存したくなる濃い解説」も試す

## 3. 投稿のしかた

### 頻度とペース
- 最初の30日は **1日1本以上** を目標に。本数が多いほど「当たり」を引く確率と、学習のスピードが上がります
- このスタジオの流れ（企画→台本→音声→モーション→書き出し）に慣れると、1本20〜40分で作れるようになります
- まとめて3〜5本作り溜めして、毎日同じ時間帯に投稿するのが続けるコツ

### 投稿時にやること
- **AI生成コンテンツのラベルをオンにする**：AI音声・AI生成映像を使った動画はラベル表示が求められます。付けておけば安心です
- **楽曲**：TikTokの編集画面で、トレンドの楽曲を **音量小さめ（5〜15%）** で重ねる。ナレーションが主役
- **カバー**：台本の「カバーテキスト」を入れる。プロフィールに並んだとき、シリーズ感が出るように統一
- **投稿文**：検索されるキーワードを自然に入れる（TikTokは検索エンジンとしても使われています）＋コメントしたくなる問いかけ
- **ハッシュタグ**：ジャンルを表す具体的なタグを3〜5個。`#fyp` のような汎用タグの効果は薄いです
- 投稿後1時間はコメントに返信（返信動画にするのも◎）

## 4. 数字の見方と改善サイクル

TikTokの「アナリティクス（TikTok Studio）」で、動画ごとに次を見ます。

1. **平均視聴時間と視聴維持率のグラフ**：どの秒で人が離れているか。最初の2秒で大きく落ちているならフックを改善
2. **最後まで視聴した割合**：完走率。尺を短くする・中盤のテンポを上げる
3. **トラフィックソース**：「おすすめ」からの流入が多いほど、TikTokに評価されています
4. **保存数・シェア数**：多い動画のテーマは「当たりネタ」。同じテーマを切り口を変えて何本も作る

### 1週間ごとの振り返り
- 伸びた上位2本：何が良かった？（フックの型・テーマ・尺）→ 同じ型で次の週に3本作る
- 伸びなかった下位2本：最初の2秒の離脱率を見る → フックの型を変えて同じテーマで作り直す（別の動画として再投稿）
- 「ネタ帳」を作り、伸びた動画のコメントから次のネタを拾う

## 5. やってはいけないこと

- **他人の動画・画像・キャラクター・有名人の声の無断利用**（著作権・肖像権・パブリシティ権）
- **不確かな情報の断定**：雑学系は信頼が命。数字は台本生成の前に「参考情報」欄へ出典のある事実を入れる
- **同じ動画の再投稿の繰り返し**：重複コンテンツは評価が下がります。作り直すならフックや構成を変える
- **フォロー・いいねを買う**：配信の学習が狂い、逆に伸びなくなります
- **医療・投資の断定的なアドバイス**：「必ず儲かる」「これで治る」などはガイドライン違反になりやすい

## 6. 30日ロードマップ

1. **1日目**：ジャンル・アカウント名・プロフィールを決める。スタジオで声・色・フォント・スタイルを決めて固定
2. **2〜7日目**：毎日1本。フックの型を毎回変えて、どれが自分のジャンルに合うか試す
3. **8〜14日目**：再生数が良かったフックの型に寄せる。シリーズ名と番号を付け始める
4. **15〜21日目**：保存・シェアが多かったテーマを深掘り。2本/日に挑戦
5. **22〜30日目**：伸びた動画の「パート2」を作る。コメントへの返信動画も投稿
6. **30日後**：上位10本の共通点を書き出し、アカウントの「勝ちパターン」を言語化する

> 最初の10〜20本は、伸びなくて当たり前です。1本ごとに「フックの型」「尺」「テーマ」のどれか1つだけを変えて、数字で比べていけば、必ず自分のジャンルの勝ちパターンが見えてきます。
