# 依頼：アニメーション用パーツ素材 v2（全部入り）

前回作ってもらったパーツ素材（rig_parts.zip）を、動画でもっと豊かに動かせるように拡張してください。
前回と同じく「基準画像をコードで切り分け、隠れていた部分だけ画像生成で補う」方式で進めてください。Python（PIL / NumPy / OpenCV など）で画像を編集・切り分けることを明示的に許可します。

## 変更点のまとめ
1. 解像度を2倍にする（2048×3072）。顔のアップでもぼやけないようにするため
2. 脚を体から分ける（歩く・ジャンプのため）
3. 黒目を別パーツにする（視線を動かすため）
4. 腕のポーズを増やす（考える・スマホ・ハート・腰に手・左手で手を振る）
5. 漫符（気持ちを表す記号）を追加する（照れ・ハート目・汗・キラキラ・涙・怒り・はてな）

## 大原則（前回と同じ。厳守）
- 基準画像は固定し、描き直さない。パーツの見えている部分は、基準画像からコードで切り出す。
- 画像生成は「隠れていた部分を埋める」「新しいポーズや表情を作る」「高精細化する」ときだけ使う。生成結果はマスクの内側だけを採用し、コードで位置合わせしてから合成する。
- 全パーツは 2048×3072 の透過PNG。基準画像と同じ座標に置く（切り抜いて中央に寄せない、トリミングしない）。
- 重ねると1体のキャラにぴったり戻ること。
- 左右は「画像を見たときの左右」（画面の左＝_L、右＝_R）。
- のりしろ（ほかのパーツの下に隠れる部分）は、2倍解像度なので 40〜80px にする。前回は肩と耳の付け根で少し切れ目が見えたので、前回より多めにする。

## 手順1：2倍の基準画像を作る
📄 base_full.png（2048×3072 に作り直す）
1. 前回の base_full.png を、Python で2倍に拡大する（Lanczos）。これを座標の基準にする。
2. 顔・目・口・耳・手を優先して、部位ごとに画像生成で高精細化する（同じ構図・同じ形のまま、細部だけをくっきり描き直す）。
3. 描き直した部分は、OpenCV の ECC などで、2倍拡大した画像に位置合わせしてから合成する。継ぎ目はぼかして（フェザーで）なじませる。
4. 描き直しで形が変わってしまう部位は、無理をせず、2倍拡大のままにする。
5. 確認用に、前回の base_full.png を2倍にしたものと並べた check_upscale.png を見せる。
※ どうしても2倍化がうまくいかない場合は、1024×1536 のまま手順2以降を進めてもよい（その場合は rig.json の canvas を 1024×1536 にする）。

## 手順8：rig.json（v2）
座標は、すべて 2048×3072 のキャンバス上のピクセル。
```json
{
  "version": 2,
  "canvas": { "width": 2048, "height": 3072 },
  "pivots": {
    "body":   [x, y],
    "head":   [x, y],
    "ear_L":  [x, y],
    "ear_R":  [x, y],
    "arm_L":  [x, y],
    "arm_R":  [x, y],
    "leg_L":  [x, y],
    "leg_R":  [x, y],
    "arms_heart": [x, y]
  },
  "anchors": {
    "eyes":    [x, y],
    "mouth":   [x, y],
    "pupil_L": [x, y],
    "pupil_R": [x, y]
  },
  "pupil_range": [rx, ry],
  "parts": ["実際に作ったファイル名の一覧"]
}
```
- body：両足の間の地面（全体の中心）
- head：首の付け根
- ear_L / ear_R：耳の付け根
- arm_L / arm_R：肩の関節
- leg_L / leg_R：股関節（短パンの中）
- arms_heart：ハートの手の中心
- pupil_L / pupil_R：黒目の中心（まっすぐ前を見ているとき）
- pupil_range：黒目が白目からはみ出さずに動ける最大の距離（横 rx、縦 ry。ピクセル）
